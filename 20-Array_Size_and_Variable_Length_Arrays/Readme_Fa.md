# 20- محاسبه اندازه آرایه و آرایه‌های با طول متغیر در زبان C

## معرفی پروژه

در این پروژه با نحوه تعریف آرایه‌ای آشنا می‌شویم که اندازه آن بر اساس ورودی کاربر تعیین می‌شود. همچنین یاد می‌گیریم چگونه با استفاده از عملگر `sizeof()` تعداد عناصر یک آرایه را محاسبه کنیم.

برنامه ابتدا یک عدد صحیح به نام `N` از کاربر دریافت می‌کند. سپس آرایه‌ای با `2 * N` عنصر تعریف کرده و تعداد عناصر آن را با استفاده از `sizeof()` محاسبه می‌کند.

مفاهیم اصلی این پروژه:

- دریافت ورودی از کاربر با `scanf()`
- تعریف آرایه در زبان C
- آرایه‌های با طول متغیر (VLA)
- عملگر `sizeof()`
- محاسبه تعداد عناصر آرایه
- تفاوت تعداد عناصر و فضای حافظه آرایه

---

## کد برنامه

```c
#include <stdio.h>

int main()
{
    int N;

    printf("Please enter the array size (N): ");
    scanf("%d", &N);
    printf("\n");

    int a[2 * N];

    int L = sizeof(a) / sizeof(a[0]);

    printf("Size of array is: %d\n", L);

    return 0;
}
```

## ۱. بررسی بخش‌های مختلف برنامه

### ۱.۱ اضافه کردن کتابخانه ورودی و خروجی

```c
#include <stdio.h>
```

این دستور کتابخانه استاندارد ورودی و خروجی زبان C را به برنامه اضافه می‌کند.

در این برنامه از دو تابع زیر استفاده می‌کنیم:

- `printf()` برای نمایش پیام به کاربر.
- `scanf()` برای دریافت اطلاعات از کاربر.

### ۱.۲ تعریف متغیر اندازه آرایه

```c
int N;
```

در این قسمت یک متغیر صحیح با نام `N` تعریف می‌کنیم.

این متغیر قرار است مقدار واردشده توسط کاربر را ذخیره کند.

### ۱.۳ دریافت مقدار از کاربر

```c
printf("Please enter the array size (N): ");
scanf("%d", &N);
printf("\n");
```

ابتدا با استفاده از `printf()` از کاربر می‌خواهیم یک عدد صحیح وارد کند.

سپس تابع `scanf()` مقدار واردشده را دریافت می‌کند.

در این تابع:

- `%d` برای دریافت عدد صحیح استفاده می‌شود.
- `&N` آدرس حافظه متغیر `N` را مشخص می‌کند.

استفاده از `&` ضروری است؛ زیرا تابع `scanf()` باید بتواند مقدار دریافت‌شده را در آدرس متغیر ذخیره کند.

### ۱.۴ تعریف آرایه با طول متغیر

```c
int a[2 * N];
```

در این قسمت یک آرایه از نوع `int` با نام `a` تعریف می‌کنیم.

تعداد عناصر آرایه برابر است با:

\[
\text{Array Length} = 2 \times N
\]

برای مثال، اگر کاربر مقدار ۵ را وارد کند:

```text
N = 5
```

تعریف آرایه به شکل زیر خواهد بود:

```c
int a[10];
```

به این نوع آرایه، **Variable Length Array یا VLA** گفته می‌شود.

ویژگی این آرایه آن است که اندازه آن هنگام اجرای برنامه مشخص می‌شود، نه لزوماً هنگام کامپایل.

**نکته مهم:** آرایه‌های VLA در استاندارد C99 پشتیبانی می‌شوند. در استانداردهای C11 و C17 پشتیبانی از آن‌ها اختیاری است و ممکن است بعضی کامپایلرها از این قابلیت پشتیبانی نکنند.

همچنین اندازه آرایه باید معتبر و مثبت باشد. تعریف آرایه با اندازه صفر یا منفی معتبر نیست.

### ۱.۵ محاسبه تعداد عناصر آرایه با sizeof()

```c
int L = sizeof(a) / sizeof(a[0]);
```

این دستور یکی از روش‌های بسیار کاربردی برای محاسبه تعداد عناصر یک آرایه در زبان C است.

برای درک بهتر، باید دو قسمت آن را جداگانه بررسی کنیم.

**قسمت اول:**

```c
sizeof(a)
```

اندازه کل آرایه را بر حسب بایت محاسبه می‌کند.

**قسمت دوم:**

```c
sizeof(a[0])
```

اندازه یک عنصر از آرایه را بر حسب بایت محاسبه می‌کند.

از آنجایی که آرایه ما از نوع `int` است، عبارت `sizeof(a[0])` اندازه یک متغیر از نوع `int` را برمی‌گرداند.

با تقسیم اندازه کل آرایه بر اندازه یک عنصر، تعداد عناصر به دست می‌آید:

\[
L = \frac{\text{sizeof}(a)}{\text{sizeof}(a[0])}
\]

برای مثال فرض کنیم:

- مقدار `N` برابر ۵ باشد.
- تعداد عناصر آرایه برابر ۱۰ باشد.
- اندازه هر متغیر `int` برابر ۴ بایت باشد.

در این صورت:

\[
L = \frac{40}{4} = 10
\]

بنابراین تعداد عناصر آرایه برابر ۱۰ خواهد بود.

**نکته:** اندازه `int` در تمام سیستم‌ها الزاماً ۴ بایت نیست. عملگر `sizeof()` اندازه واقعی را بر اساس سیستم و کامپایلر مشخص می‌کند.

### ۱.۶ نمایش نتیجه

```c
printf("Size of array is: %d\n", L);
```

در این قسمت تعداد عناصر آرایه نمایش داده می‌شود.

برای مثال:

```text
Size of array is: 10
```

توجه داشته باشید که پیام `Size of array` ممکن است کمی گمراه‌کننده باشد؛ زیرا مقدار `L` تعداد عناصر را نشان می‌دهد، نه اندازه حافظه بر حسب بایت.

پیام دقیق‌تر می‌تواند به شکل زیر باشد:

```c
printf("Number of elements in array: %d\n", L);
```

## ۳. مفاهیم مهم

### ۳.۱ تفاوت تعداد عناصر آرایه و اندازه حافظه آن

این دو مفهوم با یکدیگر متفاوت هستند.

| عبارت | مفهوم |
|---|---|
| `sizeof(a)` | اندازه کل آرایه بر حسب بایت |
| `sizeof(a[0])` | اندازه یک عنصر آرایه بر حسب بایت |
| `sizeof(a) / sizeof(a[0])` | تعداد عناصر آرایه |

برای مثال، اگر آرایه شامل ۱۰ عدد صحیح باشد و اندازه هر `int` برابر ۴ بایت باشد:

| مشخصه | مقدار |
|---|---:|
| تعداد عناصر | ۱۰ |
| اندازه هر عنصر | ۴ بایت |
| حافظه کل آرایه | ۴۰ بایت |

### ۳.۲ چرا از sizeof() استفاده می‌کنیم؟

به جای اینکه تعداد عناصر را به‌صورت ثابت وارد کنیم:

```c
int L = 10;
```

می‌توانیم از روش زیر استفاده کنیم:

```c
int L = sizeof(a) / sizeof(a[0]);
```

مزیت این روش آن است که اگر اندازه آرایه تغییر کند، تعداد عناصر نیز به‌صورت خودکار محاسبه می‌شود.

این کار باعث می‌شود برنامه انعطاف‌پذیرتر و قابل نگهداری‌تر باشد.

### ۳.۳ محدودیت sizeof() هنگام ارسال آرایه به تابع

روش محاسبه تعداد عناصر با `sizeof()` زمانی درست کار می‌کند که آرایه واقعی در همان محدوده تعریف شده باشد.

اما هنگام ارسال آرایه به یک تابع، پارامتر آرایه در زبان C به اشاره‌گر تبدیل می‌شود.

برای مثال:

```c
void PrintArray(int a[])
{
    printf("%zu\n", sizeof(a));
}
```

در این مثال، عبارت `sizeof(a)` اندازه اشاره‌گر را برمی‌گرداند، نه اندازه کل آرایه اصلی را.

به همین دلیل هنگام ارسال آرایه به تابع، بهتر است تعداد عناصر را نیز به‌صورت یک پارامتر جداگانه ارسال کنیم:

```c
void PrintArray(int a[], int N);
```

## ۴. نسخه بهبودیافته و ایمن‌تر برنامه

کد اولیه برای یادگیری آرایه‌های VLA و عملگر `sizeof()` مناسب است؛ اما یک مشکل مهم دارد: ورودی کاربر را بررسی نمی‌کند.

برای مثال، اگر کاربر عدد صفر یا یک عدد منفی وارد کند، تعریف آرایه معتبر نخواهد بود.

همچنین ممکن است کاربر به‌جای عدد، یک مقدار متنی وارد کند و تابع `scanf()` نتواند ورودی را دریافت کند.

نسخه بهبودیافته:

```c
#include <stdio.h>

int main(void)
{
    int N;

    printf("Please enter the array size (N): ");

    if (scanf("%d", &N) != 1)
    {
        printf("Invalid input!\n");
        return 1;
    }

    if (N <= 0)
    {
        printf("Array size must be positive!\n");
        return 1;
    }

    int a[2 * N];

    size_t L = sizeof(a) / sizeof(a[0]);

    printf("\nNumber of elements in array: %zu\n", L);
    printf("Total memory used by array: %zu bytes\n", sizeof(a));
    printf("Memory used by one element: %zu bytes\n", sizeof(a[0]));

    return 0;
}
```

### تغییرات نسخه جدید

۱. مقدار بازگشتی `scanf()` بررسی می‌شود تا از دریافت صحیح ورودی اطمینان حاصل کنیم.

۲. ورودی صفر و اعداد منفی پذیرفته نمی‌شوند.

۳. برای ذخیره نتیجه `sizeof()` از نوع `size_t` استفاده شده است.

۴. برای نمایش مقدار `size_t` از قالب `%zu` استفاده می‌کنیم.

۵. علاوه بر تعداد عناصر، اندازه کل حافظه آرایه و اندازه یک عنصر نیز نمایش داده می‌شود.

**نکته تکمیلی:** این نسخه برای آموزش مناسب است، اما در برنامه‌های واقعی باید حداکثر مقدار مجاز `N` نیز بررسی شود تا از تخصیص بیش از حد حافظه روی Stack و سرریز محاسبه `2 * N` جلوگیری شود. برای آرایه‌های بزرگ معمولاً استفاده از `malloc()` گزینه مناسب‌تری است.

## ۵. کامپایل و اجرای برنامه

### کامپایل با GCC

برای کامپایل برنامه از دستور زیر استفاده کنید:

```bash
gcc main.c -o array_size
```

اجرای برنامه در Linux:

```bash
./array_size
```

اجرای برنامه در Windows:

```powershell
.\array_size.exe
```

برای کامپایل با استاندارد C99 و فعال‌کردن هشدارها:

```bash
gcc -std=c99 -Wall -Wextra -pedantic main.c -o array_size
```

توجه داشته باشید که پشتیبانی از VLA به کامپایلر و استاندارد انتخاب‌شده بستگی دارد.

## ۶. پیچیدگی زمانی و حافظه

این برنامه تعداد محدودی عملیات انجام می‌دهد.

| مشخصه | پیچیدگی |
|---|---|
| پیچیدگی زمانی | O(1) |
| پیچیدگی حافظه | O(N) |

- **پیچیدگی زمانی:** محاسبه تعداد عناصر با `sizeof()` در زمان ثابت انجام می‌شود.
- **پیچیدگی حافظه:** آرایه شامل `2 * N` عنصر است؛ بنابراین حافظه موردنیاز با افزایش `N` به‌صورت خطی افزایش پیدا می‌کند.

## ۷. تمرین‌های پیشنهادی

برای یادگیری بهتر، تمرین‌های زیر را انجام دهید:

۱. تعریف آرایه را به `int a[N];` تغییر دهید و تعداد عناصر آن را محاسبه کنید.

۲. اندازه کل حافظه آرایه را بر حسب بایت نمایش دهید.

۳. اندازه یک متغیر صحیح را با `sizeof(int)` نمایش دهید.

۴. یک آرایه از نوع `float` تعریف کنید و تعداد عناصر آن را محاسبه کنید.

۵. از کاربر دو عدد دریافت کنید و آرایه‌ای با `N * M` عنصر بسازید.

۶. خروجی عبارت‌های `sizeof(a)` و `sizeof(a[0])` را با یکدیگر مقایسه کنید.

۷. برنامه را به‌جای VLA با استفاده از تابع `malloc()` پیاده‌سازی کنید.

## ۸. اهداف آموزشی

پس از انجام این پروژه باید بتوانید:

- اندازه آرایه را از کاربر دریافت کنید.
- آرایه با طول متغیر (VLA) تعریف کنید.
- با عملگر `sizeof()` کار کنید.
- تعداد عناصر آرایه را محاسبه کنید.
- تفاوت تعداد عناصر و اندازه حافظه آرایه را درک کنید.
- از `size_t` و قالب `%zu` برای کار با اندازه حافظه استفاده کنید.
- ورودی کاربر و اندازه آرایه را اعتبارسنجی کنید.
