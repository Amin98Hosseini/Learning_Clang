# 6 - عملگرهای افزایش پیشوندی و پسوندی در زبان C (Pre-Increment & Post-Increment)

## معرفی پروژه (Overview)

این پروژه با هدف آموزش تفاوت دو عملگر افزایش در زبان برنامه‌نویسی C طراحی شده است:

- **افزایش پیشوندی (Pre-Increment):** عملگر `++a`
- **افزایش پسوندی (Post-Increment):** عملگر `a++`

هر دو عملگر مقدار متغیر را یک واحد افزایش می‌دهند؛ اما تفاوت اصلی آن‌ها در زمان افزایش متغیر و نحوه استفاده از مقدار آن در یک عبارت است.

در این برنامه، دو متغیر با مقدار اولیه ۱۰ تعریف شده‌اند تا عملکرد این دو عملگر در یک دستور انتساب (Assignment) با یکدیگر مقایسه شود.

## اهداف آموزشی (Learning Objectives)

با مطالعه این برنامه، مفاهیم زیر را یاد می‌گیرید:

- آشنایی با عملگر افزایش (Increment Operator).
- شناخت تفاوت Pre-Increment و Post-Increment.
- نحوه استفاده از عملگرهای افزایش در دستورات انتساب.
- آشنایی با ترتیب ارزیابی عبارت‌ها.
- بررسی تأثیر عملگرهای افزایش بر مقدار متغیرها.
- نمایش چند متغیر با استفاده از تابع `printf()`.

## بررسی و توضیح کد (Source Code Explanation)

### 1. فراخوانی کتابخانه

```c
#include <stdio.h>
```

کتابخانه استاندارد ورودی و خروجی زبان C را فراخوانی می‌کند.

این کتابخانه شامل توابعی مانند `printf()` برای نمایش اطلاعات در خروجی است.

### 2. تعریف و مقداردهی اولیه متغیرها

```c
int a1 = 10;
int a2 = 10;
int b1, b2;
```

در این قسمت چهار متغیر از نوع صحیح (`int`) تعریف شده‌اند.

| متغیر | مقدار اولیه | توضیحات |
|---|---:|---|
| `a1` | 10 | برای بررسی افزایش پیشوندی |
| `a2` | 10 | برای بررسی افزایش پسوندی |
| `b1` | مقداردهی نشده | ذخیره نتیجه افزایش پیشوندی |
| `b2` | مقداردهی نشده | ذخیره نتیجه افزایش پسوندی |

### 3. عملگر افزایش پیشوندی (Pre-Increment)

```c
b1 = ++a1;
```

در این دستور از عملگر `++a1` استفاده شده است.

در افزایش پیشوندی، ابتدا مقدار متغیر یک واحد افزایش پیدا می‌کند و سپس مقدار جدید در عبارت مورد استفاده قرار می‌گیرد.

**مراحل اجرای دستور:**

1. مقدار اولیه `a1` برابر ۱۰ است.
2. عملگر `++` مقدار `a1` را یک واحد افزایش می‌دهد.
3. مقدار جدید `a1` برابر ۱۱ می‌شود.
4. مقدار جدید در متغیر `b1` ذخیره می‌شود.

نتیجه:

```text
a1 = 11
b1 = 11
```

**نکته:** در Pre-Increment ابتدا متغیر افزایش پیدا می‌کند و سپس مقدار جدید آن استفاده می‌شود.

### 4. عملگر افزایش پسوندی (Post-Increment)

```c
b2 = a2++;
```

در این دستور از عملگر `a2++` استفاده شده است.

در افزایش پسوندی، ابتدا مقدار فعلی متغیر در عبارت استفاده می‌شود و سپس مقدار متغیر یک واحد افزایش پیدا می‌کند.

**مراحل اجرای دستور:**

1. مقدار اولیه `a2` برابر ۱۰ است.
2. مقدار فعلی `a2` در متغیر `b2` ذخیره می‌شود.
3. مقدار `b2` برابر ۱۰ خواهد بود.
4. سپس مقدار `a2` یک واحد افزایش پیدا می‌کند.
5. مقدار نهایی `a2` برابر ۱۱ می‌شود.

نتیجه:

```text
a2 = 11
b2 = 10
```

**نکته:** در Post-Increment ابتدا مقدار فعلی متغیر استفاده می‌شود و سپس خود متغیر افزایش پیدا می‌کند.

### 5. نمایش نتایج برنامه

```c
printf("a1 = %d, b1 = %d\n\n", a1, b1);
printf("a2 = %d, b2 = %d\n", a2, b2);
```

در این قسمت با استفاده از تابع `printf()` مقادیر نهایی متغیرها نمایش داده می‌شوند.

- `%d` برای نمایش مقادیر صحیح استفاده می‌شود.
- `\n` باعث رفتن به خط بعدی می‌شود.

## خروجی برنامه (Example Output)

```text
a1 = 11, b1 = 11

a2 = 11, b2 = 10
```

## مقایسه Pre-Increment و Post-Increment

| ویژگی | Pre-Increment | Post-Increment |
|---|---|---|
| ساختار | `++a` | `a++` |
| زمان افزایش | قبل از استفاده از مقدار | بعد از استفاده از مقدار |
| مقدار مورد استفاده | مقدار جدید | مقدار قبلی |
| مثال | `b = ++a` | `b = a++` |
| مقدار اولیه `a` | 10 | 10 |
| مقدار نهایی `a` | 11 | 11 |
| مقدار نهایی `b` | 11 | 10 |

## نمایش مراحل اجرای دستورات (Execution Flow)

### افزایش پیشوندی (Pre-Increment)

```text
a = 10
   |
   v
افزایش مقدار a
   |
   v
a = 11
   |
   v
ذخیره مقدار در b
   |
   v
b = 11
```

### افزایش پسوندی (Post-Increment)

```text
a = 10
   |
   v
ذخیره مقدار فعلی در b
   |
   v
b = 10
   |
   v
افزایش مقدار a
   |
   v
a = 11
```

## مفاهیم مهم برنامه‌نویسی C

| مفهوم | توضیحات |
|---|---|
| `++a` | افزایش پیشوندی متغیر |
| `a++` | افزایش پسوندی متغیر |
| `int` | تعریف متغیر از نوع عدد صحیح |
| `=` | عملگر انتساب مقدار |
| `printf()` | نمایش اطلاعات در خروجی |
| `%d` | نمایش مقدار عدد صحیح |

## تمرین‌های پیشنهادی (Practice Exercises)

برای درک بهتر عملکرد عملگرهای افزایش و کاهش، تمرین‌های زیر را انجام دهید:

1. مقدار اولیه `a1` و `a2` را از ۱۰ به ۲۰ تغییر دهید.
2. به‌جای افزایش، از عملگر کاهش پیشوندی (`--a`) استفاده کنید.
3. عملگر کاهش پسوندی (`a--`) را آزمایش کنید.
4. دستور `b = ++a;` را با مقدار اولیه `a = 5` اجرا کنید.
5. دستور `b = a++;` را با مقدار اولیه `a = 5` اجرا کنید.
6. عملگرهای افزایش را داخل حلقه‌های `for` و `while` به کار ببرید.
7. نتایج اجرای `printf("%d", ++a);` و `printf("%d", a++);` را مقایسه کنید.

## نکات مهم (Important Notes)

- هر دو عملگر `++a` و `a++` مقدار متغیر را یک واحد افزایش می‌دهند.
- تفاوت آن‌ها در زمان استفاده از مقدار متغیر در یک عبارت است.
- اگر این عملگرها به‌صورت مستقل استفاده شوند، هر دو فقط متغیر را یک واحد افزایش می‌دهند.
- از تغییر چندباره یک متغیر در یک عبارت پیچیده خودداری کنید؛ زیرا ممکن است باعث رفتار تعریف‌نشده (Undefined Behavior) در زبان C شود.

## جمع‌بندی (Summary)

در این پروژه با دو عملگر مهم افزایش در زبان برنامه‌نویسی C آشنا شدیم:

- **Pre-Increment (`++a`):** ابتدا مقدار متغیر افزایش پیدا می‌کند و سپس مقدار جدید استفاده می‌شود.
- **Post-Increment (`a++`):** ابتدا مقدار فعلی متغیر استفاده می‌شود و سپس مقدار آن افزایش پیدا می‌کند.

درک صحیح این دو عملگر برای برنامه‌نویسی با حلقه‌ها، شمارنده‌ها، آرایه‌ها و عبارت‌های محاسباتی اهمیت زیادی دارد.

**مرحله بعدی یادگیری:** استفاده از عملگرهای افزایش و کاهش در حلقه‌های `for` و `while` و بررسی تأثیر آن‌ها بر تعداد تکرار حلقه.
