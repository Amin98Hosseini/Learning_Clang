# 35- آموزش زبان C – جستجوی کاراکتر و زیررشته با توابع `strchr()` و `strstr()`

## ۱. مقدمه

در زبان برنامه‌نویسی C، کتابخانه `<string.h>` توابع مختلفی برای جستجو و پردازش رشته‌ها در اختیار برنامه‌نویس قرار می‌دهد.

در بسیاری از برنامه‌ها لازم است یک کاراکتر مشخص را درون یک رشته پیدا کنیم. در موارد دیگر ممکن است بخواهیم یک کلمه یا بخشی از یک رشته را درون یک متن بزرگ‌تر جستجو کنیم.

در این آموزش دو تابع مهم برای جستجوی رشته‌ها را بررسی می‌کنیم:

- `strchr()` – پیدا کردن اولین رخداد یک کاراکتر مشخص در رشته.
- `strstr()` – پیدا کردن اولین رخداد یک زیررشته درون یک رشته دیگر.

همچنین یاد می‌گیریم چگونه با استفاده از اشاره‌گرها موقعیت کاراکترها و کلمات را پیدا کنیم، تعداد تکرار یک کاراکتر را بشماریم و چندین رخداد را جستجو کنیم.

## ۲. کتابخانه‌های موردنیاز

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
```

کاربرد هر کتابخانه:

| کتابخانه | کاربرد |
|---|---|
| `stdio.h` | برای توابع ورودی و خروجی مانند `printf()` و `puts()` |
| `stdlib.h` | برای توابع عمومی زبان C؛ در این مثال ضروری نیست. |
| `string.h` | برای توابع پردازش رشته مانند `strchr()` و `strstr()` |

در این برنامه فقط به دو کتابخانه `stdio.h` و `string.h` نیاز داریم.

## ۳. کد کامل برنامه

در نسخه زیر عملکرد برنامه اصلی حفظ شده است، اما چند بهبود نیز انجام داده‌ایم:

- برای اشاره‌گرهای مربوط به رشته‌های فقط خواندنی از `const char *` استفاده شده است.
- برای ذخیره موقعیت و تعداد تکرارها از `size_t` استفاده می‌کنیم.
- موقعیت‌ها به‌صورت اندیس صفرمبنا (Zero-Based Index) نمایش داده می‌شوند.
- تمام رخدادهای یک کاراکتر و اولین رخداد یک زیررشته جستجو می‌شوند.

```c
#include <stdio.h>
#include <string.h>

void FindCharacter(const char *str, char c);
void FindWord(const char *str, const char *w);

int main()
{
    char str[] = "To be, or not to be. That's the question.";

    FindCharacter(str, 'b');

    // FindCharacter(str, 'e');
    // FindCharacter(str, 'a');
    // FindCharacter(str, 'w');

    FindWord(str, "not");
    FindWord(str, "This");

    return 0;
}

void FindCharacter(const char *str, char c)
{
    printf("Finding all occurrences of character '%c' "
           "in the following string:\n", c);

    puts(str);
    printf("\n");

    const char *pc;
    size_t i, n = 0;

    pc = strchr(str, c);

    while (pc != NULL)
    {
        i = (size_t)(pc - str);

        printf("Found '%c' at index %zu\n", c, i);

        n++;

        pc = strchr(pc + 1, c);
    }

    printf("\n");

    if (n > 0)
    {
        printf("%zu occurrences of character '%c' found.\n", n, c);
    }
    else
    {
        printf("Nothing found.\n");
    }

    printf("---------------------------------------\n");
}

void FindWord(const char *str, const char *w)
{
    printf("Finding first occurrence of word '%s' "
           "in the following sentence:\n", w);

    puts(str);
    printf("\n");

    const char *pw = strstr(str, w);

    if (pw == NULL)
    {
        printf("Nothing found.\n");
    }
    else
    {
        size_t i = (size_t)(pw - str);

        printf("Found at index %zu.\n", i);
    }

    printf("\n---------------------------------------\n");
}
```

## ۴. بررسی قسمت‌های مختلف برنامه

### ۴.۱. اعلان توابع (Function Prototype)

```c
void FindCharacter(const char *str, char c);
void FindWord(const char *str, const char *w);
```

در این قسمت دو تابع را قبل از تابع `main()` معرفی می‌کنیم.

**تابع اول: `FindCharacter()`**

```c
void FindCharacter(const char *str, char c);
```

این تابع دو ورودی دریافت می‌کند:

- `str`: رشته‌ای که قرار است در آن جستجو انجام شود.
- `c`: کاراکتری که به دنبال آن هستیم.

این تابع تمام رخدادهای کاراکتر موردنظر را پیدا کرده و موقعیت آن‌ها را نمایش می‌دهد.

**تابع دوم: `FindWord()`**

```c
void FindWord(const char *str, const char *w);
```

این تابع نیز دو ورودی دریافت می‌کند:

- `str`: رشته اصلی
- `w`: زیررشته‌ای که قصد داریم آن را پیدا کنیم.

این تابع اولین رخداد زیررشته موردنظر را جستجو می‌کند.

نوع خروجی هر دو تابع `void` است؛ یعنی نتیجه را مستقیماً نمایش می‌دهند و مقداری را به محل فراخوانی برنمی‌گردانند.

### ۴.۲. مفهوم `const char *`

در پارامترهای توابع از عبارت زیر استفاده کرده‌ایم:

```c
const char *str
```

کلمه کلیدی `const` مشخص می‌کند که محتوای رشته از طریق این اشاره‌گر نباید تغییر کند.

برای مثال دستور زیر مجاز نیست:

```c
str[0] = 'A';
```

زیرا تابع فقط اجازه دارد محتوای رشته را بخواند و نباید آن را تغییر دهد.

البته خود اشاره‌گر می‌تواند تغییر کند. برای مثال:

```c
pc = strchr(pc + 1, c);
```

در این دستور، اشاره‌گر `pc` به موقعیت دیگری منتقل می‌شود، اما محتوای کاراکترهای رشته تغییر نمی‌کند.

### ۴.۳. تعریف رشته اصلی

```c
char str[] = "To be, or not to be. That's the question.";
```

در این قسمت یک آرایه از نوع `char` تعریف می‌کنیم که شامل جمله زیر است:

```text
To be, or not to be. That's the question.
```

کامپایلر به‌صورت خودکار کاراکتر `'\0'` را در انتهای رشته قرار می‌دهد.

نمایش ساده محتوای رشته در حافظه:

```text
T o   b e ,   o r   n o t   t o   b e .   T h a t ' s   t h e   q u e s t i o n . \0
```

کاراکتر Null Terminator مشخص می‌کند که رشته در کجا به پایان رسیده است.

### ۴.۴. فراخوانی توابع جستجو

```c
FindCharacter(str, 'b');

FindWord(str, "not");
FindWord(str, "This");
```

در این قسمت توابع جستجو را فراخوانی می‌کنیم.

دستور اول تمام رخدادهای کاراکتر `'b'` را در رشته پیدا می‌کند.

دستور دوم به دنبال زیررشته `"not"` می‌گردد.

دستور سوم نیز زیررشته `"This"` را جستجو می‌کند.

به تفاوت نحوه نوشتن کاراکتر و رشته توجه کنید:

- برای یک کاراکتر از کوتیشن تکی استفاده می‌کنیم: `'b'`
- برای یک رشته از کوتیشن دوتایی استفاده می‌کنیم: `"not"`

دستورات زیر نیز در برنامه وجود دارند:

```c
// FindCharacter(str, 'e');
// FindCharacter(str, 'a');
// FindCharacter(str, 'w');
```

این دستورات با استفاده از `//` به‌صورت کامنت نوشته شده‌اند و اجرا نمی‌شوند.

در صورت حذف علامت‌های کامنت می‌توانیم کاراکترهای دیگری را نیز جستجو کنیم.

## ۵. جستجوی کاراکتر با تابع `strchr()`

تابع `strchr()` برای پیدا کردن اولین رخداد یک کاراکتر مشخص درون یک رشته استفاده می‌شود.

این تابع در کتابخانه `<string.h>` تعریف شده است.

ساختار کلی:

```c
strchr(string, character);
```

مثال:

```c
char str[] = "Hello World!";

char *p = strchr(str, 'o');
```

تابع از ابتدای رشته شروع به جستجو می‌کند.

در رشته `"Hello World!"` اولین کاراکتر `'o'` در اندیس ۴ قرار دارد.

تابع یک اشاره‌گر به همان موقعیت برمی‌گرداند.

### ۵.۱. مقدار بازگشتی تابع

تابع `strchr()` دو حالت دارد:

- اگر کاراکتر موردنظر پیدا شود، آدرس محل اولین رخداد را برمی‌گرداند.
- اگر کاراکتر پیدا نشود، مقدار `NULL` را برمی‌گرداند.

مثال:

```c
char str[] = "Hello";

char *p1 = strchr(str, 'e');
char *p2 = strchr(str, 'x');
```

نتیجه:

```text
p1 -> اشاره به کاراکتر 'e'
p2 -> NULL
```

**نکته مهم:** تابع `strchr()` می‌تواند برای جستجوی کاراکتر Null Terminator نیز استفاده شود:

```c
strchr(str, '\0');
```

در این حالت، اشاره‌گری به کاراکتر پایان‌دهنده رشته برگردانده می‌شود.

## ۶. بررسی تابع `FindCharacter()`

اکنون قسمت‌های مختلف تابع را بررسی می‌کنیم.

### ۶.۱. نمایش اطلاعات جستجو

```c
printf("Finding all occurrences of character '%c' "
       "in the following string:\n", c);

puts(str);
printf("\n");
```

در این قسمت ابتدا کاراکتری که قرار است جستجو شود نمایش داده می‌شود.

فرمت `%c` برای چاپ یک کاراکتر استفاده می‌شود.

تابع `puts()` نیز رشته را چاپ می‌کند و به‌صورت خودکار یک خط جدید در انتهای خروجی قرار می‌دهد.

### ۶.۲. تعریف متغیرها

```c
const char *pc;
size_t i, n = 0;
```

در این قسمت سه متغیر تعریف می‌کنیم:

| متغیر | نوع داده | کاربرد |
|---|---|---|
| `pc` | `const char *` | اشاره‌گر به کاراکتر پیدا شده |
| `i` | `size_t` | ذخیره اندیس کاراکتر در رشته |
| `n` | `size_t` | شمارش تعداد رخدادهای کاراکتر |

چرا از `size_t` به‌جای `int` استفاده می‌کنیم؟

نوع داده `size_t` در زبان C برای نمایش اندازه اشیا و موقعیت‌های مرتبط با آرایه‌ها استفاده می‌شود.

برای نمایش متغیرهایی از این نوع در `printf()` باید از فرمت `%zu` استفاده کنیم.

### ۶.۳. پیدا کردن اولین رخداد

```c
pc = strchr(str, c);
```

این دستور به دنبال اولین رخداد کاراکتر `c` در رشته `str` می‌گردد.

برای فراخوانی زیر:

```c
FindCharacter(str, 'b');
```

عملیات جستجو به شکل زیر خواهد بود:

```c
pc = strchr(str, 'b');
```

اولین کاراکتر `'b'` در اندیس ۳ قرار دارد.

بنابراین `pc` به همان موقعیت در رشته اشاره می‌کند.

### ۶.۴. بررسی حلقه `while`

```c
while (pc != NULL)
{
    /* Search results */
}
```

حلقه تا زمانی اجرا می‌شود که مقدار `pc` برابر `NULL` نباشد.

یعنی کاراکتر موردنظر پیدا شده است.

اگر تابع `strchr()` نتواند رخداد دیگری پیدا کند، مقدار `NULL` را برمی‌گرداند و حلقه به پایان می‌رسد.

### ۶.۵. محاسبه موقعیت کاراکتر

```c
i = (size_t)(pc - str);
```

این دستور یکی از مهم‌ترین قسمت‌های برنامه است.

هر دو متغیر `pc` و `str` اشاره‌گرهایی هستند که به عناصر یک آرایه کاراکتری اشاره می‌کنند.

با تفریق دو اشاره‌گر، فاصله آن‌ها بر اساس تعداد عناصر آرایه محاسبه می‌شود.

برای مثال:

```text
اندیس:    0  1  2  3  4  5
رشته:     T  o     b  e  ,
                     ^
                     pc
```

در این حالت:

```c
pc - str
```

برابر با عدد زیر است:

```text
3
```

بنابراین کاراکتر در اندیس ۳ قرار دارد.

نتیجه برای ذخیره در متغیر `size_t` تبدیل نوع داده می‌شود.

**نکته مهم:** تفریق اشاره‌گرها در اینجا معتبر است؛ زیرا هر دو اشاره‌گر به عناصر یک آرایه مشترک اشاره می‌کنند. نتیجه بر اساس تعداد عناصر محاسبه می‌شود، نه تعداد بایت‌ها.

### ۶.۶. نمایش موقعیت کاراکتر

```c
printf("Found '%c' at index %zu\n", c, i);
```

در این قسمت کاراکتر پیدا شده و اندیس آن نمایش داده می‌شود.

برای مثال:

```text
Found 'b' at index 3
```

### ۶.۷. شمارش تعداد رخدادها

```c
n++;
```

هر بار که کاراکتر موردنظر پیدا می‌شود، مقدار متغیر `n` یک واحد افزایش پیدا می‌کند.

عملگر `++` برای افزایش مقدار یک متغیر به‌اندازه یک استفاده می‌شود.

### ۶.۸. پیدا کردن رخداد بعدی

```c
pc = strchr(pc + 1, c);
```

این دستور مهم‌ترین قسمت برای پیدا کردن چندین رخداد از یک کاراکتر است.

به‌جای اینکه جستجو را دوباره از ابتدای رشته شروع کنیم، از کاراکتر بعد از موقعیت فعلی جستجو را ادامه می‌دهیم.

اجزای دستور:

- `pc`: اشاره به کاراکتری دارد که قبلاً پیدا شده است.
- `pc + 1`: به کاراکتر بعدی اشاره می‌کند.
- `strchr(pc + 1, c)`: از موقعیت جدید به بعد به دنبال کاراکتر موردنظر می‌گردد.

برای مثال، فرض کنید می‌خواهیم کاراکتر `'b'` را در رشته زیر پیدا کنیم:

```text
To be, or not to be.
```

اولین رخداد در اندیس ۳ پیدا می‌شود.

جستجوی بعدی از اندیس ۴ شروع می‌شود؛ بنابراین همان رخداد قبلی دوباره پیدا نمی‌شود.

رخداد بعدی در اندیس ۱۶ قرار دارد.

پس از پیدا شدن تمام رخدادها، تابع `strchr()` مقدار `NULL` را برمی‌گرداند و حلقه متوقف می‌شود.

### ۶.۹. نمایش تعداد نهایی رخدادها

```c
if (n > 0)
{
    printf("%zu occurrences of character '%c' found.\n", n, c);
}
else
{
    printf("Nothing found.\n");
}
```

اگر مقدار `n` بزرگ‌تر از صفر باشد، یعنی حداقل یک رخداد پیدا شده است.

در غیر این صورت، کاراکتر موردنظر در رشته وجود ندارد.

## ۷. جستجوی زیررشته با تابع `strstr()`

تابع `strstr()` برای پیدا کردن اولین رخداد یک رشته درون رشته دیگر استفاده می‌شود.

این تابع نیز در کتابخانه `<string.h>` تعریف شده است.

ساختار کلی:

```c
strstr(main_string, substring);
```

مثال:

```c
char str[] = "Hello World!";

char *p = strstr(str, "World");
```

تابع به دنبال زیررشته `"World"` در رشته `"Hello World!"` می‌گردد.

اگر زیررشته پیدا شود، اشاره‌گری به اولین کاراکتر آن برگردانده می‌شود.

در صورت پیدا نشدن زیررشته، مقدار `NULL` برگردانده می‌شود.

### ۷.۱. مقدار بازگشتی تابع

مثال:

```c
char str[] = "Embedded Systems";

char *p1 = strstr(str, "Systems");
char *p2 = strstr(str, "Hardware");
```

نتیجه:

```text
p1 -> اشاره به ابتدای رشته "Systems"
p2 -> NULL
```

**نکته مهم:** اگر رشته جستجو یک رشته خالی (`""`) باشد، تابع `strstr()` اشاره‌گری به ابتدای رشته اصلی برمی‌گرداند.

## ۸. بررسی تابع `FindWord()`

اکنون تابع دوم برنامه را بررسی می‌کنیم.

### ۸.۱. نمایش اطلاعات جستجو

```c
printf("Finding first occurrence of word '%s' "
       "in the following sentence:\n", w);

puts(str);
printf("\n");
```

در این قسمت از فرمت `%s` برای نمایش رشته استفاده می‌کنیم.

ابتدا زیررشته موردنظر و سپس جمله اصلی نمایش داده می‌شود.

### ۸.۲. جستجوی زیررشته

```c
const char *pw = strstr(str, w);
```

این دستور به دنبال اولین رخداد رشته `w` درون رشته `str` می‌گردد.

برای مثال:

```c
FindWord(str, "not");
```

تابع به دنبال `"not"` در جمله زیر می‌گردد:

```text
To be, or not to be. That's the question.
```

زیررشته پیدا می‌شود و اشاره‌گر `pw` به اولین کاراکتر `"not"` اشاره می‌کند.

### ۸.۳. بررسی پیدا شدن زیررشته

```c
if (pw == NULL)
{
    printf("Nothing found.\n");
}
```

اگر تابع `strstr()` مقدار `NULL` برگرداند، یعنی زیررشته موردنظر پیدا نشده است.

در غیر این صورت، قسمت `else` اجرا می‌شود.

### ۸.۴. محاسبه موقعیت زیررشته

```c
size_t i = (size_t)(pw - str);
```

مانند تابع قبلی، با تفریق اشاره‌گرها می‌توانیم موقعیت زیررشته را نسبت به ابتدای رشته اصلی محاسبه کنیم.

برای زیررشته `"not"`:

```text
To be, or not to be.
           ^
           |
           اولین کاراکتر زیررشته "not"
```

اندیس صفرمبنا برابر با ۱۱ است.

بنابراین خروجی برنامه به شکل زیر خواهد بود:

```text
Found at index 11.
```

**نکته مهم:** در کد اصلی از دستور زیر استفاده شده است:

```c
int i = pw - str + 1;
```

این دستور موقعیت را به‌صورت یک‌مبنا (One-Based Position) محاسبه می‌کند، نه اندیس صفرمبنا.

برای زیررشته `"not"`، برنامه اصلی عدد ۱۲ را نمایش می‌دهد.

هر دو روش معتبر هستند، اما مفهوم متفاوتی دارند:

- اندیس صفرمبنا: شمارش از صفر شروع می‌شود.
- موقعیت یک‌مبنا: شمارش از یک شروع می‌شود.

در این آموزش از اندیس صفرمبنا استفاده می‌کنیم؛ زیرا با نحوه اندیس‌گذاری آرایه‌ها در زبان C هماهنگ است.

### ۸.۵. آیا `strstr()` حتماً یک کلمه کامل را پیدا می‌کند؟

خیر.

تابع `strstr()` به دنبال یک توالی از کاراکترها می‌گردد و لزوماً مرز کلمات را بررسی نمی‌کند.

برای مثال:

```c
strstr("notebook", "not");
```

زیررشته `"not"` را در ابتدای `"notebook"` پیدا می‌کند.

همچنین:

```c
strstr("another", "not");
```

می‌تواند زیررشته `"not"` را درون کلمه `"another"` پیدا کند.

بنابراین نام `FindWord()` در برنامه اصلی برای سادگی انتخاب شده است؛ اما از نظر فنی این تابع یک **زیررشته (Substring)** را جستجو می‌کند، نه لزوماً یک کلمه کامل را.

برای پیدا کردن کلمات کامل باید کاراکترهای قبل و بعد از زیررشته را نیز بررسی کنیم.

## ۹. خروجی برنامه

با اجرای دستورات زیر:

```c
FindCharacter(str, 'b');

FindWord(str, "not");
FindWord(str, "This");
```

خروجی نسخه بهبودیافته به شکل زیر خواهد بود:

```text
Finding all occurrences of character 'b' in the following string:
To be, or not to be. That's the question.

Found 'b' at index 3
Found 'b' at index 16

2 occurrences of character 'b' found.
---------------------------------------
Finding first occurrence of word 'not' in the following sentence:
To be, or not to be. That's the question.

Found at index 11.

---------------------------------------
Finding first occurrence of word 'This' in the following sentence:
To be, or not to be. That's the question.

Nothing found.

---------------------------------------
```

## ۱۰. تفاوت توابع `strchr()` و `strstr()`

| تابع | کاربرد | ورودی جستجو |
|---|---|---|
| `strchr()` | جستجوی یک کاراکتر | یک کاراکتر |
| `strstr()` | جستجوی یک زیررشته | یک رشته |

مثال:

```c
strchr(str, 'a');
```

به دنبال کاراکتر `'a'` می‌گردد.

```c
strstr(str, "abc");
```

به دنبال زیررشته `"abc"` می‌گردد.

هر دو تابع در صورت پیدا شدن، اشاره‌گری به اولین رخداد را برمی‌گردانند و در صورت پیدا نشدن مقدار `NULL` را برمی‌گردانند.

## ۱۱. نکات مهم و اشتباهات رایج

### ۱۱.۱. حساسیت به حروف بزرگ و کوچک

هر دو تابع `strchr()` و `strstr()` به حروف بزرگ و کوچک حساس هستند.

برای مثال:

```c
strstr("Hello World", "hello");
```

هیچ نتیجه‌ای پیدا نمی‌کند؛ زیرا کاراکتر `'H'` با `'h'` متفاوت است.

### ۱۱.۲. پیدا کردن چندین رخداد

تابع `strchr()` در هر بار فراخوانی فقط اولین رخداد را برمی‌گرداند.

برای پیدا کردن تمام رخدادها باید جستجو را از کاراکتر بعد از رخداد قبلی ادامه دهیم:

```c
pc = strchr(pc + 1, c);
```

### ۱۱.۳. محاسبات اشاره‌گری

عبارت زیر:

```c
pc - str
```

تعداد عناصر بین دو اشاره‌گر را در یک آرایه محاسبه می‌کند.

این عبارت به‌صورت عمومی تعداد بایت‌ها را محاسبه نمی‌کند. البته چون نوع آرایه `char` است و هر عنصر آن یک بایت فضا اشغال می‌کند، مقدار عددی حاصل با موقعیت بایتی نیز برابر خواهد بود.

### ۱۱.۴. استفاده از فرمت مناسب در `printf()`

اگر موقعیت یا تعداد رخدادها از نوع `size_t` باشد، باید از فرمت زیر استفاده کنیم:

```c
printf("%zu", i);
```

استفاده از `%d` برای متغیر `size_t` صحیح نیست.

### ۱۱.۵. تابع `strstr()` زیررشته را جستجو می‌کند، نه الزاماً کلمه کامل

اگر عبارت `"cat"` را در رشته `"concatenate"` جستجو کنید، تابع می‌تواند آن را پیدا کند.

این تابع به‌صورت خودکار مرز کلمات را بررسی نمی‌کند.

### ۱۱.۶. جستجوی رشته خالی

رفتارهای زیر طبق استاندارد C معتبر هستند:

- `strchr(str, '\0')` اشاره‌گری به Null Terminator برمی‌گرداند.
- `strstr(str, "")` اشاره‌گری به ابتدای رشته اصلی برمی‌گرداند.

## ۱۲. روش تکمیلی – پیدا کردن کلمه کامل

اگر بخواهیم به‌جای یک زیررشته، فقط یک کلمه کامل را جستجو کنیم، باید مرزهای کلمه را نیز بررسی کنیم.

برای مثال، جستجوی `"cat"` باید در جمله زیر نتیجه داشته باشد:

```text
The cat is sleeping.
```

اما نباید در جمله زیر نتیجه داشته باشد:

```text
The concatenate function.
```

یک پیاده‌سازی ساده برای متونی که کلمات آن‌ها با فاصله یا علائم نگارشی جدا شده‌اند:

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

void FindWholeWord(const char *str, const char *word)
{
    size_t len = strlen(word);
    const char *p = str;

    while ((p = strstr(p, word)) != NULL)
    {
        int left_ok = (p == str || !isalnum((unsigned char)p[-1]));
        int right_ok = (p[len] == '\0' ||
                        !isalnum((unsigned char)p[len]));

        if (left_ok && right_ok)
        {
            printf("Whole word found at index %zu\n",
                   (size_t)(p - str));
            return;
        }

        p++;
    }

    printf("Whole word not found.\n");
}

int main()
{
    FindWholeWord("The cat is sleeping.", "cat");
    FindWholeWord("The concatenate function.", "cat");

    return 0;
}
```

در این مثال، حروف و اعداد به‌عنوان کاراکترهای تشکیل‌دهنده کلمه در نظر گرفته شده‌اند.

این روش یک پیاده‌سازی ساده و مبتنی بر کاراکترهای ASCII است. برای پردازش پیشرفته متن، زبان‌های مختلف و کاراکترهای Unicode ممکن است به قوانین کامل‌تری برای تشخیص مرز کلمات نیاز داشته باشیم.

## ۱۴. تمرین‌ها

**تمرین ۱ – پیدا کردن تمام رخدادهای یک کاراکتر**

برنامه‌ای بنویسید که تمام رخدادهای کاراکتر `'a'` را در رشته زیر پیدا کند:

```c
char str[] = "banana";
```

موقعیت تمام رخدادها را نمایش دهید.

اندیس‌های مورد انتظار:

```text
1, 3, 5
```

**تمرین ۲ – جستجوی یک زیررشته**

زیررشته `"System"` را در رشته زیر جستجو کنید:

```c
char str[] = "Embedded Systems Programming";
```

اندیس شروع زیررشته را نمایش دهید.

**تمرین ۳ – جستجوی کاراکتر ناموجود**

کاراکتر `'z'` را در رشته زیر جستجو کنید:

```c
char str[] = "Hello World";
```

اگر کاراکتر پیدا نشد، پیام مناسبی نمایش دهید.

**تمرین ۴ – شمارش تمام رخدادهای یک زیررشته**

تابع `FindWord()` را تغییر دهید تا به‌جای توقف در اولین رخداد، تمام رخدادهای یک زیررشته را پیدا کرده و تعداد آن‌ها را بشمارد.

برای مثال:

```c
char str[] = "one two one three one";
```

زیررشته موردنظر:

```text
one
```

تعداد مورد انتظار: `3`

**تمرین ۵ – جستجوی یک کلمه کامل**

برنامه را تغییر دهید تا هنگام جستجوی `"cat"` فقط کلمات کامل را پیدا کند و مواردی که درون کلمات طولانی‌تر قرار دارند نادیده گرفته شوند.

**تمرین ۶ – جستجوی بدون حساسیت به حروف بزرگ و کوچک**

برنامه‌ای بنویسید که بدون توجه به بزرگ یا کوچک بودن حروف، یک کلمه را جستجو کند.

برای مثال، جستجوی `"hello"` باید بتواند `"Hello"` را نیز پیدا کند.

## ۱۵. اهداف آموزشی

پس از مطالعه این آموزش باید بتوانید:

- با استفاده از `strchr()` یک کاراکتر را در رشته جستجو کنید.
- با استفاده از `strstr()` یک زیررشته را پیدا کنید.
- با بررسی `NULL` متوجه شوید که جستجو موفق بوده است یا خیر.
- تمام رخدادهای یک کاراکتر را پیدا کنید.
- با استفاده از تفریق اشاره‌گرها موقعیت یک کاراکتر را محاسبه کنید.
- نحوه کار با اشاره‌گرها و محاسبات اشاره‌گری در آرایه‌های کاراکتری را درک کنید.
- تفاوت کاراکتر و رشته را تشخیص دهید.
- تفاوت جستجوی زیررشته و جستجوی کلمه کامل را درک کنید.
- کاربرد `size_t` و فرمت `%zu` را برای ذخیره و نمایش موقعیت و تعداد رخدادها یاد بگیرید.
