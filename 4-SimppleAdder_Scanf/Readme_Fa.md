# 4- آموزش برنامه‌نویسی C – جمع دو عدد صحیح

## ۱. مقدمه

در این مثال ساده با زبان برنامه‌نویسی C، یاد می‌گیریم چگونه دو عدد صحیح را از کاربر دریافت کنیم، آن‌ها را با یکدیگر جمع کنیم و نتیجه را در خروجی نمایش دهیم.

این برنامه برای افرادی طراحی شده است که در ابتدای مسیر یادگیری زبان C هستند.

## ۲. کد برنامه

```c
#include "stdio.h"

int main(int argc, char const *argv[])
{
    int a, b, c;

    // Get first number from user
    printf("Please enter first integer number: ");
    scanf("%d", &a);

    printf("\n");

    // Get second number from user
    printf("Please enter second integer number: ");
    scanf("%d", &b);

    // Add two numbers
    c = a + b;

    // Display the result
    printf("Result: %d + %d = %d\n", a, b, c);

    return 0;
}
```

## ۳. بررسی و توضیح کد

### ۳.۱. اضافه کردن کتابخانه ورودی و خروجی

```c
#include "stdio.h"
```

این دستور کتابخانه استاندارد ورودی و خروجی زبان C را به برنامه اضافه می‌کند.

این کتابخانه شامل توابع مختلفی است که برای ارتباط با کاربر استفاده می‌شوند.

مهم‌ترین توابع مورد استفاده در این مثال:

- `printf()` : برای نمایش اطلاعات در صفحه‌نمایش.
- `scanf()` : برای دریافت اطلاعات از کاربر.

نکته: روش استاندارد فراخوانی این کتابخانه به شکل زیر است:

```c
#include <stdio.h>
```

### ۳.۲. تابع اصلی برنامه (Main)

```c
int main(int argc, char const *argv[])
```

تابع `main()` نقطه شروع اجرای برنامه در زبان C است. اجرای برنامه از این تابع آغاز می‌شود.

اجزای این تابع:

- `int` : مشخص می‌کند که خروجی تابع از نوع عدد صحیح است.
- `argc` : تعداد آرگومان‌های ورودی خط فرمان را مشخص می‌کند.
- `argv` : آرگومان‌های ورودی خط فرمان را نگهداری می‌کند.

### ۳.۳. تعریف متغیرها

```c
int a, b, c;
```

در این قسمت سه متغیر از نوع `int` تعریف شده‌اند.

| متغیر | کاربرد |
|---|---|
| `a` | ذخیره عدد اول |
| `b` | ذخیره عدد دوم |
| `c` | ذخیره حاصل جمع دو عدد |

نوع داده `int` برای ذخیره اعداد صحیح (بدون قسمت اعشاری) استفاده می‌شود.

### ۳.۴. دریافت اطلاعات از کاربر

```c
printf("Please enter first integer number: ");
scanf("%d", &a);
```

ابتدا با استفاده از تابع `printf()` یک پیام برای کاربر نمایش داده می‌شود تا عدد اول را وارد کند.

سپس تابع `scanf()` مقدار واردشده توسط کاربر را دریافت کرده و در متغیر `a` ذخیره می‌کند.

**بررسی دو مفهوم مهم:**

- `%d` : مشخص‌کننده فرمت عدد صحیح (Integer) است.
- `&a` : آدرس حافظه متغیر `a` را مشخص می‌کند.

چرا از `&` استفاده می‌کنیم؟

زیرا تابع `scanf()` برای ذخیره مقدار ورودی باید آدرس حافظه متغیر را دریافت کند، نه فقط مقدار آن را.

همین فرآیند برای دریافت عدد دوم و ذخیره آن در متغیر `b` تکرار می‌شود.

### ۳.۵. جمع دو عدد

```c
c = a + b;
```

در این قسمت از عملگر جمع (`+`) استفاده می‌کنیم.

مقدار متغیرهای `a` و `b` با یکدیگر جمع شده و نتیجه در متغیر `c` ذخیره می‌شود.

مثال:

```c
a = 10;
b = 20;
c = a + b;
```

نتیجه:

```text
c = 30
```

### ۳.۶. نمایش نتیجه

```c
printf("Result: %d + %d = %d\n", a, b, c);
```

در این قسمت نتیجه محاسبات به کاربر نمایش داده می‌شود.

سه مشخص‌کننده `%d` به ترتیب با مقادیر متغیرهای `a`، `b` و `c` جایگزین می‌شوند.

خروجی:

```text
Result: 10 + 20 = 30
```

### ۳.۷. پایان برنامه

```c
return 0;
```

این دستور باعث پایان اجرای تابع `main()` می‌شود.

مقدار صفر نشان‌دهنده اجرای موفقیت‌آمیز برنامه است.

## ۴. نمونه اجرای برنامه

**ورودی کاربر:**

```text
Please enter first integer number: 10

Please enter second integer number: 20
```

**خروجی برنامه:**

```text
Result: 10 + 20 = 30
```

## ۵. مفاهیم برنامه‌نویسی یادگرفته‌شده

با بررسی این مثال با مفاهیم زیر آشنا می‌شویم:

۱. اضافه کردن کتابخانه‌ها (Header Files).

۲. آشنایی با تابع اصلی `main()`.

۳. تعریف متغیرهای عدد صحیح با `int`.

۴. نمایش اطلاعات با تابع `printf()`.

۵. دریافت اطلاعات با تابع `scanf()`.

۶. آشنایی با مشخص‌کننده فرمت `%d`.

۷. آشنایی با عملگر آدرس حافظه `&`.

۸. انجام عملیات ریاضی.

۹. ذخیره نتیجه محاسبات در متغیر.

۱۰. پایان دادن به برنامه با `return 0`.

## ۶. کامپایل و اجرای برنامه

اگر کامپایلر GCC را نصب کرده باشید، می‌توانید با دستور زیر برنامه را کامپایل کنید:

```bash
gcc main.c -o addition
```

اجرای برنامه در ویندوز:

```powershell
.\addition.exe
```

اجرای برنامه در لینوکس:

```bash
./addition
```

## ۷. تمرین‌های پیشنهادی

برای درک بهتر مفاهیم، تمرین‌های زیر را انجام دهید:

- تمرین ۱: برنامه را تغییر دهید تا دو عدد را از یکدیگر کم کند.
- تمرین ۲: عملیات ضرب و تقسیم را به برنامه اضافه کنید.
- تمرین ۳: سه عدد صحیح از کاربر دریافت کرده و مجموع آن‌ها را محاسبه کنید.
- تمرین ۴: میانگین دو عدد را محاسبه و نمایش دهید.
- تمرین ۵: به جای `int` از `float` استفاده کنید تا بتوانید اعداد اعشاری را نیز پردازش کنید.
