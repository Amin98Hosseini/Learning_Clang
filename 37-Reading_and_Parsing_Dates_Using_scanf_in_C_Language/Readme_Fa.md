# 37- دریافت و تجزیه تاریخ با استفاده از تابع `scanf()` در زبان C

## 1. مقدمه

در این پروژه یاد می‌گیریم چگونه یک تاریخ را از کاربر دریافت کنیم و آن را به سه مقدار عددی جداگانه تقسیم کنیم:

- سال (Year)
- ماه (Month)
- روز (Day)

برنامه انتظار دارد کاربر تاریخ را با قالب زیر وارد کند:

```text
YYYY-MM-DD
```

برای مثال:

```text
2026-11-27
```

در این برنامه از تابع `scanf()` به همراه مشخص‌کننده قالب `%*c` استفاده می‌کنیم تا اعداد را دریافت کنیم و کاراکترهای جداکننده بین آن‌ها را نادیده بگیریم.

در این پروژه با مفاهیم مهمی در زبان C آشنا می‌شویم:

- دریافت چند مقدار با استفاده از `scanf()`.
- استفاده از Format Specifierها.
- حذف ذخیره‌سازی یک کاراکتر با استفاده از علامت `*`.
- خواندن و نادیده گرفتن کاراکترهای جداکننده.
- تجزیه ورودی‌های ساختاریافته (Structured Input).
- محدودیت‌های تابع `scanf()` در اعتبارسنجی تاریخ.

## 2. کد کامل برنامه

کد اصلی:

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    int y, m, d;

    printf("Please enter the date as YYYY-MM-DD: ");

    // scanf("%4d-%2d-%2d", &y, &m, &d);
    scanf("%d%*c%d%*c%d", &y, &m, &d);

    printf("\n");

    printf("Result:\n");
    printf(" Year: %d\n", y);
    printf("Month: %d\n", m);
    printf("  Day: %d\n", d);

    return 0;
}
```

این برنامه سه مقدار عددی را دریافت می‌کند و کاراکترهای بین آن‌ها را نادیده می‌گیرد.

برای مثال، اگر کاربر تاریخ زیر را وارد کند:

```text
2026-11-27
```

مقادیر زیر در متغیرها ذخیره می‌شوند:

```text
y = 2026
m = 11
d = 27
```

**نکته مهم:** کد اصلی فقط مقادیر عددی را دریافت می‌کند و به‌طور کامل قالب ورودی یا معتبر بودن تاریخ را بررسی نمی‌کند. در ادامه این محدودیت‌ها را بررسی و برنامه را اصلاح می‌کنیم.

## 3. کتابخانه‌های موردنیاز

### کتابخانه `stdio.h`

این کتابخانه توابع ورودی و خروجی استاندارد را در اختیار برنامه قرار می‌دهد.

در این برنامه از توابع زیر استفاده شده است:

- `printf()` برای نمایش پیام‌ها و نتایج.
- `scanf()` برای دریافت تاریخ واردشده توسط کاربر.

### کتابخانه `stdlib.h`

این کتابخانه شامل توابع عمومی و کاربردی زبان C است.

در برنامه فعلی از هیچ تابعی از این کتابخانه استفاده نشده است؛ بنابراین می‌توان آن را حذف کرد.

برنامه فقط به کتابخانه زیر نیاز دارد:

```c
#include <stdio.h>
```

## 4. بررسی متغیرهای برنامه

```c
int y, m, d;
```

در این قسمت سه متغیر از نوع `int` تعریف شده‌اند.

| متغیر | مفهوم | مثال |
|---|---|---:|
| `y` | سال (Year) | 2026 |
| `m` | ماه (Month) | 11 |
| `d` | روز (Day) | 27 |

این متغیرها سه بخش عددی تاریخ را به‌صورت جداگانه ذخیره می‌کنند.

برای مثال تاریخ زیر:

```text
2026-11-27
```

به شکل زیر تقسیم می‌شود:

```text
Year  = 2026
Month = 11
Day   = 27
```

## 5. بررسی تابع `scanf()`

مهم‌ترین دستور برنامه به شکل زیر است:

```c
scanf("%d%*c%d%*c%d", &y, &m, &d);
```

برای درک بهتر این دستور باید اجزای رشته قالب (Format String) را بررسی کنیم.

### 5.1. مشخص‌کننده `%d`

مشخص‌کننده `%d` برای دریافت یک عدد صحیح علامت‌دار در مبنای ده استفاده می‌شود.

برای مثال:

```c
scanf("%d", &y);
```

اگر کاربر مقدار زیر را وارد کند:

```text
2026
```

عدد `2026` در متغیر `y` ذخیره می‌شود.

علامت `&` آدرس متغیر را در اختیار تابع `scanf()` قرار می‌دهد تا بتواند مقدار دریافت‌شده را در آن ذخیره کند.

### 5.2. مشخص‌کننده `%*c`

مشخص‌کننده `%c` برای دریافت یک کاراکتر استفاده می‌شود.

به‌طور معمول می‌توانیم از دستور زیر استفاده کنیم:

```c
scanf("%c", &separator);
```

تا یک کاراکتر دریافت و در متغیر `separator` ذخیره شود.

اما وجود علامت ستاره (`*`) رفتار آن را تغییر می‌دهد:

```c
%*c
```

معنی این دستور:

**یک کاراکتر بخوان، اما آن را در هیچ متغیری ذخیره نکن.**

به این قابلیت Assignment Suppression گفته می‌شود.

در برنامه ما از `%*c` برای عبور از کاراکترهای جداکننده بین بخش‌های تاریخ استفاده شده است.

برای مثال:

```text
2026-11-27
    ^  ^
    |  |
    -  -
```

دو خط تیره موجود در تاریخ توسط دو مشخص‌کننده `%*c` خوانده و دور ریخته می‌شوند.

### 5.3. بررسی کامل رشته قالب

به رشته زیر توجه کنید:

```c
"%d%*c%d%*c%d"
```

این رشته شامل پنج مشخص‌کننده تبدیل است:

| قالب | عملکرد | محل ذخیره |
|---|---|---|
| `%d` | دریافت عدد صحیح | `y` |
| `%*c` | دریافت و حذف یک کاراکتر | هیچ متغیری |
| `%d` | دریافت عدد صحیح | `m` |
| `%*c` | دریافت و حذف یک کاراکتر | هیچ متغیری |
| `%d` | دریافت عدد صحیح | `d` |

ورودی زیر را در نظر بگیرید:

```text
2026-11-27
```

تابع `scanf()` آن را به ترتیب زیر پردازش می‌کند:

1. `%d` مقدار `2026` را دریافت و در `y` ذخیره می‌کند.
2. `%*c` کاراکتر `-` را می‌خواند و حذف می‌کند.
3. `%d` مقدار `11` را دریافت و در `m` ذخیره می‌کند.
4. `%*c` کاراکتر `-` دوم را می‌خواند و حذف می‌کند.
5. `%d` مقدار `27` را دریافت و در `d` ذخیره می‌کند.

در پایان خواهیم داشت:

```text
y = 2026
m = 11
d = 27
```

## 6. بررسی قالب جایگزین `scanf()`

در کد اصلی یک دستور دیگر نیز به‌صورت کامنت قرار داده شده است:

```c
// scanf("%4d-%2d-%2d", &y, &m, &d);
```

این دستور نیز روش دیگری برای دریافت تاریخ است.

ساختار آن:

```c
scanf("%4d-%2d-%2d", &y, &m, &d);
```

اجزای این قالب به شکل زیر هستند:

| قالب | توضیحات |
|---|---|
| `%4d` | دریافت عدد صحیح با حداکثر 4 کاراکتر |
| `-` | تطبیق با یک خط تیره واقعی |
| `%2d` | دریافت عدد صحیح با حداکثر 2 کاراکتر |
| `-` | تطبیق با خط تیره دوم |
| `%2d` | دریافت عدد صحیح با حداکثر 2 کاراکتر |

برای ورودی زیر:

```text
2026-11-27
```

تابع مقادیر زیر را دریافت می‌کند:

- `2026` در متغیر `y`.
- خط تیره اول باید با ورودی مطابقت داشته باشد.
- `11` در متغیر `m`.
- خط تیره دوم باید با ورودی مطابقت داشته باشد.
- `27` در متغیر `d`.

### تفاوت دو روش

| ویژگی | `%d%*c%d%*c%d` | `%4d-%2d-%2d` |
|---|---|---|
| دریافت سال، ماه و روز | بله | بله |
| عبور از جداکننده | هر کاراکتری را می‌خواند و حذف می‌کند | خط تیره مشخص‌شده را تطبیق می‌دهد |
| بررسی وجود خط تیره | خیر | بله |
| محدودیت طول فیلد | ندارد | دارد |
| الزام به قالب دقیق تاریخ | خیر | تا حد بیشتری بله، اما نه به‌طور کامل |

**پیشنهاد:** برای قالب مشخص `YYYY-MM-DD`، روش دوم معمولاً انتخاب بهتری است؛ زیرا وجود خط تیره را به‌صورت صریح بررسی می‌کند.

با این حال، هیچ‌کدام از این دو روش به‌تنهایی تضمین نمی‌کنند که تاریخ واردشده واقعاً یک تاریخ معتبر تقویمی باشد.

## 7. آشنایی بیشتر با Assignment Suppression

قابلیت Assignment Suppression زمانی کاربرد دارد که بخواهیم بخشی از ورودی را دریافت کنیم، اما نیازی به ذخیره آن نداشته باشیم.

برای مثال:

```c
scanf("%d%*c%d", &a, &b);
```

اگر کاربر مقدار زیر را وارد کند:

```text
25,50
```

تابع به ترتیب عملیات زیر را انجام می‌دهد:

1. عدد `25` را در `a` ذخیره می‌کند.
2. کاراکتر `,` را می‌خواند و حذف می‌کند.
3. عدد `50` را در `b` ذخیره می‌کند.

نتیجه:

```text
a = 25
b = 50
```

مثال دیگر:

```c
scanf("%d%*c%d%*c%d", &a, &b, &c);
```

ورودی:

```text
10-20-30
```

نتیجه:

```text
a = 10
b = 20
c = 30
```

به یاد داشته باشید که `%*c` دقیقاً یک کاراکتر را حذف می‌کند. این دستور بررسی نمی‌کند که کاراکتر موردنظر حتماً کاما، خط تیره یا جداکننده مشخص دیگری باشد.

## 8. نمایش نتیجه

پس از دریافت تاریخ، برنامه دستورات زیر را اجرا می‌کند:

```c
printf("Result:\n");
printf(" Year: %d\n", y);
printf("Month: %d\n", m);
printf("  Day: %d\n", d);
```

هر متغیر به‌صورت جداگانه نمایش داده می‌شود.

از مشخص‌کننده `%d` استفاده کرده‌ایم؛ زیرا هر سه متغیر از نوع `int` هستند.

برای ورودی:

```text
2026-11-27
```

خروجی به شکل زیر خواهد بود:

```text
Result:
 Year: 2026
Month: 11
  Day: 27
```

## 9. خروجی نمونه

مثال اول:

```text
Please enter the date as YYYY-MM-DD: 2026-11-27

Result:
 Year: 2026
Month: 11
  Day: 27
```

مثال دوم:

```text
Please enter the date as YYYY-MM-DD: 2000-01-05

Result:
 Year: 2000
Month: 1
  Day: 5
```

توجه کنید که متغیرهای عددی صفرهای ابتدایی را حفظ نمی‌کنند.

برای مثال، ماه `01` به‌صورت عدد صحیح `1` ذخیره می‌شود.

اگر بخواهیم هنگام نمایش ماه همیشه دو رقم داشته باشیم، می‌توانیم از دستور زیر استفاده کنیم:

```c
printf("Month: %02d\n", m);
```

علامت `0` باعث می‌شود در صورت نیاز، صفر در ابتدای عدد قرار بگیرد تا عرض مشخص‌شده تکمیل شود.

## 10. محدودیت مهم: برنامه اصلی ورودی را اعتبارسنجی نمی‌کند

ورودی زیر را در نظر بگیرید:

```text
2026/11/27
```

در قالب اصلی:

```c
scanf("%d%*c%d%*c%d", &y, &m, &d);
```

کاراکترهای `/` نیز پذیرفته می‌شوند؛ زیرا `%*c` هر کاراکتری را می‌خواند و حذف می‌کند.

بنابراین برنامه ممکن است نتیجه زیر را نمایش دهد:

```text
Year: 2026
Month: 11
Day: 27
```

درحالی‌که کاربر از قالب خط تیره استفاده نکرده است.

همچنین برنامه تاریخ‌های نامعتبر مانند زیر را رد نمی‌کند:

```text
2026-15-40
```

اعداد با موفقیت دریافت می‌شوند، اما چنین تاریخی از نظر تقویمی معتبر نیست.

به همین دلیل باید دو مرحله را از یکدیگر جدا کنیم:

1. **Parsing:** استخراج سال، ماه و روز از ورودی.
2. **Validation:** بررسی اینکه مقادیر استخراج‌شده یک تاریخ معتبر تشکیل می‌دهند یا خیر.

## 11. نسخه ایمن‌تر با بررسی مقدار بازگشتی `scanf()`

در نسخه زیر از قالب دارای خط تیره واقعی استفاده می‌کنیم و بررسی می‌کنیم که هر سه مقدار عددی با موفقیت دریافت شده باشند:

```c
#include <stdio.h>

int main()
{
    int y, m, d;

    printf("Please enter the date as YYYY-MM-DD: ");

    if (scanf("%4d-%2d-%2d", &y, &m, &d) != 3)
    {
        printf("Invalid input format.\n");
        return 1;
    }

    printf("\nResult:\n");
    printf(" Year: %04d\n", y);
    printf("Month: %02d\n", m);
    printf("  Day: %02d\n", d);

    return 0;
}
```

### تغییرات ایجادشده

**1. حذف کتابخانه غیرضروری**

```c
#include <stdio.h>
```

برنامه فقط به توابع ورودی و خروجی استاندارد نیاز دارد.

**2. استفاده از خط تیره واقعی**

```c
scanf("%4d-%2d-%2d", &y, &m, &d);
```

در این حالت وجود خط تیره بین فیلدهای عددی الزامی است.

**3. بررسی مقدار بازگشتی تابع**

```c
if (scanf("%4d-%2d-%2d", &y, &m, &d) != 3)
```

تابع `scanf()` تعداد مقادیری را برمی‌گرداند که با موفقیت دریافت و در متغیرها ذخیره شده‌اند.

در این برنامه:

- مقدار `3` یعنی هر سه عدد با موفقیت دریافت شده‌اند.
- مقدار کمتر از 3 یعنی پردازش قبل از تکمیل هر سه مقدار متوقف شده است.
- مقدار `EOF` یعنی پیش از تکمیل اولین تبدیل، خطای ورودی یا پایان جریان ورودی اتفاق افتاده است.

این بررسی مانع استفاده از متغیرهایی می‌شود که مقداردهی نشده‌اند.

**نکته:** این نسخه موفقیت سه تبدیل را بررسی می‌کند، اما تضمین نمی‌کند که تمام خط ورودی فقط شامل یک تاریخ باشد. برای اعتبارسنجی دقیق‌تر، بهتر است ابتدا کل خط را دریافت و سپس آن را پردازش کنیم.

## 12. نسخه کامل همراه با اعتبارسنجی تاریخ تقویمی

در مثال زیر ابتدا یک خط کامل با استفاده از `fgets()` دریافت می‌کنیم، سپس تاریخ را با `sscanf()` استخراج می‌کنیم و در نهایت جداکننده‌ها و معتبر بودن تاریخ را بررسی می‌کنیم.

این نسخه سال کبیسه را نیز در نظر می‌گیرد.

```c
#include <stdio.h>

int IsLeapYear(int year)
{
    return (year % 400 == 0) ||
           (year % 4 == 0 && year % 100 != 0);
}

int IsValidDate(int year, int month, int day)
{
    int daysInMonth[] =
    {
        31, 28, 31, 30, 31, 30,
        31, 31, 30, 31, 30, 31
    };

    if (year < 1 || month < 1 || month > 12)
    {
        return 0;
    }

    if (IsLeapYear(year))
    {
        daysInMonth[1] = 29;
    }

    if (day < 1 || day > daysInMonth[month - 1])
    {
        return 0;
    }

    return 1;
}

int main()
{
    char input[100];
    int y, m, d;
    char extra;

    printf("Please enter the date as YYYY-MM-DD: ");

    if (fgets(input, sizeof(input), stdin) == NULL)
    {
        printf("Input error.\n");
        return 1;
    }

    if (sscanf(input, "%4d-%2d-%2d %c", &y, &m, &d, &extra) != 3)
    {
        printf("Invalid date format.\n");
        return 1;
    }

    if (!IsValidDate(y, m, d))
    {
        printf("Invalid calendar date.\n");
        return 1;
    }

    printf("\nValid date:\n");
    printf(" Year: %04d\n", y);
    printf("Month: %02d\n", m);
    printf("  Day: %02d\n", d);

    return 0;
}
```

### بررسی تابع `IsLeapYear()`

```c
int IsLeapYear(int year)
{
    return (year % 400 == 0) ||
           (year % 4 == 0 && year % 100 != 0);
}
```

این تابع بررسی می‌کند که آیا سال کبیسه است یا خیر.

یک سال در صورتی کبیسه است که:

- بر 400 بخش‌پذیر باشد؛ یا
- بر 4 بخش‌پذیر باشد، اما بر 100 بخش‌پذیر نباشد.

چند مثال:

| سال | کبیسه است؟ |
|---:|---|
| 2024 | بله |
| 2025 | خیر |
| 1900 | خیر |
| 2000 | بله |
| 2028 | بله |

در سال کبیسه، ماه فوریه به‌جای 28 روز، 29 روز دارد.

### بررسی تابع `IsValidDate()`

این تابع موارد زیر را بررسی می‌کند:

1. سال باید بزرگ‌تر از صفر باشد.
2. ماه باید بین 1 تا 12 باشد.
3. روز باید حداقل 1 باشد.
4. تعداد روزها نباید از تعداد روزهای مجاز ماه بیشتر باشد.
5. در سال کبیسه، ماه فوریه باید 29 روز داشته باشد.

برای مثال:

| تاریخ | نتیجه | توضیح |
|---|---|---|
| `2026-11-27` | معتبر | تاریخ معمولی |
| `2024-02-29` | معتبر | تاریخ در سال کبیسه |
| `2025-02-29` | نامعتبر | سال 2025 کبیسه نیست |
| `2026-04-31` | نامعتبر | ماه آوریل 30 روز دارد |
| `2026-13-10` | نامعتبر | ماه 13 وجود ندارد |
| `2026-00-10` | نامعتبر | ماه صفر وجود ندارد |

### بررسی قالب `sscanf()`

```c
sscanf(input, "%4d-%2d-%2d %c", &y, &m, &d, &extra)
```

این قالب به ترتیب عملیات زیر را انجام می‌دهد:

- حداکثر چهار کاراکتر برای سال می‌خواند.
- وجود یک خط تیره را بررسی می‌کند.
- حداکثر دو کاراکتر برای ماه می‌خواند.
- خط تیره دوم را بررسی می‌کند.
- حداکثر دو کاراکتر برای روز می‌خواند.
- فاصله‌های احتمالی را رد می‌کند.
- در صورت وجود، یک کاراکتر اضافی را در `extra` ذخیره می‌کند.

استفاده از `%c` اضافی کمک می‌کند وجود کاراکترهای غیرخالی پس از تاریخ تشخیص داده شود.

اگر مقدار بازگشتی دقیقاً `3` باشد، هر سه بخش تاریخ با موفقیت دریافت شده‌اند و کاراکتر غیرخالی اضافی دیگری وجود نداشته است.

برای مثال:

```text
2026-11-27
```

پذیرفته می‌شود، اما:

```text
2026-11-27abc
```

رد می‌شود.

این مثال تاریخ تقویمی را بررسی می‌کند، اما برای تمام ورودی‌های نامعتبر تضمین نمی‌کند که دقیقاً چهار رقم برای سال و دو رقم برای ماه و روز وارد شده باشد. برای اعتبارسنجی کاملاً دقیق قالب، می‌توان بررسی کاراکتر به کاراکتر را نیز اضافه کرد.

## 13. کامپایل و اجرای برنامه

کد را در فایلی با نام زیر ذخیره کنید:

```text
main.c
```

کامپایل با GCC:

```bash
gcc -std=c11 -Wall -Wextra -pedantic main.c -o date_parser
```

اجرا در Linux:

```bash
./date_parser
```

اجرا در Windows:

```powershell
date_parser.exe
```

برای اجرای این برنامه به کتابخانه اضافی نیاز ندارید.

## 14. تمرین‌های پیشنهادی

برای تسلط بیشتر بر مفاهیم این پروژه، تمرین‌های زیر را انجام دهید:

1. برنامه را تغییر دهید تا تاریخ را با قالب `DD-MM-YYYY` دریافت کند.
2. برنامه را تغییر دهید تا از قالب `YYYY/MM/DD` پشتیبانی کند.
3. نام ماه را به‌جای عدد نمایش دهید؛ برای مثال `November`.
4. بررسی کنید که سال واردشده کبیسه است یا خیر.
5. تعداد روزهای ماه واردشده را محاسبه کنید.
6. برنامه را طوری تغییر دهید که جداکننده‌های نامعتبر را رد کند.
7. امکان دریافت چند تاریخ را به برنامه اضافه کنید.
8. تابعی بنویسید که تاریخ را به قالب `27 November 2026` تبدیل کند.
9. تعداد روزهای بین دو تاریخ معتبر را محاسبه کنید.

## 15. مواردی که در این پروژه یاد می‌گیرید

پس از انجام این پروژه با مفاهیم زیر آشنا می‌شوید:

- نحوه دریافت چند عدد صحیح با استفاده از `scanf()`.
- کاربرد `%d` برای دریافت اعداد صحیح ده‌دهی.
- کاربرد `%*c` برای دریافت و حذف یک کاراکتر.
- مفهوم Assignment Suppression.
- نحوه استفاده از کاراکترهای ثابت در Format String تابع `scanf()`.
- تفاوت بین `%d%*c%d` و قالب دارای جداکننده ثابت.
- محدود کردن طول فیلدها هنگام دریافت ورودی.
- اهمیت بررسی مقدار بازگشتی تابع `scanf()`.
- تفاوت بین تجزیه ورودی (Parsing) و اعتبارسنجی تاریخ تقویمی.
- استفاده از `fgets()` و `sscanf()` برای پردازش ایمن‌تر ورودی خطی.
