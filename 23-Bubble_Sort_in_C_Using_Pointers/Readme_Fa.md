در این پروژه، یک آرایه از اعداد صحیح با استفاده از الگوریتم **Bubble Sort** به ترتیب صعودی مرتب می‌شود.

این برنامه علاوه بر آموزش الگوریتم مرتب‌سازی حبابی، چند مفهوم مهم در زبان C را نیز آموزش می‌دهد:

## ۳. کد کامل برنامه

کد زیر نسخه بهینه‌شده برنامه شماست. عملکرد اصلی برنامه حفظ شده است، اما محدوده حلقه داخلی در هر مرحله کاهش پیدا می‌کند تا مقایسه‌های غیرضروری انجام نشوند.

```c
#include <stdio.h>

void PrintArray(const int *const a, int N);
void BubbleSort(int *const a, int N);
void Swap(int *p1, int *p2);

int main()
{
    int a[] = {
        23, 53, 12, 10, 17, 56, 78, 34, 29,
        37, 45, 12, 19, 20, 40, 90, 43, 48, 62
    };

    int N = sizeof(a) / sizeof(a[0]);

    printf("Array before sorting:\n");
    PrintArray(a, N);
    printf("\n\n");

    BubbleSort(a, N);

    printf("Array after sorting:\n");
    PrintArray(a, N);
    printf("\n\n");

    return 0;
}

void BubbleSort(int *const a, int N)
{
    int i, j;
    int swapped;

    for (i = 0; i < N - 1; i++)
    {
        swapped = 0;

        for (j = 0; j < N - i - 1; j++)
        {
            if (a[j] > a[j + 1])
            {
                Swap(&a[j], &a[j + 1]);
                swapped = 1;
            }
        }

        if (!swapped)
        {
            break;
        }
    }
}

void Swap(int *p1, int *p2)
{
    int temp;

    temp = *p1;
    *p1 = *p2;
    *p2 = temp;
}

void PrintArray(const int *const a, int N)
{
    int i;

    for (i = 0; i < N; i++)
    {
        printf("%d", a[i]);

        if (i < N - 1)
        {
            printf(", ");
        }
    }
}
```

### ۴.۴. محاسبه تعداد عناصر آرایه

```c
int N = sizeof(a) / sizeof(a[0]);
```

عملگر `sizeof` اندازه یک متغیر یا شیء را بر حسب بایت محاسبه می‌کند.

در این مثال:

- `sizeof(a)` اندازه کل آرایه است.
- `sizeof(a[0])` اندازه یک عنصر آرایه است.

اگر اندازه هر عدد صحیح ۴ بایت باشد:

```text
sizeof(a)    = 19 × 4 = 76 bytes
sizeof(a[0]) = 4 bytes

N = 76 / 4 = 19
```

این روش یکی از روش‌های رایج برای محاسبه تعداد عناصر یک آرایه واقعی در همان محدوده تعریف آن است.

**نکته مهم:** وقتی آرایه را به یک تابع ارسال می‌کنیم، پارامتر تابع به یک اشاره‌گر تبدیل می‌شود. بنابراین استفاده از `sizeof(a)` داخل تابع، اندازه اشاره‌گر را می‌دهد، نه اندازه کل آرایه اصلی.

### ۴.۵. نمایش آرایه قبل از مرتب‌سازی

```c
printf("Array before sorting:\n");
PrintArray(a, N);
```

در این قسمت تابع `PrintArray()` فراخوانی می‌شود.

دو پارامتر به تابع ارسال می‌شوند:

- `a`: آدرس اولین عنصر آرایه
- `N`: تعداد عناصر آرایه

تابع عناصر آرایه را نمایش می‌دهد، بدون اینکه مقدار آن‌ها را تغییر دهد.

### ۴.۶. فراخوانی تابع مرتب‌سازی

```c
BubbleSort(a, N);
```

در این قسمت آرایه به تابع `BubbleSort()` ارسال می‌شود.

تابع به کمک اشاره‌گر به عناصر آرایه اصلی دسترسی پیدا می‌کند و آن‌ها را مرتب می‌کند.

به همین دلیل پس از بازگشت از تابع، آرایه در تابع `main()` نیز مرتب شده است.

## ۵. بررسی اشاره‌گرها در پارامترهای توابع

یکی از مهم‌ترین قسمت‌های این پروژه، استفاده از اشاره‌گر در تعریف توابع است.

به این تعریف توجه کنید:

```c
void BubbleSort(int *const a, int N);
```

عبارت:

```c
int *const a
```

به این معناست که:

- `a` یک اشاره‌گر به متغیر `int` است.
- خود اشاره‌گر نمی‌تواند در داخل تابع به آدرس دیگری اشاره کند.
- اما مقدار متغیری که به آن اشاره می‌کند قابل تغییر است.

برای مثال:

```c
a[0] = 100;
```

مجاز است.

اما:

```c
a++;
```

مجاز نیست، چون اشاره‌گر `a` ثابت تعریف شده است.

### انواع تعریف اشاره‌گر با const

| تعریف | مفهوم |
|---|---|
| `int *p` | اشاره‌گر به عدد صحیح قابل تغییر |
| `const int *p` | اشاره‌گر به عدد صحیحی که از طریق آن قابل تغییر نیست |
| `int *const p` | اشاره‌گر ثابت به عدد صحیح قابل تغییر |
| `const int *const p` | اشاره‌گر ثابت به عدد صحیح غیرقابل تغییر از طریق اشاره‌گر |

در تابع `PrintArray()` از این تعریف استفاده شده است:

```c
void PrintArray(const int *const a, int N);
```

یعنی:

۱. تابع اجازه تغییر عناصر آرایه از طریق `a` را ندارد.

۲. خود اشاره‌گر `a` نیز نمی‌تواند به آدرس دیگری منتقل شود.

این روش برای توابعی مناسب است که فقط باید داده‌ها را بخوانند و نباید آن‌ها را تغییر دهند.

## ۶. الگوریتم Bubble Sort چگونه کار می‌کند؟

Bubble Sort یکی از ساده‌ترین الگوریتم‌های مرتب‌سازی است.

در این الگوریتم، عناصر مجاور آرایه با یکدیگر مقایسه می‌شوند. اگر عنصر سمت چپ از عنصر سمت راست بزرگ‌تر باشد، جای آن دو عوض می‌شود.

این عملیات تا زمانی ادامه پیدا می‌کند که آرایه مرتب شود.

برای مرتب‌سازی صعودی، شرط زیر استفاده می‌شود:

```c
if (a[j] > a[j + 1])
```

اگر شرط برقرار باشد، دو عنصر باید جابه‌جا شوند.

### یک مثال ساده

فرض کنید آرایه زیر را داریم:

```text
[5, 3, 8, 1]
```

**مرحله اول (Pass 1)**

| مقایسه | عملیات | آرایه |
|---|---|---|
| 5 و 3 | جابه‌جایی | 3, 5, 8, 1 |
| 5 و 8 | بدون جابه‌جایی | 3, 5, 8, 1 |
| 8 و 1 | جابه‌جایی | 3, 5, 1, 8 |

در پایان مرحله اول، بزرگ‌ترین عدد یعنی `8` به آخر آرایه منتقل می‌شود و در جایگاه نهایی خود قرار می‌گیرد.

**مرحله دوم (Pass 2)**

| مقایسه | عملیات | آرایه |
|---|---|---|
| 3 و 5 | بدون جابه‌جایی | 3, 5, 1, 8 |
| 5 و 1 | جابه‌جایی | 3, 1, 5, 8 |

**مرحله سوم (Pass 3)**

| مقایسه | عملیات | آرایه |
|---|---|---|
| 3 و 1 | جابه‌جایی | 1, 3, 5, 8 |

در این مرحله آرایه به‌صورت صعودی مرتب شده است.

## ۷. بررسی تابع BubbleSort()

```c
void BubbleSort(int *const a, int N)
```

این تابع دو پارامتر دریافت می‌کند:

- `a`: اشاره‌گر به اولین عنصر آرایه
- `N`: تعداد عناصر آرایه

نوع خروجی تابع `void` است؛ زیرا نیازی به برگرداندن آرایه نداریم و عناصر آرایه اصلی مستقیماً تغییر می‌کنند.

### حلقه بیرونی

```c
for (i = 0; i < N - 1; i++)
```

این حلقه تعداد مراحل مرتب‌سازی را کنترل می‌کند.

برای مرتب‌سازی یک آرایه با `N` عنصر، حداکثر `N-1` مرحله لازم است.

### متغیر swapped

```c
swapped = 0;
```

این متغیر مشخص می‌کند که آیا در مرحله فعلی جابه‌جایی انجام شده است یا خیر.

- مقدار `0`: هنوز هیچ جابه‌جایی انجام نشده است.
- مقدار `1`: حداقل یک جابه‌جایی انجام شده است.

### حلقه داخلی

```c
for (j = 0; j < N - i - 1; j++)
```

این حلقه عناصر مجاور را با یکدیگر مقایسه می‌کند.

عبارت زیر اهمیت زیادی دارد:

```c
N - i - 1
```

چرا؟

چون بعد از هر مرحله، بزرگ‌ترین عنصر بخش مرتب‌نشده در انتهای آن بخش قرار می‌گیرد.

بنابراین دیگر نیازی نیست آن عنصر را در مراحل بعدی دوباره مقایسه کنیم.

برای یک آرایه با ۵ عنصر:

| مرحله | حداکثر تعداد مقایسه |
|---:|---:|
| 1 | 4 |
| 2 | 3 |
| 3 | 2 |
| 4 | 1 |

این کار باعث کاهش مقایسه‌های غیرضروری می‌شود.

### مقایسه عناصر مجاور

```c
if (a[j] > a[j + 1])
```

در این قسمت مقدار دو عنصر مجاور بررسی می‌شود.

برای مثال:

```c
a[j] = 9;
a[j + 1] = 4;
```

چون عدد ۹ بزرگ‌تر از عدد ۴ است، باید جای آن‌ها عوض شود.

### فراخوانی تابع Swap()

```c
Swap(&a[j], &a[j + 1]);
```

این خط یکی از مهم‌ترین بخش‌های برنامه است.

عملگر `&` آدرس یک متغیر را به دست می‌آورد.

بنابراین:

- `&a[j]` آدرس عنصر اول است.
- `&a[j + 1]` آدرس عنصر دوم است.

این دو آدرس به تابع `Swap()` ارسال می‌شوند تا مقادیر اصلی آرایه تغییر کنند.

### تغییر مقدار swapped

```c
swapped = 1;
```

این دستور نشان می‌دهد که در مرحله فعلی حداقل یک جابه‌جایی انجام شده است.

### توقف زودهنگام الگوریتم

```c
if (!swapped)
{
    break;
}
```

اگر در یک مرحله هیچ جابه‌جایی انجام نشود، یعنی آرایه از قبل مرتب شده است.

در این شرایط دستور `break` اجرای حلقه بیرونی را متوقف می‌کند.

این بهینه‌سازی برای آرایه‌های از قبل مرتب‌شده یا تقریباً مرتب‌شده مفید است.

## ۸. بررسی تابع Swap()

```c
void Swap(int *p1, int *p2)
{
    int temp;

    temp = *p1;
    *p1 = *p2;
    *p2 = temp;
}
```

این تابع وظیفه جابه‌جایی دو مقدار را بر عهده دارد.

تابع دو اشاره‌گر دریافت می‌کند:

- `p1`: آدرس عدد اول
- `p2`: آدرس عدد دوم

### مفهوم عملگر Dereference

عملگر `*` برای دسترسی به مقدار ذخیره‌شده در آدرس یک اشاره‌گر استفاده می‌شود.

مثال:

```c
int x = 10;
int *p = &x;
```

در این مثال:

| عبارت | مفهوم |
|---|---|
| `x` | مقدار متغیر |
| `&x` | آدرس متغیر |
| `p` | آدرسی که داخل اشاره‌گر ذخیره شده است |
| `*p` | مقدار موجود در آدرس اشاره‌گر |

### بررسی مرحله‌به‌مرحله جابه‌جایی

فرض کنید دو متغیر زیر را داریم:

```text
a = 10
b = 20
```

سپس تابع زیر را فراخوانی می‌کنیم:

```c
Swap(&a, &b);
```

**مرحله اول**

```c
temp = *p1;
```

مقدار ۱۰ از آدرس اول خوانده شده و داخل متغیر موقت `temp` ذخیره می‌شود.

**مرحله دوم**

```c
*p1 = *p2;
```

مقدار ۲۰ در آدرس متغیر اول نوشته می‌شود.

**مرحله سوم**

```c
*p2 = temp;
```

مقدار ۱۰ در آدرس متغیر دوم نوشته می‌شود.

نتیجه نهایی:

```text
a = 20
b = 10
```

به دلیل استفاده از آدرس متغیرها، مقدار متغیرهای اصلی تغییر می‌کند.

## ۹. بررسی تابع PrintArray()

```c
void PrintArray(const int *const a, int N)
{
    int i;

    for (i = 0; i < N; i++)
    {
        printf("%d", a[i]);

        if (i < N - 1)
        {
            printf(", ");
        }
    }
}
```

این تابع تمام عناصر آرایه را چاپ می‌کند.

حلقه از اندیس صفر شروع شده و تا اندیس `N-1` ادامه پیدا می‌کند.

شرط زیر:

```c
if (i < N - 1)
```

باعث می‌شود بعد از آخرین عنصر، کاما چاپ نشود.

همچنین استفاده از `const` تضمین می‌کند که این تابع از طریق اشاره‌گر، مقادیر آرایه را تغییر ندهد.

## ۱۰. خروجی مورد انتظار

```text
Array before sorting:
23, 53, 12, 10, 17, 56, 78, 34, 29, 37, 45, 12, 19, 20, 40, 90, 43, 48, 62

Array after sorting:
10, 12, 12, 17, 19, 20, 23, 29, 34, 37, 40, 43, 45, 48, 53, 56, 62, 78, 90
```

همان‌طور که مشاهده می‌کنید، آرایه از کوچک‌ترین مقدار به بزرگ‌ترین مقدار مرتب شده است.

توجه کنید که عدد `12` دو بار در آرایه وجود دارد و پس از مرتب‌سازی نیز هر دو نسخه حفظ شده‌اند. الگوریتم فقط ترتیب عناصر را تغییر می‌دهد و مقدار یا تعداد آن‌ها را حذف نمی‌کند.

## ۱۱. پیچیدگی زمانی و حافظه‌ای

الگوریتم Bubble Sort دارای پیچیدگی زیر است:

| حالت | پیچیدگی زمانی | توضیح |
|---|---|---|
| بهترین حالت | O(N) | آرایه از قبل مرتب است و الگوریتم پس از یک مرحله متوقف می‌شود |
| حالت متوسط | O(N²) | معمولاً به چندین مرحله مقایسه و جابه‌جایی نیاز است |
| بدترین حالت | O(N²) | آرایه به ترتیب معکوس قرار گرفته است |

**پیچیدگی حافظه‌ای: O(1)**

این الگوریتم فقط از چند متغیر کمکی مانند `i`، `j`، `swapped` و `temp` استفاده می‌کند.

بنابراین آرایه جدیدی ایجاد نمی‌کند و مرتب‌سازی روی همان آرایه اصلی انجام می‌شود.

### چرا پیچیدگی زمانی O(N²) است؟

در بدترین حالت، تعداد مقایسه‌ها تقریباً برابر است با:

```text
(N - 1) + (N - 2) + ... + 2 + 1
```

فرمول مجموع این اعداد:

```text
N × (N - 1) / 2
```

بنابراین پیچیدگی زمانی الگوریتم از مرتبه O(N²) است.

## ۱۲. نکات مهم زبان C در این پروژه

### ارتباط آرایه و اشاره‌گر

هنگامی که آرایه به تابع ارسال می‌شود، پارامتر آرایه در تعریف تابع به یک اشاره‌گر تبدیل می‌شود.

برای مثال:

```c
void Function(int a[], int N);
```

از نظر نوع پارامتر تابع معادل است با:

```c
void Function(int *a, int N);
```

هر دو روش اجازه دسترسی به عناصر آرایه اصلی را می‌دهند.

### Pointer Arithmetic

عبارت‌های زیر معادل یکدیگر هستند:

```c
a[j]
*(a + j)
```

هر دو به عنصر شماره `j` آرایه دسترسی دارند.

برای مثال:

```c
a[2]
```

معادل است با:

```c
*(a + 2)
```

### ارسال اشاره‌گر به تابع

در زبان C تمام آرگومان‌ها به‌صورت مقداری (Pass by Value) ارسال می‌شوند؛ حتی آرگومان‌هایی که از نوع اشاره‌گر هستند.

هنگامی که تابع `Swap()` دو اشاره‌گر دریافت می‌کند، در واقع نسخه‌ای از آدرس‌ها را دریافت می‌کند.

با این حال، این آدرس‌ها همچنان به متغیرهای اصلی اشاره می‌کنند. بنابراین تابع با استفاده از عملگر `*` می‌تواند مقادیر متغیرهای اصلی را تغییر دهد.

این روش یکی از کاربردهای مهم اشاره‌گرها در زبان C است.

## ۱۳. کامپایل و اجرای برنامه

### استفاده از GCC

ترمینال را در پوشه پروژه باز کنید.

برای کامپایل:

```bash
gcc main.c -o bubble_sort
```

برای اجرا در Linux یا macOS:

```bash
./bubble_sort
```

برای اجرا در Windows:

```powershell
.\bubble_sort.exe
```


## ۱۴. تمرین‌های پیشنهادی

برای یادگیری بهتر، تمرین‌های زیر را انجام دهید.

**تمرین ۱ — مرتب‌سازی نزولی**

برنامه را تغییر دهید تا آرایه از بزرگ‌ترین عدد به کوچک‌ترین عدد مرتب شود.

راهنمایی: شرط مقایسه را تغییر دهید.

**تمرین ۲ — دریافت آرایه از کاربر**

به‌جای تعریف مقادیر ثابت، ابتدا تعداد عناصر و سپس مقادیر آرایه را از کاربر دریافت کنید.

**تمرین ۳ — جابه‌جایی دو متغیر**

برنامه‌ای بنویسید که دو عدد صحیح دریافت کند و با استفاده از تابع `Swap()` جای آن‌ها را عوض کند.

**تمرین ۴ — شمارش تعداد جابه‌جایی‌ها**

تابع `BubbleSort()` را تغییر دهید تا تعداد عملیات Swap را محاسبه کند.

**تمرین ۵ — شمارش تعداد مقایسه‌ها**

یک شمارنده اضافه کنید تا تعداد مقایسه‌های انجام‌شده توسط الگوریتم مشخص شود.

**تمرین ۶ — حذف مقادیر تکراری**

پس از مرتب‌سازی، یک آرایه جدید ایجاد کنید که فقط شامل مقادیر غیرتکراری باشد.

**تمرین ۷ — استفاده از Pointer Arithmetic**

عبارت زیر را:

```c
a[j]
```

با عبارت زیر جایگزین کنید:

```c
*(a + j)
```

سپس بررسی کنید که برنامه همچنان درست کار می‌کند.
