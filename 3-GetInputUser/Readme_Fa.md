# پروژه 3 - دریافت ورودی از کاربر (scanf و printf)

## معرفی پروژه (Overview)

در این پروژه با نحوه دریافت اطلاعات از کاربر از طریق صفحه‌کلید (Keyboard Input) آشنا می‌شویم.

برای دریافت عدد صحیح (Integer) از تابع `scanf()` و برای نمایش مقدار واردشده از تابع `printf()` استفاده می‌کنیم.

این پروژه یکی از مباحث پایه‌ای برنامه‌نویسی C و مقدمه‌ای برای ساخت برنامه‌های تعاملی (Interactive Programs) است.

## اهداف آموزشی (Learning Objectives)

با انجام این پروژه، مفاهیم زیر را یاد می‌گیرید:

- تعریف متغیر از نوع عدد صحیح (`int`).
- نمایش متن و اطلاعات با استفاده از `printf()`.
- دریافت اطلاعات از کاربر با استفاده از `scanf()`.
- آشنایی با عملگر آدرس (`&`).
- آشنایی با قالب نمایش عدد صحیح (`%d`).
- نمایش مقدار ذخیره‌شده در یک متغیر.

## کد برنامه (Source Code)

```c
#include <stdio.h>

int main(int argc, char const *argv[])
{
    /* code */
    int n;

    printf("Please an entern integer number : ");

    // First input for scanf is type of input and second input is variable for save value from user
    scanf("%d", &n);

    printf("\n");

    printf("User enter This number : %d \n", n);

    return 0;
}
```

## بررسی و توضیح کد (Code Explanation)

### ۱. اضافه کردن کتابخانه استاندارد ورودی و خروجی

```c
#include <stdio.h>
```

کتابخانه `stdio.h` شامل توابع استاندارد ورودی و خروجی (Standard Input/Output) در زبان C است.

دو تابع مهم این کتابخانه عبارت‌اند از:

- `printf()` برای نمایش اطلاعات روی صفحه‌نمایش.
- `scanf()` برای دریافت اطلاعات از کاربر.

### ۲. تابع اصلی برنامه (Main Function)

```c
int main(int argc, char const *argv[])
```

تابع `main()` نقطه شروع اجرای برنامه است.

این تابع دو پارامتر دارد:

- `argc`: تعداد آرگومان‌های ورودی برنامه از طریق خط فرمان.
- `argv`: آرایه‌ای از آرگومان‌های ورودی برنامه.

در این پروژه از این دو پارامتر استفاده نمی‌کنیم، اما در پروژه‌های پیشرفته‌تر کاربرد دارند.

### ۳. تعریف متغیر

```c
int n;
```

در این قسمت یک متغیر با نام `n` و از نوع `int` تعریف می‌کنیم.

این متغیر برای ذخیره عدد صحیحی استفاده می‌شود که کاربر وارد می‌کند.

### ۴. نمایش پیام به کاربر

```c
printf("Please enter an integer number: ");
```

تابع `printf()` پیام موردنظر را روی صفحه‌نمایش نمایش می‌دهد و از کاربر می‌خواهد یک عدد صحیح وارد کند.

### ۵. دریافت ورودی از کاربر

```c
scanf("%d", &n);
```

تابع `scanf()` برای دریافت اطلاعات از کاربر استفاده می‌شود.

در این دستور دو بخش مهم وجود دارد:

- `%d`: مشخص می‌کند که نوع داده ورودی باید عدد صحیح (Integer) باشد.
- `&n`: آدرس حافظه متغیر `n` را به تابع `scanf()` می‌دهد تا مقدار واردشده را در آن ذخیره کند.

**نکته مهم:** علامت `&` در زبان C عملگر آدرس (Address-of Operator) نام دارد.

### ۶. رفتن به خط بعدی

```c
printf("\n");
```

کاراکتر کنترلی `\n` باعث انتقال مکان‌نما (Cursor) به خط بعدی می‌شود.

### ۷. نمایش عدد واردشده

```c
printf("User entered this number: %d\n", n);
```

در این دستور مقدار ذخیره‌شده در متغیر `n` نمایش داده می‌شود.

عبارت `%d` با مقدار متغیر `n` جایگزین می‌شود.

### ۸. پایان برنامه

```c
return 0;
```

با اجرای این دستور، برنامه با موفقیت خاتمه پیدا می‌کند.

## نمونه خروجی (Example Output)

```text
Please enter an integer number: 25

User entered this number: 25
```

## مفاهیم مهم (Important Concepts)

| دستور یا مفهوم | توضیحات |
|---|---|
| `int` | تعریف متغیر عدد صحیح |
| `printf()` | نمایش اطلاعات |
| `scanf()` | دریافت اطلاعات از کاربر |
| `%d` | قالب دریافت یا نمایش عدد صحیح |
| `&` | عملگر آدرس |
| `\n` | رفتن به خط بعدی |
| `return 0` | پایان موفقیت‌آمیز برنامه |

## نکات مهم (Important Notes)

- هنگام دریافت مقدار برای متغیرهای معمولی با `scanf()`، باید از عملگر `&` استفاده کنید. برای مثال: `scanf("%d", &n);`.
- قالب ورودی باید با نوع متغیر مطابقت داشته باشد.
- متن اولیه برنامه دارای چند اشتباه تایپی بود. شکل صحیح پیام ورودی این است:

```c
printf("Please enter an integer number: ");
```

- در برنامه‌های حرفه‌ای بهتر است مقدار بازگشتی تابع `scanf()` بررسی شود تا از معتبر بودن ورودی اطمینان حاصل کنیم.

مثال:

```c
if (scanf("%d", &n) == 1)
{
    printf("You entered: %d\n", n);
}
else
{
    printf("Invalid input!\n");
}
```
