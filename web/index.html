Introduction

What this course is

This is a progressive, hands-on C course kept as a single repository and split into 40 numbered lesson folders. Each lesson is a small, self-contained program plus its own documentation, and the numbering follows the order the topics are meant to be studied in — from printing a line of text to structures, function pointers and enumerations.

Every lesson builds on the ones before it, so reading the lessons in order gives a complete beginner-to-intermediate path through the language. The programs are short enough to read in one sitting and are meant to be compiled, run and modified.

Each lesson's notes in the repository are available in both English and Persian (Readme.md and Readme_Fa.md). The pages on this site reproduce the English notes of every lesson.

  • Read the lesson page — concept, code and explanation.
  • Compile the matching .c file with GCC.
  • Run it, then change something and observe the result.
  • Practise with the exercises at the end of the notes.

Getting started

Build and run a lesson

You only need a C compiler. The repository's examples are built with GCC.

Compile one lesson

Terminal
gcc -Wall -g 5-EvenOdd_PositiveNegative_Zero/main.c -o evenodd
./evenodd

Lessons 10, 12, 14, 16 and 39 use <math.h> and need -lm on Linux and macOS, for example gcc -Wall 14-Quadratic_Equation_Solver/main.c -o quad -lm.

Or use Visual Studio Code

Open the repository in VS Code, open a .c file and press Ctrl+Shift+B to run the provided C/C++: gcc.exe build active file task. The binary is written next to the source. If your compiler is not at C:\mingw64\bin\gcc.exe, update the command field in .vscode/tasks.json.

Known quirks in the code

These are part of the repository as it stands, kept so that earlier lessons stay exactly as they were written.

Lesson 5 has a real bug worth fixing.

The sign branches print "%d is Positive.\n" without passing a, so the number is missing. Adding the argument is a good first exercise.

25-…/mian.c

The source file is misspelled (mian instead of main), and its binary is therefore mian.exe.

4-SimppleAdder_Scanf

"Simpple" is the original spelling — build commands must match it.

A folder name with a space

36-Reading_Strings_with_scanf_Using_Scanset _in_C_Language contains a space, so quote paths in the shell.

#include "stdio.h"

Lessons 1–4 use quotes instead of angle brackets. It compiles, but <stdio.h> is the portable form.

Lesson 13 is deliberately slow.

Printing F(0)…F(44) with the recursive implementation performs billions of calls.
