Formatting Floating-Point Numbers Using printf() and sprintf() in C

1. Introduction

In C programming, we often need to display numbers in a formatted way or convert numeric values into strings.

For example, consider these two floating-point numbers:

C
double x = 10.5624;
double y = -4.8746;

Sometimes, displaying all decimal places is unnecessary. We may want to display only two digits after the decimal point:

Output
(x = 10.56, y = -4.87)

C provides several functions for formatted output. Two commonly used functions are:

  • printf() – Formats and displays data directly on the standard output (usually the terminal).
  • sprintf() – Formats data and stores the resulting text inside a character array (string).

In this tutorial, we will learn how to use both functions and understand their differences.

2. Required Header Files

C
#include <stdio.h>
#include <stdlib.h>

stdio.h

The stdio.h header provides standard input/output functions, including:

  • printf() – Displays formatted output.
  • sprintf() – Writes formatted output into a string.
  • puts() – Displays a string followed by a newline.

stdlib.h

The stdlib.h header provides general-purpose utility functions, such as:

  • malloc()
  • free()
  • atoi()
  • strtod()
  • exit()

Note: This example does not use any function from stdlib.h, so this header can be removed without affecting the program.

3. Complete Source Code

C
#include <stdio.h>
#include <stdlib.h>

int main()
{
    double x = 10.5624;
    double y = -4.8746;

    printf("Using printf function:\n");
    printf("(x = %.2f, y = %.2f)", x, y);
    printf("\n\n");

    char str[100];

    sprintf(str, "(x = %.2f, y = %.2f)", x, y);

    printf("Using sprintf function:\n");
    puts(str);
    printf("\n\n");

    return 0;
}

4. Understanding the Code

4.1. Declaring Floating-Point Variables

C
double x = 10.5624;
double y = -4.8746;

Here, we declare two variables of type double.

The double data type stores floating-point numbers with more precision than the float data type.

VariableValue
x10.5624
y-4.8746

These values will be used to demonstrate formatted output.

4.2. Displaying Text with printf()

C
printf("Using printf function:\n");

The printf() function displays formatted text on the standard output.

The special character \n represents a newline.

Therefore, the program prints the heading and moves the cursor to the next line.

4.3. Formatting Floating-Point Numbers

C
printf("(x = %.2f, y = %.2f)", x, y);

This statement is the most important part of the first example.

The printf() function uses format specifiers to determine how values should be displayed.

The format specifier:

C
%.2f

means:

  • % indicates the beginning of a format specifier.
  • .2 specifies two digits after the decimal point.
  • f indicates a floating-point value formatted in decimal notation.

For example:

Original valueFormatDisplayed value
10.5624%.2f10.56
-4.8746%.2f-4.87
10.5624%.3f10.562
-4.8746%.1f-4.9
10.5624%.0f11

The number of decimal places is controlled by the precision specified after the decimal point.

Important: Formatting with %.2f changes only the displayed representation. It does not modify the original value stored in the variable.

For example:

C
double x = 10.5624;

printf("%.2f\n", x);
printf("%.4f\n", x);

Output:

Output
10.56
10.5624

The original value of x remains 10.5624.

4.4. Adding New Lines

C
printf("\n\n");

This statement prints two newline characters.

It creates two line breaks, leaving an empty line before the next section of the output.

4.5. Declaring a Character Array

C
char str[100];

Here, we declare a character array named str with a capacity of 100 characters.

In C, a string is stored as a sequence of characters terminated by a special character called the null terminator:

C
'\0'

For example, the string:

Output
Hello

is stored in memory as:

Output
'H' 'e' 'l' 'l' 'o' '\0'

The array has enough space to store the formatted text generated by this example.

4.6. Understanding sprintf()

C
sprintf(str, "(x = %.2f, y = %.2f)", x, y);

The sprintf() function works similarly to printf(), but instead of displaying the formatted result on the terminal, it stores the result inside a character array.

Its general syntax is:

C
sprintf(destination, format, value1, value2, ...);

Parameters:

ParameterDescription
destinationCharacter array where the formatted text is stored
formatFormatting string containing ordinary text and format specifiers
value1, value2, ...Values used to replace the format specifiers

In our example:

C
sprintf(str, "(x = %.2f, y = %.2f)", x, y);

The function:

  1. Reads the value of x.
  2. Formats it with two decimal places.
  3. Reads the value of y.
  4. Formats it with two decimal places.
  5. Stores the complete formatted string in str.
  6. Adds the null terminator '\0' at the end.

After this statement, str contains:

Output
(x = 10.56, y = -4.87)

Important: sprintf() does not check the size of the destination array. If the formatted output is larger than the available buffer, it can write beyond the array boundaries and cause undefined behavior.

For safer formatting, use snprintf():

C
snprintf(str, sizeof(str), "(x = %.2f, y = %.2f)", x, y);

The second argument specifies the maximum size of the destination buffer, including space for the null terminator.

For this example, snprintf() is recommended.

4.7. Displaying the Formatted String with puts()

C
printf("Using sprintf function:\n");
puts(str);

The first statement displays a heading.

The second statement displays the string stored in str.

The puts() function automatically adds a newline after printing the string.

Therefore:

C
puts(str);

is generally equivalent to:

C
printf("%s\n", str);

For displaying a string, both approaches are commonly used.

5. Difference Between printf(), sprintf(), and snprintf()

These functions all support formatted output, but their destinations and safety characteristics are different.

FunctionDestinationAutomatically adds null terminator?Checks destination size?
printf()Standard outputNot applicableNot applicable
sprintf()Character arrayYesNo
snprintf()Character arrayYes, when buffer size is greater than zeroYes

printf()

Displays formatted data directly:

C
printf("Temperature: %.2f\n", 25.6789);

Output:

Output
Temperature: 25.68

sprintf()

Stores formatted data in a string:

C
char buffer[50];

sprintf(buffer, "Temperature: %.2f", 25.6789);

The resulting string is:

Output
Temperature: 25.68

snprintf()

Stores formatted data in a string while limiting the number of characters written:

C
char buffer[50];

snprintf(buffer, sizeof(buffer), "Temperature: %.2f", 25.6789);

This is generally the preferred approach when formatting text into a fixed-size character array.

6. Complete Improved Version

The following version uses snprintf() instead of sprintf() to prevent writing beyond the destination buffer.

C
#include <stdio.h>

int main(void)
{
    double x = 10.5624;
    double y = -4.8746;

    printf("Using printf function:\n");
    printf("(x = %.2f, y = %.2f)\n\n", x, y);

    char str[100];

    int result = snprintf(
        str,
        sizeof(str),
        "(x = %.2f, y = %.2f)",
        x,
        y
    );

    if (result < 0)
    {
        printf("Formatting error!\n");
        return 1;
    }

    if ((size_t)result >= sizeof(str))
    {
        printf("Warning: Output was truncated!\n");
        return 1;
    }

    printf("Using snprintf function:\n");
    puts(str);

    return 0;
}

Why use snprintf()?

The function returns the number of characters that would have been written, excluding the terminating null character.

  • If the return value is negative, a formatting error occurred.
  • If the return value is greater than or equal to the buffer size, the output was truncated.
  • Otherwise, the complete formatted string was stored successfully.

The cast to size_t is safe in the comparison because the code first checks that result is nonnegative.

8. Practical Applications

Formatted string generation is useful in many C programming applications.

8.1. Creating Debug Messages

C
char message[100];

double voltage = 12.567;
double current = 2.345;

snprintf(message, sizeof(message),
         "Voltage: %.2f V, Current: %.2f A",
         voltage, current);

printf("%s\n", message);

Output:

Output
Voltage: 12.57 V, Current: 2.35 A

8.2. Preparing Data for UART Transmission

In embedded systems, you may need to convert numeric values into text before transmitting them through UART.

C
char uart_buffer[100];

float temperature = 28.65f;

snprintf(uart_buffer, sizeof(uart_buffer),
         "TEMP:%.2f\r\n", temperature);

The resulting string can then be transmitted using an appropriate UART function.

For example, in STM32 HAL:

C
HAL_UART_Transmit(
    &huart1,
    (uint8_t *)uart_buffer,
    (uint16_t)strlen(uart_buffer),
    HAL_MAX_DELAY
);

This STM32 example requires:

C
#include <string.h>

and the appropriate STM32 HAL header and UART handle declaration.

8.3. Preparing Data for TCP Communication

Formatted strings can also be used to prepare readable messages before sending them over a TCP connection.

C
char tcp_buffer[100];

double x = 10.5624;
double y = -4.8746;

int length = snprintf(
    tcp_buffer,
    sizeof(tcp_buffer),
    "X=%.2f,Y=%.2f",
    x,
    y
);

The resulting message is:

Output
X=10.56,Y=-4.87

The returned length can be used to determine how many bytes should be sent.

For TCP, remember that one send() call does not necessarily transmit the entire message. Your networking code must handle partial sends and define a message-framing protocol.

9. Common Mistakes

Mistake 1: Using sprintf() Without Considering Buffer Size

Unsafe:

C
char str[10];

sprintf(str, "Temperature: %.2f", 25.67);

The destination buffer is too small for the resulting string.

Safer:

C
char str[100];

snprintf(str, sizeof(str), "Temperature: %.2f", 25.67);

Mistake 2: Confusing Precision with Variable Accuracy

C
printf("%.2f", x);

This does not change the actual value of x. It only controls how the number is displayed.

Mistake 3: Forgetting the Null Terminator

A C string must end with '\0'.

Functions such as sprintf() and snprintf() add this terminator when there is sufficient destination space.

Mistake 4: Using %s for a Floating-Point Number

Incorrect:

C
printf("%s", x);

Correct:

C
printf("%.2f", x);

The %s specifier is used for strings, while %f is used for floating-point values passed to printf().
