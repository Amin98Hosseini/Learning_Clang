# 32- آموزش زبان C – کپی و اتصال رشته‌ها با توابع `strcpy`، `strncpy` و `strcat`

## ۱. مقدمه

در زبان برنامه‌نویسی C، رشته‌ها (Strings) به‌صورت آرایه‌ای از کاراکترها ذخیره می‌شوند.

هر رشته در زبان C با یک کاراکتر ویژه به نام **Null Terminator یا `'\0'`** به پایان می‌رسد. این کاراکتر مشخص می‌کند که رشته در کجا تمام شده است.

کتابخانه استاندارد `<string.h>` توابع مختلفی برای مدیریت و پردازش رشته‌ها در اختیار برنامه‌نویس قرار می‌دهد.

در این آموزش سه تابع مهم را بررسی می‌کنیم:

- `strcpy()` – کپی کردن یک رشته در رشته دیگر.
- `strncpy()` – کپی کردن تعداد مشخصی از کاراکترهای یک رشته.
- `strcat()` – اضافه کردن یک رشته به انتهای رشته دیگر.

این توابع از پرکاربردترین توابع کتابخانه `<string.h>` هستند.

## ۲. کتابخانه‌های موردنیاز

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
```

کاربرد هر کتابخانه:

| کتابخانه | کاربرد |
|---|---|
| `stdio.h` | برای توابع ورودی و خروجی مانند `printf()` |
| `stdlib.h` | برای توابع عمومی زبان C؛ در این برنامه ضروری نیست. |
| `string.h` | برای توابع پردازش رشته مانند `strcpy()`، `strncpy()` و `strcat()` |

در این مثال فقط به دو کتابخانه `stdio.h` و `string.h` نیاز داریم.

## ۳. کد کامل برنامه

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char s1[] = "Hello World!";
    char s2[40];
    char s3[40];

    printf("Using strcpy:\n");

    strcpy(s2, s1);

    printf("s1 = %s\n", s1);
    printf("s2 = %s\n", s2);
    printf("\n");

    printf("Using strncpy:\n");

    strncpy(s3, s1, 5);
    s3[5] = '\0';

    printf("s1 = %s\n", s1);
    printf("s3 = %s\n", s3);
    printf("\n");

    char s4[] = "World!";
    char s5[50];

    strcpy(s5, "Hello ");
    s5[6] = '\0';

    printf("Before strcat:\n");

    printf("s4 = %s\n", s4);
    printf("s5 = %s\n", s5);

    strcat(s5, s4);

    printf("After strcat:\n");

    printf("s4 = %s\n", s4);
    printf("s5 = %s\n", s5);

    return 0;
}
```

## ۴. بررسی قسمت‌های مختلف برنامه

### ۴.۱. تعریف متغیرهای رشته‌ای

```c
char s1[] = "Hello World!";
char s2[40];
char s3[40];
```

در این قسمت سه آرایه از نوع `char` تعریف شده‌اند.

- `s1` شامل رشته `"Hello World!"` است.
- `s2` یک آرایه با ظرفیت ۴۰ کاراکتر است.
- `s3` نیز یک آرایه با ظرفیت ۴۰ کاراکتر است.

هنگامی که یک رشته را با استفاده از علامت دابل کوتیشن تعریف می‌کنیم، کامپایلر به‌صورت خودکار کاراکتر `'\0'` را در انتهای آن قرار می‌دهد.

برای مثال، رشته `"Hello"` در حافظه به شکل زیر ذخیره می‌شود:

```text
H  e  l  l  o  \0
```

کاراکتر `'\0'` پایان رشته را مشخص می‌کند.

### ۴.۲. تابع `strcpy()` – کپی کردن رشته

```c
strcpy(s2, s1);
```

تابع `strcpy()` برای کپی کردن کامل یک رشته در آرایه رشته‌ای دیگر استفاده می‌شود.

ساختار کلی تابع:

```c
strcpy(destination, source);
```

دو ورودی اصلی این تابع عبارت‌اند از:

- `destination`: آرایه مقصد که اطلاعات در آن کپی می‌شوند.
- `source`: رشته مبدأ که قرار است کپی شود.

در برنامه ما:

```c
strcpy(s2, s1);
```

محتویات `s1` درون `s2` کپی می‌شود.

بنابراین بعد از اجرای تابع:

```text
s1 = Hello World!
s2 = Hello World!
```

نکته مهم این است که تابع `strcpy()` علاوه بر کاراکترهای رشته، کاراکتر پایان‌دهنده `'\0'` را نیز کپی می‌کند.

پس آرایه مقصد باید فضای کافی برای تمام کاراکترهای رشته و کاراکتر پایان‌دهنده داشته باشد.

برای رشته `"Hello World!"` به ۱۳ بایت فضا نیاز داریم:

- ۱۲ بایت برای کاراکترهای رشته
- ۱ بایت برای `'\0'`

از آنجایی که `s2` دارای ۴۰ بایت ظرفیت است، عملیات کپی در این مثال ایمن است.

### ۴.۳. تابع `strncpy()` – کپی تعداد مشخصی از کاراکترها

```c
strncpy(s3, s1, 5);
s3[5] = '\0';
```

تابع `strncpy()` برای کپی کردن تعداد مشخصی از کاراکترهای رشته مبدأ در آرایه مقصد استفاده می‌شود.

ساختار کلی:

```c
strncpy(destination, source, number_of_characters);
```

پارامترهای تابع:

- `destination`: آرایه مقصد
- `source`: رشته مبدأ
- `number_of_characters`: حداکثر تعداد کاراکترهایی که باید کپی شوند.

در برنامه ما:

```c
strncpy(s3, s1, 5);
```

فقط پنج کاراکتر اول رشته `s1` در آرایه `s3` کپی می‌شوند.

در نتیجه:

```text
s1 = Hello World!
s3 = Hello
```

**تفاوت مهم `strncpy()` با `strcpy()`**

تابع `strncpy()` برخلاف `strcpy()` همیشه کاراکتر پایان‌دهنده `'\0'` را به انتهای رشته مقصد اضافه نمی‌کند.

اگر طول رشته مبدأ برابر یا بیشتر از تعداد کاراکترهای تعیین‌شده باشد، ممکن است رشته مقصد فاقد Null Terminator باشد.

به همین دلیل در برنامه از دستور زیر استفاده شده است:

```c
s3[5] = '\0';
```

این دستور به‌صورت دستی کاراکتر پایان‌دهنده را در اندیس ۵ قرار می‌دهد.

بدون این دستور، چاپ `s3` با استفاده از `%s` می‌تواند باعث خواندن اطلاعات خارج از محدوده رشته و ایجاد رفتار تعریف‌نشده (Undefined Behavior) شود.

### ۴.۴. آماده‌سازی رشته‌ها برای اتصال

```c
char s4[] = "World!";
char s5[50];
```

در این قسمت دو آرایه رشته‌ای تعریف می‌کنیم:

- `s4` شامل `"World!"` است.
- `s5` یک آرایه با ظرفیت ۵۰ بایت است.

سپس دستور زیر اجرا می‌شود:

```c
strcpy(s5, "Hello ");
```

این دستور رشته `"Hello "` را درون `s5` کپی می‌کند.

محتویات `s5` پس از اجرای دستور:

```text
Hello \0
```

سپس در کد اصلی داریم:

```c
s5[6] = '\0';
```

این دستور کاراکتر Null Terminator را در اندیس ۶ قرار می‌دهد.

البته در این برنامه، این دستور اضافه است؛ زیرا تابع `strcpy()` قبلاً Null Terminator را در همین موقعیت قرار داده است.

جدول اندیس‌های رشته:

| اندیس | کاراکتر |
|---:|:---:|
| ۰ | H |
| ۱ | e |
| ۲ | l |
| ۳ | l |
| ۴ | o |
| ۵ | Space |
| ۶ | `'\0'` |

### ۴.۵. تابع `strcat()` – اتصال دو رشته

```c
strcat(s5, s4);
```

تابع `strcat()` برای اضافه کردن محتوای یک رشته به انتهای رشته دیگر استفاده می‌شود.

ساختار کلی:

```c
strcat(destination, source);
```

در این مثال:

- رشته مقصد `s5` است که شامل `"Hello "` است.
- رشته مبدأ `s4` است که شامل `"World!"` است.

پس از اجرای تابع:

```c
strcat(s5, s4);
```

محتوای رشته `s4` به انتهای رشته `s5` اضافه می‌شود.

نتیجه:

```text
Hello World!
```

نمایش ساده نحوه ذخیره‌سازی در حافظه:

```text
H  e  l  l  o     W  o  r  l  d  !  \0
```

توجه کنید که فاصله موجود در انتهای `"Hello "` حفظ می‌شود و به همین دلیل خروجی به‌صورت `"Hello World!"` خواهد بود.

همچنین رشته اصلی `s4` تغییر نمی‌کند؛ زیرا تابع `strcat()` فقط محتوای آن را به انتهای رشته مقصد اضافه می‌کند.

**نکته بسیار مهم:**

آرایه مقصد باید فضای کافی برای رشته فعلی، رشته جدید و کاراکتر پایانی `'\0'` داشته باشد.

در این برنامه `s5` دارای ۵۰ بایت ظرفیت است؛ بنابراین فضای کافی برای نتیجه نهایی وجود دارد.

## ۵. خروجی برنامه

با اجرای برنامه، خروجی زیر نمایش داده می‌شود:

```text
Using strcpy:
s1 = Hello World!
s2 = Hello World!

Using strncpy:
s1 = Hello World!
s3 = Hello

Before strcat:
s4 = World!
s5 = Hello
After strcat:
s4 = World!
s5 = Hello World!
```

## ۶. مقایسه توابع رشته‌ای

| تابع | کاربرد | کپی کردن Null Terminator |
|---|---|---|
| `strcpy()` | کپی کامل رشته | بله |
| `strncpy()` | کپی حداکثر تعداد مشخصی کاراکتر | همیشه خیر |
| `strcat()` | اضافه کردن رشته به انتهای رشته دیگر | بله، در انتهای نتیجه |

تفاوت اصلی این توابع:

**تابع `strcpy()`**

```c
strcpy(destination, source);
```

تمام رشته مبدأ را همراه با کاراکتر پایان‌دهنده کپی می‌کند.

**تابع `strncpy()`**

```c
strncpy(destination, source, n);
```

حداکثر `n` کاراکتر را کپی می‌کند و در بعضی شرایط Null Terminator را اضافه نمی‌کند.

**تابع `strcat()`**

```c
strcat(destination, source);
```

ابتدا انتهای رشته مقصد را پیدا می‌کند و سپس رشته مبدأ را به آن اضافه می‌کند.

## ۷. نکات ایمنی و روش‌های بهتر

توابع استاندارد `strcpy()`، `strncpy()` و `strcat()` ظرفیت واقعی آرایه مقصد را نمی‌دانند.

بنابراین برنامه‌نویس باید قبل از استفاده از آن‌ها مطمئن شود که فضای کافی در آرایه مقصد وجود دارد.

### ۷.۱. جایگزین ایمن‌تر برای `strcpy()`

برای کپی رشته با محدود کردن فضای خروجی می‌توان از `snprintf()` استفاده کرد:

```c
char destination[20];
const char source[] = "Hello World!";

snprintf(destination, sizeof(destination), "%s", source);

printf("%s\n", destination);
```

تابع `snprintf()` تعداد بایت‌های نوشته‌شده را محدود می‌کند و فضای Null Terminator را نیز در نظر می‌گیرد.

### ۷.۲. جایگزین ایمن‌تر برای `strcat()`

برای اتصال دو رشته نیز می‌توان از `snprintf()` استفاده کرد:

```c
char destination[30] = "Hello ";
const char source[] = "World!";

size_t used = strlen(destination);

snprintf(destination + used,
         sizeof(destination) - used,
         "%s",
         source);

printf("%s\n", destination);
```

در این مثال ابتدا طول رشته موجود در `destination` با تابع `strlen()` محاسبه می‌شود.

سپس با استفاده از `destination + used`، آدرس محل پایان رشته فعلی به تابع داده می‌شود تا رشته جدید از همان نقطه نوشته شود.

همچنین با استفاده از:

```c
sizeof(destination) - used
```

فقط فضای باقی‌مانده آرایه در اختیار تابع قرار می‌گیرد.

در برنامه‌های واقعی بهتر است مقدار بازگشتی `snprintf()` نیز بررسی شود تا مشخص شود خروجی به دلیل کمبود فضا ناقص نشده است.

## ۸. خطاهای رایج

۱. **کوچک بودن آرایه مقصد**

اگر فضای کافی برای کپی یا اتصال رشته‌ها وجود نداشته باشد، ممکن است برنامه دچار رفتار تعریف‌نشده شود.

۲. **فراموش کردن Null Terminator**

تابع `strncpy()` در همه شرایط کاراکتر `'\0'` را به انتهای رشته اضافه نمی‌کند.

۳. **استفاده از `strcat()` روی آرایه مقداردهی‌نشده**

تابع `strcat()` نیاز دارد که آرایه مقصد از قبل شامل یک رشته معتبر و پایان‌یافته با `'\0'` باشد.

روش اشتباه:

```c
char s[30];
strcat(s, "Hello");
```

روش صحیح:

```c
char s[30] = "";
strcat(s, "Hello");
```

۴. **اشتباه گرفتن کپی و اتصال رشته**

- `strcpy()` محتوای قبلی مقصد را جایگزین می‌کند.
- `strcat()` رشته جدید را به انتهای محتوای قبلی مقصد اضافه می‌کند.

۵. **نادیده گرفتن ظرفیت آرایه**

همیشه باید فضای موردنیاز برای کاراکترهای رشته و Null Terminator محاسبه شود.

## ۱۰. تمرین‌ها

برای تسلط بیشتر بر توابع رشته‌ای، تمرین‌های زیر را انجام دهید.

**تمرین ۱ – کپی کردن رشته**

دو آرایه رشته‌ای تعریف کنید و با استفاده از `strcpy()` محتوای آرایه اول را در آرایه دوم کپی کنید.

**تمرین ۲ – کپی تعداد مشخصی کاراکتر**

برنامه‌ای بنویسید که یک رشته از کاربر دریافت کند و فقط پنج کاراکتر اول آن را با استفاده از `strncpy()` در آرایه دیگری کپی کند.

فراموش نکنید که رشته مقصد باید با `'\0'` پایان یابد.

**تمرین ۳ – اتصال دو رشته**

دو رشته زیر را تعریف کنید:

```c
char first[50] = "Embedded ";
char second[] = "Systems";
```

با استفاده از `strcat()` آن‌ها را به هم متصل کنید تا خروجی زیر تولید شود:

```text
Embedded Systems
```

**تمرین ۴ – اتصال سه رشته**

سه رشته زیر را تعریف کنید:

```c
char s1[] = "STM32";
char s2[] = " ";
char s3[] = "Programming";
```

با استفاده از `strcpy()` و `strcat()` خروجی زیر را تولید کنید:

```text
STM32 Programming
```

**تمرین ۵ – برنامه اتصال ایمن رشته‌ها**

برنامه‌ای بنویسید که:

۱. دو رشته از کاربر دریافت کند.

۲. هر رشته را در یک آرایه جداگانه ذخیره کند.

۳. محتوای دو رشته را در آرایه سوم به هم متصل کند.

۴. قبل از اتصال، ظرفیت آرایه مقصد را بررسی کند.

۵. رشته نهایی را چاپ کند.

## ۱۱. اهداف آموزشی

پس از مطالعه این آموزش باید بتوانید:

- نحوه ذخیره‌سازی رشته‌ها در آرایه‌های `char` را توضیح دهید.
- اهمیت کاراکتر پایان‌دهنده `'\0'` را درک کنید.
- با استفاده از `strcpy()` یک رشته را کپی کنید.
- با استفاده از `strncpy()` تعداد مشخصی از کاراکترها را کپی کنید.
- تفاوت `strcpy()` و `strncpy()` را تشخیص دهید.
- با استفاده از `strcat()` دو رشته را به هم متصل کنید.
- با استفاده از `strlen()` طول یک رشته را محاسبه کنید.
- از سرریز حافظه هنگام کار با رشته‌ها جلوگیری کنید.
- از `snprintf()` برای کپی و اتصال ایمن‌تر رشته‌ها استفاده کنید.
