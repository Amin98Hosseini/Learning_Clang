# 11- تحلیل آماری نمرات در زبان C

## 1. معرفی برنامه

این برنامه مجموعه‌ای از نمرات دانشجویان را از ورودی دریافت می‌کند و تعداد تکرار هر نمره را محاسبه می‌کند.

نمرات قابل قبول عبارت‌اند از:

- `A` یا `a`
- `B` یا `b`
- `C` یا `c`
- `D` یا `d`
- `F` یا `f`

پس از پایان دریافت ورودی، برنامه موارد زیر را محاسبه می‌کند:

1. تعداد تکرار هر نمره.
2. درصد هر نمره نسبت به کل نمرات.
3. درصد تجمعی نمرات.
4. بررسی اینکه آیا بیش از ۶۰ درصد نمرات شامل A، B یا C هستند یا خیر.

در این برنامه از تابع `getchar()` برای دریافت کاراکترها استفاده شده است. دریافت ورودی تا زمانی ادامه پیدا می‌کند که برنامه به مقدار `EOF` برسد.

## 2. کد برنامه

```c
#include <stdio.h>
#define TRUE -1

int main()
{
    char g;
    int nA = 0;
    int nB = 0;
    int nC = 0;
    int nD = 0;
    int nF = 0;

    while((g = getchar()) != EOF)
    {
        switch(g)
        {
            case 'A':
            case 'a':
                nA++;
                break;

            case 'B':
            case 'b':
                nB++;
                break;

            case 'C':
            case 'c':
                nC++;
                break;

            case 'D':
            case 'd':
                nD++;
                break;

            case 'F':
            case 'f':
                nF++;
                break;

            case ' ':
            case '\n':
            case '\t':
                break;

            default:
                printf("Incorrect input. Please enter from letters set {A, B, C, D, F}.\n");
                break;
        }
    }

    int n = nA + nB + nC + nD + nF;

    int cA = nA;
    int cB = nB + cA;
    int cC = nC + cB;
    int cD = nD + cC;
    int cF = nF + cD;

    printf("Grade\tCount\tPercent\tCum. Percent\n");
    printf("A\t%d of %d\t%.2f\t%.2f\n", nA, n, (float)nA*100/n, (float)cA*100/n);
    printf("B\t%d of %d\t%.2f\t%.2f\n", nB, n, (float)nB*100/n, (float)cB*100/n);
    printf("C\t%d of %d\t%.2f\t%.2f\n", nC, n, (float)nC*100/n, (float)cC*100/n);
    printf("D\t%d of %d\t%.2f\t%.2f\n", nD, n, (float)nD*100/n, (float)cD*100/n);
    printf("F\t%d of %d\t%.2f\t%.2f\n", nF, n, (float)nF*100/n, (float)cF*100/n);

    if((float)cC/n > 0.6)
    {
        printf("\nCongratulations to Teacher!\n");
    }

    return 0;
}
```

## 3. مبانی ریاضی برنامه

این برنامه برای تحلیل نمرات از دو نوع محاسبه درصد استفاده می‌کند:

- درصد مستقل هر نمره
- درصد تجمعی نمرات

### 3.1. محاسبه تعداد کل نمرات

ابتدا تعداد کل نمرات معتبر محاسبه می‌شود:

\[
n=n_A+n_B+n_C+n_D+n_F
\]

که در آن:

- \(n_A\): تعداد نمرات A
- \(n_B\): تعداد نمرات B
- \(n_C\): تعداد نمرات C
- \(n_D\): تعداد نمرات D
- \(n_F\): تعداد نمرات F

### 3.2. محاسبه درصد هر نمره

برای محاسبه درصد هر گروه از رابطه زیر استفاده می‌کنیم:

\[
P_X=\frac{n_X}{n}\times100
\]

برای مثال، اگر تعداد کل نمرات ۲۰ باشد و ۵ نفر نمره A گرفته باشند:

\[
P_A=\frac{5}{20}\times100=25\%
\]

بنابراین ۲۵ درصد از کل دانشجویان نمره A گرفته‌اند.

### 3.3. محاسبه درصد تجمعی

درصد تجمعی نشان می‌دهد که مجموع درصد نمرات تا گروه موردنظر چقدر است.

ابتدا تعداد تجمعی را محاسبه می‌کنیم:

\[
c_A=n_A
\]

\[
c_B=n_A+n_B
\]

\[
c_C=n_A+n_B+n_C
\]

\[
c_D=n_A+n_B+n_C+n_D
\]

\[
c_F=n_A+n_B+n_C+n_D+n_F
\]

سپس درصد تجمعی از رابطه زیر به دست می‌آید:

\[
CP_X=\frac{c_X}{n}\times100
\]

برای مثال:

\[
CP_C=\frac{n_A+n_B+n_C}{n}\times100
\]

این مقدار نشان می‌دهد چند درصد از دانشجویان نمره A، B یا C گرفته‌اند.

## 4. بررسی بخش‌های مختلف برنامه

### 4.1. اضافه کردن کتابخانه ورودی و خروجی

```c
#include <stdio.h>
```

کتابخانه `stdio.h` امکانات استاندارد ورودی و خروجی زبان C را فراهم می‌کند.

در این برنامه از موارد زیر استفاده شده است:

- `getchar()` برای دریافت یک کاراکتر.
- `printf()` برای نمایش اطلاعات.
- `EOF` برای تشخیص پایان ورودی.

### 4.2. تعریف یک ماکرو

```c
#define TRUE -1
```

دستور `#define` برای تعریف ماکرو در مرحله پیش‌پردازش استفاده می‌شود.

در این برنامه مقدار `TRUE` برابر با `-1` تعریف شده است، اما در هیچ قسمتی از کد استفاده نمی‌شود.

بنابراین حذف آن هیچ تغییری در عملکرد برنامه ایجاد نمی‌کند.

### 4.3. تعریف متغیرها

```c
char g;

int nA = 0;
int nB = 0;
int nC = 0;
int nD = 0;
int nF = 0;
```

متغیر `g` برای ذخیره کاراکتر دریافت‌شده از ورودی استفاده می‌شود.

پنج متغیر دیگر شمارنده هستند و تعداد تکرار هر نمره را نگهداری می‌کنند.

تمام شمارنده‌ها با مقدار صفر مقداردهی اولیه شده‌اند؛ زیرا در ابتدای برنامه هنوز هیچ نمره‌ای دریافت نشده است.

### 4.4. دریافت کاراکتر با getchar()

```c
while((g = getchar()) != EOF)
```

تابع `getchar()` یک کاراکتر از ورودی استاندارد دریافت می‌کند.

حلقه `while` تا زمانی ادامه پیدا می‌کند که مقدار دریافت‌شده برابر با `EOF` نباشد.

`EOF` مخفف End Of File است و نشان‌دهنده پایان ورودی است.

برای ارسال EOF در ترمینال:

- در ویندوز: کلیدهای `Ctrl + Z` و سپس Enter
- در لینوکس و macOS: کلیدهای `Ctrl + D`

**نکته مهم:** تابع `getchar()` مقدار بازگشتی از نوع `int` دارد، نه `char`.

دلیل این موضوع آن است که تابع باید بتواند تمام مقادیر ممکن کاراکترها و همچنین مقدار ویژه `EOF` را نمایش دهد.

بنابراین بهتر است متغیر `g` به شکل زیر تعریف شود:

```c
int g;
```

به‌جای:

```c
char g;
```

این کار تشخیص صحیح `EOF` را تضمین می‌کند.

### 4.5. استفاده از switch-case

```c
switch(g)
{
    case 'A':
    case 'a':
        nA++;
        break;
}
```

دستور `switch` مقدار متغیر `g` را بررسی می‌کند و بر اساس مقدار آن، بخش مناسب را اجرا می‌کند.

در این برنامه حروف بزرگ و کوچک هر دو پذیرفته می‌شوند.

برای مثال:

```c
case 'A':
case 'a':
    nA++;
    break;
```

هر دو حالت باعث اجرای دستور زیر می‌شوند:

```c
nA++;
```

عملگر `++` مقدار متغیر را یک واحد افزایش می‌دهد.

دستور `break` نیز از اجرای ناخواسته Case بعدی جلوگیری می‌کند.

### 4.6. نادیده گرفتن کاراکترهای فاصله

```c
case ' ':
case '\n':
case '\t':
    break;
```

در این قسمت سه نوع کاراکتر نادیده گرفته می‌شوند:

| کاراکتر | مفهوم |
|---|---|
| `' '` | فاصله معمولی |
| `'\n'` | رفتن به خط بعد |
| `'\t'` | فاصله افقی یا Tab |

با این روش می‌توان نمرات را در خطوط مختلف یا با فاصله از یکدیگر وارد کرد.

### 4.7. مدیریت ورودی نامعتبر

```c
default:
    printf("Incorrect input. Please enter from letters set {A, B, C, D, F}.\n");
    break;
```

بخش `default` زمانی اجرا می‌شود که کاراکتر ورودی با هیچ‌کدام از نمرات مجاز یا کاراکترهای فاصله مطابقت نداشته باشد.

برای مثال، اگر کاربر کاراکتر `X` را وارد کند، پیام خطا نمایش داده می‌شود.

کاراکتر نامعتبر در هیچ‌کدام از شمارنده‌های نمرات ثبت نمی‌شود.

### 4.8. محاسبه تعداد کل نمرات

```c
int n = nA + nB + nC + nD + nF;
```

پس از پایان حلقه، تعداد تمام نمرات معتبر با یکدیگر جمع می‌شوند.

نکته مهم این است که کاراکترهای فاصله، Tab، خط جدید و ورودی‌های نامعتبر در این مقدار محاسبه نمی‌شوند.

### 4.9. محاسبه تعداد تجمعی

```c
int cA = nA;
int cB = nB + cA;
int cC = nC + cB;
int cD = nD + cC;
int cF = nF + cD;
```

متغیرهای `cA` تا `cF` تعداد تجمعی نمرات را نگهداری می‌کنند.

برای مثال:

```c
int cC = nC + cB;
```

از آنجایی که `cB` شامل تعداد نمرات A و B است، مقدار `cC` برابر مجموع نمرات A، B و C خواهد بود.

### 4.10. نمایش نتایج

```c
printf("Grade\tCount\tPercent\tCum. Percent\n");
```

کاراکتر `\t` برای ایجاد فاصله افقی و مرتب‌سازی ستون‌های خروجی استفاده می‌شود.

برای مثال:

```c
printf("A\t%d of %d\t%.2f\t%.2f\n",
       nA, n, (float)nA*100/n, (float)cA*100/n);
```

معنی قالب‌های استفاده‌شده در `printf()`:

| قالب | مفهوم |
|---|---|
| `%d` | نمایش عدد صحیح |
| `%f` | نمایش عدد اعشاری |
| `%.2f` | نمایش عدد اعشاری با دو رقم بعد از ممیز |
| `\t` | ایجاد فاصله افقی |
| `\n` | رفتن به خط بعد |

عبارت زیر را در نظر بگیرید:

```c
(float)nA * 100 / n
```

با تبدیل `nA` به نوع `float`، محاسبات به صورت اعشاری انجام می‌شوند.

این کار مهم است؛ زیرا در تقسیم اعداد صحیح، قسمت اعشاری نتیجه حذف می‌شود.

### 4.11. بررسی عملکرد معلم

```c
if((float)cC/n > 0.6)
{
    printf("\nCongratulations to Teacher!\n");
}
```

در این قسمت بررسی می‌شود که آیا نسبت نمرات A، B و C به کل نمرات بیشتر از ۶۰ درصد است یا خیر.

شرط ریاضی آن به شکل زیر است:

\[
\frac{c_C}{n}>0.6
\]

اگر برای مثال ۷۰ درصد دانشجویان نمره A، B یا C گرفته باشند، شرط برقرار شده و پیام تبریک نمایش داده می‌شود.

## 6. مفاهیم برنامه‌نویسی یادگرفته‌شده

با بررسی این برنامه، مفاهیم زیر را یاد می‌گیرید:

1. **دریافت کاراکتر:** استفاده از `getchar()` برای خواندن کاراکترها.
2. **تشخیص پایان ورودی:** استفاده از `EOF`.
3. **حلقه while:** تکرار دستورات تا زمانی که شرط برقرار باشد.
4. **ساختار switch-case:** انتخاب عملیات بر اساس مقدار یک کاراکتر.
5. **شمارنده‌ها:** استفاده از متغیرهای عدد صحیح برای شمارش.
6. **عملگر افزایش:** استفاده از `++`.
7. **دستور break:** خروج از Case جاری.
8. **بخش default:** مدیریت ورودی‌های غیرمجاز.
9. **تبدیل نوع داده:** تبدیل `int` به `float`.
10. **محاسبه درصد:** به دست آوردن درصد هر گروه.
11. **محاسبه تجمعی:** محاسبه تعداد و درصد تجمعی.
12. **دستور شرطی:** استفاده از `if`.
13. **قالب‌بندی خروجی:** استفاده از قالب‌های `printf()`.

## 7. نکات مهم و بهبودهای احتمالی

برنامه ارائه‌شده برای یادگیری مفاهیم مختلف زبان C مناسب است؛ اما چند نکته مهم در آن وجود دارد.

### 7.1. استفاده از int برای getchar()

روش پیشنهادی:

```c
int g;

while((g = getchar()) != EOF)
{
    switch(g)
    {
        /* grade cases */
    }
}
```

استفاده از `int` باعث می‌شود مقدار ویژه `EOF` به‌درستی قابل تشخیص باشد.

### 7.2. جلوگیری از تقسیم بر صفر

اگر کاربر هیچ نمره معتبری وارد نکند:

```c
int n = 0;
```

در این شرایط محاسبه درصد باعث تقسیم بر صفر می‌شود.

برای جلوگیری از این مشکل، پس از محاسبه `n` و قبل از محاسبه درصدها، کد زیر را اضافه کنید:

```c
if(n == 0)
{
    printf("No valid grades were entered.\n");
    return 0;
}
```

### 7.3. حذف ماکروی استفاده‌نشده

```c
#define TRUE -1
```

این ماکرو در هیچ قسمت برنامه استفاده نشده است و می‌توان آن را بدون تغییر عملکرد برنامه حذف کرد.

### 7.4. درک مفهوم درصد تجمعی

درصد تجمعی نمره C شامل مجموع نمرات A، B و C است.

این مقدار فقط درصد نمرات C نیست.

در مثال بالا:

- درصد A برابر ۳۰ درصد است.
- درصد B برابر ۳۰ درصد است.
- درصد C برابر ۲۰ درصد است.
- درصد تجمعی تا C برابر ۸۰ درصد است.

### 7.5. مدیریت بهتر ورودی‌های نامعتبر

در برنامه فعلی برای هر کاراکتر نامعتبر یک پیام خطا نمایش داده می‌شود.

برای مثال، اگر ورودی `ABCX` باشد، برای کاراکتر `X` پیام خطا نمایش داده می‌شود.

می‌توان برنامه را توسعه داد تا تعداد ورودی‌های نامعتبر را نیز محاسبه کند یا فقط یک پیام خلاصه در پایان نمایش دهد.

### تمرین ۴: نمایش فقط نمرات موجود

برنامه را تغییر دهید تا نمراتی که تعداد آن‌ها صفر است در خروجی نمایش داده نشوند.

### تمرین ۵: بهبود مدیریت ورودی

متغیر دریافت کاراکتر را از نوع `char` به `int` تغییر دهید و از تقسیم بر صفر جلوگیری کنید.

## 10. هدف آموزشی

هدف اصلی این تمرین، یادگیری نحوه پردازش یک جریان پیوسته از کاراکترها در زبان C است.

در این برنامه یاد می‌گیریم چگونه:

- کاراکترها را دریافت کنیم.
- کاراکترها را دسته‌بندی کنیم.
- تعداد تکرار هر دسته را بشماریم.
- اطلاعات آماری محاسبه کنیم.
- نتایج را با استفاده از `printf()` نمایش دهیم.

این مفاهیم در پردازش متن، تحلیل داده، اعتبارسنجی ورودی و بسیاری از کاربردهای برنامه‌نویسی C مورد استفاده قرار می‌گیرند.
