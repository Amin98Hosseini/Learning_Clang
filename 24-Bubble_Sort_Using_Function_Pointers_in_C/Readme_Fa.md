# 24- الگوریتم Bubble Sort با استفاده از اشاره‌گر به تابع (Function Pointer) در زبان C

## ۱. مقدمه

در این پروژه، الگوریتم مرتب‌سازی حبابی (Bubble Sort) با استفاده از **اشاره‌گر به تابع (Function Pointer)** پیاده‌سازی شده است.

تفاوت این برنامه با نسخه معمولی Bubble Sort این است که تابع مرتب‌سازی، تابع مقایسه را به‌عنوان ورودی دریافت می‌کند.

به این ترتیب می‌توان بدون نوشتن چند الگوریتم مرتب‌سازی جداگانه، یک الگوریتم واحد داشت که با قوانین مختلف داده‌ها را مرتب کند.

در این برنامه سه روش مرتب‌سازی پیاده‌سازی شده است:

۱. **Ascending:** مرتب‌سازی از کوچک به بزرگ.

۲. **Descending:** مرتب‌سازی از بزرگ به کوچک.

۳. **Ascending by Remainder:** مرتب‌سازی بر اساس باقی‌مانده تقسیم اعداد بر ۳.

مفاهیم مهمی که در این پروژه آموزش داده می‌شوند:

- الگوریتم Bubble Sort
- تعریف قوانین مقایسه سفارشی
- مرتب‌سازی پایدار (Stable Sorting)

## ۳. کد کامل برنامه

نسخه زیر عملکرد اصلی برنامه شما را حفظ می‌کند، اما محدوده حلقه داخلی را در هر مرحله کاهش می‌دهد تا مقایسه‌های غیرضروری انجام نشوند.

```c
#include <stdio.h>

void PrintArray(const int *const a, int N);
void BubbleSort(int *const a, int N, int (*compare)(int a, int b));
void Swap(int *p1, int *p2);

int Ascending(int a, int b);
int Descending(int a, int b);
int AscendingRem3(int a, int b);

int main()
{
    int a[] = {
        23, 53, 12, 10, 17, 56, 78, 34, 29,
        37, 45, 12, 19, 20, 40, 90, 43, 48, 62
    };

    int N = sizeof(a) / sizeof(a[0]);

    printf("Array before sorting:\n");
    PrintArray(a, N);
    printf("\n\n");

    int (*f[3])(int, int) = {
        Ascending,
        Descending,
        AscendingRem3
    };

    int i;

    for (i = 0; i < 3; i++)
    {
        BubbleSort(a, N, f[i]);

        printf("Array after sorting with f[%d]:\n", i);
        PrintArray(a, N);
        printf("\n\n");
    }

    return 0;
}

void BubbleSort(int *const a, int N, int (*compare)(int a, int b))
{
    int i, j;
    int swapped;

    for (i = 0; i < N - 1; i++)
    {
        swapped = 0;

        for (j = 0; j < N - i - 1; j++)
        {
            if (!compare(a[j], a[j + 1]))
            {
                Swap(&a[j], &a[j + 1]);
                swapped = 1;
            }
        }

        if (!swapped)
        {
            break;
        }
    }
}

void Swap(int *p1, int *p2)
{
    int temp;

    temp = *p1;
    *p1 = *p2;
    *p2 = temp;
}

int Ascending(int a, int b)
{
    return (a <= b);
}

int Descending(int a, int b)
{
    return (a >= b);
}

int AscendingRem3(int a, int b)
{
    return ((a % 3) <= (b % 3));
}

void PrintArray(const int *const a, int N)
{
    int i;

    for (i = 0; i < N; i++)
    {
        printf("%d", a[i]);

        if (i < N - 1)
        {
            printf(", ");
        }
    }
}
```

### ۴.۲. تعریف اولیه توابع (Function Prototypes)

```c
void PrintArray(const int *const a, int N);

void BubbleSort(
    int *const a,
    int N,
    int (*compare)(int a, int b)
);

void Swap(int *p1, int *p2);

int Descending(int a, int b);

```

این دستورات به کامپایلر اعلام می‌کنند که توابع موردنظر در برنامه وجود دارند.

مهم‌ترین قسمت این تعریف:

```c
int (*compare)(int a, int b);
```

این عبارت یک اشاره‌گر به تابع است.

این اشاره‌گر می‌تواند آدرس تابعی را دریافت کند که:

- دو پارامتر از نوع `int` دریافت می‌کند.
- یک مقدار از نوع `int` برمی‌گرداند.

تمام توابع مقایسه‌ای این پروژه همین ساختار را دارند و به همین دلیل می‌توان آن‌ها را به تابع `BubbleSort()` ارسال کرد.

## ۵. اشاره‌گر به تابع (Function Pointer) چیست؟

یک اشاره‌گر معمولی آدرس یک متغیر یا شیء را در حافظه نگهداری می‌کند.

برای مثال:

```c
int x = 10;
int *p = &x;
```

در این مثال اشاره‌گر `p` آدرس متغیر `x` را نگهداری می‌کند.

اما Function Pointer به‌جای آدرس یک متغیر، آدرس یک تابع را نگهداری می‌کند.

### ۵.۱. مثال ساده از Function Pointer

تابع زیر را در نظر بگیرید:

```c
int Add(int a, int b)
{
    return a + b;
}
```

برای اشاره به این تابع می‌توانیم یک Function Pointer تعریف کنیم:

```c
int (*operation)(int, int);
```

معنی این تعریف:

- `operation` نام اشاره‌گر است.
- این متغیر یک اشاره‌گر به تابع است.
- تابع موردنظر دو عدد صحیح دریافت می‌کند.
- خروجی تابع از نوع `int` است.

حالا می‌توانیم آدرس تابع `Add` را به آن اختصاص دهیم:

```c
operation = Add;
```

اکنون می‌توانیم تابع را از طریق اشاره‌گر فراخوانی کنیم:

```c
int result = operation(10, 20);
```

مقدار خروجی:

```text
result = 30
```

روش زیر نیز معتبر است:

```c
int result = (*operation)(10, 20);
```

هر دو روش تابع را از طریق اشاره‌گر اجرا می‌کنند.

### ۵.۲. بررسی ساختار تعریف Function Pointer

به تفاوت تعریف‌های زیر توجه کنید:

| تعریف | مفهوم |
|---|---|
| `int *p` | اشاره‌گر به متغیر عدد صحیح |
| `int (*f)(int, int)` | اشاره‌گر به تابعی با دو ورودی صحیح و خروجی صحیح |
| `int *f(int, int)` | تابعی با دو ورودی صحیح که یک اشاره‌گر به عدد صحیح برمی‌گرداند |

وجود پرانتز در تعریف Function Pointer بسیار مهم است.

برای مثال:

```c
int (*f)(int, int);
```

یک اشاره‌گر به تابع تعریف می‌کند.

اما:

```c
int *f(int, int);
```

یک تابع تعریف می‌کند که خروجی آن اشاره‌گر به عدد صحیح است.

این دو تعریف کاملاً متفاوت هستند.

## ۶. آرایه‌ای از اشاره‌گرهای تابع (Array of Function Pointers)

یکی از مهم‌ترین خطوط برنامه:

```c
int (*f[3])(int, int) = {
    Ascending,
    Descending,
    AscendingRem3
};
```

در این قسمت یک آرایه با سه عنصر تعریف شده است که هر عنصر آن یک Function Pointer است.

اجزای این تعریف:

| قسمت | مفهوم |
|---|---|
| `f` | نام آرایه |
| `[3]` | آرایه دارای سه عنصر است |
| `*` | هر عنصر یک اشاره‌گر است |
| `(int, int)` | تابع دو ورودی از نوع صحیح دریافت می‌کند |
| `int` | خروجی تابع از نوع صحیح است |

این آرایه شامل آدرس سه تابع زیر است:

```text
f[0] -> Ascending
f[1] -> Descending
f[2] -> AscendingRem3
```

بنابراین می‌توانیم هر تابع را از طریق آرایه فراخوانی کنیم:

```c
f[0](10, 20);
f[1](10, 20);
f[2](10, 20);
```

هر دستور تابع متفاوتی را اجرا می‌کند.

### چرا از آرایه Function Pointer استفاده می‌کنیم؟

بدون استفاده از Function Pointer ممکن بود مجبور شویم سه تابع مرتب‌سازی جداگانه بنویسیم:

```c
BubbleSortAscending();
BubbleSortDescending();
BubbleSortByRemainder();
```

در این حالت بخش زیادی از کد مرتب‌سازی تکراری می‌شد.

اما با استفاده از اشاره‌گر به تابع، تنها به یک تابع مرتب‌سازی نیاز داریم:

```c
BubbleSort(a, N, compare);
```

قانون مقایسه می‌تواند تغییر کند، بدون اینکه نیاز باشد الگوریتم مرتب‌سازی را دوباره بنویسیم.

این یکی از قابلیت‌های بسیار مهم زبان C برای طراحی توابع قابل استفاده مجدد است.

## ۷. بررسی توابع مقایسه (Comparison Functions)

هر سه تابع مقایسه دو عدد صحیح دریافت کرده و یک مقدار صحیح برمی‌گردانند.

مقدار خروجی مانند یک مقدار منطقی استفاده می‌شود:

- مقدار غیرصفر: ترتیب دو عنصر درست است.
- مقدار صفر: ترتیب دو عنصر درست نیست و باید جابه‌جا شوند.

### ۷.۱. تابع Ascending()

```c
int Ascending(int a, int b)
{
    return (a <= b);
}
```

این تابع بررسی می‌کند که آیا مقدار اول کوچک‌تر یا مساوی مقدار دوم است یا خیر.

برای مثال:

```text
a = 10
b = 20
```

در این حالت:

```c
Ascending(10, 20);
```

مقدار `1` را برمی‌گرداند.

یعنی ترتیب دو عنصر درست است و نیازی به جابه‌جایی نیست.

اما:

```c
Ascending(20, 10);
```

مقدار `0` را برمی‌گرداند.

بنابراین دو عنصر باید جابه‌جا شوند.

مثال:

```text
قبل:
23, 12, 10, 17

بعد:
10, 12, 17, 23
```

### ۷.۲. تابع Descending()

```c
int Descending(int a, int b)
{
    return (a >= b);
}
```

این تابع بررسی می‌کند که آیا مقدار اول بزرگ‌تر یا مساوی مقدار دوم است یا خیر.

برای مثال:

```c
Descending(30, 20);
```

مقدار `1` را برمی‌گرداند؛ زیرا ترتیب نزولی درست است.

اما:

```c
Descending(10, 20);
```

مقدار `0` را برمی‌گرداند و دو عنصر باید جابه‌جا شوند.

مثال:

```text
قبل:
10, 20, 30, 40

بعد:
40, 30, 20, 10
```

### ۷.۳. تابع AscendingRem3()

```c
int AscendingRem3(int a, int b)
{
    return ((a % 3) <= (b % 3));
}
```

این تابع یک روش متفاوت برای مقایسه اعداد پیاده‌سازی می‌کند.

در این روش به‌جای مقایسه مقدار اصلی اعداد، باقی‌مانده تقسیم آن‌ها بر ۳ مقایسه می‌شود.

عملگر `%` در زبان C برای محاسبه باقی‌مانده تقسیم استفاده می‌شود.

برای مثال:

```c
10 % 3 = 1
20 % 3 = 2
30 % 3 = 0
```

در تابع بالا عبارت زیر بررسی می‌شود:

```c
(a % 3) <= (b % 3)
```

بنابراین اعداد بر اساس باقی‌مانده تقسیم بر ۳ در سه گروه قرار می‌گیرند:

۱. اعدادی که باقی‌مانده آن‌ها صفر است.

۲. اعدادی که باقی‌مانده آن‌ها یک است.

۳. اعدادی که باقی‌مانده آن‌ها دو است.

مثال:

```text
ورودی:
5, 3, 7, 9, 4, 8

باقی‌مانده‌ها:
5 % 3 = 2
3 % 3 = 0
7 % 3 = 1
9 % 3 = 0
4 % 3 = 1
8 % 3 = 2

خروجی:
3, 9, 7, 4, 5, 8
```

توجه کنید که در این روش، اعداد داخل هر گروه الزاماً از کوچک به بزرگ مرتب نمی‌شوند.

تنها باقی‌مانده تقسیم آن‌ها معیار مرتب‌سازی است.

**نکته مهم:** در زبان C باقی‌مانده تقسیم اعداد منفی ممکن است منفی باشد. برای مثال:

```c
-4 % 3 = -1
```

بنابراین این تابع برای اعداد منفی از قواعد عملگر باقی‌مانده زبان C استفاده می‌کند و نباید فرض کرد که همیشه باقی‌مانده بین صفر و دو خواهد بود.

## ۸. بررسی تابع BubbleSort() با Function Pointer

تابع اصلی مرتب‌سازی:

```c
void BubbleSort(
    int *const a,
    int N,
    int (*compare)(int a, int b)
)
```

این تابع سه ورودی دریافت می‌کند:

| پارامتر | مفهوم |
|---|---|
| `a` | اشاره‌گر به آرایه اصلی |
| `N` | تعداد عناصر آرایه |
| `compare` | اشاره‌گر به تابع مقایسه |

نکته مهم این است که تابع `BubbleSort()` نیازی ندارد بداند مرتب‌سازی صعودی است یا نزولی یا بر اساس باقی‌مانده انجام می‌شود.

تنها کاری که انجام می‌دهد، فراخوانی تابع مقایسه‌ای است که به آن ارسال شده است.

### ۸.۱. حلقه بیرونی

```c
for (i = 0; i < N - 1; i++)
```

این حلقه تعداد مراحل مرتب‌سازی را کنترل می‌کند.

برای آرایه‌ای با `N` عنصر، حداکثر `N-1` مرحله لازم است.

### ۸.۲. مقداردهی متغیر swapped

```c
swapped = 0;
```

این متغیر مشخص می‌کند که آیا در مرحله فعلی جابه‌جایی انجام شده است یا خیر.

- `0`: هنوز هیچ جابه‌جایی انجام نشده است.
- `1`: حداقل یک جابه‌جایی انجام شده است.

### ۸.۳. حلقه داخلی

```c
for (j = 0; j < N - i - 1; j++)
```

در این حلقه عناصر مجاور با یکدیگر مقایسه می‌شوند.

بعد از هر مرحله، محدوده مقایسه کاهش پیدا می‌کند؛ زیرا بزرگ‌ترین عنصر باقی‌مانده بر اساس قانون مقایسه انتخاب‌شده، به انتهای بخش مرتب‌نشده منتقل می‌شود.

### ۸.۴. فراخوانی تابع مقایسه

```c
if (!compare(a[j], a[j + 1]))
```

این خط مهم‌ترین بخش برنامه است.

در اینجا از اشاره‌گر `compare` برای اجرای تابع مقایسه استفاده می‌شود.

برای مثال، اگر `compare` به تابع `Ascending` اشاره کند، عبارت بالا معادل است با:

```c
if (!Ascending(a[j], a[j + 1]))
```

اگر `compare` به تابع `Descending` اشاره کند، معادل است با:

```c
if (!Descending(a[j], a[j + 1]))
```

عملگر `!` به معنی NOT منطقی است.

بنابراین:

- اگر تابع مقایسه مقدار غیرصفر برگرداند، نیازی به جابه‌جایی نیست.
- اگر تابع مقایسه صفر برگرداند، دو عنصر باید جابه‌جا شوند.

همچنین می‌توان این دستور را به شکل زیر نوشت:

```c
if (!(*compare)(a[j], a[j + 1]))
```

هر دو شکل در زبان C معتبر هستند.

### ۸.۵. جابه‌جایی عناصر

```c
Swap(&a[j], &a[j + 1]);
```

آدرس دو عنصر مجاور به تابع `Swap()` ارسال می‌شود.

این تابع مقادیر اصلی آرایه را جابه‌جا می‌کند.

### ۸.۶. توقف زودهنگام

```c
if (!swapped)
{
    break;
}
```

اگر در یک مرحله هیچ جابه‌جایی انجام نشود، یعنی آرایه بر اساس قانون مقایسه انتخاب‌شده مرتب شده است.

در این حالت الگوریتم زودتر متوقف می‌شود.

## ۹. بررسی تابع Swap()

```c
void Swap(int *p1, int *p2)
{
    int temp;

    temp = *p1;
    *p1 = *p2;
    *p2 = temp;
}
```

این تابع دو مقدار را با استفاده از اشاره‌گرها جابه‌جا می‌کند.

فرض کنید دو متغیر زیر را داریم:

```c
int a = 10;
int b = 20;
```

تابع را به شکل زیر فراخوانی می‌کنیم:

```c
Swap(&a, &b);
```

در این حالت آدرس متغیرهای `a` و `b` به تابع ارسال می‌شود.

مراحل اجرا:

۱. مقدار متغیر اول در `temp` ذخیره می‌شود.

۲. مقدار متغیر دوم در متغیر اول قرار می‌گیرد.

۳. مقدار ذخیره‌شده در `temp` در متغیر دوم قرار می‌گیرد.

نتیجه:

```text
قبل:
a = 10
b = 20

بعد:
a = 20
b = 10
```

به دلیل استفاده از اشاره‌گر، مقدار متغیرهای اصلی تغییر می‌کند.

## ۱۰. بررسی تابع PrintArray()

```c
void PrintArray(const int *const a, int N)
{
    int i;

    for (i = 0; i < N; i++)
    {
        printf("%d", a[i]);

        if (i < N - 1)
        {
            printf(", ");
        }
    }
}
```

این تابع تمام عناصر آرایه را نمایش می‌دهد.

در تعریف زیر:

```c
const int *const a
```

دو محدودیت وجود دارد:

- تابع نمی‌تواند از طریق `a` مقدار عناصر آرایه را تغییر دهد.
- خود اشاره‌گر نیز نمی‌تواند به آدرس دیگری منتقل شود.

این روش برای توابعی مناسب است که فقط باید اطلاعات را بخوانند و نمایش دهند.

## ۱۱. بررسی تابع main()

### ۱۱.۱. تعریف آرایه

```c
int a[] = {
    23, 53, 12, 10, 17, 56, 78, 34, 29,
    37, 45, 12, 19, 20, 40, 90, 43, 48, 62
};
```

در این قسمت آرایه‌ای با ۱۹ عدد صحیح تعریف می‌شود.

### ۱۱.۲. محاسبه تعداد عناصر

```c
int N = sizeof(a) / sizeof(a[0]);
```

تعداد عناصر آرایه به‌صورت خودکار محاسبه می‌شود.

### ۱۱.۳. تعریف آرایه Function Pointer

```c
int (*f[3])(int, int) = {
    Ascending,
    Descending,
    AscendingRem3
};
```

در این قسمت آرایه‌ای از سه اشاره‌گر به تابع تعریف شده است.

### ۱۱.۴. اجرای روش‌های مختلف مرتب‌سازی

```c
for (i = 0; i < 3; i++)
{
    BubbleSort(a, N, f[i]);

    printf("Array after sorting with f[%d]:\n", i);
    PrintArray(a, N);
    printf("\n\n");
}
```

این حلقه سه بار اجرا می‌شود.

| شماره مرحله | اشاره‌گر تابع | روش مرتب‌سازی |
|---:|---|---|
| 0 | `f[0]` | صعودی |
| 1 | `f[1]` | نزولی |
| 2 | `f[2]` | بر اساس باقی‌مانده تقسیم بر ۳ |

**نکته بسیار مهم:** در هر سه مرحله، همان آرایه `a` به تابع ارسال می‌شود.

یعنی بعد از هر مرتب‌سازی، آرایه دوباره از ابتدا مقداردهی نمی‌شود.

بنابراین:

۱. در مرحله اول، آرایه اولیه به ترتیب صعودی مرتب می‌شود.

۲. در مرحله دوم، همان آرایه صعودی به ترتیب نزولی مرتب می‌شود.

۳. در مرحله سوم، آرایه نزولی بر اساس باقی‌مانده تقسیم بر ۳ مرتب می‌شود.

در نتیجه، مرحله سوم از ترتیب اولیه آرایه شروع نمی‌کند.

## ۱۲. خروجی مورد انتظار برنامه

```text
Array before sorting:
23, 53, 12, 10, 17, 56, 78, 34, 29, 37, 45, 12, 19, 20, 40, 90, 43, 48, 62

Array after sorting with f[0]:
10, 12, 12, 17, 19, 20, 23, 29, 34, 37, 40, 43, 45, 48, 53, 56, 62, 78, 90

Array after sorting with f[1]:
90, 78, 62, 56, 53, 48, 45, 43, 40, 37, 34, 29, 23, 20, 19, 17, 12, 12, 10

Array after sorting with f[2]:
90, 78, 48, 45, 12, 12, 43, 40, 37, 34, 19, 10, 62, 56, 53, 29, 23, 20, 17
```

### بررسی خروجی مرحله سوم

در مرحله سوم، تابع فقط باقی‌مانده تقسیم بر ۳ را مقایسه می‌کند.

بنابراین خروجی به سه گروه تقسیم می‌شود:

| گروه | باقی‌مانده | مقادیر به ترتیب خروجی |
|---|---:|---|
| اول | 0 | 90, 78, 48, 45, 12, 12 |
| دوم | 1 | 43, 40, 37, 34, 19, 10 |
| سوم | 2 | 62, 56, 53, 29, 23, 20, 17 |

چرا مقادیر داخل هر گروه همچنان نزولی هستند؟

زیرا Bubble Sort در این برنامه یک الگوریتم پایدار است. وقتی دو عنصر از نظر معیار مقایسه مقدار یکسانی داشته باشند، جابه‌جا نمی‌شوند و ترتیب نسبی آن‌ها حفظ می‌شود.

از آنجا که آرایه قبل از مرحله سوم نزولی بوده است، ترتیب نزولی اعداد داخل هر گروه نیز حفظ می‌شود.

## ۱۳. مرتب‌سازی پایدار (Stable Sorting) چیست؟

یک الگوریتم مرتب‌سازی زمانی پایدار است که ترتیب نسبی عناصر با کلید مرتب‌سازی یکسان را حفظ کند.

برای مثال:

```text
8, 5, 11
```

باقی‌مانده تقسیم این اعداد بر ۳:

```text
8 % 3  = 2
5 % 3  = 2
11 % 3 = 2
```

هر سه عدد کلید مرتب‌سازی یکسانی دارند.

در یک الگوریتم پایدار، ترتیب اولیه این اعداد حفظ می‌شود.

در برنامه ما، توابع مقایسه از `<=` و `>=` استفاده می‌کنند. بنابراین وقتی کلید دو عنصر برابر باشد، شرط مقایسه برقرار است و جابه‌جایی انجام نمی‌شود.

به همین دلیل پیاده‌سازی Bubble Sort در این پروژه پایدار است.

## ۱۴. مفاهیم مهم زبان C در این پروژه

### ۱۴.۱. تفاوت اشاره‌گر معمولی و Function Pointer

اشاره‌گر معمولی:

```c
int x = 10;
int *p = &x;
```

اشاره‌گر به تابع:

```c
int (*f)(int, int);
```

اشاره‌گر اول آدرس یک متغیر عدد صحیح را نگهداری می‌کند.

اشاره‌گر دوم آدرس یک تابع را نگهداری می‌کند.

### ۱۴.۲. ارسال تابع به‌عنوان پارامتر

تابع زیر یک تابع دیگر را از طریق اشاره‌گر دریافت می‌کند:

```c
void BubbleSort(
    int *a,
    int N,
    int (*compare)(int, int)
);
```

به این روش معمولاً Callback Function گفته می‌شود.

تابع دریافت‌کننده می‌تواند در زمان نیاز، تابع ارسال‌شده را فراخوانی کند.

### ۱۴.۳. چرا تمام توابع مقایسه باید امضای یکسان داشته باشند؟

توابع زیر را در نظر بگیرید:

```c
int Ascending(int a, int b);
int Descending(int a, int b);
int AscendingRem3(int a, int b);
```

تمام این توابع از یک نوع هستند:

- دو ورودی از نوع `int`
- یک خروجی از نوع `int`

به همین دلیل می‌توان آدرس آن‌ها را در اشاره‌گر زیر ذخیره کرد:

```c
int (*compare)(int, int);
```

اگر نوع پارامترها یا نوع خروجی یک تابع متفاوت باشد، نمی‌توان آن را به‌صورت ایمن به‌عنوان این Callback استفاده کرد.

## ۱۵. پیچیدگی زمانی و حافظه‌ای

برای نسخه بهینه‌شده Bubble Sort:

| حالت | پیچیدگی زمانی | توضیح |
|---|---|---|
| بهترین حالت | O(N) | آرایه بر اساس قانون مقایسه انتخاب‌شده مرتب است |
| حالت متوسط | O(N²) | معمولاً چندین مرحله مقایسه و جابه‌جایی لازم است |
| بدترین حالت | O(N²) | ترتیب آرایه معکوس ترتیب موردنیاز است |

پیچیدگی حافظه‌ای:

```text
O(1)
```

الگوریتم روی همان آرایه اصلی کار می‌کند و فقط از چند متغیر کمکی استفاده می‌کند.

استفاده از Function Pointer پیچیدگی زمانی الگوریتم Bubble Sort را تغییر نمی‌دهد.

مزیت آن این است که می‌توانیم رفتار مرتب‌سازی را بدون نوشتن چند الگوریتم جداگانه تغییر دهیم.

## ۱۷. تمرین‌های پیشنهادی

### تمرین ۱ — تعریف تابع مقایسه جدید

تابعی بنویسید که اعداد را بر اساس قدر مطلق آن‌ها مرتب کند.

مثال:

```text
ورودی:
-8, 3, -2, 5, 1

خروجی:
1, -2, 3, 5, -8
```

راهنمایی: از تابع `abs()` در کتابخانه `<stdlib.h>` استفاده کنید.

### تمرین ۲ — مرتب‌سازی اعداد زوج و فرد

تابعی بنویسید که ابتدا اعداد زوج و سپس اعداد فرد را قرار دهد.

مثال:

```text
ورودی:
5, 2, 7, 4, 3, 8

خروجی:
2, 4, 8, 5, 7, 3
```

### تمرین ۳ — مرتب‌سازی بر اساس رقم آخر

تابعی بنویسید که اعداد را بر اساس رقم آخر آن‌ها مرتب کند.

راهنمایی:

```c
a % 10
```

### تمرین ۴ — افزایش تعداد Function Pointerها

دو تابع مقایسه جدید به برنامه اضافه کنید و اندازه آرایه Function Pointer را افزایش دهید.

### تمرین ۵ — انتخاب روش مرتب‌سازی توسط کاربر

به‌جای اجرای خودکار تمام روش‌ها، از کاربر بخواهید روش مرتب‌سازی را انتخاب کند.

برای مثال:

```text
Select sorting method:

1. Ascending
2. Descending
3. Sort by remainder

Your choice:
```

سپس با توجه به انتخاب کاربر، اشاره‌گر تابع مناسب را فراخوانی کنید.

### تمرین ۶ — بازگرداندن آرایه به حالت اولیه

برنامه را تغییر دهید تا هر روش مرتب‌سازی از آرایه اولیه و نامرتب شروع شود.

برای این کار می‌توانید یک آرایه دیگر ایجاد کنید یا قبل از هر مرتب‌سازی، آرایه اولیه را کپی کنید.

### تمرین ۷ — آشنایی با رابط مقایسه عمومی

بررسی کنید که چگونه می‌توان از Function Pointer برای ساخت توابع مرتب‌سازی قابل استفاده مجدد برای انواع داده‌های دیگر استفاده کرد.

برای این منظور تابع استاندارد زیر را مطالعه کنید:

```c
qsort()
```

تابع `qsort()` از یک تابع مقایسه به‌عنوان Callback استفاده می‌کند و نمونه کاربردی همین مفهوم است.

## ۱۸. اهداف آموزشی

پس از انجام این پروژه باید بتوانید:

- مفهوم Function Pointer را توضیح دهید.
- یک اشاره‌گر به تابع تعریف و استفاده کنید.
- آرایه‌ای از اشاره‌گرهای تابع ایجاد کنید.
- یک تابع را به‌عنوان پارامتر به تابع دیگر ارسال کنید.
- مفهوم Callback Function را درک کنید.
- منطق مرتب‌سازی را از منطق مقایسه جدا کنید.
- قوانین مرتب‌سازی سفارشی ایجاد کنید.
- مفهوم Stable Sorting را توضیح دهید.
- یک الگوریتم مرتب‌سازی را برای چند روش مختلف استفاده کنید.

## ۱۹. مرحله بعدی یادگیری

پیشنهاد می‌شود در پروژه بعدی یک رابط مرتب‌سازی عمومی با استفاده از تابع استاندارد `qsort()` پیاده‌سازی کنید.

سپس مفاهیم زیر را بررسی کنید:

- Function Pointer در ساختارها (Structures)
- Callback Function در سیستم‌های Embedded
- پیاده‌سازی State Machine با Function Pointer
- جدول توابع وقفه (Interrupt Callback Table)
- رابط درایورها و Hardware Abstraction Layer

استفاده از Function Pointer در برنامه‌نویسی Embedded C بسیار کاربردی است؛ به‌خصوص زمانی که چند سخت‌افزار یا چند حالت کاری مختلف باید از یک رابط مشترک برای اجرای توابع استفاده کنند.
