# 12- تشخیص اعداد اول در زبان C

## 1. معرفی برنامه

این برنامه بررسی می‌کند که آیا یک عدد صحیح، عدد اول (Prime Number) است یا خیر.

عدد اول، یک عدد صحیح مثبت بزرگ‌تر از ۱ است که دقیقاً دو مقسوم‌علیه مثبت دارد:

- عدد ۱
- خود عدد

برای مثال:

- عدد ۲ اول است.
- عدد ۳ اول است.
- عدد ۷ اول است.
- عدد ۹ اول نیست؛ زیرا بر ۳ بخش‌پذیر است.
- عدد ۱۵ اول نیست؛ زیرا بر ۳ و ۵ بخش‌پذیر است.

برنامه به‌صورت مکرر از کاربر یک عدد صحیح دریافت می‌کند و اول بودن آن را بررسی می‌کند.

برای انجام محاسبات، یک تابع جداگانه با نام `IsPrime()` تعریف شده است.

دریافت ورودی تا زمانی ادامه پیدا می‌کند که عدد واردشده بزرگ‌تر از صفر باشد.

## 2. کد برنامه

```c
#include <stdio.h>
#include <math.h>

#define TRUE 1
#define FALSE 0

int IsPrime(int a);

int main()
{
    int a;

    do
    {
        printf("Enter an integer: ");
        scanf("%d", &a);

        if(IsPrime(a))
        {
            printf("%d is a PRIME number.\n", a);
        }
        else
        {
            printf("%d is a NOT PRIME number.\n", a);
        }

        printf("\n");

    } while (a > 0);

    return 0;
}

int IsPrime(int a)
{
    int prime = TRUE;
    int i;

    for(i = 2; i <= sqrt(a); i++)
    {
        if(a % i == 0)
        {
            prime = FALSE;
            break;
        }
    }

    return prime;
}
```

## 3. مبانی ریاضی برنامه

### 3.1. عدد اول چیست؟

عدد اول یک عدد صحیح بزرگ‌تر از ۱ است که فقط بر ۱ و خودش بخش‌پذیر باشد.

از نظر ریاضی، یک عدد صحیح \(a\) زمانی اول است که:

\[
a>1
\]

و تنها مقسوم‌علیه‌های مثبت آن عبارت باشند از:

\[
1 \quad \text{و} \quad a
\]

مثال:

| عدد | مقسوم‌علیه‌ها | نتیجه |
|---|---|---|
| 2 | 1، 2 | اول |
| 3 | 1، 3 | اول |
| 4 | 1، 2، 4 | غیر اول |
| 5 | 1، 5 | اول |
| 9 | 1، 3، 9 | غیر اول |
| 11 | 1، 11 | اول |

**نکته مهم:** عدد ۱ عدد اول نیست؛ زیرا فقط یک مقسوم‌علیه مثبت دارد.

عدد صفر و اعداد منفی نیز عدد اول محسوب نمی‌شوند.

### 3.2. بررسی بخش‌پذیری با عملگر Modulo

عملگر `%` باقی‌مانده تقسیم صحیح دو عدد را محاسبه می‌کند.

برای مثال:

```c
10 % 2 = 0
10 % 3 = 1
15 % 5 = 0
```

اگر:

\[
a \bmod i=0
\]

باشد، یعنی عدد `a` بر `i` بخش‌پذیر است.

بنابراین اگر عددی به‌جز ۱ و خودش مقسوم‌علیه دیگری داشته باشد، آن عدد اول نیست.

### 3.3. چرا فقط تا جذر عدد بررسی می‌کنیم؟

در یک روش ساده برای تشخیص عدد اول، می‌توان تمام اعداد از ۲ تا `a-1` را بررسی کرد.

اما این روش بهینه نیست.

اگر یک عدد \(a\) دارای مقسوم‌علیه‌ای بزرگ‌تر از جذر خودش باشد، حتماً یک مقسوم‌علیه متناظر کوچک‌تر از جذر نیز خواهد داشت.

بنابراین کافی است اعداد موجود در بازه زیر را بررسی کنیم:

\[
2\leq i\leq\sqrt{a}
\]

برای مثال، عدد ۳۶ را در نظر بگیرید:

\[
36=6\times6
\]

جفت مقسوم‌علیه‌های آن عبارت‌اند از:

\[
2\times18,\quad 3\times12,\quad 4\times9,\quad 6\times6
\]

با رسیدن به جذر عدد، تمام جفت‌های ممکن بررسی شده‌اند.

این روش تعداد تکرارهای حلقه را به میزان قابل توجهی کاهش می‌دهد.

- مقدار `0`: عدد اول نیست.

با استفاده از Function Prototype می‌توان بدنه اصلی تابع را بعد از تابع `main()` قرار داد.

**نکته مهم:** در نسخه اولیه، حتی برای صفر و اعداد منفی نیز تابع `IsPrime()` فراخوانی می‌شود. این موضوع یک مشکل منطقی دارد که در بخش بهبود برنامه بررسی می‌شود.

### 4.6. دریافت عدد با scanf()


تابع `scanf()` برای دریافت ورودی از کاربر استفاده می‌شود.

- `%d` مشخص می‌کند که ورودی از نوع عدد صحیح است.
- `&a` آدرس حافظه متغیر `a` را به تابع می‌دهد.

عملگر `&` با نام Address-of Operator شناخته می‌شود.

### 4.7. فراخوانی تابع IsPrime()

```c
if(IsPrime(a))
{
    printf("%d is a PRIME number.\n", a);
}
else
{
    printf("%d is a NOT PRIME number.\n", a);
}
```

در این قسمت تابع `IsPrime()` فراخوانی شده و عدد واردشده به‌عنوان آرگومان به آن ارسال می‌شود.

اگر تابع یک مقدار غیرصفر برگرداند، شرط `if` برقرار خواهد بود.

اگر مقدار بازگشتی صفر باشد، بخش `else` اجرا می‌شود.

این روش نمونه‌ای از استفاده مستقیم مقدار بازگشتی یک تابع در یک دستور شرطی است.

### 4.8. پیاده‌سازی تابع IsPrime()

```c
int IsPrime(int a)
{
    int prime = TRUE;
    int i;

    for(i = 2; i <= sqrt(a); i++)
    {
        if(a % i == 0)
        {
            prime = FALSE;
            break;
        }
    }

    return prime;
}
```

این تابع الگوریتم اصلی تشخیص عدد اول را پیاده‌سازی می‌کند.

بیایید آن را مرحله‌به‌مرحله بررسی کنیم.

**مرحله اول: مقداردهی اولیه نتیجه**

```c
int prime = TRUE;
```

در ابتدای تابع فرض می‌کنیم عدد موردنظر اول است.

اگر مقسوم‌علیه دیگری پیدا شود، مقدار این متغیر به `FALSE` تغییر می‌کند.

**مرحله دوم: تعریف متغیر حلقه**

```c
int i;
```

متغیر `i` برای بررسی مقسوم‌علیه‌های احتمالی استفاده می‌شود.

**مرحله سوم: بررسی مقسوم‌علیه‌ها**

```c
for(i = 2; i <= sqrt(a); i++)
```

حلقه از عدد ۲ شروع می‌شود و تا جذر عدد `a` ادامه پیدا می‌کند.

در هر مرحله بررسی می‌شود که آیا عدد موردنظر بر `i` بخش‌پذیر است یا خیر.

**مرحله چهارم: بررسی باقی‌مانده تقسیم**

```c
if(a % i == 0)
```

اگر باقی‌مانده تقسیم صفر باشد، یعنی عدد بر `i` بخش‌پذیر است.

در نتیجه عدد اول نیست.

**مرحله پنجم: تغییر نتیجه**

```c
prime = FALSE;
```

در این قسمت مشخص می‌کنیم که عدد موردنظر اول نیست.

**مرحله ششم: خروج از حلقه**

```c
break;
```

وقتی یک مقسوم‌علیه پیدا شود، دیگر نیازی به بررسی اعداد بعدی نیست.

دستور `break` باعث خروج فوری از حلقه می‌شود.

**مرحله هفتم: بازگرداندن نتیجه**

```c
return prime;
```

در پایان تابع، نتیجه محاسبه به محل فراخوانی تابع بازگردانده می‌شود.

- `TRUE` یعنی عدد اول است.
- `FALSE` یعنی عدد اول نیست.

## 7. نکات مهم و بهبودهای احتمالی

کد اولیه برای یادگیری مفاهیم برنامه‌نویسی مناسب است، اما چند مشکل دارد که بهتر است اصلاح شوند.

### 7.1. مدیریت اعداد کوچک‌تر یا مساوی ۱

در تابع فعلی:

```c
int prime = TRUE;
```

مقدار اولیه متغیر `prime` برابر True است.

برای اعدادی مانند صفر، یک و اعداد منفی، حلقه `for` اجرا نمی‌شود.

در نتیجه تابع به‌اشتباه مقدار `TRUE` برمی‌گرداند.

برای رفع مشکل، در ابتدای تابع شرط زیر را اضافه می‌کنیم:

```c
int IsPrime(int a)
{
    if(a <= 1)
    {
        return FALSE;
    }

    int i;

    for(i = 2; i <= sqrt(a); i++)
    {
        if(a % i == 0)
        {
            return FALSE;
        }
    }

    return TRUE;
}
```

با این تغییر، تمام اعداد کوچک‌تر یا مساوی ۱ به‌درستی غیر اول تشخیص داده می‌شوند.

### 7.2. جلوگیری از بررسی عدد خروجی

در حلقه `do-while` ابتدا دستورات اجرا می‌شوند و سپس شرط بررسی می‌شود.

می‌توان برنامه را به شکل زیر اصلاح کرد:

```c
do
{
    printf("Enter an integer: ");
    scanf("%d", &a);

    if(a <= 0)
    {
        break;
    }

    if(IsPrime(a))
    {
        printf("%d is a PRIME number.\n", a);
    }
    else
    {
        printf("%d is NOT a PRIME number.\n", a);
    }

```

در این نسخه، عدد صفر یا منفی به‌عنوان دستور خروج در نظر گرفته می‌شود و دیگر بررسی اول بودن آن انجام نمی‌شود.

### 7.3. جلوگیری از محاسبه غیرضروری جذر

در کد اولیه از عبارت زیر استفاده شده است:

```c
for(i = 2; i <= sqrt(a); i++)
```

یک روش جایگزین و کارآمدتر برای اعداد مثبت:

```c

```

این شرط از نظر ریاضی معادل بررسی تا جذر عدد است، اما دیگر نیازی به فراخوانی مکرر تابع `sqrt()` ندارد.

همچنین از سرریز احتمالی در عبارتی مانند `i * i <= a` جلوگیری می‌کند.

### 7.4. بررسی مقدار بازگشتی scanf()

در برنامه اولیه فرض شده است که کاربر همیشه یک عدد صحیح معتبر وارد می‌کند.

با این شرط بررسی می‌کنیم که آیا تابع `scanf()` موفق به دریافت یک عدد صحیح شده است یا خیر.

## 8. نسخه کامل اصلاح‌شده برنامه

نسخه زیر شامل اصلاحات اصلی است:

```c
#include <stdio.h>

#define TRUE 1
#define FALSE 0

int IsPrime(int a);

int main()
{
    int a;

    do
    {
        printf("Enter an integer (0 or negative to exit): ");

        if(scanf("%d", &a) != 1)
        {
            printf("Invalid input.\n");
            return 1;
        }

        if(a <= 0)
        {
            break;
        }

        if(IsPrime(a))
        {
            printf("%d is a PRIME number.\n", a);
        }
        else
        {
            printf("%d is NOT a PRIME number.\n", a);
        }

        printf("\n");

    } while(a > 0);

    printf("Program terminated.\n");

    return 0;
}

int IsPrime(int a)
{
    if(a <= 1)
    {
        return FALSE;
    }

    for(int i = 2; i <= a / i; i++)
    {
        if(a % i == 0)
        {
            return FALSE;
        }
    }

    return TRUE;
}
```

ویژگی‌های نسخه اصلاح‌شده:

- اعداد کوچک‌تر یا مساوی ۱ را به‌درستی غیر اول تشخیص می‌دهد.
- با وارد کردن صفر یا عدد منفی از برنامه خارج می‌شود.
- معتبر بودن ورودی عددی را بررسی می‌کند.
- از فراخوانی غیرضروری تابع `sqrt()` جلوگیری می‌کند.
- در صورت پیدا کردن مقسوم‌علیه، بلافاصله نتیجه را برمی‌گرداند.

1. پوشه پروژه را باز کنید.
2. فایل `main.c` را باز کنید.
3. ترمینال داخلی VS Code را اجرا کنید.
4. برنامه را با GCC کامپایل کنید.
5. فایل اجرایی را اجرا کنید.
6. اعداد مثبت را برای بررسی وارد کنید.
7. برای خروج، عدد صفر یا منفی وارد کنید.

## 10. تمرین‌های پیشنهادی

برای تقویت مهارت برنامه‌نویسی، تمرین‌های زیر را انجام دهید.

### تمرین ۱: تشخیص زوج و فرد

تابعی با نام `IsEven()` بنویسید که اگر عدد زوج بود مقدار `TRUE` و در غیر این صورت مقدار `FALSE` برگرداند.

### تمرین ۲: شمارش اعداد اول

برنامه را توسعه دهید تا تعداد اعداد اول واردشده توسط کاربر را قبل از خروج محاسبه کند.

### تمرین ۳: نمایش اعداد اول در یک بازه

برنامه‌ای بنویسید که دو عدد صحیح دریافت کند و تمام اعداد اول بین آن دو عدد را نمایش دهد.

### تمرین ۴: پیدا کردن عدد اول بعدی

تابعی بنویسید که یک عدد صحیح دریافت کند و نزدیک‌ترین عدد اول بزرگ‌تر از آن را برگرداند.

### تمرین ۵: محاسبه تعداد مقسوم‌علیه‌ها

تابع `IsPrime()` را توسعه دهید یا تابع جدیدی بسازید که تعداد مقسوم‌علیه‌های مثبت یک عدد را محاسبه کند.

### تمرین ۶: بهینه‌سازی تشخیص عدد اول

دو شرط زیر را با یکدیگر مقایسه کنید:

```c
i <= sqrt(a)
```

و:

```c
i <= a / i
```

بررسی کنید که چرا هر دو روش امکان بررسی نکردن تمام اعداد تا `a-1` را فراهم می‌کنند.

## 11. هدف آموزشی

هدف اصلی این تمرین، یادگیری نحوه تعریف و استفاده از توابع در زبان C برای حل یک مسئله ریاضی است.

با انجام این تمرین یاد می‌گیرید چگونه:

- یک محاسبه را در قالب یک تابع مستقل پیاده‌سازی کنید.

- توابع، حلقه‌ها و دستورات شرطی را با یکدیگر ترکیب کنید.
