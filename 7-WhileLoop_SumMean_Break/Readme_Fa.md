# 7 - محاسبه مجموع و میانگین اعداد با استفاده از While و Break در زبان C

## معرفی پروژه (Overview)

این پروژه با هدف آموزش حلقه `while`، دستور `break` و انجام عملیات محاسباتی در زبان برنامه‌نویسی C طراحی شده است.

برنامه به‌صورت پیوسته از کاربر عدد صحیح دریافت می‌کند، مجموع اعداد واردشده را محاسبه می‌کند و در پایان میانگین (Average / Mean) آن‌ها را نمایش می‌دهد.

فرآیند دریافت اعداد زمانی متوقف می‌شود که کاربر عدد `-1` را وارد کند.

در این برنامه عدد `-1` به‌عنوان مقدار پایان ورودی (Sentinel Value) در نظر گرفته شده و در محاسبات مجموع و میانگین شرکت نمی‌کند.

## اهداف آموزشی (Learning Objectives)

با مطالعه این برنامه، مفاهیم زیر را یاد می‌گیرید:

- آشنایی با حلقه `while`.
- نحوه ایجاد حلقه بی‌نهایت (Infinite Loop).
- آشنایی با دستور `break` برای خروج از حلقه.
- دریافت چندین ورودی از کاربر با استفاده از `scanf()`.
- محاسبه مجموع اعداد با استفاده از متغیر تجمعی (Accumulator).
- شمارش تعداد ورودی‌ها با استفاده از متغیر شمارنده (Counter).
- محاسبه میانگین حسابی اعداد.
- آشنایی با تبدیل نوع داده (Type Casting).

## بررسی و توضیح کد (Source Code Explanation)

### 1. فراخوانی کتابخانه

```c
#include <stdio.h>
```

کتابخانه استاندارد ورودی و خروجی زبان C را فراخوانی می‌کند.

این کتابخانه شامل توابعی مانند `printf()` و `scanf()` است.

### 2. تعریف مقادیر ثابت (Constants)

```c
#define TRUE -1
#define FALSE 0
```

با استفاده از دستور `#define` دو مقدار ثابت تعریف می‌کنیم:

- `TRUE`: نشان‌دهنده برقرار بودن شرط.
- `FALSE`: نشان‌دهنده برقرار نبودن شرط.

در زبان C هر مقدار صحیح غیرصفر به‌عنوان مقدار منطقی True در نظر گرفته می‌شود؛ بنابراین مقدار `-1` نیز برای ایجاد یک حلقه بی‌نهایت معتبر است.

**نکته:** استفاده از مقدار `1` برای تعریف `TRUE` رایج‌تر است.

### 3. تعریف متغیرها

```c
int n = 10;
int a, S, i;
```

در این قسمت متغیرهای موردنیاز برنامه تعریف می‌شوند.

| متغیر | مقدار اولیه | کاربرد |
|---|---|---|
| `n` | 10 | تعداد ورودی موردنظر (در کد فعلی استفاده نشده است). |
| `a` | مقداردهی نشده | ذخیره عدد واردشده توسط کاربر |
| `S` | مقداردهی نشده | ذخیره مجموع اعداد |
| `i` | مقداردهی نشده | شمارش تعداد اعداد واردشده |

### 4. مقداردهی اولیه متغیرها

```c
i = 0;
S = 0;
```

در این قسمت مقادیر اولیه متغیرها مشخص می‌شوند:

- `i = 0`: شمارنده تعداد اعداد را صفر می‌کند.
- `S = 0`: مجموع اعداد را صفر می‌کند.

این کار باعث می‌شود محاسبات از یک مقدار مشخص و صحیح آغاز شوند.

### 5. ایجاد حلقه While

```c
while(TRUE)
{
    printf("Enter a number: ");
    scanf("%d", &a);

    if(a == -1)
        break;

    S += a;
    i++;
}
```

در این قسمت از حلقه `while` استفاده شده است.

از آنجا که مقدار `TRUE` برابر با `-1` است و هر مقدار غیرصفر در زبان C معادل True محسوب می‌شود، شرط حلقه همیشه برقرار خواهد بود.

بنابراین یک حلقه بی‌نهایت ایجاد می‌شود.

**مراحل اجرای حلقه:**

1. برنامه از کاربر درخواست ورود یک عدد می‌کند.
2. تابع `scanf()` عدد واردشده را دریافت می‌کند.
3. بررسی می‌شود که آیا عدد برابر با `-1` است یا خیر.
4. اگر عدد برابر با `-1` باشد، دستور `break` اجرا شده و حلقه خاتمه پیدا می‌کند.
5. در غیر این صورت، عدد واردشده به مجموع اضافه می‌شود.
6. شمارنده `i` یک واحد افزایش پیدا می‌کند.
7. مراحل بالا مجدداً تکرار می‌شوند.

### 6. دستور Break

```c
if(a == -1)
    break;
```

دستور `break` برای خروج فوری از حلقه استفاده می‌شود.

در این برنامه، عدد `-1` به‌عنوان علامت پایان دریافت ورودی (Sentinel Value) در نظر گرفته شده است.

به‌محض وارد کردن این عدد، حلقه متوقف می‌شود.

**نکته مهم:** عدد `-1` قبل از اضافه شدن به مجموع و افزایش شمارنده بررسی می‌شود؛ بنابراین در محاسبات شرکت نمی‌کند.

### 7. محاسبه مجموع اعداد (Sum)

```c
S += a;
```

این دستور معادل عبارت زیر است:

```c
S = S + a;
```

در هر بار اجرای حلقه، عدد جدید به مجموع اعداد قبلی اضافه می‌شود.

برای مثال، اگر کاربر اعداد زیر را وارد کند:

```text
10
20
30
40
-1
```

مراحل محاسبه مجموع:

| مرحله | عدد ورودی | مجموع قبلی | مجموع جدید |
|---|---:|---:|---:|
| 1 | 10 | 0 | 10 |
| 2 | 20 | 10 | 30 |
| 3 | 30 | 30 | 60 |
| 4 | 40 | 60 | 100 |
| 5 | -1 | 100 | پایان حلقه |

در نتیجه:

```text
Sum = 100
```

### 8. شمارش تعداد اعداد

```c
i++;
```

در هر بار ورود یک عدد معتبر، متغیر `i` یک واحد افزایش پیدا می‌کند.

این متغیر تعداد اعداد واردشده را نگهداری می‌کند.

برای مثال، اگر کاربر چهار عدد وارد کند و سپس `-1` را وارد کند:

```text
i = 4
```

عدد `-1` در شمارش لحاظ نمی‌شود.

### 9. نمایش مجموع اعداد

```c
printf("\nSum of numbers = %d\n\n", S);
```

با استفاده از تابع `printf()` مجموع اعداد واردشده نمایش داده می‌شود.

مشخص‌کننده قالب `%d` برای نمایش مقادیر صحیح استفاده می‌شود.

### 10. محاسبه میانگین (Mean)

```c
float m = (float)S / i;
```

در این قسمت میانگین حسابی اعداد محاسبه می‌شود.

فرمول میانگین:

\[
Mean = \frac{Sum}{Number\ of\ Inputs}
\]

در این برنامه:

- `S`: مجموع اعداد واردشده.
- `i`: تعداد اعداد واردشده.
- `m`: میانگین محاسبه‌شده.

**نکته مهم: تبدیل نوع داده (Type Casting)**

عبارت `(float)` باعث تبدیل مقدار `S` از نوع `int` به نوع `float` می‌شود.

این تبدیل برای جلوگیری از تقسیم صحیح (Integer Division) ضروری است.

برای مثال:

```c
int a = 5;
int b = 2;

printf("%d\n", a / b);
```

خروجی:

```text
2
```

اما با تبدیل نوع داده:

```c
printf("%.2f\n", (float)a / b);
```

خروجی:

```text
2.50
```

### 11. نمایش میانگین

```c
printf("Mean of numbers = %.2f", m);
```

در این دستور میانگین محاسبه‌شده نمایش داده می‌شود.

مشخص‌کننده `%.2f` مقدار اعشاری را با دو رقم بعد از ممیز نمایش می‌دهد.

## خروجی برنامه (Example Output)

```text
Enter a number: 10
Enter a number: 20
Enter a number: 30
Enter a number: 40
Enter a number: -1

Sum of numbers = 100

Mean of numbers = 25.00
```

## مفاهیم مهم برنامه‌نویسی C

| دستور یا مفهوم | کاربرد |
|---|---|
| `while()` | تکرار دستورات تا زمانی که شرط برقرار باشد |
| `break` | خروج فوری از حلقه |
| `#define` | تعریف ماکرو در مرحله پیش‌پردازش |
| `scanf()` | دریافت ورودی از کاربر |
| `printf()` | نمایش خروجی |
| `S += a` | اضافه کردن مقدار جدید به مجموع |
| `i++` | افزایش شمارنده به اندازه یک واحد |
| `(float)` | تبدیل نوع داده به عدد اعشاری |
| `%.2f` | نمایش عدد اعشاری با دو رقم اعشار |
| Sentinel Value | مقدار مشخص برای پایان دریافت ورودی |

## نکته مهم: جلوگیری از تقسیم بر صفر

در کد اولیه یک مشکل احتمالی وجود دارد:

```c
float m = (float)S / i;
```

اگر کاربر از همان ابتدا عدد `-1` را وارد کند، مقدار `i` برابر صفر باقی می‌ماند.

در نتیجه برنامه با مشکل تقسیم بر صفر (Division by Zero) مواجه می‌شود.

برای جلوگیری از این مشکل، باید قبل از محاسبه میانگین تعداد اعداد بررسی شود:

```c
if(i > 0)
{
    float m = (float)S / i;
    printf("Mean of numbers = %.2f\n", m);
}
else
{
    printf("No numbers were entered.\n");
}
```

## نکته تکمیلی: محدود کردن تعداد ورودی‌ها

در ابتدای برنامه متغیر زیر تعریف شده است:

```c
int n = 10;
```

اما در کد فعلی از این متغیر استفاده نشده است.

اگر بخواهیم تعداد ورودی‌ها حداکثر ۱۰ عدد باشد، می‌توانیم شرط حلقه را به شکل زیر تغییر دهیم:

```c
while(i < n)
{
    printf("Enter a number: ");
    scanf("%d", &a);

    if(a == -1)
        break;

    S += a;
    i++;
}
```

در این حالت حلقه حداکثر ۱۰ بار اجرا می‌شود و در صورت وارد کردن `-1` زودتر متوقف خواهد شد.

6. میانگین اعداد زوج را محاسبه کنید.

8. برنامه را طوری تغییر دهید که در صورت وارد کردن `-1` بلافاصله، پیام مناسبی نمایش دهد.
