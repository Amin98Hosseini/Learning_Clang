# 17- محاسبه طول آرایه کاراکتری و طول رشته در زبان C

## مقدمه

این برنامه نحوه دریافت نام کاربر، ذخیره آن در یک آرایه کاراکتری و محاسبه طول واقعی رشته را آموزش می‌دهد.

یکی از مفاهیم مهم زبان C که در این مثال بررسی می‌شود، تفاوت بین **اندازه آرایه کاراکتری (Array Length)** و **طول واقعی رشته (String Length)** است.

برنامه دو مقدار را محاسبه می‌کند:

- **طول آرایه:** تعداد کل خانه‌هایی که برای آرایه اختصاص داده شده است.
- **طول رشته:** تعداد کاراکترهای واردشده توسط کاربر، بدون احتساب کاراکتر پایان رشته (`'\0'`).

## کد برنامه

```c
#include <stdio.h>

int main()
{
    printf("Please enter your name:\n");

    char name[10];
    scanf("%9s", name);

    printf("\nYour name is: %s.\n", name);

    int N = sizeof(name) / sizeof(name[0]);
    printf("Length of array = %d\n", N);

    int M = 0;
    int i;

    for(i = 0; i < N; i++)
    {
        if(name[i] == '\0') break;
        M++;
    }

    printf("Length of string = %d\n", M);

    return 0;
}
```

## ۱. آشنایی با آرایه کاراکتری

در زبان C، رشته‌ها (String) با استفاده از آرایه‌ای از کاراکترها ذخیره می‌شوند.

برای مثال:

```c
char name[10];
```

این دستور یک آرایه با ۱۰ خانه از نوع `char` ایجاد می‌کند.

هر خانه می‌تواند یک کاراکتر ذخیره کند.

برای مثال، اگر نام کاربر `Amin` باشد، محتوای آرایه به شکل زیر خواهد بود:

| اندیس | مقدار |
|---|---|
| name[0] | 'A' |
| name[1] | 'm' |
| name[2] | 'i' |
| name[3] | 'n' |
| name[4] | '\0' |
| name[5] | استفاده‌نشده |
| ... | ... |
| name[9] | استفاده‌نشده |

در زبان C برای مشخص‌کردن پایان رشته از یک کاراکتر ویژه به نام **Null Terminator** استفاده می‌شود که با `'\0'` نمایش داده می‌شود.

این کاراکتر نشان می‌دهد که رشته در کجا به پایان رسیده است.

## ۲. دریافت رشته از کاربر

```c
printf("Please enter your name:\n");

char name[10];
scanf("%9s", name);
```

توضیح دستورات:

- `printf()` پیام درخواست نام را نمایش می‌دهد.
- `char name[10]` یک آرایه کاراکتری با ۱۰ خانه ایجاد می‌کند.
- `scanf("%9s", name)` رشته واردشده توسط کاربر را دریافت می‌کند.

### چرا از `%9s` استفاده می‌کنیم؟

آرایه ما ۱۰ خانه دارد؛ اما یکی از خانه‌ها باید برای ذخیره کاراکتر پایان رشته (`'\0'`) باقی بماند.

بنابراین با استفاده از `%9s` حداکثر ۹ کاراکتر از ورودی دریافت می‌شود و یک خانه برای کاراکتر پایان رشته باقی می‌ماند.

این کار از سرریز آرایه (Buffer Overflow) در این عملیات ورودی جلوگیری می‌کند.

**نکته مهم:** دستور `%s` فقط تا اولین فاصله را دریافت می‌کند. بنابراین اگر کاربر عبارت `Amin Hosseini` را وارد کند، فقط `Amin` ذخیره خواهد شد.

## ۳. محاسبه طول آرایه

```c
int N = sizeof(name) / sizeof(name[0]);
printf("Length of array = %d\n", N);
```

در زبان C، عملگر `sizeof` اندازه یک متغیر یا آرایه را بر حسب بایت محاسبه می‌کند.

در این مثال:

- `sizeof(name)` اندازه کل آرایه را بر حسب بایت برمی‌گرداند.
- `sizeof(name[0])` اندازه یک خانه از آرایه را برمی‌گرداند.

از آنجا که هر متغیر از نوع `char` یک بایت فضا اشغال می‌کند:

```c
N = 10 / 1;
N = 10;
```

بنابراین طول آرایه همیشه ۱۰ است؛ حتی اگر کاربر فقط یک کاراکتر وارد کند.

## ۴. محاسبه طول واقعی رشته

```c
int M = 0;
int i;

for(i = 0; i < N; i++)
{
    if(name[i] == '\0') break;
    M++;
}
```

در این قسمت از یک حلقه `for` برای شمارش کاراکترهای رشته استفاده شده است.

حلقه تا زمانی ادامه پیدا می‌کند که به کاراکتر پایان رشته (`'\0'`) برسد.

مراحل اجرای برنامه:

1. متغیر `M` با مقدار صفر مقداردهی اولیه می‌شود.
2. حلقه `for` خانه‌های آرایه را از ابتدا بررسی می‌کند.
3. شرط `if(name[i] == '\0')` بررسی می‌کند که آیا به پایان رشته رسیده‌ایم یا خیر.
4. دستور `break` در صورت مشاهده کاراکتر پایان رشته، حلقه را متوقف می‌کند.
5. دستور `M++` تعداد کاراکترهای واقعی رشته را یک واحد افزایش می‌دهد.

برای مثال، اگر کاربر عبارت زیر را وارد کند:

```text
Amin
```

محتوای آرایه به شکل زیر خواهد بود:

```text
'A'  'm'  'i'  'n'  '\0'
```

حلقه چهار کاراکتر را شمارش می‌کند و هنگام رسیدن به `'\0'` متوقف می‌شود.

در نتیجه:

```c
M = 4;
```

## ۵. نمونه ورودی و خروجی

**ورودی:**

```text
Please enter your name:
Amin
```

**خروجی:**

```text
Your name is: Amin.
Length of array = 10
Length of string = 4
```

## ۶. تفاوت طول آرایه و طول رشته

| ویژگی | طول آرایه | طول رشته |
|---|---|---|
| مفهوم | تعداد کل خانه‌های اختصاص‌یافته | تعداد کاراکترهای واقعی |
| روش محاسبه | `sizeof(name) / sizeof(name[0])` | شمارش تا رسیدن به `'\0'` |
| احتساب Null Terminator | فضای آن در آرایه وجود دارد | در طول رشته محاسبه نمی‌شود |
| مثال | 10 | 4 |

اندازه آرایه ثابت است و در این برنامه همیشه ۱۰ خواهد بود؛ اما طول رشته به تعداد کاراکترهای واردشده توسط کاربر بستگی دارد.

## ۷. مفاهیم مهم زبان C در این برنامه

### کاراکتر پایان رشته (`'\0'`)

در زبان C تمام رشته‌ها با یک کاراکتر ویژه به نام Null Terminator پایان می‌یابند.

این کاراکتر با `'\0'` نمایش داده می‌شود و با کاراکتر `'0'` متفاوت است.

### عملگر `sizeof()`

برای محاسبه اندازه یک متغیر یا آرایه بر حسب بایت استفاده می‌شود.

هنگامی که آرایه به‌صورت مستقیم در دسترس باشد، می‌توان با تقسیم اندازه کل آرایه بر اندازه یک عضو، تعداد خانه‌های آن را محاسبه کرد.

### تابع `scanf()` و قالب `%s`

برای دریافت رشته از ورودی استاندارد استفاده می‌شود.

استفاده از محدودکننده طول مانند `%9s` باعث می‌شود تعداد کاراکترهای ورودی از ظرفیت در نظر گرفته‌شده برای آرایه بیشتر نشود.

### دستور `break`

برای خروج فوری از نزدیک‌ترین حلقه یا ساختار کنترلی قابل‌خروج استفاده می‌شود.

### عملگر افزایش (`++`)

مقدار یک متغیر را یک واحد افزایش می‌دهد.

برای مثال:

```c
M++;
```

معادل دستور زیر است:

```c
M = M + 1;
```

## ۸. پیچیدگی زمانی و حافظه

اگر `N` اندازه آرایه باشد:

- **پیچیدگی زمانی:** در بدترین حالت `O(N)` است؛ زیرا حلقه ممکن است تمام خانه‌های آرایه را بررسی کند.
- **پیچیدگی حافظه کمکی:** برابر `O(1)` است؛ زیرا از تعداد ثابتی متغیر و یک آرایه با اندازه مشخص استفاده شده است.

## ۹. نکات مهم

۱. آرایه `char name[10]` حداکثر می‌تواند ۹ کاراکتر به همراه کاراکتر پایان رشته ذخیره کند.

۲. استفاده از `%9s` مانع نوشتن بیش از ظرفیت آرایه در این عملیات ورودی می‌شود.

۳. تابع `scanf()` با قالب `%s` فاصله را به‌عنوان پایان ورودی در نظر می‌گیرد. برای مثال، از ورودی `Amin Hosseini` فقط `Amin` ذخیره می‌شود.

۴. طول آرایه همیشه ۱۰ است؛ حتی اگر کاربر فقط یک کاراکتر وارد کند.

۵. کاراکتر `'\0'` در محاسبه طول واقعی رشته شمارش نمی‌شود.

۶. این برنامه فرض می‌کند که `scanf()` با موفقیت ورودی را دریافت کرده است. در برنامه‌های واقعی بهتر است مقدار بازگشتی آن نیز بررسی شود.

## ۱۰. تمرین‌های پیشنهادی

۱. اندازه آرایه را از ۱۰ به ۲۰ تغییر دهید و خروجی را بررسی کنید.

۲. یک نام تک‌کاراکتری وارد کنید و تفاوت طول آرایه و طول رشته را مشاهده کنید.

۳. نامی بیشتر از ۹ کاراکتر وارد کنید و محدودیت دریافت ورودی را بررسی کنید.

۴. برنامه را با استفاده از `fgets()` تغییر دهید تا بتواند نام‌های دارای فاصله را نیز دریافت کند.

۵. برنامه‌ای بنویسید که تعداد حروف صدادار یک رشته را محاسبه کند.

۶. برنامه‌ای بنویسید که بدون استفاده از توابع کتابخانه‌ای، یک رشته را معکوس کند.
