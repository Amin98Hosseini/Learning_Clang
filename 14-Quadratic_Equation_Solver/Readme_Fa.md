# 14- حل معادله درجه دوم با زبان C

## ۱. معرفی پروژه

در این پروژه یک برنامه برای **حل معادله درجه دوم (Quadratic Equation)** با استفاده از زبان برنامه‌نویسی C پیاده‌سازی شده است.

برنامه سه ضریب معادله، یعنی `a`، `b` و `c` را از کاربر دریافت می‌کند و سپس با استفاده از محاسبه دلتا، نوع ریشه‌ها را تشخیص داده و آن‌ها را محاسبه می‌کند.

فرم کلی معادله به صورت زیر است:

\[
ax^2 + bx + c = 0
\]

برنامه می‌تواند حالت‌های مختلف زیر را تشخیص دهد:

- معادله درجه اول با یک ریشه حقیقی
- معادله درجه دوم با یک ریشه حقیقی تکراری
- معادله درجه دوم با دو ریشه حقیقی متفاوت
- معادله با دو ریشه موهومی
- معادله با دو ریشه مختلط
- حالت نامعتبر بودن معادله

در این پروژه با مفاهیمی مانند تابع، متغیرهای اعشاری، دستورات شرطی، محاسبات ریاضی و کتابخانه `math.h` آشنا می‌شویم.

## ۲. کد برنامه

```c
#include <stdio.h>
#include <math.h>

void SolveQuad();

int main()
{
    SolveQuad();
    return 0;
}

void SolveQuad()
{
    float a, b, c;

    printf("We are going to solve a quadratic equation in the form of:\n\n");
    printf("ax%c + bx + c = 0\n\n",0xFD);
    printf("Please enter coefficients of this equation.\n");
    printf("a = ");
    scanf("%f",&a);
    printf("b = ");
    scanf("%f",&b);
    printf("c = ");
    scanf("%f",&c);
    printf("\n");

    float x1, x2;

    if(a==0)
    {
        if(b==0)
        {
            printf("Error: The equation can not be solved.\n");
        }
        else
        {
            x1 = -c/b;
            printf("This equation if of the first-order and has a real root:\n");
            printf("x = %f\n",x1);
        }
    }
    else
    {
        float delta = b*b - 4*a*c;
        if(delta==0)
        {
            printf("This equation has a real double root:\n");
            x1 = -b/(2*a);
            printf("x1 = x2 = %f\n",x1);
        }
        else if(delta>0)
        {
            printf("This equation has two distinct real roots:\n");
            x1 = (-b + sqrt(delta))/(2*a);
            x2 = (-b - sqrt(delta))/(2*a);
            printf("x1 = %f\n",x1);
            printf("x2 = %f\n",x2);
        }
        else
        {
            if(b==0)
            {
                printf("This equation has two imaginary roots.\n");
                printf("x1 =  %fi\n",sqrt(-delta)/(2*a));
                printf("x2 = -%fi\n",sqrt(-delta)/(2*a));
            }
            else
            {
                printf("This equation has two complex roots.\n");
                printf("x1 =  %f + %fi\n",-b/(2*a),sqrt(-delta)/(2*a));
                printf("x2 =  %f - %fi\n",-b/(2*a),sqrt(-delta)/(2*a));
            }
        }
    }
    printf("\n-----------------------------------\n");
}
```

> **نکته:** در کد اصلی برای نمایش توان ۲ از کاراکتر `0xFD` استفاده شده است. نمایش این کاراکتر به Encoding ترمینال بستگی دارد. برای سازگاری بیشتر می‌توانید آن را با عبارت زیر جایگزین کنید:
>
> ```c
> printf("ax^2 + bx + c = 0\n\n");
> ```

## ۳. مبانی ریاضی معادله درجه دوم

معادله درجه دوم به شکل کلی زیر نوشته می‌شود:

\[
ax^2 + bx + c = 0
\]

در این رابطه:

- `a`: ضریب جمله درجه دوم
- `b`: ضریب جمله درجه اول
- `c`: جمله ثابت
- `x`: مجهول معادله

برای اینکه معادله واقعاً درجه دوم باشد، باید مقدار `a` مخالف صفر باشد.

### ۳.۱. محاسبه دلتا (Discriminant)

برای تشخیص تعداد و نوع ریشه‌های معادله، ابتدا مقدار دلتا محاسبه می‌شود:

\[
\Delta = b^2 - 4ac
\]

<LearningViz type_id="QUADRATIC_FORMULA" locale_override="fa-IR" initial_values={{"a":1,"b":-5,"c":6}} />

مقدار دلتا مشخص می‌کند که معادله چه نوع ریشه‌هایی دارد.

### ۳.۲. حالت اول: دلتا برابر صفر

اگر:

\[
\Delta = 0
\]

معادله دارای یک ریشه حقیقی تکراری است.

فرمول محاسبه ریشه:

\[
x_1 = x_2 = \frac{-b}{2a}
\]

مثال:

\[
x^2 - 4x + 4 = 0
\]

نتیجه:

\[
x_1 = x_2 = 2
\]

### ۳.۳. حالت دوم: دلتا بزرگ‌تر از صفر

اگر:

\[
\Delta > 0
\]

معادله دارای دو ریشه حقیقی و متفاوت است.

فرمول ریشه اول:

\[
x_1 = \frac{-b+\sqrt{\Delta}}{2a}
\]

فرمول ریشه دوم:

\[
x_2 = \frac{-b-\sqrt{\Delta}}{2a}
\]

مثال:

\[
x^2 - 5x + 6 = 0
\]

نتیجه:

\[
x_1 = 3,\qquad x_2 = 2
\]

### ۳.۴. حالت سوم: دلتا کوچک‌تر از صفر

اگر:

\[
\Delta < 0
\]

معادله دارای دو ریشه مختلط مزدوج است.

فرمول ریشه‌ها:

\[
x_1 = \frac{-b}{2a} + \frac{\sqrt{-\Delta}}{2a}i
\]

\[
x_2 = \frac{-b}{2a} - \frac{\sqrt{-\Delta}}{2a}i
\]

در این رابطه، `i` واحد موهومی است:

\[
i^2 = -1
\]

مثال:

\[
x^2 + 4 = 0
\]

نتیجه:

\[
x_1 = 2i,\qquad x_2 = -2i
\]

### ۳.۵. حالت چهارم: ضریب a برابر صفر

اگر:

\[
a = 0
\]

معادله دیگر درجه دوم نیست و به معادله درجه اول تبدیل می‌شود:

\[
bx+c=0
\]

اگر `b` مخالف صفر باشد:

\[
x = \frac{-c}{b}
\]

اما اگر هر دو ضریب `a` و `b` صفر باشند، وضعیت به مقدار `c` بستگی دارد:

- اگر `c` نیز صفر باشد، تمام اعداد حقیقی جواب هستند.
- اگر `c` مخالف صفر باشد، معادله هیچ جوابی ندارد.

کد اولیه در هر دو حالت فقط پیام خطا نمایش می‌دهد؛ این قسمت می‌تواند در نسخه‌های بعدی دقیق‌تر پیاده‌سازی شود.

## ۴. بررسی بخش‌های مختلف کد

### ۴.۱. فراخوانی کتابخانه‌ها

```c
#include <stdio.h>
#include <math.h>
```

در این قسمت دو کتابخانه مورد نیاز برنامه اضافه شده‌اند:

- `stdio.h`: برای استفاده از توابع ورودی و خروجی مانند `printf()` و `scanf()`.
- `math.h`: برای استفاده از توابع ریاضی مانند `sqrt()`.

تابع `sqrt()` برای محاسبه جذر یک عدد استفاده می‌شود.

### ۴.۲. تعریف تابع اولیه (Function Prototype)

```c
void SolveQuad();
```

در این قسمت تابعی با نام `SolveQuad` معرفی شده است.

کلمه `void` نشان می‌دهد که این تابع مقداری را به تابع فراخواننده برنمی‌گرداند.

شکل دقیق‌تر اعلان تابع در C استاندارد جدید:

```c
void SolveQuad(void);
```

### ۴.۳. تابع اصلی main

```c
int main()
{
    SolveQuad();
    return 0;
}
```

اجرای برنامه از تابع `main()` آغاز می‌شود.

در این تابع:

1. تابع `SolveQuad()` فراخوانی می‌شود.
2. تمام عملیات دریافت ضرایب و محاسبه ریشه‌ها در آن انجام می‌شود.
3. مقدار `0` از تابع `main()` برگردانده می‌شود که نشان‌دهنده پایان موفق برنامه است.

### ۴.۴. تعریف متغیرها

```c
float a, b, c;
```

سه متغیر از نوع `float` تعریف شده‌اند تا ضرایب معادله را ذخیره کنند.

استفاده از `float` باعث می‌شود بتوانیم اعداد اعشاری نیز به‌عنوان ضرایب وارد کنیم.

در ادامه:

```c
float x1, x2;
```

دو متغیر برای ذخیره ریشه‌های معادله تعریف شده‌اند.

### ۴.۵. دریافت ورودی از کاربر

```c
printf("a = ");
scanf("%f",&a);

printf("b = ");
scanf("%f",&b);

printf("c = ");
scanf("%f",&c);
```

در این قسمت ضرایب معادله از کاربر دریافت می‌شوند.

در تابع `scanf()`:

- `%f` برای دریافت مقدار از نوع `float` استفاده می‌شود.
- `&` آدرس حافظه متغیر را به تابع می‌دهد تا مقدار ورودی در آن ذخیره شود.

برای مثال:

```c
scanf("%f", &a);
```

یعنی مقدار واردشده توسط کاربر در متغیر `a` ذخیره شود.

### ۴.۶. بررسی درجه معادله

```c
if(a == 0)
{
    if(b == 0)
    {
        printf("Error: The equation can not be solved.\n");
    }
    else
    {
        x1 = -c/b;
    }
}
```

ابتدا بررسی می‌شود که آیا ضریب `a` برابر صفر است یا خیر.

اگر `a` صفر باشد، معادله درجه دوم نیست و باید به‌صورت معادله درجه اول حل شود.

اگر `b` نیز صفر باشد، برنامه پیام خطا نمایش می‌دهد.

در غیر این صورت ریشه معادله درجه اول از رابطه زیر محاسبه می‌شود:

\[
x = \frac{-c}{b}
\]

### ۴.۷. محاسبه دلتا

```c
float delta = b*b - 4*a*c;
```

در این قسمت مقدار دلتا محاسبه می‌شود.

این دستور معادل رابطه ریاضی زیر است:

\[
\Delta = b^2 - 4ac
\]

نتیجه این محاسبه مشخص می‌کند که کدام بخش از دستورات شرطی باید اجرا شود.

### ۴.۸. بررسی مقدار دلتا با if و else if

```c
if(delta == 0)
{
    // One repeated real root
}
else if(delta > 0)
{
    // Two distinct real roots
}
else
{
    // Two complex roots
}
```

در این قسمت سه حالت اصلی بررسی می‌شوند:

| شرط | نتیجه |
|---|---|
| `delta == 0` | یک ریشه حقیقی تکراری |
| `delta > 0` | دو ریشه حقیقی متفاوت |
| `delta < 0` | دو ریشه مختلط |

استفاده از `if` و `else if` باعث می‌شود تنها یکی از حالت‌های ممکن اجرا شود.

### ۴.۹. محاسبه ریشه‌های حقیقی

```c
x1 = (-b + sqrt(delta))/(2*a);
x2 = (-b - sqrt(delta))/(2*a);
```

در این قسمت از تابع `sqrt()` برای محاسبه جذر دلتا استفاده می‌شود.

تابع `sqrt()` از کتابخانه `math.h` در دسترس است.

### ۴.۱۰. محاسبه ریشه‌های مختلط

```c
sqrt(-delta)
```

وقتی دلتا منفی است، جذر مستقیم آن در مجموعه اعداد حقیقی تعریف نشده است.

به همین دلیل برنامه از `sqrt(-delta)` استفاده می‌کند تا اندازه بخش موهومی ریشه را محاسبه کند.

بخش حقیقی ریشه از رابطه زیر به دست می‌آید:

\[
Real = \frac{-b}{2a}
\]

و بخش موهومی از رابطه زیر محاسبه می‌شود:

\[
Imaginary = \frac{\sqrt{-\Delta}}{2a}
\]

در خروجی برنامه، حرف `i` برای نمایش واحد موهومی استفاده شده است.

## ۵. نمونه ورودی و خروجی برنامه

### مثال اول: دو ریشه حقیقی متفاوت

ورودی:

```text
a = 1
b = -5
c = 6
```

خروجی:

```text
This equation has two distinct real roots:
x1 = 3.000000

```

### مثال دوم: یک ریشه تکراری

ورودی:

```text
a = 1
b = -4
c = 4
```

خروجی:

```text
This equation has a real double root:
x1 = x2 = 2.000000
```

### مثال سوم: دو ریشه موهومی

ورودی:

```text
a = 1
b = 0
c = 4
```

خروجی:

```text
This equation has two imaginary roots.
x1 = 2.000000i
x2 = -2.000000i
```

### مثال چهارم: دو ریشه مختلط

ورودی:

```text
a = 1
b = 2
c = 5
```

خروجی:

```text
This equation has two complex roots.
x1 = -1.000000 + 2.000000i
x2 = -1.000000 - 2.000000i
```

### مثال پنجم: معادله درجه اول

ورودی:

```text
a = 0
b = 2
c = -6
```

خروجی:

```text
This equation if of the first-order and has a real root:

```

## ۷. کامپایل و اجرای برنامه

اگر از کامپایلر GCC استفاده می‌کنید، دستور زیر را اجرا کنید:

```bash
gcc main.c -o quadratic -lm
```

اجرای برنامه در Linux:

```bash
./quadratic
```

اجرای برنامه در Windows PowerShell:

```powershell
gcc main.c -o quadratic.exe -lm
.\quadratic.exe
```

پارامتر `-lm` برای اتصال کتابخانه ریاضی در محیط‌های معمول GCC استفاده می‌شود؛ این کتابخانه برای تابع `sqrt()` مورد نیاز است.

## ۸. نکات مهم و پیشنهادهای بهبود

این پروژه برای یادگیری مناسب است، اما می‌توان آن را از نظر دقت و مدیریت خطا بهبود داد:

۱. **بررسی ورودی‌ها:** بهتر است بررسی شود که `scanf()` واقعاً موفق به دریافت عدد شده است یا خیر.

۲. **مقایسه اعداد اعشاری:** مقایسه مستقیم اعداد اعشاری با صفر ممکن است به دلیل خطای گرد کردن نتیجه دقیقی نداشته باشد. می‌توان از یک مقدار تلورانس مانند `EPSILON` استفاده کرد.

۳. **مدیریت حالت‌های خاص:** اگر `a` و `b` هر دو صفر باشند، باید مقدار `c` نیز بررسی شود تا تفاوت بین بی‌نهایت جواب و بدون جواب مشخص شود.

۴. **استفاده از double:** برای افزایش دقت محاسبات می‌توان به‌جای `float` از `double` استفاده کرد. در این صورت برای دریافت ورودی با `scanf()` باید از `%lf` استفاده شود.

۵. **نمایش دقیق ریشه‌های مختلط:** بهتر است علامت بخش موهومی جداگانه مدیریت شود؛ به‌خصوص زمانی که مقدار `a` منفی است.

۶. **استفاده از فرمول پایدارتر:** در بعضی معادلات، به دلیل اختلاف زیاد اندازه ضرایب، فرمول استاندارد ممکن است دقت عددی را کاهش دهد. استفاده از روش پایدارتر محاسبه ریشه‌ها می‌تواند این مشکل را کمتر کند.

## ۹. تمرین‌های پیشنهادی

برای درک بهتر این پروژه، تمرین‌های زیر را انجام دهید:

۱. نوع متغیرهای `float` را به `double` تغییر دهید.

۲. برای هر سه ورودی، اعتبارسنجی با `scanf()` اضافه کنید.

۳. حالت‌های `a = 0` و `b = 0` را با توجه به مقدار `c` دقیق‌تر مدیریت کنید.

۴. مقدار دلتا را قبل از محاسبه ریشه‌ها نمایش دهید.

۵. امکان حل چند معادله متوالی را به برنامه اضافه کنید.

۶. برنامه را به چند تابع کوچک‌تر تقسیم کنید:

- `CalculateDelta()`
- `CalculateRealRoots()`
- `CalculateComplexRoots()`

۷. روش پایدارتر محاسبه ریشه‌های معادله درجه دوم را پیاده‌سازی کنید.
