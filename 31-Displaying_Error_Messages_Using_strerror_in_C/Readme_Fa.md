# 31- نمایش پیام‌های خطا با استفاده از تابع `strerror()` در زبان C

## 1. مقدمه

هنگام توسعه برنامه‌های زبان C، ممکن است در عملیات مختلفی مانند باز کردن فایل‌ها، دسترسی به منابع، تخصیص حافظه یا انجام عملیات ورودی و خروجی با خطا مواجه شویم.

کتابخانه استاندارد C تابعی به نام `strerror()` در اختیار ما قرار می‌دهد که یک کد خطا را به یک پیام متنی قابل فهم برای انسان تبدیل می‌کند.

برای مثال، به‌جای نمایش فقط یک شماره خطا:

```text
Error Code: 2
```

می‌توانیم پیام توضیحی آن را نمایش دهیم:

```text
No such file or directory
```

تابع `strerror()` زمانی کاربرد دارد که بخواهیم بدانیم یک کد خطا به چه مفهومی اشاره می‌کند.

در این آموزش یاد می‌گیریم:

- چگونه از تابع `strerror()` استفاده کنیم.
- کدهای خطا در زبان C چگونه نمایش داده می‌شوند.
- چگونه پیام‌های خطا را با `puts()` و `printf()` نمایش دهیم.
- چگونه از کتابخانه `errno.h` و ثابت‌های از پیش تعریف‌شده خطا استفاده کنیم.
- چگونه ورودی نامعتبر کاربر را مدیریت کنیم.
- چگونه از `strerror()` در برنامه‌های واقعی C استفاده کنیم.

## 2. کتابخانه‌های مورد نیاز

کد اصلی برنامه شامل موارد زیر است:

```c
#include <stdio.h>
#include <stdlib.h>
#define TRUE 1
```

اما در این برنامه از تابع `strerror()` استفاده شده است، بدون اینکه کتابخانه موردنیاز آن اضافه شده باشد.

کتابخانه صحیح عبارت است از:

```c
#include <string.h>
```

مجموعه کامل‌تری از کتابخانه‌ها برای کار با کدهای خطا به شکل زیر است:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <errno.h>
```

### کتابخانه `stdio.h`

توابع ورودی و خروجی استاندارد را فراهم می‌کند:

- `printf()` – نمایش خروجی قالب‌بندی‌شده.
- `scanf()` – دریافت ورودی قالب‌بندی‌شده.
- `puts()` – نمایش یک رشته و افزودن خط جدید.
- `fgets()` – دریافت یک خط از ورودی.

### کتابخانه `stdlib.h`

توابع عمومی و کاربردی زبان C را فراهم می‌کند، از جمله:

- `strtol()` – تبدیل یک رشته به عدد صحیح از نوع `long`.
- `malloc()` – تخصیص حافظه.
- `free()` – آزادسازی حافظه تخصیص‌یافته.
- `exit()` – خاتمه دادن به برنامه.

در کد اصلی از هیچ تابعی در این کتابخانه استفاده نشده است، اما در نسخه اصلاح‌شده این آموزش از `strtol()` استفاده خواهیم کرد.

### کتابخانه `string.h`

توابع مربوط به مدیریت رشته‌ها را فراهم می‌کند، از جمله:

- `strlen()`
- `strcpy()`
- `strcmp()`
- `strcat()`
- `strerror()`

تابع `strerror()` در این کتابخانه تعریف شده است.

### کتابخانه `errno.h`

این کتابخانه شامل ثابت‌ها و اعلان‌های مرتبط با مدیریت خطا است.

برخی از ثابت‌های خطای آن عبارت‌اند از:

- `EINVAL` – آرگومان نامعتبر.
- `ENOENT` – فایل یا مسیر موردنظر وجود ندارد.
- `ERANGE` – مقدار خارج از محدوده مجاز.
- `ENOMEM` – حافظه کافی وجود ندارد.
- `EACCES` – دسترسی مجاز نیست.

مقادیر عددی اختصاص‌یافته به این ثابت‌ها ممکن است در سیستم‌عامل‌ها و پیاده‌سازی‌های مختلف کتابخانه C متفاوت باشند.

## 3. کد کامل اصلی برنامه

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define TRUE 1

int main()
{
    int e;

    while (TRUE)
    {
        printf("Please enter an error code: ");
        scanf("%d", &e);
        printf("\n");

        if (e < 0)
            break;

        printf("Error message for Error Code #%d:\n", e);
        puts(strerror(e));
        printf("\n");
    }

    return 0;
}
```

مهم‌ترین اصلاح نسبت به کد اولیه، اضافه کردن کتابخانه زیر است:

```c
#include <string.h>
```

بدون این کتابخانه، برنامه اعلان صحیح تابع `strerror()` را در اختیار ندارد.

## 4. بررسی و توضیح بخش‌های مختلف برنامه

### 4.1. تعریف ماکروی `TRUE`

```c
#define TRUE 1
```

دستور `#define` برای تعریف یک ماکرو در مرحله پیش‌پردازش استفاده می‌شود.

هر جا که پیش‌پردازنده با عبارت `TRUE` مواجه شود، آن را با مقدار `1` جایگزین می‌کند.

برای مثال:

```c
while (TRUE)
```

عملاً به شکل زیر پردازش می‌شود:

```c
while (1)
```

در زبان C، شرطی که مقدار آن غیرصفر باشد، درست و شرطی که مقدار آن صفر باشد، نادرست در نظر گرفته می‌شود.

بنابراین:

- `1` به معنی True است.
- `0` به معنی False است.

با استفاده از این ماکرو می‌توانیم حلقه‌ای ایجاد کنیم که به‌صورت نامحدود اجرا شود و فقط زمانی متوقف شود که خودمان دستور توقف را اجرا کنیم.

روش جایگزین:

```c
while (1)
{
    // Statements
}
```

هر دو روش یک حلقه بی‌نهایت ایجاد می‌کنند.

### 4.2. تعریف متغیر کد خطا

```c
int e;
```

در این قسمت یک متغیر صحیح به نام `e` تعریف می‌کنیم.

این متغیر کد خطایی را که کاربر وارد می‌کند، ذخیره خواهد کرد.

برای مثال، اگر کاربر مقدار زیر را وارد کند:

```text
2
```

مقدار متغیر به شکل زیر خواهد بود:

```c
e = 2;
```

### 4.3. ایجاد حلقه بی‌نهایت

```c
while (TRUE)
{
    // Statements
}
```

از آنجا که مقدار `TRUE` برابر با `1` است، حلقه `while` به‌صورت مداوم دستورات داخل خود را اجرا می‌کند.

این حلقه زمانی متوقف می‌شود که دستور `break` اجرا شود.

این روش زمانی کاربرد دارد که برنامه باید چندین بار از کاربر ورودی دریافت کند.

### 4.4. درخواست کد خطا از کاربر

```c
printf("Please enter an error code: ");
```

این دستور یک پیام در خروجی نمایش می‌دهد و از کاربر می‌خواهد کد خطا را وارد کند.

### 4.5. دریافت کد خطا با تابع `scanf()`

```c
scanf("%d", &e);
```

تابع `scanf()` برای دریافت ورودی قالب‌بندی‌شده از ورودی استاندارد، معمولاً صفحه‌کلید، استفاده می‌شود.

مشخص‌کننده قالب‌بندی زیر:

```c
%d
```

نشان می‌دهد که برنامه انتظار دریافت یک عدد صحیح را دارد.

عملگر آدرس:

```c
&e
```

آدرس حافظه متغیر `e` را به تابع ارسال می‌کند تا مقدار واردشده در آن ذخیره شود.

برای مثال، اگر کاربر مقدار زیر را وارد کند:

```text
5
```

تابع `scanf()` مقدار زیر را در متغیر ذخیره می‌کند:

```c
e = 5;
```

**نکته مهم:** در برنامه اصلی بررسی نمی‌شود که آیا `scanf()` موفق به دریافت عدد صحیح شده است یا خیر. این موضوع هنگام وارد کردن اطلاعات نامعتبر می‌تواند مشکل ایجاد کند. در ادامه برنامه را اصلاح خواهیم کرد.

### 4.6. بررسی منفی بودن کد خطا

```c
if (e < 0)
    break;
```

در این قسمت بررسی می‌کنیم که آیا مقدار واردشده منفی است یا خیر.

اگر شرط درست باشد، دستور `break` بلافاصله نزدیک‌ترین حلقه در حال اجرا را متوقف می‌کند.

برای مثال:

| مقدار واردشده | نتیجه |
|---:|---|
| `0` | ادامه برنامه و نمایش پیام |
| `1` | ادامه برنامه و نمایش پیام |
| `2` | ادامه برنامه و نمایش پیام |
| `10` | ادامه برنامه و نمایش پیام |
| `-1` | خروج از حلقه |
| `-5` | خروج از حلقه |

در این برنامه از یک عدد منفی به‌عنوان علامت پایان استفاده شده است.

باید توجه داشته باشیم که عدد منفی الزاماً یک کد خطای معتبر برای `strerror()` نیست. در این برنامه فقط برای متوقف کردن حلقه از آن استفاده می‌کنیم.

### 4.7. نمایش شماره کد خطا

```c
printf("Error message for Error Code #%d:\n", e);
```

این دستور شماره کد خطایی را که کاربر وارد کرده است نمایش می‌دهد.

مشخص‌کننده `%d` برای نمایش اعداد صحیح استفاده می‌شود.

برای مثال، اگر:

```c
e = 2;
```

خروجی به شکل زیر خواهد بود:

```text
Error message for Error Code #2:
```

### 4.8. آشنایی با تابع `strerror()`

```c
puts(strerror(e));
```

این دستور مهم‌ترین قسمت برنامه است.

تابع `strerror()` یک شماره خطا را به یک رشته متنی قابل فهم تبدیل می‌کند.

ساختار عمومی آن:

```c
strerror(error_code);
```

این تابع یک عدد صحیح به‌عنوان کد خطا دریافت می‌کند و اشاره‌گری به رشته‌ای حاوی توضیح آن خطا برمی‌گرداند.

برای مثال:

```c
strerror(2);
```

در بسیاری از سیستم‌ها ممکن است پیام زیر را برگرداند:

```text
No such file or directory
```

البته متن دقیق پیام و ارتباط شماره‌های خطا با مفهوم آن‌ها به سیستم‌عامل و پیاده‌سازی کتابخانه C بستگی دارد.

در برنامه ما:

```c
puts(strerror(e));
```

از دو تابع به‌صورت ترکیبی استفاده می‌شود:

1. تابع `strerror(e)` توضیح متنی خطا را دریافت می‌کند.
2. تابع `puts()` متن برگشتی را نمایش می‌دهد.

تابع `puts()` بعد از نمایش رشته، به‌صورت خودکار یک کاراکتر خط جدید اضافه می‌کند.

دو دستور زیر از نظر کاربرد معمول مفهوم مشابهی دارند:

```c
puts(strerror(e));
```

و:

```c
printf("%s\n", strerror(e));
```

### 4.9. ایجاد یک خط خالی

```c
printf("\n");
```

این دستور یک کاراکتر خط جدید چاپ می‌کند تا خروجی مربوط به هر بار اجرای حلقه از قسمت بعدی جدا شود.

این کار باعث خواناتر شدن خروجی ترمینال می‌شود.

### 4.10. پایان تابع `main()`

```c
return 0;
```

این دستور اجرای برنامه را خاتمه می‌دهد و موفقیت‌آمیز بودن اجرای برنامه را نشان می‌دهد.

به‌طور معمول، برگرداندن مقدار `0` از تابع `main()` به معنی پایان موفقیت‌آمیز برنامه است.

## 5. تابع `strerror()` چیست؟

تابع `strerror()` بخشی از کتابخانه استاندارد زبان C است.

این تابع در کتابخانه زیر اعلان شده است:

```c
#include <string.h>
```

نمونه اعلان تابع:

```c
char *strerror(int errnum);
```

### پارامتر ورودی

| پارامتر | توضیح |
|---|---|
| `errnum` | کد عددی خطایی که می‌خواهیم توضیح آن را دریافت کنیم |

### مقدار بازگشتی

این تابع اشاره‌گری به یک رشته برمی‌گرداند که توضیح متنی خطای مشخص‌شده را در خود دارد.

برای مثال:

```c
printf("%s\n", strerror(2));
```

خروجی احتمالی در یک سیستم رایج:

```text
No such file or directory
```

**نکات مهم:**

- پیام برگشتی به پیاده‌سازی سیستم وابسته است و ممکن است بر اساس تنظیمات زبان سیستم ترجمه شده باشد.
- فرض نکنید که یک شماره خطای مشخص در تمام سیستم‌عامل‌ها مفهوم یکسانی دارد.
- رشته برگشتی را نباید تغییر دهید.
- اشاره‌گر برگشتی ممکن است به حافظه داخلی مدیریت‌شده توسط کتابخانه C اشاره کند. اگر لازم است متن را مستقل نگهداری کنید، آن را در یک بافر جداگانه کپی کنید.
- در برنامه‌های چندنخی، برای اطمینان از ایمنی استفاده هم‌زمان باید مستندات سیستم‌عامل بررسی شود. برخی سیستم‌ها تابع `strerror_r()` را نیز ارائه می‌کنند، اما رابط آن در پیاده‌سازی‌های مختلف یکسان نیست.

## 6. آشنایی با کدهای خطای رایج

کتابخانه `errno.h` تعدادی ثابت نمادین برای خطاهای متداول تعریف می‌کند.

برخی از آن‌ها عبارت‌اند از:

| ثابت | مفهوم |
|---|---|
| `EINVAL` | آرگومان نامعتبر |
| `ENOENT` | فایل یا مسیر موردنظر وجود ندارد |
| `ERANGE` | مقدار خارج از محدوده مجاز |
| `ENOMEM` | حافظه کافی وجود ندارد |
| `EACCES` | دسترسی مجاز نیست |
| `EBADF` | شناسه فایل نامعتبر است |
| `EEXIST` | فایل از قبل وجود دارد |
| `EIO` | خطای ورودی و خروجی |
| `ENOSPC` | فضای ذخیره‌سازی کافی وجود ندارد |

این ثابت‌ها نسبت به استفاده مستقیم از اعداد، خواناتر و قابل‌حمل‌تر هستند.

برای مثال، به‌جای نوشتن:

```c
strerror(2);
```

می‌توانیم بنویسیم:

```c
strerror(ENOENT);
```

روش دوم مفهوم موردنظر را واضح‌تر نشان می‌دهد.

**نکته:** مجموعه ثابت‌های موجود و مقدار عددی آن‌ها به پیاده‌سازی سیستم وابسته است. از ثابت‌هایی استفاده کنید که در سیستم هدف تعریف شده‌اند.

## 7. نسخه اصلاح‌شده با استفاده از ثابت‌های استاندارد خطا

در مثال زیر نحوه استفاده از `strerror()` همراه با ثابت‌های از پیش تعریف‌شده را بررسی می‌کنیم:

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void)
{
    printf("Common error messages:\n\n");

    printf("EINVAL: %s\n", strerror(EINVAL));
    printf("ENOENT: %s\n", strerror(ENOENT));
    printf("ERANGE: %s\n", strerror(ERANGE));
    printf("ENOMEM: %s\n", strerror(ENOMEM));
    printf("EACCES: %s\n", strerror(EACCES));

    return 0;
}
```

این برنامه از کاربر کد خطا دریافت نمی‌کند.

در عوض، پیام‌های مربوط به چند ثابت خطای استاندارد را نمایش می‌دهد.

خروجی برنامه به سیستم‌عامل و کتابخانه C مورد استفاده بستگی دارد.

## 8. نسخه تعاملی اصلاح‌شده

برنامه اصلی دو محدودیت مهم دارد:

1. بررسی نمی‌کند که آیا `scanf()` موفق به خواندن یک عدد صحیح شده است یا خیر.
2. اگر کاربر به‌جای عدد، متن وارد کند، تابع `scanf()` شکست می‌خورد اما کاراکترهای نامعتبر را از ورودی حذف نمی‌کند. در نتیجه ممکن است حلقه همان ورودی نامعتبر را بارها پردازش کند.

می‌توانیم با استفاده از `fgets()` و `strtol()` برنامه را به شکل مطمئن‌تری بنویسیم.

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <errno.h>
#include <ctype.h>
#include <limits.h>

int main(void)
{
    char input[100];
    char *endptr;

    while (1)
    {
        printf("Please enter an error code (negative number to exit): ");

        if (fgets(input, sizeof(input), stdin) == NULL)
        {
            printf("\nInput ended.\n");
            break;
        }

        errno = 0;

        long value = strtol(input, &endptr, 10);

        if (endptr == input)
        {
            printf("Invalid input: Please enter an integer.\n\n");
            continue;
        }

        while (isspace((unsigned char)*endptr))
        {
            endptr++;
        }

        if (*endptr != '\0')
        {
            printf("Invalid input: Unexpected characters found.\n\n");
            continue;
        }

        if (errno == ERANGE || value < INT_MIN || value > INT_MAX)
        {
            printf("Error: Integer value is out of range.\n\n");
            continue;
        }

        int e = (int)value;

        if (e < 0)
        {
            printf("Exiting program...\n");
            break;
        }

        printf("\nError message for Error Code #%d:\n", e);
        puts(strerror(e));
        printf("\n");
    }

    return 0;
}
```

### بررسی نسخه اصلاح‌شده

**مرحله اول – دریافت یک خط کامل از ورودی**

```c
fgets(input, sizeof(input), stdin);
```

به‌جای اینکه مستقیماً یک عدد صحیح دریافت کنیم، ابتدا یک خط کامل را داخل آرایه کاراکتری ذخیره می‌کنیم.

این روش به ما اجازه می‌دهد قبل از تبدیل، ورودی را بررسی کنیم.

**مرحله دوم – مقداردهی مجدد `errno`**

```c
errno = 0;
```

متغیر `errno` توسط بسیاری از توابع کتابخانه‌ای برای گزارش برخی خطاها استفاده می‌شود.

قبل از اجرای `strtol()` مقدار آن را صفر می‌کنیم تا مقدار خطای قبلی با بررسی تبدیل فعلی اشتباه گرفته نشود.

**مرحله سوم – تبدیل رشته به عدد صحیح**

```c
long value = strtol(input, &endptr, 10);
```

تابع `strtol()` یک رشته را به عدد صحیح از نوع `long` تبدیل می‌کند.

ساختار عمومی:

```c
strtol(string, endptr, base);
```

| پارامتر | توضیح |
|---|---|
| `string` | رشته‌ای که مقدار عددی در آن قرار دارد |
| `endptr` | آدرس اولین کاراکتری که تبدیل نشده است را دریافت می‌کند |
| `base` | مبنای عددی؛ مقدار `10` به معنی مبنای ده‌دهی است |

برای مثال:

```c
char input[] = "123abc";
char *endptr;

long value = strtol(input, &endptr, 10);
```

پس از تبدیل:

```text
value = 123
```

و اشاره‌گر `endptr` به بخش زیر اشاره می‌کند:

```text
abc
```

**مرحله چهارم – بررسی انجام شدن تبدیل**

```c
if (endptr == input)
```

اگر `endptr` همچنان به ابتدای رشته اشاره کند، یعنی هیچ تبدیل عددی انجام نشده است.

برای مثال، ورودی زیر نامعتبر است:

```text
hello
```

**مرحله پنجم – نادیده گرفتن فاصله‌های اضافی**

```c
while (isspace((unsigned char)*endptr))
{
    endptr++;
}
```

تابع `isspace()` بررسی می‌کند که آیا یک کاراکتر از نوع فضای خالی است یا خیر.

برای مثال:

- Space
- Tab
- Newline

با استفاده از این حلقه، فاصله‌های اضافی بعد از عدد را نادیده می‌گیریم.

تبدیل به `(unsigned char)` تضمین می‌کند که آرگومان ارسال‌شده به `isspace()` در محدوده معتبر این تابع قرار دارد.

**مرحله ششم – رد کردن کاراکترهای اضافی**

```c
if (*endptr != '\0')
```

پس از حذف فاصله‌های خالی، بررسی می‌کنیم که آیا کاراکتر دیگری در رشته باقی مانده است یا خیر.

برای مثال:

```text
123abc
```

نامعتبر است؛ زیرا بعد از عدد، متن `abc` باقی می‌ماند.

**مرحله هفتم – بررسی محدوده عدد صحیح**

```c
if (errno == ERANGE || value < INT_MIN || value > INT_MAX)
```

تابع `strtol()` یک مقدار از نوع `long` برمی‌گرداند، درحالی‌که متغیر اصلی برنامه از نوع `int` است.

بنابراین باید مطمئن شویم مقدار تبدیل‌شده در محدوده قابل‌قبول برای `int` قرار دارد.

**مرحله هشتم – تبدیل به `int`**

```c
int e = (int)value;
```

پس از بررسی محدوده، مقدار را به نوع `int` تبدیل می‌کنیم.

**مرحله نهم – بررسی شرط خروج**

```c
if (e < 0)
{
    printf("Exiting program...\n");
    break;
}
```

اگر مقدار منفی باشد، حلقه متوقف می‌شود.

در غیر این صورت، برنامه پیام خطای مربوط به مقدار واردشده را نمایش می‌دهد.

## 9. کاربرد عملی: نمایش خطا هنگام باز کردن فایل

یکی از رایج‌ترین کاربردهای `strerror()` نمایش پیام مناسب هنگام شکست عملیات فایل است.

برنامه زیر را در نظر بگیرید:

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void)
{
    FILE *file = fopen("data.txt", "r");

    if (file == NULL)
    {
        printf("Failed to open file!\n");
        printf("Reason: %s\n", strerror(errno));

        return 1;
    }

    printf("File opened successfully.\n");

    fclose(file);

    return 0;
}
```

### توضیح برنامه

برنامه تلاش می‌کند فایل `data.txt` را در حالت خواندن باز کند.

```c
FILE *file = fopen("data.txt", "r");
```

اگر فایل باز نشود، تابع `fopen()` مقدار `NULL` را برمی‌گرداند.

در این حالت، پیام توضیحی خطا را نمایش می‌دهیم:

```c
strerror(errno)
```

متغیر `errno` از طریق کتابخانه `errno.h` در دسترس است.

این متغیر معمولاً زمانی که یک تابع کتابخانه‌ای با شکست مواجه می‌شود و خطا برای آن تعریف شده است، مقدار خطا را نگهداری می‌کند.

**نکته مهم:** فقط زمانی `errno` را بررسی کنید که مستندات تابع مورد استفاده مشخص کرده باشند در حالت شکست، مقدار آن قابل استفاده است. اجرای موفق یک تابع لزوماً `errno` را صفر نمی‌کند؛ بنابراین نباید از مقدار قدیمی `errno` برای توضیح یک عملیات موفق استفاده کنید.

## 10. تفاوت توابع `strerror()` و `perror()`

در زبان C تابع مفید دیگری به نام `perror()` نیز وجود دارد.

هر دو تابع برای نمایش توضیحات خطا استفاده می‌شوند، اما عملکرد آن‌ها متفاوت است.

| تابع | کاربرد |
|---|---|
| `strerror()` | یک رشته شامل توضیح کد خطا برمی‌گرداند |
| `perror()` | یک متن دلخواه را همراه با پیام مربوط به `errno` نمایش می‌دهد |

### استفاده از `strerror()`

```c
printf("Error: %s\n", strerror(errno));
```

### استفاده از `perror()`

```c
perror("File operation failed");
```

خروجی احتمالی:

```text
File operation failed: No such file or directory
```

تابع `perror()` زمانی مفید است که بخواهیم بدون قالب‌بندی دستی، پیام خطا را مستقیماً نمایش دهیم.

زمانی از `strerror()` استفاده می‌کنیم که به متن خطا به‌عنوان یک رشته نیاز داشته باشیم؛ برای مثال، هنگام ساخت پیام Log یا ذخیره آن در یک بافر.

## 11. اشتباهات رایج

### اشتباه اول: فراموش کردن کتابخانه `string.h`

نادرست:

```c
#include <stdio.h>

int main(void)
{
    puts(strerror(2));
    return 0;
}
```

درست:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    puts(strerror(2));
    return 0;
}
```

اعلان تابع `strerror()` در کتابخانه `string.h` قرار دارد.

### اشتباه دوم: فرض کردن یکسان بودن شماره خطاها در تمام سیستم‌ها

نباید فرض کنیم یک شماره خطای مشخص در تمام سیستم‌عامل‌ها مفهوم یکسانی دارد.

بهتر است از ثابت‌های استاندارد استفاده کنیم:

```c
strerror(ENOENT);
```

به‌جای اینکه یک عدد را مستقیماً وارد کنیم:

```c
strerror(2);
```

### اشتباه سوم: بررسی نکردن نتیجه `scanf()`

روش نامناسب:

```c
scanf("%d", &e);
```

روش بهتر:

```c
if (scanf("%d", &e) != 1)
{
    printf("Invalid input!\n");
}
```

البته در برنامه‌هایی که از `scanf()` استفاده می‌کنند، باید کاراکترهای نامعتبر باقی‌مانده در ورودی نیز مدیریت شوند. روش `fgets()` و `strtol()` که در این آموزش بررسی کردیم، کنترل بهتری روی ورودی فراهم می‌کند.

### اشتباه چهارم: تصور اینکه `strerror()` خودش خطا را تشخیص می‌دهد

تابع `strerror()` فقط یک شماره خطا را به پیام متنی تبدیل می‌کند.

این تابع به‌تنهایی خطا را تشخیص نمی‌دهد و مشخص نمی‌کند که یک عملیات ناموفق بوده است یا خیر.

برای مثال:

```c
strerror(ENOENT);
```

فقط توضیح مربوط به `ENOENT` را درخواست می‌کند.

برای تشخیص واقعی خطا هنگام باز کردن فایل، ابتدا باید مقدار بازگشتی `fopen()` را بررسی کنیم.

### اشتباه پنجم: فرض کردن اینکه پیام خطا همیشه انگلیسی است

پیام برگشتی ممکن است به پیاده‌سازی کتابخانه و تنظیمات زبان سیستم بستگی داشته باشد.

برای تصمیم‌گیری در منطق برنامه نباید به متن دقیق پیام وابسته شویم. برای این کار از ثابت‌های خطا و مقادیر بازگشتی توابع استفاده می‌کنیم.

## 12. کامپایل و اجرای برنامه

```text
main.c
```

کامپایل با استفاده از GCC:

```bash
gcc main.c -o strerror_example
```

اجرای برنامه در Linux یا macOS:

```bash
./strerror_example
```

اجرای برنامه در Windows:

```powershell
gcc main.c -o strerror_example.exe
.\strerror_example.exe
```

برای اجرای برنامه به کتابخانه خارجی اضافی نیاز نداریم.

## 13. تمرین‌ها

برای درک بهتر مطالب، تمرین‌های زیر را انجام دهید.

**تمرین اول – نمایش پیام خطاهای رایج**

برنامه‌ای بنویسید که پیام‌های مربوط به ثابت‌های زیر را نمایش دهد:

- `EINVAL`
- `ENOENT`
- `ENOMEM`
- `EACCES`
- `ERANGE`

برای هر کدام از ثابت‌ها از تابع `strerror()` استفاده کنید.

**تمرین دوم – ساخت برنامه تعاملی**

برنامه اصلی را تغییر دهید تا کاربر بتواند چندین کد خطا وارد کند.

برنامه باید زمانی متوقف شود که کاربر یک عدد منفی وارد کند.

**تمرین سوم – مدیریت ورودی نامعتبر**

برنامه تعاملی را طوری تغییر دهید که ورودی‌های زیر را مدیریت کند:

```text
hello
```

```text
12abc
```

```text
999999999999999999999999
```

برنامه باید پیام خطای مناسب نمایش دهد و از خاتمه غیرمنتظره یا پردازش مداوم ورودی نامعتبر جلوگیری کند.

**تمرین چهارم – مدیریت خطای فایل**

برنامه‌ای بنویسید که تلاش کند فایلی با نام `example.txt` را باز کند.

اگر فایل باز نشد، پیام خطای مربوطه را با استفاده از `strerror(errno)` نمایش دهید.

**تمرین پنجم – مقایسه `strerror()` و `perror()`**

برنامه‌ای بنویسید که تلاش کند یک فایل غیرموجود را باز کند.

یک بار پیام خطا را با `strerror()` و بار دیگر با `perror()` نمایش دهید.

خروجی دو روش را با یکدیگر مقایسه کنید.

**تمرین ششم – ساخت جدول پیام‌های خطا**

برنامه‌ای ایجاد کنید که چند ثابت خطای از پیش تعریف‌شده را همراه با توضیح آن‌ها نمایش دهد.

برای مثال:

```text
ENOENT: No such file or directory
EINVAL: Invalid argument
ENOMEM: Not enough memory
```

## 14. اهداف آموزشی

پس از مطالعه این آموزش باید بتوانید:

- از تابع `strerror()` برای دریافت پیام متنی خطا استفاده کنید.
- دلیل نیاز به کتابخانه `string.h` را توضیح دهید.
- مفهوم کدهای خطا در زبان C را درک کنید.
- از ثابت‌های خطای موجود در `errno.h` استفاده کنید.
- رشته‌های برگشتی از توابع کتابخانه‌ای را نمایش دهید.
- از حلقه‌های `while` و دستور `break` استفاده کنید.
- ورودی کاربر را اعتبارسنجی کنید.
- با استفاده از `strtol()` رشته‌ها را به اعداد صحیح تبدیل کنید.
- کاربرد متغیر `errno` را درک کنید.
- تفاوت توابع `strerror()` و `perror()` را توضیح دهید.
- هنگام شکست عملیات فایل، پیام خطای مناسب نمایش دهید.
