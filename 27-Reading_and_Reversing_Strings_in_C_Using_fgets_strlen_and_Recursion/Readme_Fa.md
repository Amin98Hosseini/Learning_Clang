# 27- خواندن و معکوس کردن رشته در زبان C با استفاده از `fgets()`، `strlen()` و Recursion

## ۱. مقدمه

در زبان برنامه‌نویسی C، رشته‌ها (Strings) مجموعه‌ای از کاراکترها هستند که در آرایه‌های نوع `char` ذخیره می‌شوند.

در این آموزش یاد می‌گیریم چگونه:

- یک خط کامل متن را از کاربر دریافت کنیم.
- ورودی را در یک آرایه از نوع `char` ذخیره کنیم.
- از تابع `fgets()` برای دریافت رشته استفاده کنیم.
- طول رشته را با تابع `strlen()` محاسبه کنیم.
- مفهوم کاراکتر پایان رشته (`'\0'`) را درک کنیم.
- با استفاده از بازگشت یا Recursion یک رشته را معکوس کنیم.
- نحوه اجرای توابع بازگشتی را بررسی کنیم.

برنامه ابتدا از کاربر می‌خواهد یک خط متن وارد کند، سپس متن واردشده را نمایش می‌دهد، طول آن را محاسبه می‌کند و در نهایت متن را به‌صورت معکوس چاپ می‌کند.

برای مثال، اگر کاربر عبارت زیر را وارد کند:

```text
Hello World
```

خروجی برنامه به شکل زیر خواهد بود:

```text
Entered text is:
Hello World

Length of entered text: 11

Reversed text:
dlroW olleH
```

## ۲. کتابخانه‌های مورد نیاز

در این برنامه از کتابخانه زیر استفاده می‌کنیم:

```c
#include <stdio.h>
#include <string.h>
```

### کتابخانه `<stdio.h>`

این کتابخانه برای عملیات ورودی و خروجی استفاده می‌شود و توابع و امکانات زیر را در اختیار ما قرار می‌دهد:

- `printf()` برای نمایش اطلاعات.
- `fgets()` برای دریافت یک خط متن.
- `putchar()` برای چاپ یک کاراکتر.
- `stdin` برای دسترسی به جریان ورودی استاندارد.

### کتابخانه `<string.h>`

این کتابخانه شامل توابع مختلف برای کار با رشته‌ها است، از جمله:

- `strlen()` برای محاسبه طول رشته.
- `strcpy()` برای کپی کردن رشته.
- `strcat()` برای اتصال دو رشته.
- `strcmp()` برای مقایسه دو رشته.
- `strchr()` برای جست‌وجوی یک کاراکتر.
- `strcspn()` برای پیدا کردن طول بخش ابتدایی رشته که هیچ‌کدام از کاراکترهای مشخص‌شده را ندارد.

در کد اولیه از تابع `strlen()` استفاده شده، اما کتابخانه `<string.h>` اضافه نشده است. این مورد باید اصلاح شود.

## ۳. بررسی کد اصلی برنامه

ابتدا کد اولیه را بررسی می‌کنیم:

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    char str[50];

    printf("Enter a line of text:\n");
    fgets(str, 50, stdin);

    printf("\nEntered text is:\n%s\n", str);

    printf("Length of entered text: %d\n", strlen(str) - 1);

    printf("\nReversed text:\n");
    ReverseString(str);
    printf("\n");

    return 0;
}

void ReverseString(const char *s)
{
    if (s[0] == '\0')
    {
        return;
    }
    else
    {
        ReverseString(&s[1]);

        if (s[0] != '\n')
        {
            putchar(s[0]);
        }
    }
}
```

در ادامه تمام قسمت‌های برنامه را بررسی می‌کنیم و سپس نسخه اصلاح‌شده را خواهیم نوشت.

## ۴. آشنایی با آرایه کاراکتری

```c
char str[50];
```

این دستور یک آرایه از نوع `char` با ظرفیت ۵۰ کاراکتر ایجاد می‌کند.

در زبان C، رشته باید با یک کاراکتر ویژه به نام Null Terminator پایان یابد:

```c
'\0'
```

برای مثال:

```c
char name[] = "Amin";
```

محتوای آرایه به شکل زیر خواهد بود:

| اندیس | کاراکتر |
|---:|:---:|
| 0 | `A` |
| 1 | `m` |
| 2 | `i` |
| 3 | `n` |
| 4 | `\0` |

اگرچه کلمه `"Amin"` فقط چهار کاراکتر قابل مشاهده دارد، آرایه برای ذخیره کاراکتر پایان رشته به پنج خانه نیاز دارد.

این موضوع بسیار مهم است؛ زیرا زبان C با استفاده از `'\0'` تشخیص می‌دهد که یک رشته در کجا به پایان رسیده است.

## ۵. دریافت یک خط متن با استفاده از `fgets()`

در برنامه اصلی از دستور زیر استفاده شده است:

```c
fgets(str, 50, stdin);
```

ساختار تابع `fgets()` به شکل زیر است:

```c
char *fgets(char *str, int size, FILE *stream);
```

این تابع سه پارامتر دریافت می‌کند:

| پارامتر | توضیحات |
|---|---|
| `str` | آرایه مقصد برای ذخیره کاراکترها |
| `size` | حداکثر تعداد کاراکترهای قابل ذخیره، با احتساب Null Terminator |
| `stream` | جریان ورودی که داده‌ها از آن خوانده می‌شوند |

### ۵.۱. پارامتر `str`

```c
fgets(str, 50, stdin);
```

پارامتر اول آرایه‌ای است که متن واردشده توسط کاربر در آن ذخیره می‌شود.

### ۵.۲. پارامتر `50`

پارامتر دوم حداکثر تعداد کاراکترهایی را مشخص می‌کند که تابع می‌تواند ذخیره کند.

این مقدار شامل کاراکتر پایان رشته نیز می‌شود.

بنابراین اگر آرایه ۵۰ خانه داشته باشد، تابع حداکثر ۴۹ کاراکتر ورودی و یک کاراکتر `'\0'` را ذخیره می‌کند.

این محدودیت باعث می‌شود اطلاعات خارج از محدوده آرایه نوشته نشوند.

### ۵.۳. پارامتر `stdin`

عبارت `stdin` مخفف Standard Input است.

در حالت معمول، ورودی استاندارد همان صفحه‌کلید است.

بنابراین دستور:

```c
fgets(str, 50, stdin);
```

یعنی:

یک خط از ورودی استاندارد بخوان و آن را در آرایه `str` ذخیره کن، به‌طوری که حداکثر ۴۹ کاراکتر ورودی خوانده شود.

### ۵.۴. آیا `fgets()` کاراکتر Newline را هم ذخیره می‌کند؟

بله.

اگر کاربر عبارت زیر را وارد کند:

```text
Hello World
```

و کلید Enter را فشار دهد، تابع `fgets()` در صورتی که فضای کافی داشته باشد، کاراکتر Newline یعنی `'\n'` را نیز در رشته ذخیره می‌کند.

بنابراین محتوای آرایه به‌صورت مفهومی چنین خواهد بود:

```text
H e l l o   W o r l d \n \0
```

باید تفاوت این دو کاراکتر را بدانیم:

- `'\n'` نشان‌دهنده رفتن به خط بعدی است و معمولاً هنگام فشردن Enter وارد رشته می‌شود.
- `'\0'` نشان‌دهنده پایان رشته در زبان C است.

این تفاوت در محاسبه طول رشته و معکوس کردن آن اهمیت زیادی دارد.

## ۶. محاسبه طول رشته با استفاده از `strlen()`

در کد اصلی دستور زیر وجود دارد:

```c
strlen(str) - 1
```

تابع `strlen()` تعداد کاراکترهای یک رشته را محاسبه می‌کند، اما کاراکتر Null Terminator را در محاسبه طول در نظر نمی‌گیرد.

ساختار تابع:

```c
size_t strlen(const char *str);
```

برای مثال:

```c
char text[] = "Hello";

printf("Length = %zu\n", strlen(text));
```

خروجی:

```text
Length = 5
```

کاراکتر `'\0'` در نتیجه محاسبه نمی‌شود.

### ۶.۱. چرا در کد اصلی عدد یک را کم کرده‌ایم؟

در برنامه اولیه از دستور زیر استفاده شده است:

```c
strlen(str) - 1
```

دلیل آن این است که تابع `fgets()` معمولاً کاراکتر Newline را نیز در رشته ذخیره می‌کند.

برای مثال، اگر کاربر عبارت `Hello` را وارد کند، رشته ذخیره‌شده ممکن است به شکل زیر باشد:

```text
Hello\n\0
```

در این حالت طول رشته برابر با ۶ است:

- `H`
- `e`
- `l`
- `l`
- `o`
- `\n`

بنابراین با کم کردن یک واحد، طول متن بدون کاراکتر Newline محاسبه می‌شود.

اما این روش همیشه صحیح نیست.

اگر کاربر متنی طولانی‌تر از ظرفیت آرایه وارد کند، ممکن است `fgets()` تمام فضای موجود را پر کند و دیگر فرصت خواندن کاراکتر Newline را نداشته باشد.

در چنین شرایطی، کم کردن یک واحد باعث می‌شود طول رشته اشتباه محاسبه شود.

روش بهتر این است که ابتدا کاراکتر Newline را به‌صورت مستقیم حذف کنیم و سپس طول رشته را محاسبه کنیم.

## ۷. آشنایی با مفهوم Recursion

مهم‌ترین قسمت این برنامه تابع زیر است:

```c
void ReverseString(const char *s)
{
    if (s[0] == '\0')
    {
        return;
    }
    else
    {
        ReverseString(&s[1]);

        if (s[0] != '\n')
        {
            putchar(s[0]);
        }
    }
}
```

این تابع با استفاده از تکنیک Recursion یا بازگشت، ترتیب چاپ کاراکترهای رشته را معکوس می‌کند.

### ۷.۱. Recursion چیست؟

Recursion یک روش برنامه‌نویسی است که در آن یک تابع، خودش را فراخوانی می‌کند.

برای مثال:

```c
void CountDown(int n)
{
    if (n == 0)
    {
        return;
    }

    printf("%d\n", n);

    CountDown(n - 1);
}
```

اگر تابع را به شکل زیر فراخوانی کنیم:

```c
CountDown(5);
```

خروجی زیر تولید می‌شود:

```text
5
4
3
2
1
```

هر تابع بازگشتی باید یک شرط پایان داشته باشد. در غیر این صورت، فراخوانی‌های تابع ممکن است تا زمان پر شدن Stack ادامه پیدا کنند.

### ۷.۲. بررسی پارامتر تابع

```c
void ReverseString(const char *s)
```

پارامتر ورودی یک اشاره‌گر به کاراکتر ثابت است.

این تعریف به این معنی است که:

- `s` به یک کاراکتر یا ابتدای یک رشته اشاره می‌کند.
- تابع می‌تواند کاراکترهای رشته را بخواند.
- تابع از طریق این اشاره‌گر اجازه تغییر کاراکترهای رشته را ندارد.

کلمه کلیدی `const` از تغییر ناخواسته رشته اصلی از طریق این اشاره‌گر جلوگیری می‌کند.

### ۷.۳. شرط پایان تابع بازگشتی

```c
if (s[0] == '\0')
{
    return;
}
```

این شرط بررسی می‌کند که آیا کاراکتر فعلی برابر با Null Terminator است یا خیر.

اگر شرط برقرار باشد، تابع بدون فراخوانی مجدد به محل فراخوانی خود بازمی‌گردد.

به این شرط، Base Case یا شرط پایه گفته می‌شود.

وجود شرط پایه برای جلوگیری از اجرای بی‌نهایت تابع بازگشتی ضروری است.

### ۷.۴. حرکت به سمت کاراکتر بعدی

```c
ReverseString(&s[1]);
```

این دستور مهم‌ترین بخش الگوریتم است.

برای درک بهتر:

- `s` به کاراکتر فعلی اشاره می‌کند.
- `s[1]` کاراکتر بعدی رشته است.
- `&s[1]` آدرس کاراکتر بعدی را مشخص می‌کند.

بنابراین:

```c
ReverseString(&s[1]);
```

تابع را دوباره فراخوانی می‌کند، اما این بار از کاراکتر بعدی شروع می‌شود.

برای مثال، اگر رشته ما چنین باشد:

```text
ABC
```

فراخوانی‌ها به شکل زیر انجام می‌شوند:

```text
ReverseString(&s[0])  // A
    ReverseString(&s[1])  // B
        ReverseString(&s[2])  // C
            ReverseString(&s[3])  // '\0'
```

وقتی تابع به Null Terminator می‌رسد، دیگر فراخوانی جدیدی انجام نمی‌دهد.

### ۷.۵. چاپ کاراکتر بعد از فراخوانی بازگشتی

```c
putchar(s[0]);
```

به محل قرارگیری این دستور توجه کنید.

این دستور بعد از فراخوانی مجدد تابع قرار گرفته است.

دقیقاً به همین دلیل کاراکترها به ترتیب معکوس چاپ می‌شوند.

تابع ابتدا تا انتهای رشته پیش می‌رود و سپس هنگام بازگشت از فراخوانی‌های قبلی، کاراکترها را چاپ می‌کند.

برای رشته زیر:

```text
ABC
```

ترتیب اجرای دستورات چنین است:

```text
1. فراخوانی تابع با A
2. فراخوانی تابع با B
3. فراخوانی تابع با C
4. رسیدن به '\0' و بازگشت
5. چاپ C
6. چاپ B
7. چاپ A
```

خروجی نهایی:

```text
CBA
```

این یکی از ویژگی‌های مهم Recursion است: دستوراتی که بعد از فراخوانی بازگشتی قرار دارند، هنگام بازگشت از توابع اجرا می‌شوند.

## ۸. آشنایی با تابع `putchar()`

دستور زیر:

```c
putchar(s[0]);
```

برای چاپ یک کاراکتر در خروجی استاندارد استفاده می‌شود.

برای مثال:

```c
putchar('A');
putchar('B');
putchar('C');
```

خروجی:

```text
ABC
```

برخلاف `printf()`، تابع `putchar()` برای چاپ یک کاراکتر طراحی شده است.

در تابع بازگشتی ما، این تابع در هر مرحله یک کاراکتر را چاپ می‌کند.

## ۹. نسخه اصلاح‌شده و بهینه‌تر برنامه

در برنامه اولیه چند مورد وجود دارد که بهتر است اصلاح شوند:

1. اضافه کردن کتابخانه `<string.h>` برای استفاده از توابع رشته‌ای.
2. تعریف Function Prototype قبل از تابع `main()`.
3. بررسی موفقیت دریافت اطلاعات با `fgets()`.
4. حذف صحیح کاراکتر Newline به‌جای فرض کردن وجود همیشگی آن.
5. استفاده از `%zu` برای نمایش خروجی `strlen()`، زیرا نوع خروجی این تابع `size_t` است.
6. حذف کتابخانه غیرضروری `<stdlib.h>`.

کد کامل اصلاح‌شده:

```c
#include <stdio.h>
#include <string.h>

void ReverseString(const char *s);

int main(void)
{
    char str[50];

    printf("Enter a line of text:\n");

    if (fgets(str, sizeof(str), stdin) == NULL)
    {
        printf("Error: Unable to read input.\n");
        return 1;
    }

    /* Remove the newline character, if present */
    str[strcspn(str, "\r\n")] = '\0';

    printf("\nEntered text is:\n%s\n", str);

    printf("Length of entered text: %zu\n", strlen(str));

    printf("\nReversed text:\n");
    ReverseString(str);
    printf("\n");

    return 0;
}

void ReverseString(const char *s)
{
    if (s[0] == '\0')
    {
        return;
    }

    ReverseString(&s[1]);

    putchar(s[0]);
}
```

### ۹.۱. بررسی تغییرات انجام‌شده

**استفاده از `sizeof(str)`**

```c
fgets(str, sizeof(str), stdin);
```

به‌جای نوشتن مستقیم عدد ۵۰، از `sizeof(str)` استفاده کرده‌ایم.

این روش باعث می‌شود اگر در آینده اندازه آرایه تغییر کرد، نیازی به تغییر جداگانه عدد داخل تابع `fgets()` نباشد.

**بررسی مقدار بازگشتی `fgets()`**

```c
if (fgets(str, sizeof(str), stdin) == NULL)
```

اگر تابع `fgets()` نتواند اطلاعاتی بخواند، مقدار `NULL` برمی‌گرداند.

این اتفاق ممکن است به دلیل خطای ورودی یا رسیدن به انتهای جریان ورودی قبل از خواندن کاراکترها رخ دهد.

بررسی این مقدار از استفاده از رشته مقداردهی‌نشده جلوگیری می‌کند.

**حذف کاراکتر Newline**

```c
str[strcspn(str, "\r\n")] = '\0';
```

تابع `strcspn()` محل اولین کاراکتر موجود در رشته را پیدا می‌کند که با یکی از کاراکترهای `'\r'` یا `'\n'` برابر باشد.

سپس آن کاراکتر را با `'\0'` جایگزین می‌کنیم.

به این ترتیب، کاراکترهای پایان خط در صورت وجود حذف می‌شوند.

اگر هیچ‌کدام از این کاراکترها در رشته وجود نداشته باشند، تابع طول رشته را برمی‌گرداند و قرار دادن `'\0'` در آن موقعیت باعث می‌شود رشته بدون تغییر باقی بماند.

**محاسبه طول رشته**

```c
strlen(str)
```

حالا که Newline حذف شده است، مقدار بازگشتی تابع دقیقاً تعداد کاراکترهای متن خواهد بود.

**نمایش طول رشته**

```c
printf("Length of entered text: %zu\n", strlen(str));
```

از مشخص‌کننده قالب `%zu` استفاده می‌کنیم؛ زیرا نوع خروجی تابع `strlen()` برابر با `size_t` است.

## ۱۰. خروجی برنامه

## ۱۱. نحوه معکوس شدن رشته با استفاده از Recursion

رشته زیر را در نظر بگیرید:

```text
CODE
```

تابع بازگشتی ابتدا در رشته به سمت جلو حرکت می‌کند:

```text
C → O → D → E → '\0'
```

سپس هنگام بازگشت از فراخوانی‌های قبلی، کاراکترها چاپ می‌شوند:

```text
E → D → O → C
```

نتیجه نهایی:

```text
EDOC
```

نکته مهم این است که تابع بازگشتی آرایه اصلی را تغییر نمی‌دهد؛ بلکه فقط ترتیب چاپ کاراکترها را معکوس می‌کند.

## ۱۲. مقایسه معکوس کردن بازگشتی و مستقیم رشته

روش‌های مختلفی برای معکوس کردن یک رشته وجود دارد.

### روش اول: چاپ معکوس با Recursion

روش فعلی ما:

```c
void ReverseString(const char *s)
{
    if (*s == '\0')
    {
        return;
    }

    ReverseString(s + 1);
    putchar(*s);
}
```

ویژگی‌ها:

- رشته اصلی را تغییر نمی‌دهد.
- از فراخوانی بازگشتی استفاده می‌کند.
- به حافظه اضافی Stack متناسب با طول رشته نیاز دارد.
- کاراکترها را مستقیماً به‌صورت معکوس چاپ می‌کند.

### روش دوم: معکوس کردن خود آرایه

روش دیگر این است که کاراکترهای ابتدا و انتهای رشته را با یکدیگر جابه‌جا کنیم.

```c
#include <stdio.h>
#include <string.h>

void ReverseString(char *s)
{
    size_t left = 0;
    size_t right = strlen(s);

    if (right == 0)
    {
        return;
    }

    right--;

    while (left < right)
    {
        char temp = s[left];

        s[left] = s[right];
        s[right] = temp;

        left++;
        right--;
    }
}

int main(void)
{
    char str[] = "Hello World";

    ReverseString(str);

    printf("Reversed string: %s\n", str);

    return 0;
}
```

خروجی:

```text
Reversed string: dlroW olleH
```

در این روش، آرایه اصلی واقعاً تغییر می‌کند.

مقایسه دو روش:

| ویژگی | روش بازگشتی | روش معکوس‌سازی آرایه |
|---|---|---|
| استفاده از Recursion | بله | خیر |
| تغییر رشته اصلی | خیر | بله |
| حافظه اضافی | O(N) برای Stack | O(1) |
| پیچیدگی زمانی | O(N) | O(N) |
| نتیجه | چاپ معکوس رشته | ذخیره رشته معکوس‌شده |

هر دو روش برای یادگیری مفاهیم متفاوت برنامه‌نویسی کاربرد دارند.

## ۱۳. نکات مهم

- هر رشته در زبان C باید با `'\0'` پایان یابد.
- تابع `fgets()` یک خط متن را با محدودیت مشخص دریافت می‌کند.
- تابع `fgets()` در صورت وجود فضای کافی، معمولاً کاراکتر Newline را نیز ذخیره می‌کند.
- تابع `strlen()` کاراکتر Null Terminator را در محاسبه طول در نظر نمی‌گیرد.
- نوع خروجی تابع `strlen()` برابر با `size_t` است.
- برای نمایش مقدار `size_t` باید از `%zu` استفاده کنیم.
- تابع `putchar()` برای چاپ یک کاراکتر استفاده می‌شود.
- در روش Recursion، یک تابع خودش را فراخوانی می‌کند.
- هر تابع بازگشتی باید یک شرط پایان داشته باشد.
- تابع `ReverseString()` کاراکترها را معکوس چاپ می‌کند، اما آرایه اصلی را تغییر نمی‌دهد.
- توابع بازگشتی از حافظه Stack استفاده می‌کنند؛ برای رشته‌های بسیار طولانی، روش تکراری معمولاً امن‌تر است.
- این مثال بایت‌ها را معکوس می‌کند، نه لزوماً کاراکترهای کامل Unicode را. کاراکترهای UTF-8 ممکن است از چند بایت تشکیل شده باشند.

**محدودیت ظرفیت آرایه:** در این برنامه، آرایه `str[50]` حداکثر ۴۹ کاراکتر ورودی را همراه با یک کاراکتر پایان رشته ذخیره می‌کند. اگر کاربر متن طولانی‌تری وارد کند، بخش باقی‌مانده در جریان ورودی باقی می‌ماند و ممکن است توسط عملیات ورودی بعدی خوانده شود. برنامه فعلی فقط بخشی از متن را که در آرایه جا می‌شود پردازش می‌کند.

## ۱۵. تمرین‌ها

برای تسلط بیشتر بر این مبحث، تمرین‌های زیر را انجام دهید.

**تمرین اول:**

برنامه را تغییر دهید تا کاربر بتواند یک رشته شامل فاصله، اعداد و کاراکترهای خاص وارد کند.

**تمرین دوم:**

size_t StringLength(const char *s);

**تمرین سوم:**

یک تابع بازگشتی بنویسید که تعداد حروف صدادار (Vowels) موجود در یک رشته را محاسبه کند.

تابعی بنویسید که رشته را به‌صورت معکوس چاپ کند، اما به‌جای `putchar()` از `printf()` استفاده کند.

**تمرین پنجم:**

تابعی بنویسید که بررسی کند آیا یک رشته Palindrome است یا خیر.

مثال:

```text

hello  → Not a palindrome
```

**تمرین ششم:**

هر دو روش معکوس کردن رشته، یعنی روش بازگشتی و روش تکراری را پیاده‌سازی کنید و از نظر عملکرد و مصرف حافظه با یکدیگر مقایسه کنید.
