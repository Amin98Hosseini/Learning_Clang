# 30- خواندن و استخراج اطلاعات از رشته‌ها با استفاده از تابع `sscanf()` در زبان C

## 1. مقدمه

در برنامه‌نویسی C، گاهی اطلاعاتی را داخل یک آرایه کاراکتری (String) ذخیره می‌کنیم و نیاز داریم مقادیر عددی یا اطلاعات مشخصی را از داخل آن استخراج کنیم.

برای مثال، رشته زیر را در نظر بگیرید:

```c
char str[] = "(x = -5.45, y = 10.67)";
```

این رشته شامل دو مقدار اعشاری است:

- `x = -5.45`
- `y = 10.67`

چگونه می‌توانیم این دو مقدار را از رشته استخراج کرده و در دو متغیر جداگانه ذخیره کنیم؟

زبان C تابعی به نام `sscanf()` در اختیار ما قرار می‌دهد که امکان خواندن اطلاعات قالب‌بندی‌شده از داخل یک رشته را فراهم می‌کند.

عملکرد `sscanf()` مشابه `scanf()` است؛ با این تفاوت که به‌جای دریافت ورودی از صفحه‌کلید، اطلاعات را از یک آرایه کاراکتری موجود می‌خواند.

در این آموزش یاد می‌گیریم:

- چگونه اطلاعات قالب‌بندی‌شده را از یک رشته بخوانیم.
- چگونه با استفاده از `sscanf()` اعداد اعشاری را استخراج کنیم.
- مشخص‌کننده‌های قالب‌بندی چگونه کار می‌کنند.
- چگونه بررسی کنیم که استخراج اطلاعات با موفقیت انجام شده است.
- چگونه ورودی‌های نامعتبر یا غیرمنتظره را مدیریت کنیم.

## 2. کتابخانه‌های مورد نیاز

```c
#include <stdio.h>
#include <stdlib.h>
```

### کتابخانه `stdio.h`

این کتابخانه توابع ورودی و خروجی استاندارد زبان C را فراهم می‌کند، از جمله:

- `printf()` – نمایش خروجی قالب‌بندی‌شده.
- `puts()` – نمایش یک رشته و افزودن خط جدید در انتهای آن.
- `scanf()` – دریافت ورودی قالب‌بندی‌شده از ورودی استاندارد.
- `sscanf()` – خواندن اطلاعات قالب‌بندی‌شده از یک رشته.

### کتابخانه `stdlib.h`

این کتابخانه شامل توابع عمومی زبان C است، مانند:

- `malloc()`
- `free()`
- `atoi()`
- `strtod()`
- `exit()`

**نکته:** در برنامه فعلی از هیچ تابعی در `stdlib.h` استفاده نشده است؛ بنابراین می‌توان این کتابخانه را حذف کرد.

## 3. کد کامل برنامه

در ادامه کد اصلی را مشاهده می‌کنید:

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    char str[] = "(x = -5.45, y = 10.67)";

    printf("Input string is:\n");
    puts(str);
    printf("\n\n");

    float x, y;

    sscanf(str, "(x = %f, y = %f)", &x, &y);

    printf("Results of sscanf:\n");
    printf("x = %.2f\n", x);
    printf("y = %.2f\n", y);

    return 0;
}
```

## 4. بررسی و توضیح بخش‌های مختلف برنامه

### 4.1. تعریف و مقداردهی اولیه رشته

```c
char str[] = "(x = -5.45, y = 10.67)";
```

در این قسمت یک آرایه کاراکتری به نام `str` تعریف کرده و مقدار اولیه آن را مشخص می‌کنیم.

این رشته شامل کاراکترهای معمولی، نام متغیرها، علائم نگارشی و دو مقدار عددی است.

محتوای رشته:

```text
(x = -5.45, y = 10.67)
```

در زبان C، رشته‌ها به‌صورت آرایه‌ای از کاراکترها ذخیره می‌شوند و در انتهای آن‌ها یک کاراکتر ویژه به نام Null Terminator قرار می‌گیرد:

```c
'\0'
```

هنگامی که آرایه را به این شکل مقداردهی اولیه می‌کنیم، کامپایلر فضای موردنیاز برای تمام کاراکترها و کاراکتر پایان رشته را اختصاص می‌دهد.

### 4.2. نمایش رشته ورودی

```c
printf("Input string is:\n");
puts(str);
printf("\n\n");
```

دستور اول عنوان زیر را نمایش می‌دهد:

```text
Input string is:
```

دستور دوم:

```c
puts(str);
```

تمام محتوای رشته ذخیره‌شده در `str` را چاپ می‌کند.

تابع `puts()` پس از نمایش رشته، به‌صورت خودکار یک کاراکتر خط جدید اضافه می‌کند.

دستور آخر:

```c
printf("\n\n");
```

دو کاراکتر خط جدید چاپ می‌کند تا بین قسمت‌های مختلف خروجی فاصله ایجاد شود.

### 4.3. تعریف متغیرهای مقصد

```c
float x, y;
```

در این قسمت دو متغیر از نوع `float` تعریف می‌کنیم:

- متغیر `x` برای ذخیره اولین مقدار استخراج‌شده استفاده می‌شود.
- متغیر `y` برای ذخیره دومین مقدار استخراج‌شده استفاده می‌شود.

پس از استخراج موفق اطلاعات، مقادیر مورد انتظار عبارت‌اند از:

```text
x = -5.45
y = 10.67
```

### 4.4. آشنایی با تابع `sscanf()`

```c
sscanf(str, "(x = %f, y = %f)", &x, &y);
```

این دستور مهم‌ترین قسمت برنامه است.

تابع `sscanf()` اطلاعات قالب‌بندی‌شده را از یک رشته می‌خواند و مقادیر استخراج‌شده را در متغیرهای مشخص‌شده ذخیره می‌کند.

ساختار عمومی تابع:

```c
sscanf(source_string, format, argument1, argument2, ...);
```

توضیح پارامترها:

| پارامتر | توضیح |
|---|---|
| `source_string` | رشته‌ای که اطلاعات از آن خوانده می‌شوند |
| `format` | الگوی مورد انتظار برای ساختار رشته ورودی |
| `argument1`, `argument2`, ... | آدرس متغیرهایی که مقادیر استخراج‌شده در آن‌ها ذخیره می‌شوند |

در مثال ما:

```c
sscanf(str, "(x = %f, y = %f)", &x, &y);
```

تابع چهار ورودی اصلی دریافت می‌کند:

**پارامتر اول:**

```c
str
```

رشته‌ای است که اطلاعات موردنظر داخل آن قرار دارند.

**پارامتر دوم:**

```c
"(x = %f, y = %f)"
```

این رشته، الگوی مورد انتظار برای ورودی را مشخص می‌کند.

**پارامتر سوم و چهارم:**

```c
&x, &y
```

این دو عبارت آدرس حافظه متغیرهایی هستند که قرار است مقادیر استخراج‌شده در آن‌ها ذخیره شوند.

### 4.5. بررسی رشته قالب‌بندی

بیایید عبارت زیر را با دقت بررسی کنیم:

```c
"(x = %f, y = %f)"
```

این رشته قالب‌بندی از دو نوع بخش تشکیل شده است:

1. کاراکترهای معمولی که باید با متن ورودی مطابقت داشته باشند.
2. مشخص‌کننده‌های قالب‌بندی که محل استخراج مقادیر را مشخص می‌کنند.

| بخش قالب | مفهوم |
|---|---|
| `(` | مطابقت با پرانتز باز |
| `x = ` | مطابقت با متن ثابت `x = ` |
| `%f` | خواندن یک عدد اعشاری |
| `, y = ` | مطابقت با متن ثابت `, y = ` |
| `%f` | خواندن عدد اعشاری دوم |
| `)` | مطابقت با پرانتز بسته |

تابع اطلاعات را از چپ به راست پردازش می‌کند.

برای رشته ورودی:

```text
(x = -5.45, y = 10.67)
```

مراحل استخراج به شکل زیر انجام می‌شوند:

1. پرانتز باز `(` بررسی و تطبیق داده می‌شود.
2. متن `x = ` بررسی و تطبیق داده می‌شود.
3. مقدار `-5.45` با استفاده از `%f` خوانده شده و در متغیر `x` ذخیره می‌شود.
4. متن `, y = ` بررسی و تطبیق داده می‌شود.
5. مقدار `10.67` با استفاده از `%f` خوانده شده و در متغیر `y` ذخیره می‌شود.
6. پرانتز بسته `)` بررسی می‌شود.

پس از استخراج موفق اطلاعات:

```c
x = -5.45f;
y = 10.67f;
```

**نکته مهم:** رشته قالب‌بندی باید ساختار رشته ورودی را توصیف کند. اگر ورودی با الگوی مورد انتظار مطابقت نداشته باشد، تابع ممکن است قبل از استخراج تمام اطلاعات متوقف شود.

### 4.6. چرا از `&x` و `&y` استفاده می‌کنیم؟

```c
sscanf(str, "(x = %f, y = %f)", &x, &y);
```

عملگر `&` آدرس حافظه یک متغیر را برمی‌گرداند.

تابع `sscanf()` به این آدرس‌ها نیاز دارد؛ زیرا باید مقادیر تبدیل‌شده را مستقیماً در متغیرهای مقصد ذخیره کند.

برای مثال:

```c
float x;

sscanf("12.5", "%f", &x);
```

پس از تبدیل موفق، مقدار متغیر `x` برابر خواهد بود با:

```text
12.5
```

**نکته مهم:** در تابع `sscanf()`، مشخص‌کننده `%f` به یک اشاره‌گر از نوع `float` نیاز دارد؛ بنابراین اگر متغیر از نوع `float` باشد، باید آدرس آن را ارسال کنیم.

اگر متغیر مقصد از نوع `double` باشد، باید از `%lf` استفاده کنیم:

```c
double x;

sscanf("12.5", "%lf", &x);
```

تفاوت این دو حالت:

| نوع متغیر | مشخص‌کننده در `sscanf()` | آرگومان |
|---|---|---|
| `float` | `%f` | `&x` |
| `double` | `%lf` | `&x` |

**توجه:** در تابع `printf()`، برای نمایش هر دو نوع `float` و `double` از `%f` استفاده می‌شود؛ زیرا مقادیر `float` هنگام ارسال به توابعی مانند `printf()` به `double` ارتقا پیدا می‌کنند.

### 4.7. نمایش مقادیر استخراج‌شده

پس از استخراج اطلاعات، مقادیر متغیرها را نمایش می‌دهیم.

مشخص‌کننده قالب‌بندی زیر:

```c
%.2f
```

به معنی نمایش عدد اعشاری با دو رقم بعد از ممیز است.

خروجی:

```text

```

## 6. بررسی مقدار بازگشتی تابع `sscanf()`

یکی از نکات مهم درباره تابع `sscanf()` مقدار بازگشتی آن است.

این تابع تعداد مقادیری را برمی‌گرداند که با موفقیت تبدیل و در متغیرهای مقصد ذخیره شده‌اند.

برای مثال:

```c
int result;

result = sscanf(str, "(x = %f, y = %f)", &x, &y);
```

در این مثال دو تبدیل اعشاری وجود دارد.

اگر هر دو تبدیل موفق باشند:

```text
result = 2
```

اگر فقط تبدیل اول موفق باشد:

```text
result = 1
```

اگر هیچ تبدیلی موفق نباشد:

```text
result = 0
```

همچنین اگر قبل از انجام اولین تبدیل، خطای ورودی رخ دهد، تابع می‌تواند مقدار `EOF` را برگرداند.

در برنامه‌های مطمئن و حرفه‌ای باید مقدار بازگشتی تابع را بررسی کنیم و فقط در صورت موفقیت، از متغیرهای مقصد استفاده کنیم.

## 7. نسخه اصلاح‌شده و ایمن‌تر برنامه

در برنامه اصلی بررسی نکرده‌ایم که آیا تابع `sscanf()` هر دو مقدار را با موفقیت استخراج کرده است یا خیر.

اگر رشته ورودی نامعتبر باشد، ممکن است یکی از متغیرها یا هر دو مقداردهی نشده باقی بمانند. چاپ مقدار یک متغیر مقداردهی‌نشده می‌تواند باعث رفتار تعریف‌نشده (Undefined Behavior) شود.

در نسخه زیر مقدار بازگشتی تابع را بررسی می‌کنیم:

```c
#include <stdio.h>

int main(void)
{
    char str[] = "(x = -5.45, y = 10.67)";

    float x, y;

    printf("Input string is:\n");
    puts(str);

    int result = sscanf(
        str,
        "(x = %f, y = %f)",
        &x,
        &y
    );

    if (result == 2)
    {
        printf("\nResults of sscanf:\n");
        printf("x = %.2f\n", x);
        printf("y = %.2f\n", y);
    }
    else
    {
        printf("\nError: Could not extract both values!\n");
        printf("Successfully converted values: %d\n", result);
    }

    return 0;
}
```

### چرا این نسخه بهتر است؟

در این برنامه شرط زیر را بررسی می‌کنیم:

```c
if (result == 2)
```

این شرط مشخص می‌کند که هر دو مقدار اعشاری با موفقیت تبدیل و در متغیرهای مقصد ذخیره شده‌اند یا خیر.

اگر مقدار بازگشتی برابر با ۲ نباشد، برنامه پیام خطا نمایش می‌دهد و از چاپ متغیرهایی که ممکن است مقداردهی نشده باشند جلوگیری می‌کند.

**نکته:** این بررسی فقط موفقیت دو تبدیل عددی را تأیید می‌کند. لزوماً به این معنی نیست که تمام کاراکترهای رشته ورودی مطابق الگو بوده‌اند. برای مثال، ممکن است بعد از پرانتز بسته کاراکترهای اضافی وجود داشته باشند.

## 8. آزمایش تابع `sscanf()` با رشته‌های ورودی مختلف

در این بخش رفتار تابع را با چند ورودی متفاوت بررسی می‌کنیم.

### مثال اول: ورودی معتبر

```c
char str[] = "(x = -5.45, y = 10.67)";
```

نتیجه:

```text
x = -5.45
y = 10.67
```

هر دو تبدیل موفق هستند؛ بنابراین مقدار بازگشتی برابر با ۲ خواهد بود.

### مثال دوم: مقدار دوم نامعتبر

```c
char str[] = "(x = -5.45, y = ABC)";
```

مقدار اول قابل تبدیل است، اما مقدار دوم یک عدد اعشاری معتبر نیست.

مقدار بازگشتی:

```text
1
```

متغیر `x` مقداردهی می‌شود، اما متغیر `y` بدون تغییر باقی می‌ماند.

### مثال سوم: مقدار اول نامعتبر

```c
char str[] = "(x = ABC, y = 10.67)";
```

اولین تبدیل اعشاری با شکست مواجه می‌شود.

مقدار بازگشتی:

```text
0
```

هیچ‌کدام از متغیرها مقدار جدیدی دریافت نمی‌کنند.

### مثال چهارم: نبودن پرانتز بسته

```c
char str[] = "(x = -5.45, y = 10.67";
```

هر دو تبدیل عددی می‌توانند قبل از رسیدن تابع به پرانتز بسته ناموجود با موفقیت انجام شوند.

در این حالت مقدار بازگشتی همچنان می‌تواند برابر با ۲ باشد.

این مثال یک نکته مهم را نشان می‌دهد: تابع `sscanf()` تعداد تبدیل‌های موفق را برمی‌گرداند، نه تعداد تمام کاراکترهایی که با رشته قالب‌بندی مطابقت داشته‌اند.

## 9. تفاوت توابع `scanf()` و `sscanf()`

هر دو تابع برای خواندن اطلاعات قالب‌بندی‌شده استفاده می‌شوند، اما منبع ورودی آن‌ها متفاوت است.

| تابع | منبع ورودی | کاربرد معمول |
|---|---|---|
| `scanf()` | ورودی استاندارد، معمولاً صفحه‌کلید | دریافت اطلاعات واردشده توسط کاربر |
| `sscanf()` | یک رشته کاراکتری موجود | استخراج اطلاعات از متن ذخیره‌شده |

### استفاده از `scanf()`

```c
float x;

printf("Enter a number: ");
scanf("%f", &x);

printf("Value = %.2f\n", x);
```

در این مثال کاربر عدد را از طریق صفحه‌کلید وارد می‌کند.

### استفاده از `sscanf()`

```c
char str[] = "25.75";

float x;

sscanf(str, "%f", &x);

printf("Value = %.2f\n", x);
```

در این مثال عدد از قبل داخل یک رشته ذخیره شده است و تابع `sscanf()` آن را استخراج می‌کند.

## 10. کاربردهای عملی

تابع `sscanf()` هنگام کار با داده‌های متنی و قالب‌های اطلاعاتی کاربرد زیادی دارد.

### 10.1. استخراج مقادیر سنسورها

فرض کنید از یک میکروکنترلر پیام زیر را دریافت کرده‌ایم:

```text
TEMP=28.65,HUM=45.20
```

می‌توانیم دما و رطوبت را استخراج کنیم:

```c
#include <stdio.h>

int main(void)
{
    char message[] = "TEMP=28.65,HUM=45.20";

    float temperature;
    float humidity;

    int result = sscanf(
        message,
        "TEMP=%f,HUM=%f",
        &temperature,
        &humidity
    );

    if (result == 2)
    {
        printf("Temperature: %.2f C\n", temperature);
        printf("Humidity: %.2f %%\n", humidity);
    }
    else
    {
        printf("Invalid sensor message!\n");
    }

    return 0;
}
```

خروجی:

```text
Temperature: 28.65 C
Humidity: 45.20 %
```

### 10.2. استخراج مختصات

فرض کنید رشته‌ای شامل دو مختصات به شکل زیر داریم:

```text
X=12.50,Y=45.75
```

می‌توانیم با استفاده از `sscanf()` مقادیر را استخراج کنیم:

```c
#include <stdio.h>

int main(void)
{
    char data[] = "X=12.50,Y=45.75";

    float x, y;

    int result = sscanf(data, "X=%f,Y=%f", &x, &y);

    if (result == 2)
    {
        printf("X = %.2f\n", x);
        printf("Y = %.2f\n", y);
    }

    return 0;
}
```

خروجی:

```text
X = 12.50
Y = 45.75
```

### 10.3. تجزیه یک دستور ساده

فرض کنید دستگاه یک دستور به شکل زیر دریافت می‌کند:

```text
SET,25.5,100
```

می‌توانیم پارامترهای عددی آن را استخراج کنیم:

```c
#include <stdio.h>

int main(void)
{
    char command[] = "SET,25.5,100";

    float temperature;
    int duration;

    int result = sscanf(
        command,
        "SET,%f,%d",
        &temperature,
        &duration
    );

    if (result == 2)
    {
        printf("Temperature = %.2f\n", temperature);
        printf("Duration = %d\n", duration);
    }
    else
    {
        printf("Invalid command!\n");
    }

    return 0;
}
```

خروجی:

```text
Temperature = 25.50
Duration = 100
```

**نکته در سیستم‌های Embedded:** تابع `sscanf()` برای پروتکل‌های متنی ساده بسیار کاربردی است؛ اما در میکروکنترلرهای کوچک ممکن است حجم کد و مصرف Stack قابل‌توجهی داشته باشد. در برنامه‌هایی که محدودیت حافظه یا نیاز به سرعت بالا دارند، استفاده از یک Parser اختصاصی می‌تواند انتخاب مناسب‌تری باشد.

همچنین `sscanf()` به‌تنهایی تمام قوانین پروتکل را اعتبارسنجی نمی‌کند و تضمین نمی‌کند که کل پیام ورودی پردازش شده باشد.

## 11. اشتباهات رایج

### اشتباه اول: فراموش کردن عملگر آدرس `&`

نادرست:

```c
float x;

sscanf(str, "%f", x);
```

درست:

```c
float x;

sscanf(str, "%f", &x);
```

تابع برای ذخیره مقدار تبدیل‌شده به آدرس متغیر نیاز دارد.

### اشتباه دوم: استفاده از مشخص‌کننده قالب اشتباه

حالت نادرست برای متغیر مقصد از نوع `double`:

```c
double x;

sscanf(str, "%f", &x);
```

حالت درست:

```c
double x;

sscanf(str, "%lf", &x);
```

در تابع `sscanf()`، مشخص‌کننده `%f` به `float *` و مشخص‌کننده `%lf` به `double *` نیاز دارد.

### اشتباه سوم: بررسی نکردن مقدار بازگشتی تابع

روش نادرست:

```c
sscanf(str, "%f,%f", &x, &y);

printf("%f %f\n", x, y);
```

اگر تبدیل با شکست مواجه شود، ممکن است یکی از متغیرها یا هر دو مقداردهی نشده باشند.

روش بهتر:

```c
if (sscanf(str, "%f,%f", &x, &y) == 2)
{
    printf("%f %f\n", x, y);
}
else
{
    printf("Invalid input!\n");
}
```

### اشتباه چهارم: فرض کردن اینکه تمام کاراکترهای ورودی پردازش شده‌اند

موفقیت تبدیل‌ها همیشه به معنی مطابقت کامل رشته ورودی با الگو نیست.

برای اعتبارسنجی دقیق‌تر، به بررسی‌های اضافی یا روش‌های دیگر تجزیه رشته نیاز داریم.

### اشتباه پنجم: اشتباه گرفتن `sscanf()` با `sprintf()`

این دو تابع کاربرد متفاوتی دارند:

- `sprintf()` مقادیر را قالب‌بندی کرده و نتیجه را داخل یک رشته ذخیره می‌کند.
- `sscanf()` اطلاعات قالب‌بندی‌شده را از یک رشته می‌خواند و در متغیرها ذخیره می‌کند.

## 13. تمرین‌ها

برای تسلط بیشتر بر مطالب، تمرین‌های زیر را انجام دهید.

**تمرین اول – استخراج سه مقدار اعشاری**

رشته زیر را تعریف کنید:

```c
char str[] = "A=12.5,B=25.7,C=30.9";
```

با استفاده از `sscanf()` هر سه مقدار را در متغیرهای جداگانه استخراج کنید.

**تمرین دوم – استخراج مقدار صحیح و اعشاری**

رشته زیر را تعریف کنید:

```c
char str[] = "ID=125,TEMP=28.75";
```

مقادیر زیر را استخراج کنید:

- مقدار `ID` به‌صورت عدد صحیح.
- مقدار `TEMP` به‌صورت عدد اعشاری.

**تمرین سوم – تجزیه اطلاعات سنسورها**

برنامه‌ای بنویسید که رشته زیر را پردازش کند:

```text
TEMP=27.5,HUM=60.2,VOLT=12.8
```

مقادیر دما، رطوبت و ولتاژ را استخراج کنید.

**تمرین چهارم – آزمایش ورودی نامعتبر**

برنامه اصلی را تغییر دهید تا مقدار دوم نامعتبر باشد:

```c
char str[] = "(x = -5.45, y = ABC)";
```

مقدار بازگشتی تابع `sscanf()` را بررسی کنید و توضیح دهید چرا فقط یک تبدیل موفق انجام می‌شود.

**تمرین پنجم – مقایسه `scanf()` و `sscanf()`**

برنامه‌ای بنویسید که:

1. یک مقدار اعشاری را با استفاده از `scanf()` از صفحه‌کلید دریافت کند.
2. یک پیام قالب‌بندی‌شده داخل آرایه کاراکتری ذخیره کند.
3. با استفاده از `sscanf()` عدد را از داخل پیام استخراج کند.
4. مقدار استخراج‌شده را نمایش دهد.

## 14. اهداف آموزشی

پس از مطالعه این آموزش باید بتوانید:

- از تابع `sscanf()` برای خواندن اطلاعات قالب‌بندی‌شده از رشته استفاده کنید.
- مقادیر اعشاری را از متن استخراج کنید.
- ساختار رشته‌های قالب‌بندی را درک کنید.
- دلیل استفاده از عملگر آدرس `&` برای متغیرهای مقصد را توضیح دهید.
- تفاوت `%f` و `%lf` را در تابع `sscanf()` تشخیص دهید.
- مقدار بازگشتی `sscanf()` را بررسی کنید.
- تفاوت توابع `scanf()`، `sscanf()` و `sprintf()` را توضیح دهید.
- پیام‌های سنسورها و دستورهای متنی ساده را تجزیه کنید.
- درک کنید که موفقیت تبدیل‌ها لزوماً به معنی اعتبارسنجی کامل ورودی نیست.
