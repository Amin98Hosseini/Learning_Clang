# 16- تحلیل آماری داده‌ها و رسم هیستوگرام با زبان C

## ۱. معرفی پروژه

در این پروژه نحوه انجام محاسبات آماری پایه با استفاده از زبان برنامه‌نویسی C بررسی می‌شود.

برنامه یک آرایه از اعداد صحیح را پردازش کرده و چند ویژگی آماری مهم را محاسبه می‌کند:

- مجموع تمام مقادیر (Sum)
- میانگین حسابی (Mean)
- انحراف معیار نمونه (Sample Standard Deviation)
- فراوانی هر عدد از ۰ تا ۹ (Frequency)
- نمایش توزیع فراوانی به‌صورت هیستوگرام متنی (Histogram)

مجموعه داده این برنامه شامل ۶۰ عدد صحیح در بازه صفر تا ۹ است.

برای تحلیل داده‌ها از آرایه، حلقه‌ها، شمارنده‌ها، عملیات ریاضی و کتابخانه `math.h` استفاده شده است.

این پروژه یک تمرین کاربردی برای آشنایی با پردازش داده و مفاهیم اولیه آمار در زبان C است.

## ۲. کد برنامه

```c id="k6ct9u"
#include <stdio.h>
#include <math.h>

int main()
{
    int i, j, k;

    int p[] = {
        1,2,3,4,5,6,7,8,9,0,
        1,4,7,2,8,6,0,2,4,3,
        8,9,7,6,8,0,3,4,2,5,
        6,7,3,7,8,9,2,3,6,8,
        4,4,6,7,8,4,9,2,3,4,
        5,6,7,8,8,3,4,7,8,9
    };

    int N = sizeof(p) / sizeof(p[0]);

    int f[10];

    for(i = 0; i < 10; i++)
    {
        f[i] = 0;
    }

    int sum = 0;
    float mean;

    for(j = 0; j < N; j++)
    {
        f[p[j]]++;
        sum += p[j];
    }

    mean = (float)sum / N;

    float stdev = 0;

    for(j = 0; j < N; j++)
    {
        stdev += (p[j] - mean) * (p[j] - mean);
    }

    stdev = sqrt(stdev / (N - 1));

    printf("Sum   = %d\n", sum);
    printf("Mean  = %f\n", mean);
    printf("StDev = %f\n", stdev);
    printf("\n");

    printf("Poll\tFreq.\tHistogram\n");

    for(i = 0; i < 10; i++)
    {
        printf("%d\t%d\t", i, f[i]);

        for(k = 0; k < f[i]; k++)
        {
            printf("*");
        }

        printf("\n");
    }

    return 0;
}
```

## ۳. مبانی ریاضی و آماری

این برنامه سه ویژگی آماری مهم را محاسبه می‌کند: مجموع، میانگین و انحراف معیار.

### ۳.۱. مجموع (Sum)

مجموع نشان‌دهنده حاصل جمع تمام مقادیر موجود در مجموعه داده است.

\[
S = \sum_{i=0}^{N-1}p_i
\]

در این رابطه:

- \(p_i\): مقدار هر عنصر از داده‌ها
- \(N\): تعداد کل عناصر
- \(S\): مجموع مقادیر

برای داده‌های این برنامه:

\[
S = 282
\]

### ۳.۲. میانگین حسابی (Mean)

میانگین حسابی نشان می‌دهد که مقدار متوسط داده‌ها چقدر است.

فرمول محاسبه میانگین:

\[
\mu = \frac{1}{N}\sum_{i=0}^{N-1}p_i
\]

در این رابطه:

- \(\mu\): میانگین حسابی
- \(N\): تعداد داده‌ها
- \(p_i\): مقدار هر عنصر

برای داده‌های این برنامه:

\[
\mu = \frac{282}{60}=4.7
\]

### ۳.۳. انحراف معیار نمونه (Sample Standard Deviation)

انحراف معیار میزان پراکندگی داده‌ها نسبت به میانگین را مشخص می‌کند.

این برنامه از فرمول انحراف معیار نمونه استفاده می‌کند:

\[
s = \sqrt{\frac{\sum_{i=0}^{N-1}(p_i-\mu)^2}{N-1}}
\]

در این رابطه:

- \(s\): انحراف معیار نمونه
- \(p_i\): مقدار هر داده
- \(\mu\): میانگین داده‌ها
- \(N\): تعداد مشاهدات

در این فرمول از \(N-1\) استفاده می‌شود، زیرا محاسبه بر اساس فرمول انحراف معیار نمونه انجام می‌شود.

برای داده‌های این برنامه:

\[
s \approx 2.685
\]

اگر داده‌ها کل جامعه آماری باشند و نه یک نمونه از آن، در فرمول انحراف معیار جامعه به‌جای \(N-1\) از \(N\) استفاده می‌شود.

### ۳.۴. فراوانی (Frequency)

فراوانی نشان می‌دهد که یک مقدار مشخص چند بار در مجموعه داده تکرار شده است.

برای مثال، اگر عدد ۴ ده بار در آرایه وجود داشته باشد، فراوانی آن برابر ۱۰ است.

در این برنامه فراوانی اعداد در یک آرایه با نام `f` ذخیره می‌شود:

\[
f[0],f[1],\ldots,f[9]
\]

فراوانی هر مقدار به‌صورت زیر تعریف می‌شود:

\[
f[x] = \text{تعداد تکرار مقدار }x
\]

### ۳.۵. هیستوگرام (Histogram)

هیستوگرام روشی برای نمایش توزیع فراوانی داده‌ها است.

در این برنامه برای نمایش فراوانی هر عدد از کاراکتر ستاره (`*`) استفاده شده است.

هر ستاره نشان‌دهنده یک بار تکرار مقدار موردنظر است.

برای مثال:

```text
4    10    **********
```

یعنی عدد ۴ در مجموعه داده ۱۰ بار تکرار شده است.

## ۴. بررسی بخش‌های مختلف کد

### ۴.۱. فراخوانی کتابخانه‌ها

```c id="7nj0q4"
#include <stdio.h>
#include <math.h>
```

در این قسمت دو کتابخانه استاندارد اضافه شده‌اند:

- `stdio.h`: برای استفاده از توابع ورودی و خروجی مانند `printf()`.
- `math.h`: برای استفاده از توابع ریاضی مانند `sqrt()`.

تابع `sqrt()` برای محاسبه جذر در فرمول انحراف معیار استفاده می‌شود.

### ۴.۲. تعریف متغیرهای شمارنده

```c id="zotnq6"
int i, j, k;
```

سه متغیر صحیح برای کنترل حلقه‌ها تعریف شده‌اند:

- `i`: برای مقداردهی اولیه و نمایش آرایه فراوانی.
- `j`: برای پردازش داده‌ها.
- `k`: برای چاپ ستاره‌های هیستوگرام.

استفاده از متغیرهای جداگانه باعث می‌شود عملیات مختلف برنامه خواناتر باشند.

### ۴.۳. تعریف مجموعه داده

```c id="8lyf4f"
int p[] = {
    1,2,3,4,5,6,7,8,9,0,
    1,4,7,2,8,6,0,2,4,3,
    8,9,7,6,8,0,3,4,2,5,
    6,7,3,7,8,9,2,3,6,8,
    4,4,6,7,8,4,9,2,3,4,
    5,6,7,8,8,3,4,7,8,9
};
```

در این قسمت یک آرایه صحیح با نام `p` تعریف شده است.

این آرایه شامل ۶۰ عنصر است و تمام مقادیر آن در محدوده صفر تا ۹ قرار دارند.

مقادیر آرایه هم‌زمان با تعریف آن مقداردهی اولیه شده‌اند.

### ۴.۴. محاسبه تعداد عناصر آرایه

```c id="1b5kza"
int N = sizeof(p) / sizeof(p[0]);
```

در این قسمت تعداد عناصر آرایه به‌صورت خودکار محاسبه می‌شود.

- `sizeof(p)`: اندازه کل آرایه را بر حسب بایت برمی‌گرداند.
- `sizeof(p[0])`: اندازه یک عنصر آرایه را بر حسب بایت برمی‌گرداند.

بنابراین:

\[
N = \frac{\text{اندازه کل آرایه}}{\text{اندازه یک عنصر}}
\]

در این مثال، اگر هر متغیر `int` چهار بایت باشد:

\[
N = \frac{240}{4}=60
\]

این روش باعث می‌شود نیازی به وارد کردن دستی تعداد عناصر آرایه نباشد.

### ۴.۵. تعریف آرایه فراوانی

```c id="1ey9mt"
int f[10];
```

در این قسمت یک آرایه با ۱۰ خانه تعریف شده است.

هر خانه تعداد تکرار یکی از اعداد صفر تا ۹ را نگهداری می‌کند.

| اندیس | اطلاعات ذخیره‌شده |
|---:|---|
| `f[0]` | فراوانی عدد صفر |
| `f[1]` | فراوانی عدد یک |
| `f[2]` | فراوانی عدد دو |
| ... | ... |
| `f[9]` | فراوانی عدد نه |

### ۴.۶. مقداردهی اولیه آرایه فراوانی

```c id="r1y1rw"
for(i = 0; i < 10; i++)
{
    f[i] = 0;
}
```

در این قسمت تمام خانه‌های آرایه فراوانی برابر صفر قرار داده می‌شوند.

این کار ضروری است، زیرا متغیرهای محلی در C به‌صورت خودکار صفر نمی‌شوند.

اگر آرایه قبل از استفاده مقداردهی نشود، عناصر آن دارای مقادیر نامعین خواهند بود.

### ۴.۷. محاسبه فراوانی و مجموع داده‌ها

```c id="y6djj7"
int sum = 0;

for(j = 0; j < N; j++)
{
    f[p[j]]++;
    sum += p[j];
}
```

در این قسمت تمام عناصر مجموعه داده پردازش می‌شوند.

در هر تکرار دو عملیات انجام می‌شود.

**عملیات اول: شمارش فراوانی**

```c id="03i15g"
f[p[j]]++;
```

این دستور مقدار شمارنده مربوط به عدد فعلی را یک واحد افزایش می‌دهد.

برای مثال، اگر:

```c id="cq07a4"
p[j] = 4;
```

باشد، دستور زیر اجرا می‌شود:

```c id="k0y35r"
f[4]++;
```

در نتیجه فراوانی عدد ۴ یک واحد افزایش پیدا می‌کند.

**عملیات دوم: محاسبه مجموع**

```c id="5yhrct"
sum += p[j];
```

این دستور شکل خلاصه‌شده عبارت زیر است:

```c id="5b4hrh"
sum = sum + p[j];
```

یعنی مقدار عنصر فعلی به مجموع کل اضافه می‌شود.

پس از پایان حلقه، مجموع تمام داده‌ها و فراوانی اعداد صفر تا ۹ محاسبه شده است.

### ۴.۸. محاسبه میانگین

```c id="54jsrz"
mean = (float)sum / N;
```

در این قسمت مجموع داده‌ها بر تعداد عناصر تقسیم می‌شود.

عبارت زیر:

```c id="34jv9u"
(float)sum
```

باعث تبدیل متغیر `sum` از نوع عدد صحیح به عدد اعشاری می‌شود.

این تبدیل اهمیت زیادی دارد؛ زیرا تقسیم دو عدد صحیح در C قسمت اعشاری نتیجه را حذف می‌کند.

برای مثال:

```c id="z1tb0x"
282 / 60
```

اگر هر دو عملوند از نوع `int` باشند، نتیجه برابر ۴ خواهد بود.

اما:

```c id="p7c1ce"
(float)282 / 60
```

نتیجه‌ای در حدود ۴٫۷ تولید می‌کند.

### ۴.۹. محاسبه انحراف معیار

```c id="xuvq99"
float stdev = 0;

for(j = 0; j < N; j++)
{
    stdev += (p[j] - mean) * (p[j] - mean);
}
```

در این حلقه مجموع مربع اختلاف هر داده با میانگین محاسبه می‌شود.

برای هر عنصر:

۱. میانگین از مقدار فعلی کم می‌شود.

۲. نتیجه در خودش ضرب می‌شود.

۳. مقدار به متغیر `stdev` اضافه می‌شود.

رابطه ریاضی این عملیات:

\[
stdev = \sum_{i=0}^{N-1}(p_i-\mu)^2
\]

در مرحله بعد محاسبه انحراف معیار کامل می‌شود:

```c id="b2nbt4"
stdev = sqrt(stdev / (N - 1));
```

در این دستور:

۱. مجموع مربع اختلاف‌ها بر `N-1` تقسیم می‌شود.

۲. تابع `sqrt()` جذر نتیجه را محاسبه می‌کند.

در نهایت انحراف معیار نمونه به دست می‌آید.

### ۴.۱۰. نمایش نتایج آماری

```c id="v8q4wn"
printf("Sum   = %d\n", sum);
printf("Mean  = %f\n", mean);
printf("StDev = %f\n", stdev);
```

در این قسمت سه نتیجه آماری نمایش داده می‌شوند.

- `%d`: برای نمایش عدد صحیح
- `%f`: برای نمایش عدد اعشاری
- `\n`: برای رفتن به خط بعد

### ۴.۱۱. نمایش جدول فراوانی و هیستوگرام

```c id="k7r3yn"
printf("Poll\tFreq.\tHistogram\n");

for(i = 0; i < 10; i++)
{
    printf("%d\t%d\t", i, f[i]);

    for(k = 0; k < f[i]; k++)
    {
        printf("*");
    }

    printf("\n");
}
```

در این قسمت فراوانی هر عدد و نمودار متنی آن نمایش داده می‌شود.

حلقه بیرونی اعداد صفر تا ۹ را بررسی می‌کند.

حلقه داخلی به تعداد فراوانی عدد فعلی، کاراکتر ستاره چاپ می‌کند.

برای مثال، اگر:

```c id="h5yujf"
f[5] = 6;
```

باشد، حلقه داخلی شش بار اجرا شده و خروجی زیر تولید می‌کند:

```text id="p3f3jn"
******
```

کاراکتر `\t` نیز برای ایجاد فاصله به‌اندازه یک Tab بین ستون‌های خروجی استفاده می‌شود.

## ۷. پیچیدگی زمانی و حافظه

فرض می‌کنیم `N` تعداد عناصر مجموعه داده باشد.

### ۷.۱. پیچیدگی زمانی (Time Complexity)

برنامه عملیات زیر را انجام می‌دهد:

- یک حلقه برای مقداردهی آرایه فراوانی با ۱۰ تکرار.
- یک حلقه برای محاسبه مجموع و فراوانی با `N` تکرار.
- یک حلقه برای محاسبه انحراف معیار با `N` تکرار.
- یک حلقه بیرونی و حلقه‌های داخلی برای نمایش هیستوگرام.

مجموع تعداد ستاره‌های چاپ‌شده در هیستوگرام نیز برابر `N` است؛ زیرا هر داده دقیقاً در یک شمارنده فراوانی قرار می‌گیرد.

بنابراین پیچیدگی زمانی کلی برابر است با:

\[
\boxed{O(N)}
\]

### ۷.۲. پیچیدگی حافظه (Space Complexity)

برنامه اطلاعات زیر را ذخیره می‌کند:

- `N` عنصر در آرایه داده‌ها
- ۱۰ شمارنده فراوانی
- تعدادی متغیر کمکی

بنابراین:

\[
\boxed{O(N)}
\]

بخش اصلی حافظه مصرفی مربوط به آرایه داده‌ها است.

## ۸. نکات مهم و پیشنهادهای بهبود

۱. **محدوده داده‌ها باید بین صفر تا ۹ باشد.** عبارت `f[p[j]]` از مقدار هر داده به‌عنوان اندیس آرایه استفاده می‌کند. اگر مقداری خارج از این محدوده باشد، دسترسی خارج از محدوده آرایه رخ می‌دهد.

۲. **انحراف معیار محاسبه‌شده از نوع نمونه است.** چون در مخرج از `N-1` استفاده شده است. اگر داده‌ها کل جامعه آماری باشند، باید از `N` استفاده شود.

۳. **برنامه فرض می‌کند مجموعه داده خالی نیست.** در غیر این صورت، محاسبه میانگین و انحراف معیار شامل تقسیم بر صفر خواهد بود.

۴. **برای افزایش دقت می‌توان از `double` استفاده کرد.** محاسبات آماری معمولاً با دقت اعشاری بالاتر نتیجه بهتری ارائه می‌کنند.

۵. **نام متغیر Poll می‌تواند بهتر انتخاب شود.** از آنجا که برنامه اعداد را نمایش می‌دهد، نام‌هایی مانند `Value` یا `Digit` گویاتر هستند.

۶. **اندازه آرایه فراوانی ثابت است.** اگر محدوده داده‌ها تغییر کند، اندازه آرایه فراوانی و منطق اندیس‌دهی نیز باید متناسب با آن تغییر کنند.

## ۹. تمرین‌های پیشنهادی

برای درک بهتر مفاهیم این پروژه، تمرین‌های زیر را انجام دهید:

۱. تابع جداگانه‌ای برای محاسبه میانگین بنویسید.

۲. محاسبه انحراف معیار نمونه را در یک تابع مستقل پیاده‌سازی کنید.

۳. به‌جای استفاده از داده‌های ثابت، مقادیر آرایه را از کاربر دریافت کنید.

۴. کمترین و بیشترین مقدار مجموعه داده را پیدا کنید.

۵. درصد فراوانی هر عدد را محاسبه کنید.

۶. برای رسم هیستوگرام به‌جای `*` از کاراکتر `#` استفاده کنید.

۷. داده‌ها را به‌صورت صعودی مرتب کنید.

۸. میانه (Median) مجموعه داده را محاسبه کنید.

۹. برنامه را برای پشتیبانی از اعداد صفر تا ۱۰۰ توسعه دهید.

۱۰. به‌جای تعداد فراوانی، درصد فراوانی هر مقدار را نمایش دهید.

## ۱۰. هدف آموزشی پروژه

هدف اصلی این پروژه یادگیری نحوه پردازش یک مجموعه داده و استخراج اطلاعات آماری مفید با استفاده از زبان C است.

با انجام این تمرین، مفاهیم زیر را به‌صورت عملی یاد می‌گیرید:

- پردازش مجموعه داده‌های مبتنی بر آرایه
- محاسبه ویژگی‌های آماری
- استفاده از آرایه برای شمارش فراوانی
- استفاده از حلقه‌های تو در تو
- استفاده از توابع ریاضی کتابخانه `math.h`
- نمایش اطلاعات عددی با استفاده از هیستوگرام متنی

این پروژه یک تمرین کاربردی برای ورود به مبحث پردازش آماری داده‌ها و نمایش ساده اطلاعات در زبان C است.
