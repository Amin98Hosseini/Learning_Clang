# 5 - تشخیص اعداد زوج، فرد، مثبت، منفی و صفر در زبان C

## معرفی پروژه (Overview)

این پروژه با هدف آموزش دستورات شرطی در زبان برنامه‌نویسی C طراحی شده است.

برنامه یک عدد صحیح از کاربر دریافت می‌کند و دو بررسی مستقل روی آن انجام می‌دهد:

1. تشخیص زوج یا فرد بودن عدد (Even / Odd).
2. تشخیص مثبت، منفی یا صفر بودن عدد (Positive / Negative / Zero).

این مثال برای یادگیری ساختارهای تصمیم‌گیری و منطق شرطی در زبان C بسیار کاربردی است.

## اهداف آموزشی (Learning Objectives)

با مطالعه این برنامه، مفاهیم زیر را یاد می‌گیرید:

- آشنایی با دستور شرطی `if`.
- آشنایی با ساختار `if-else`.
- آشنایی با ساختار `if-else if-else`.
- یادگیری عملگر باقی‌مانده تقسیم یا Modulo (`%`).
- آشنایی با عملگرهای مقایسه‌ای.
- دریافت ورودی از کاربر با استفاده از `scanf()`.
- پیاده‌سازی چند شرط مستقل در یک برنامه.

## بررسی و توضیح کد (Source Code Explanation)

### 1. فراخوانی کتابخانه

```c
#include <stdio.h>
```

کتابخانه استاندارد ورودی و خروجی زبان C را فراخوانی می‌کند.

این کتابخانه شامل توابعی مانند `printf()` و `scanf()` است.

### 2. تعریف متغیر

```c
int a;
```

یک متغیر صحیح با نام `a` تعریف می‌کنیم.

این متغیر برای ذخیره عدد واردشده توسط کاربر استفاده می‌شود.

### 3. دریافت ورودی از کاربر

```c
printf("Enter an integer:\n");
scanf("%d", &a);
```

- تابع `printf()` پیام درخواست ورود عدد را نمایش می‌دهد.
- تابع `scanf()` عدد واردشده را دریافت می‌کند.
- علامت `&` آدرس حافظه متغیر `a` را مشخص می‌کند تا مقدار ورودی در آن ذخیره شود.

### 4. تشخیص زوج یا فرد بودن عدد (Even / Odd)

```c
if(a % 2 == 0)
{
    printf("%d is Even.\n", a);
}
else
{
    printf("%d is Odd.\n", a);
}
```

در این قسمت از عملگر `%` استفاده شده است.

عملگر `%` که با نام Modulo شناخته می‌شود، باقی‌مانده تقسیم دو عدد صحیح را محاسبه می‌کند.

برای مثال:

```text
10 % 2 = 0
11 % 2 = 1
```

**منطق برنامه:**

- اگر باقی‌مانده تقسیم عدد بر ۲ برابر صفر باشد، عدد زوج (Even) است.
- در غیر این صورت، عدد فرد (Odd) خواهد بود.

| عدد ورودی | باقی‌مانده تقسیم بر ۲ | نتیجه |
|---:|---:|---|
| 10 | 0 | زوج (Even) |
| 7 | 1 | فرد (Odd) |
| 0 | 0 | زوج (Even) |
| -4 | 0 | زوج (Even) |
| -5 | -1 | فرد (Odd) |

### 5. تشخیص مثبت، منفی یا صفر بودن عدد

```c
if(a > 0)
{
    printf("%d is Positive.\n", a);
}
else if(a < 0)
{
    printf("%d is Negative.\n", a);
}
else
{
    printf("%d is Zero.\n", a);
}
```

در این قسمت با استفاده از دستورات شرطی، علامت عدد بررسی می‌شود.

**شرایط بررسی:**

| شرط | نتیجه |
|---|---|
| `a > 0` | عدد مثبت (Positive) است. |
| `a < 0` | عدد منفی (Negative) است. |
| در غیر این صورت | عدد صفر (Zero) است. |

در این ساختار از سه دستور شرطی استفاده شده است:

- `if`: در صورت صحیح بودن شرط، دستورات داخل آن اجرا می‌شوند.
- `else if`: در صورتی که شرط قبلی برقرار نباشد، شرط جدید بررسی می‌شود.
- `else`: زمانی اجرا می‌شود که هیچ‌کدام از شرط‌های قبلی برقرار نباشند.

## مفاهیم مهم برنامه‌نویسی C

| دستور یا عملگر | کاربرد |
|---|---|
| `if` | اجرای دستورات در صورت برقرار بودن شرط |
| `else` | اجرای دستورات در صورت برقرار نبودن شرط |
| `else if` | بررسی یک شرط جدید |
| `%` | محاسبه باقی‌مانده تقسیم |
| `==` | بررسی برابری دو مقدار |
| `>` | بررسی بزرگ‌تر بودن |
| `<` | بررسی کوچک‌تر بودن |
| `scanf()` | دریافت ورودی از کاربر |
| `printf()` | نمایش خروجی |

## نکته مهم: استفاده از دو شرط مستقل

در این برنامه از دو ساختار شرطی جداگانه استفاده شده است:

```c
if(a % 2 == 0)
{
    // بررسی زوج یا فرد بودن
}

if(a > 0)
{
    // بررسی مثبت، منفی یا صفر بودن
}
```

این دو ساختار مستقل از یکدیگر هستند.

بنابراین هر دو بررسی اجرا می‌شوند و برنامه می‌تواند هم‌زمان زوج یا فرد بودن و مثبت یا منفی بودن عدد را مشخص کند.

برای مثال عدد `10` هم زوج (Even) و هم مثبت (Positive) است.

## تمرین‌های پیشنهادی (Practice Exercises)

برای درک بهتر دستورات شرطی، تمرین‌های زیر را انجام دهید:

1. برنامه‌ای بنویسید که مشخص کند عدد بر ۳ بخش‌پذیر است یا خیر.
2. بررسی کنید که آیا عدد هم‌زمان بر ۲ و ۵ بخش‌پذیر است یا خیر.
3. برنامه‌ای برای پیدا کردن بزرگ‌ترین عدد از بین دو عدد بنویسید.
4. بزرگ‌ترین عدد از بین سه عدد را با استفاده از `if-else if-else` پیدا کنید.
5. برنامه‌ای برای تشخیص سال کبیسه بنویسید.
6. بررسی کنید که عدد واردشده بین ۱ تا ۱۰۰ قرار دارد یا خیر.
7. برنامه‌ای بنویسید که زوج و مثبت بودن یا فرد و منفی بودن عدد را به‌صورت جداگانه تشخیص دهد.

## نکته اصلاحی در کد (Code Correction)

در کد اولیه، سه دستور `printf()` مربوط به تشخیص مثبت، منفی و صفر بودن عدد، آرگومان `a` را دریافت نمی‌کنند.

شکل صحیح آن‌ها به این صورت است:

```c
printf("%d is Positive.\n", a);
printf("%d is Negative.\n", a);
printf("%d is Zero.\n", a);
```
