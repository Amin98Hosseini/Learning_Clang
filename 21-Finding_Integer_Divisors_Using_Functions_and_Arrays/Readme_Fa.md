# 21- پیدا کردن مقسوم‌علیه‌های یک عدد صحیح با استفاده از توابع و آرایه‌ها در زبان C

## معرفی پروژه

در این پروژه یاد می‌گیریم چگونه با استفاده از یک تابع در زبان C، تمام مقسوم‌علیه‌های مثبت یک عدد صحیح را پیدا کنیم.

برنامه ابتدا یک عدد صحیح از کاربر دریافت می‌کند، سپس تعداد مقسوم‌علیه‌های آن را محاسبه می‌کند، یک آرایه برای ذخیره مقسوم‌علیه‌ها ایجاد می‌کند و در نهایت تمام مقادیر را نمایش می‌دهد.

یکی از قسمت‌های جالب این برنامه، نحوه عملکرد تابع `GetDivisors()` است. این تابع می‌تواند در دو حالت مختلف استفاده شود:

۱. **حالت شمارش (Counting Mode):** اگر آرایه ورودی برابر `NULL` باشد، تابع فقط تعداد مقسوم‌علیه‌ها را محاسبه می‌کند.

۲. **حالت ذخیره‌سازی (Storage Mode):** اگر یک آرایه معتبر به تابع ارسال شود، مقسوم‌علیه‌ها در آن ذخیره می‌شوند.

مفاهیم آموزشی این پروژه:

- تعریف و فراخوانی تابع در زبان C
- مقدار بازگشتی توابع
- ارسال آرایه به تابع
- مفهوم اشاره‌گر `NULL`
- مقداردهی اولیه آرایه
- آرایه‌های با طول متغیر (VLA)
- استفاده از عملگر باقی‌مانده `%`
- استفاده از یک تابع برای انجام چند عملیات مختلف

## کد برنامه

```c
#include <stdio.h>

void PrintArray(const int a[], int N);
int GetDivisors(int n, int D[]);

int main()
{
    int n;
    int i;

    printf("Enter an integer: ");
    scanf("%d", &n);
    printf("\n");

    int nd = GetDivisors(n, NULL);

    printf("%d has %d divisors.\n", n, nd);

    int D[nd];

    for(i = 0; i < nd; i++)
    {
        D[i] = 0;
    }

    GetDivisors(n, D);

    printf("Divisors of %d = {", n);
    PrintArray(D, nd);
    printf("}\n");

    return 0;
}

int GetDivisors(int n, int D[])
{
    if(n == 0) return 0;

    if(n < 0) n = -n;

    int j = 0;
    int i;

    for(i = 1; i <= n; i++)
    {
        if(n % i == 0)
        {
            if(D != NULL) D[j] = i;
            j++;
        }
    }

    return j;
}

void PrintArray(const int a[], int N)
{
    int i;

    for(i = 0; i < N; i++)
    {
        printf("%d", a[i]);

        if(i < N - 1)
        {
            printf(", ");
        }
    }
}
```

## ۱. بررسی بخش‌های مختلف برنامه

### ۱.۱ اضافه کردن کتابخانه استاندارد

```c
#include <stdio.h>
```

این کتابخانه توابع استاندارد ورودی و خروجی را در اختیار ما قرار می‌دهد.

در این برنامه از دو تابع زیر استفاده می‌کنیم:

- `printf()` برای نمایش پیام‌ها و نتایج.
- `scanf()` برای دریافت عدد صحیح از کاربر.

### ۱.۲ تعریف نمونه اولیه توابع (Function Prototypes)

```c
void PrintArray(const int a[], int N);
int GetDivisors(int n, int D[]);
```

این دو خط، نمونه اولیه یا Prototype توابع هستند.

با استفاده از Function Prototype، کامپایلر قبل از رسیدن به تعریف اصلی تابع، با نام، پارامترها و نوع خروجی آن آشنا می‌شود.

**تابع اول:**

```c
void PrintArray(const int a[], int N);
```

وظیفه این تابع نمایش عناصر یک آرایه است.

پارامترهای تابع:

- `const int a[]`: آرایه‌ای از اعداد صحیح که تابع فقط اجازه خواندن عناصر آن را دارد.
- `int N`: تعداد عناصر آرایه.

نوع خروجی تابع `void` است؛ یعنی این تابع هیچ مقداری را برنمی‌گرداند.

**تابع دوم:**

```c
int GetDivisors(int n, int D[]);
```

وظیفه این تابع پیدا کردن مقسوم‌علیه‌های یک عدد صحیح است.

پارامترهای تابع:

- `int n`: عددی که قصد داریم مقسوم‌علیه‌های آن را پیدا کنیم.
- `int D[]`: آرایه‌ای که برای ذخیره مقسوم‌علیه‌ها استفاده می‌شود.

نوع خروجی تابع `int` است؛ زیرا تعداد مقسوم‌علیه‌های پیدا‌شده را برمی‌گرداند.

### ۱.۳ تعریف متغیرها

```c
int n;
int i;
```

در این قسمت دو متغیر از نوع صحیح تعریف می‌کنیم:

- `n`: برای ذخیره عدد واردشده توسط کاربر.
- `i`: برای شمارنده حلقه‌های تکرار.

### ۱.۴ دریافت عدد صحیح از کاربر

```c
printf("Enter an integer: ");
scanf("%d", &n);
printf("\n");
```

در ابتدا با استفاده از `printf()` از کاربر می‌خواهیم یک عدد صحیح وارد کند.

سپس تابع `scanf()` مقدار واردشده را دریافت می‌کند.

در این دستور:

- `%d` برای دریافت عدد صحیح استفاده می‌شود.
- `&n` آدرس حافظه متغیر `n` را مشخص می‌کند.

برای مثال، اگر کاربر عدد ۱۲ را وارد کند، مقدار متغیر `n` برابر ۱۲ خواهد شد.

### ۱.۵ فراخوانی GetDivisors() با مقدار NULL

```c
int nd = GetDivisors(n, NULL);
```

این قسمت یکی از مهم‌ترین بخش‌های برنامه است.

در اینجا تابع `GetDivisors()` را با دو آرگومان فراخوانی می‌کنیم:

- `n`: عدد ورودی کاربر.
- `NULL`: مشخص می‌کند که در این فراخوانی آرایه‌ای برای ذخیره مقسوم‌علیه‌ها ارسال نشده است.

در نتیجه تابع فقط تعداد مقسوم‌علیه‌ها را محاسبه می‌کند.

برای مثال اگر:

```c
n = 12;
```

مقسوم‌علیه‌های مثبت عدد ۱۲ عبارت‌اند از:

```text
1, 2, 3, 4, 6, 12
```

بنابراین مقدار متغیر `nd` برابر ۶ خواهد بود.

**NULL چیست؟**

`NULL` یک مقدار ثابت برای نمایش اشاره‌گر تهی است. به زبان ساده، نشان می‌دهد که یک اشاره‌گر به یک شیء معتبر در حافظه اشاره نمی‌کند.

در این برنامه از `NULL` استفاده می‌کنیم تا به تابع `GetDivisors()` بگوییم که فعلاً نیازی به ذخیره مقسوم‌علیه‌ها در آرایه نیست و فقط تعداد آن‌ها را محاسبه کند.

### ۱.۶ نمایش تعداد مقسوم‌علیه‌ها

```c
printf("%d has %d divisors.\n", n, nd);
```

این دستور عدد ورودی و تعداد مقسوم‌علیه‌های آن را نمایش می‌دهد.

برای مثال:

```text
12 has 6 divisors.
```

### ۱.۷ تعریف آرایه با اندازه متغیر

```c
int D[nd];
```

در این مرحله تعداد مقسوم‌علیه‌ها را می‌دانیم؛ بنابراین می‌توانیم آرایه‌ای با تعداد عناصر موردنیاز تعریف کنیم.

برای مثال اگر:

```c
nd = 6;
```

تعریف آرایه معادل دستور زیر خواهد بود:

```c
int D[6];
```

به این نوع آرایه، **Variable Length Array یا VLA** گفته می‌شود.

در این نوع آرایه، اندازه در زمان اجرای برنامه مشخص می‌شود.

**نکته مهم:** اندازه آرایه VLA باید مثبت باشد. در کد اولیه اگر ورودی صفر باشد، مقدار `nd` برابر صفر می‌شود و تعریف `int D[nd]` معتبر نخواهد بود.

آرایه‌های VLA در استاندارد C99 پشتیبانی می‌شوند؛ اما در استانداردهای C11 و C17 پشتیبانی از آن‌ها اختیاری است.

### ۱.۸ مقداردهی اولیه آرایه

```c
for(i = 0; i < nd; i++)
{
    D[i] = 0;
}
```

در این قسمت با استفاده از حلقه `for` تمام عناصر آرایه را با مقدار صفر مقداردهی اولیه می‌کنیم.

برای مثال اگر تعداد عناصر آرایه ۶ باشد:

```text
D = {0, 0, 0, 0, 0, 0}
```

در این برنامه مقداردهی اولیه الزامی نیست؛ زیرا تابع `GetDivisors()` قبل از نمایش آرایه، تمام عناصر آن را مقداردهی می‌کند.

با این حال، یادگیری مقداردهی اولیه آرایه اهمیت زیادی دارد و از استفاده تصادفی از مقادیر نامشخص جلوگیری می‌کند.

### ۱.۹ فراخوانی مجدد تابع GetDivisors()

```c
GetDivisors(n, D);
```

این بار به جای `NULL`، آرایه `D` را به تابع ارسال می‌کنیم.

در نتیجه تابع علاوه بر محاسبه مقسوم‌علیه‌ها، آن‌ها را داخل آرایه ذخیره می‌کند.

برای مثال، اگر عدد ورودی ۱۲ باشد، آرایه به شکل زیر خواهد بود:

```text
D = {1, 2, 3, 4, 6, 12}
```

در فراخوانی دوم از مقدار بازگشتی تابع استفاده نکرده‌ایم؛ زیرا تعداد عناصر را در فراخوانی اول محاسبه کرده‌ایم.

### ۱.۱۰ نمایش مقسوم‌علیه‌ها

```c
printf("Divisors of %d = {", n);
PrintArray(D, nd);
printf("}\n");
```

ابتدا قسمت ابتدایی خروجی نمایش داده می‌شود.

سپس تابع `PrintArray()` عناصر آرایه را با فاصله و کاما از یکدیگر جدا می‌کند.

در نهایت آکولاد بسته نمایش داده می‌شود.

خروجی:

```text
Divisors of 12 = {1, 2, 3, 4, 6, 12}
```

## ۲. بررسی کامل تابع GetDivisors()

این تابع وظیفه پیدا کردن تمام مقسوم‌علیه‌های مثبت یک عدد را بر عهده دارد.

```c
int GetDivisors(int n, int D[])
{
    if(n == 0) return 0;

    if(n < 0) n = -n;

    int j = 0;
    int i;

    for(i = 1; i <= n; i++)
    {
        if(n % i == 0)
        {
            if(D != NULL) D[j] = i;
            j++;
        }
    }

    return j;
}
```

### ۲.۱ بررسی مقدار صفر

```c
if(n == 0) return 0;
```

اگر ورودی برابر صفر باشد، تابع مقدار صفر را برمی‌گرداند.

از نظر ریاضی، صفر بی‌نهایت مقسوم‌علیه مثبت دارد؛ زیرا هر عدد صحیح مثبت، صفر را بدون باقی‌مانده تقسیم می‌کند.

برای مثال:

\[
0 \bmod 1 = 0
\]

\[
0 \bmod 2 = 0
\]

\[
0 \bmod 3 = 0
\]

بنابراین در این برنامه صفر به‌عنوان یک حالت خاص در نظر گرفته شده و تابع برای آن مقدار صفر را برمی‌گرداند.

این یک قرارداد برنامه‌نویسی است، نه تعداد واقعی مقسوم‌علیه‌های صفر در ریاضیات.

### ۲.۲ بررسی اعداد منفی

```c
if(n < 0) n = -n;
```

اگر عدد ورودی منفی باشد، تابع آن را به مقدار مثبت تبدیل می‌کند.

برای مثال:

```text
n = -12
```

به شکل زیر تبدیل می‌شود:

```text
n = 12
```

سپس مقسوم‌علیه‌های مثبت عدد ۱۲ محاسبه می‌شوند.

بنابراین خروجی برای ورودی ۱۲- به شکل زیر خواهد بود:

```text
Divisors of -12 = {1, 2, 3, 4, 6, 12}
```

**محدودیت مهم:** کوچک‌ترین مقدار ممکن در نوع `int` را نمی‌توان با عملگر منفی‌کردن به مقدار مثبت تبدیل کرد؛ زیرا مقدار مثبت آن در همان نوع داده قابل نمایش نیست. این موضوع می‌تواند باعث سرریز عدد صحیح علامت‌دار (Signed Integer Overflow) شود.

### ۲.۳ تعریف شمارنده مقسوم‌علیه‌ها

```c
int j = 0;
```

متغیر `j` تعداد مقسوم‌علیه‌های پیدا‌شده را نگهداری می‌کند.

همچنین از این متغیر برای مشخص کردن محل ذخیره مقسوم‌علیه بعدی در آرایه استفاده می‌شود.

### ۲.۴ جست‌وجوی مقسوم‌علیه‌ها

```c
for(i = 1; i <= n; i++)
```

این حلقه تمام اعداد از ۱ تا `n` را بررسی می‌کند.

برای هر مقدار `i`، برنامه بررسی می‌کند که آیا عدد `i` می‌تواند `n` را بدون باقی‌مانده تقسیم کند یا خیر.

### ۲.۵ استفاده از عملگر باقی‌مانده %

```c
if(n % i == 0)
```

عملگر `%` باقی‌مانده تقسیم صحیح را محاسبه می‌کند.

اگر باقی‌مانده صفر باشد، یعنی عدد `i` یکی از مقسوم‌علیه‌های `n` است.

برای مثال:

\[
12 \bmod 3 = 0
\]

بنابراین عدد ۳ یکی از مقسوم‌علیه‌های ۱۲ است.

اما:

\[
12 \bmod 5 = 2
\]

بنابراین عدد ۵ مقسوم‌علیه ۱۲ نیست.

### ۲.۶ بررسی آرایه مقصد

```c
if(D != NULL) D[j] = i;
```

این دستور امکان استفاده از تابع در دو حالت مختلف را فراهم می‌کند.

اگر `D` برابر `NULL` باشد، دستور ذخیره‌سازی اجرا نمی‌شود.

اما اگر یک آرایه معتبر به تابع ارسال شده باشد، مقدار مقسوم‌علیه در خانه `j` آرایه ذخیره می‌شود.

در نتیجه یک تابع می‌تواند هم برای شمارش مقسوم‌علیه‌ها و هم برای ذخیره آن‌ها استفاده شود.

### ۲.۷ افزایش شمارنده

```c
j++;
```

هر بار که یک مقسوم‌علیه پیدا می‌شود، مقدار `j` یک واحد افزایش پیدا می‌کند.

این کار باعث می‌شود مقسوم‌علیه بعدی در خانه بعدی آرایه ذخیره شود.

### ۲.۸ برگرداندن تعداد مقسوم‌علیه‌ها

```c
return j;
```

در پایان تابع، متغیر `j` تعداد کل مقسوم‌علیه‌های پیدا‌شده را مشخص می‌کند.

این مقدار به تابع فراخواننده بازگردانده می‌شود.

## ۳. بررسی تابع PrintArray()

```c
void PrintArray(const int a[], int N)
{
    int i;

    for(i = 0; i < N; i++)
    {
        printf("%d", a[i]);

        if(i < N - 1)
        {
            printf(", ");
        }
    }
}
```

وظیفه این تابع نمایش تمام عناصر یک آرایه است.

پارامترهای تابع:

- `const int a[]`: آرایه‌ای که قرار است نمایش داده شود.
- `int N`: تعداد عناصر آرایه.

استفاده از کلمه کلیدی `const` نشان می‌دهد که این تابع اجازه تغییر عناصر آرایه را ندارد.

شرط زیر:

```c
if(i < N - 1)
```

باعث می‌شود بعد از آخرین عنصر، کاما چاپ نشود.

برای مثال خروجی به شکل زیر خواهد بود:

```text
1, 2, 3, 4, 6, 12
```

## ۴. نمونه اجرای برنامه

### مثال اول: عدد مثبت

**ورودی:**

```text
Enter an integer: 12
```

**خروجی:**

```text
12 has 6 divisors.
Divisors of 12 = {1, 2, 3, 4, 6, 12}
```

### مثال دوم: عدد اول

**ورودی:**

```text
Enter an integer: 13
```

**خروجی:**

```text
13 has 2 divisors.
Divisors of 13 = {1, 13}
```

یک عدد اول دقیقاً دو مقسوم‌علیه مثبت دارد: عدد ۱ و خود عدد.

### مثال سوم: عدد منفی

**ورودی:**

```text
Enter an integer: -20
```

**خروجی:**

```text
-20 has 6 divisors.
Divisors of -20 = {1, 2, 4, 5, 10, 20}
```

برنامه مقسوم‌علیه‌های مثبت قدرمطلق عدد ورودی را محاسبه می‌کند.

### مثال چهارم: عدد صفر

**ورودی:**

```text
Enter an integer: 0
```

تابع اصلی مقدار صفر را به‌عنوان تعداد مقسوم‌علیه‌ها برمی‌گرداند.

اما تعریف آرایه با اندازه صفر در دستور `int D[nd]` معتبر نیست.

بنابراین باید قبل از تعریف آرایه، ورودی صفر را مدیریت کنیم.

## ۵. نسخه بهبودیافته و ایمن‌تر برنامه

کد اولیه برای یادگیری توابع، آرایه‌ها و `NULL` مناسب است؛ اما چند محدودیت دارد:

۱. مقدار بازگشتی `scanf()` بررسی نمی‌شود.

۲. در صورت ورود عدد صفر، آرایه‌ای با اندازه صفر تعریف می‌شود که معتبر نیست.

۳. تبدیل کوچک‌ترین عدد منفی `int` به مقدار مثبت می‌تواند باعث سرریز شود.

۴. حلقه برنامه تمام اعداد از ۱ تا `n` را بررسی می‌کند و برای اعداد بزرگ کند خواهد بود.

۵. آرایه‌های بسیار بزرگ ممکن است حافظه Stack را بیش از حد مصرف کنند.

در نسخه زیر این مشکلات مدیریت شده‌اند و الگوریتم جست‌وجوی مقسوم‌علیه‌ها نیز بهینه‌تر شده است.

```c
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>

void PrintArray(const long long a[], int N);
int GetDivisors(long long n, long long D[]);

int main(void)
{
    int input;
    long long n;
    int nd;

    printf("Enter an integer: ");

    if(scanf("%d", &input) != 1)
    {
        printf("Invalid input!\n");
        return 1;
    }

    if(input == 0)
    {
        printf("Zero has infinitely many positive divisors.\n");
        return 0;
    }

    n = input;

    if(n < 0)
    {
        n = -n;
    }

    nd = GetDivisors(n, NULL);

    printf("%d has %d positive divisors.\n", input, nd);

    long long *D = malloc((size_t)nd * sizeof(*D));

    if(D == NULL)
    {
        printf("Memory allocation failed!\n");
        return 1;
    }

    GetDivisors(n, D);

    printf("Divisors of %d = {", input);
    PrintArray(D, nd);
    printf("}\n");

    free(D);

    return 0;
}

int GetDivisors(long long n, long long D[])
{
    if(n <= 0)
    {
        return 0;
    }

    int count = 0;

    for(long long i = 1; i <= n / i; i++)
    {
        if(n % i == 0)
        {
            if(D != NULL)
            {
                D[count] = i;
            }

            count++;

            long long other = n / i;

            if(other != i)
            {
                if(D != NULL)
                {
                    D[count] = other;
                }

                count++;
            }
        }
    }

    if(D != NULL)
    {
        // Sort the divisors in ascending order.
        for(int i = 0; i < count - 1; i++)
        {
            for(int j = 0; j < count - i - 1; j++)
            {
                if(D[j] > D[j + 1])
                {
                    long long temp = D[j];
                    D[j] = D[j + 1];
                    D[j + 1] = temp;
                }
            }
        }
    }

    return count;
}

void PrintArray(const long long a[], int N)
{
    for(int i = 0; i < N; i++)
    {
        printf("%lld", a[i]);

        if(i < N - 1)
        {
            printf(", ");
        }
    }
}
```

### تغییرات نسخه جدید

**۱. بررسی ورودی**

```c
if(scanf("%d", &input) != 1)
```

بررسی می‌کند که آیا کاربر یک عدد صحیح معتبر وارد کرده است یا خیر.

**۲. مدیریت عدد صفر**

```c
if(input == 0)
{
    printf("Zero has infinitely many positive divisors.\n");
    return 0;
}
```

عدد صفر به‌صورت جداگانه مدیریت می‌شود؛ زیرا از نظر ریاضی بی‌نهایت مقسوم‌علیه مثبت دارد.

**۳. مدیریت ایمن اعداد منفی**

```c
n = input;

if(n < 0)
{
    n = -n;
}
```

ابتدا مقدار ورودی به `long long` تبدیل می‌شود. این نوع داده می‌تواند قدرمطلق کوچک‌ترین مقدار `int` را نیز در خود نگهداری کند.

**۴. تخصیص حافظه پویا**

```c
long long *D = malloc((size_t)nd * sizeof(*D));
```

به جای استفاده از VLA، حافظه موردنیاز برای ذخیره مقسوم‌علیه‌ها به‌صورت پویا تخصیص داده می‌شود.

**۵. بررسی موفقیت تخصیص حافظه**

```c
if(D == NULL)
```

بررسی می‌کند که آیا تابع `malloc()` توانسته است حافظه موردنیاز را تخصیص دهد یا خیر.

**۶. بهینه‌سازی الگوریتم جست‌وجو**

```c
for(long long i = 1; i <= n / i; i++)
```

به جای بررسی تمام اعداد از ۱ تا `n`، فقط اعداد تا ریشه دوم `n` بررسی می‌شوند.

دلیل این موضوع وجود رابطه بین جفت مقسوم‌علیه‌ها است:

\[
i \times \frac{n}{i} = n
\]

برای مثال، جفت مقسوم‌علیه‌های عدد ۳۶ عبارت‌اند از:

```text
1 × 36
2 × 18
3 × 12
4 × 9
6 × 6
```

بنابراین با پیدا کردن یک مقسوم‌علیه، می‌توان مقسوم‌علیه متناظر آن را نیز پیدا کرد.

**۷. مرتب‌سازی مقسوم‌علیه‌ها**

از آنجایی که مقسوم‌علیه‌های متناظر به ترتیب نزولی پیدا می‌شوند، در پایان آرایه مرتب می‌شود تا خروجی به ترتیب صعودی باشد.

**۸. آزادسازی حافظه**

```c
free(D);
```

پس از پایان استفاده از آرایه، حافظه تخصیص‌یافته آزاد می‌شود.

## ۷. پیچیدگی زمانی و حافظه

### نسخه اولیه

در نسخه اولیه تمام اعداد از ۱ تا `n` بررسی می‌شوند.

| مشخصه | پیچیدگی |
|---|---|
| پیچیدگی زمانی هر فراخوانی | O(n) |
| حافظه کمکی در حالت شمارش | O(1) |
| حافظه ذخیره مقسوم‌علیه‌ها | O(d) |

در اینجا `d` تعداد مقسوم‌علیه‌ها است.

از آنجایی که تابع `GetDivisors()` دو بار فراخوانی می‌شود، پیچیدگی زمانی کلی همچنان O(n) خواهد بود.

### نسخه بهبودیافته

در نسخه جدید فقط اعداد تا ریشه دوم `n` بررسی می‌شوند.

| عملیات | پیچیدگی |
|---|---|
| پیدا کردن جفت مقسوم‌علیه‌ها | O(√n) |
| مرتب‌سازی مقسوم‌علیه‌ها | O(d²) |
| پیچیدگی کلی | O(√n + d²) |
| حافظه ذخیره مقسوم‌علیه‌ها | O(d) |

در صورت نیاز می‌توان مرحله مرتب‌سازی را با یک الگوریتم سریع‌تر جایگزین کرد.

## ۸. تمرین‌های پیشنهادی

برای یادگیری بهتر، تمرین‌های زیر را انجام دهید:

۱. تابعی بنویسید که فقط تعداد مقسوم‌علیه‌های یک عدد را برگرداند.

۲. تابعی بنویسید که مجموع تمام مقسوم‌علیه‌های مثبت یک عدد را محاسبه کند.

۳. بزرگ‌ترین مقسوم‌علیه یک عدد به‌جز خود آن عدد را پیدا کنید.

۴. با استفاده از تابع `GetDivisors()` بررسی کنید که یک عدد اول است یا خیر.

۵. مقسوم‌علیه‌های یک عدد را به ترتیب نزولی نمایش دهید.

۶. مجموع مقسوم‌علیه‌های حقیقی یک عدد را محاسبه کنید؛ یعنی تمام مقسوم‌علیه‌ها به‌جز خود عدد.

۷. تمام اعداد بین ۱ تا ۱۰۰ را پیدا کنید که دقیقاً شش مقسوم‌علیه مثبت دارند.

۸. تابع `GetDivisors()` را به شکلی تغییر دهید که مقسوم‌علیه‌ها را با استفاده از تخصیص پویای حافظه برگرداند.

۹. زمان اجرای الگوریتم اولیه O(n) را با الگوریتم بهبودیافته O(√n) مقایسه کنید.
