# 39- اعداد مختلط (Complex Numbers) و انجام عملیات ریاضی با استفاده از Structure در زبان C

## ۱. مقدمه

در ریاضیات، عدد مختلط یا Complex Number عددی است که از دو بخش تشکیل شده است:

- بخش حقیقی (Real Part)
- بخش موهومی (Imaginary Part)

شکل عمومی یک عدد مختلط به‌صورت زیر است:

\[
z=a+bi
\]

در این رابطه:

- \(a\) بخش حقیقی عدد است.
- \(b\) بخش موهومی عدد است.
- \(i\) واحد موهومی است.
- مربع واحد موهومی برابر منفی یک است.

\[
i^2=-1
\]

برای مثال:

\[
z=3+4i
\]

در این مثال:

- بخش حقیقی برابر ۳ است.
- بخش موهومی برابر ۴ است.

در زبان C می‌توانیم با استفاده از `struct` یک نوع داده جدید تعریف کنیم و دو بخش حقیقی و موهومی را درون آن ذخیره کنیم.

این برنامه یک ساختار به نام `Complex` تعریف می‌کند و عملیات ریاضی مربوط به اعداد مختلط را پیاده‌سازی می‌کند.

عملیات مورد استفاده عبارت‌اند از:

۱. نمایش عدد مختلط

۲. محاسبه مزدوج عدد مختلط

۳. محاسبه قدر مطلق یا اندازه عدد مختلط

۴. جمع دو عدد مختلط

۵. تفریق دو عدد مختلط

۶. ضرب دو عدد مختلط

۷. تقسیم دو عدد مختلط

همچنین در این برنامه یاد می‌گیریم که یک تابع می‌تواند یک ساختار را به‌عنوان ورودی دریافت کند و یک ساختار جدید را به‌عنوان خروجی برگرداند.

## ۲. کد کامل برنامه

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

typedef struct
{
    float real;
    float imag;
} Complex;

void DispComplex(Complex z);
Complex Conj(Complex z);
float Abs(Complex z);
Complex Add(Complex z1, Complex z2);
Complex Subtract(Complex z1, Complex z2);
Complex Product(Complex z1, Complex z2);
Complex Division(Complex z1, Complex z2);

int main()
{

    Complex z1={3,4};
    printf("z1 = ");
    DispComplex(z1);
    printf("\n\n");

    Complex z2={1,-5};
    printf("z2 = ");
    DispComplex(z2);
    printf("\n\n");

    Complex z3={0,0};
    printf("z3 = ");
    DispComplex(z3);
    printf("\n\n");

    Complex z4={-1,0};
    printf("z4 = ");
    DispComplex(z4);
    printf("\n\n");

    Complex z5={0,7};
    printf("z5 = ");
    DispComplex(z5);
    printf("\n\n");

    printf("Conj(z1) = ");
    DispComplex(Conj(z1));
    printf("\n\n");

    printf("Abs(z1) = %f\n\n",Abs(z1));

    printf("z1 + z2 = ");
    DispComplex(Add(z1,z2));
    printf("\n\n");

    printf("z1 - z2 = ");
    DispComplex(Subtract(z1,z2));
    printf("\n\n");

    printf("z1 * z2 = ");
    DispComplex(Product(z1,z2));
    printf("\n\n");

    printf("z1 / z2 = ");
    DispComplex(Division(z1,z2));
    printf("\n\n");

    printf("z1 / z1 = ");
    DispComplex(Division(z1,z1));
    printf("\n\n");

    return 0;
}

void DispComplex(Complex z)
{
    float x=z.real;
    float y=z.imag;

    if(x==0)
    {
        if(y==0)
            printf("0");
        else
            printf("%fi",y);
    }
    else
    {
        if(y==0)
            printf("%f",x);
        else
        {
            if(y>0)
                printf("%f + %fi",x,y);
            else
                printf("%f - %fi",x,-y);
        }
    }
}

Complex Conj(Complex z)
{
    Complex zc={z.real, -z.imag};
    return zc;
}

float Abs(Complex z)
{
    return sqrt(z.real*z.real+z.imag*z.imag);
}

Complex Add(Complex z1, Complex z2)
{
    Complex z={z1.real + z2.real,z1.imag + z2.imag};
    return z;
}

Complex Subtract(Complex z1, Complex z2)
{
    Complex z={z1.real - z2.real,z1.imag - z2.imag};
    return z;
}

Complex Product(Complex z1, Complex z2)
{
    Complex z;
    z.real = z1.real*z2.real-z1.imag*z2.imag;
    z.imag = z1.real*z2.imag+z1.imag*z2.real;
    return z;
}

Complex Division(Complex z1, Complex z2)
{
    Complex z;
    float den = z2.real*z2.real + z2.imag*z2.imag;
    z.real = (z1.real*z2.real+z1.imag*z2.imag)/den;
    z.imag = (z1.imag*z2.real-z1.real*z2.imag)/den;
    return z;
}
```

## ۴. تعریف ساختار Complex

```c
typedef struct
{
    float real;
    float imag;
} Complex;
```

این ساختار پایه اصلی برنامه است.

در این ساختار، یک عدد مختلط با استفاده از دو متغیر از نوع `float` ذخیره می‌شود.

### بررسی اعضای ساختار

| عضو | نوع داده | توضیح |
|---|---|---|
| `real` | `float` | بخش حقیقی عدد |
| `imag` | `float` | بخش موهومی عدد |

برای مثال، عدد مختلط زیر را در نظر بگیرید:

\[
z=3+4i
\]

برای ذخیره آن در ساختار می‌نویسیم:

```c
Complex z1 = {3, 4};
```

در این حالت:

```text
z1.real = 3
z1.imag = 4
```

مقدار اول به عضو `real` و مقدار دوم به عضو `imag` اختصاص داده می‌شود.

### چرا از typedef استفاده می‌کنیم؟

کلمه کلیدی `typedef` برای ایجاد یک نام مستعار برای یک نوع داده استفاده می‌شود.

بدون استفاده از `typedef` می‌توانستیم ساختار را به شکل زیر تعریف کنیم:

```c
struct Complex
{
    float real;
    float imag;
};
```

برای تعریف متغیر باید می‌نوشتیم:

```c
struct Complex z1;
```

اما با استفاده از `typedef` می‌توانیم بنویسیم:

```c
Complex z1;
```

این کار باعث کوتاه‌تر و خواناتر شدن کد می‌شود.

## ۵. آشنایی با اعداد مختلط

شکل عمومی یک عدد مختلط به‌صورت زیر است:

\[
z=a+bi
\]

که در آن:

- \(a\) بخش حقیقی است.
- \(b\) بخش موهومی است.
- \(i\) واحد موهومی است.

واحد موهومی دارای خاصیت زیر است:

\[
i^2=-1
\]

برای مثال:

\[
z_1=3+4i
\]

\[
z_2=1-5i
\]

معادل این اعداد در زبان C به شکل زیر است:

```c
Complex z1 = {3, 4};
Complex z2 = {1, -5};
```

در برنامه سه عدد مختلط دیگر نیز تعریف شده‌اند:

```c
Complex z3 = {0, 0};
Complex z4 = {-1, 0};
Complex z5 = {0, 7};
```

نمایش ریاضی آن‌ها به شکل زیر است:

| متغیر | نمایش ریاضی |
|---|---|
| `z1` | \(3+4i\) |
| `z2` | \(1-5i\) |
| `z3` | \(0\) |
| `z4` | \(-1\) |
| `z5` | \(7i\) |

این مثال‌ها حالت‌های مختلف اعداد مختلط را نشان می‌دهند.

## ۶. اعلان اولیه توابع (Function Prototypes)

```c
void DispComplex(Complex z);
Complex Conj(Complex z);
float Abs(Complex z);
Complex Add(Complex z1, Complex z2);
Complex Subtract(Complex z1, Complex z2);
Complex Product(Complex z1, Complex z2);

```

این خطوط، توابع مورد استفاده در برنامه را قبل از تابع `main()` به کامپایلر معرفی می‌کنند.

بیایید هر تابع را بررسی کنیم.

| نام تابع | نوع خروجی | وظیفه |
|---|---|---|
| `DispComplex()` | `void` | نمایش عدد مختلط |
| `Conj()` | `Complex` | محاسبه مزدوج |
| `Abs()` | `float` | محاسبه اندازه عدد مختلط |
| `Add()` | `Complex` | جمع دو عدد مختلط |

دقت کنید که بیشتر توابع دارای خروجی از نوع `Complex` هستند.

در زبان C امکان بازگرداندن یک ساختار از تابع وجود دارد.

برای مثال:


این تابع دو عدد مختلط دریافت می‌کند و یک عدد مختلط جدید را برمی‌گرداند.

## ۸. نمایش اعداد مختلط

در برنامه برای نمایش عدد مختلط از تابع زیر استفاده می‌کنیم:

```c
DispComplex(z1);
```

تعریف تابع:

```c
void DispComplex(Complex z)
{
    float x=z.real;
    float y=z.imag;

    if(x==0)
    {
        if(y==0)
            printf("0");
        else
            printf("%fi",y);
    }
    else
    {
        if(y==0)
            printf("%f",x);
        else
        {
            if(y>0)
                printf("%f + %fi",x,y);
            else
                printf("%f - %fi",x,-y);
        }
    }
}
```

وظیفه این تابع نمایش عدد مختلط در قالب ریاضی قابل‌خواندن است.

شکل عمومی عدد مختلط:

\[
z=x+yi
\]

در ابتدای تابع دو متغیر محلی تعریف می‌کنیم:

```c
float x=z.real;
float y=z.imag;
```

متغیر `x` بخش حقیقی و متغیر `y` بخش موهومی را نگهداری می‌کند.

سپس تابع با استفاده از شرط‌ها چهار حالت را بررسی می‌کند.

### حالت اول: هر دو بخش حقیقی و موهومی صفر باشند

```c
if(x==0)
{
    if(y==0)
        printf("0");
}
```

اگر:

\[
x=0,\quad y=0
\]

عدد مختلط برابر صفر است:

\[
z=0
\]

بنابراین خروجی:

```text
0
```

### حالت دوم: بخش حقیقی صفر باشد

```c
else
    printf("%fi",y);
```

اگر بخش حقیقی صفر باشد ولی بخش موهومی صفر نباشد، عدد فقط دارای بخش موهومی است.

برای مثال:

\[
z=7i
\]

خروجی:

```text
7.000000i
```

### حالت سوم: بخش موهومی صفر باشد

```c
if(y==0)
    printf("%f",x);
```

اگر بخش موهومی صفر باشد، عدد فقط دارای بخش حقیقی است.

برای مثال:

\[
z=-1
\]

خروجی:

```text
-1.000000
```

### حالت چهارم: هر دو بخش غیرصفر باشند

```c
if(y>0)
    printf("%f + %fi",x,y);
else
    printf("%f - %fi",x,-y);
```

اگر بخش موهومی مثبت باشد، علامت مثبت چاپ می‌شود.

برای مثال:

\[
z=3+4i
\]

خروجی:

```text
3.000000 + 4.000000i
```

اگر بخش موهومی منفی باشد، علامت منفی چاپ می‌شود.

برای مثال:

\[
z=1-5i
\]

خروجی:

```text
1.000000 - 5.000000i
```

در حالت منفی از `-y` استفاده شده است.

اگر مقدار `y` برابر `-5` باشد، مقدار `-y` برابر `5` می‌شود.

بنابراین به‌جای نمایش نامناسب زیر:

```text
1.000000 + -5.000000i
```

نمایش صحیح زیر را خواهیم داشت:

```text
1.000000 - 5.000000i
```

### نکته مهم درباره اعداد اعشاری

در این تابع از شرط‌هایی مانند زیر استفاده شده است:

```c
if(x==0)
```

مقایسه دقیق اعداد اعشاری در محاسبات عمومی همیشه قابل‌اعتماد نیست؛ زیرا ممکن است خطاهای گرد کردن باعث شوند نتیجه یک محاسبه که از نظر ریاضی صفر است، از نظر کامپیوتری دقیقاً صفر نباشد.

برای برنامه‌های عمومی‌تر می‌توانیم از یک مقدار خطای مجاز استفاده کنیم:

```c
#define EPSILON 0.000001f

if (fabsf(x) < EPSILON)
```

البته برای مقادیر ساده استفاده‌شده در برنامه اصلی، مقایسه مستقیم مشکلی ایجاد نمی‌کند.

## ۹. مزدوج عدد مختلط (Complex Conjugate)

در برنامه برای محاسبه مزدوج از تابع زیر استفاده می‌کنیم:

```c
Conj(z1);
```

تعریف تابع:

```c
Complex Conj(Complex z)
{
    Complex zc={z.real, -z.imag};
    return zc;
}
```

### مزدوج عدد مختلط چیست؟

اگر یک عدد مختلط به شکل زیر باشد:

\[
z=a+bi
\]

مزدوج آن به شکل زیر خواهد بود:

\[
\overline{z}=a-bi
\]

یعنی:

- بخش حقیقی بدون تغییر باقی می‌ماند.
- علامت بخش موهومی تغییر می‌کند.

برای مثال:

\[
z=3+4i
\]

مزدوج آن:

\[
\overline{z}=3-4i
\]

### بررسی کد

```c
Complex zc={z.real, -z.imag};
```

در این خط یک ساختار جدید به نام `zc` ایجاد می‌کنیم.

بخش حقیقی بدون تغییر کپی می‌شود:

```c
z.real
```

بخش موهومی با علامت مخالف ذخیره می‌شود:

```c
-z.imag
```

در پایان:

```c
return zc;
```

ساختار جدید به‌عنوان خروجی تابع برگردانده می‌شود.

### یک خاصیت مهم

حاصل‌ضرب یک عدد مختلط در مزدوج خودش همیشه یک عدد حقیقی نامنفی است:

\[
z\overline{z}=a^2+b^2
\]

برای مثال:

\[
(3+4i)(3-4i)=9+16=25
\]

این خاصیت در محاسبه اندازه عدد مختلط و عملیات تقسیم کاربرد زیادی دارد.

## ۱۰. قدر مطلق یا اندازه عدد مختلط (Magnitude)

در برنامه از تابع زیر استفاده می‌کنیم:

```c
Abs(z1);
```

تعریف تابع:

```c
float Abs(Complex z)
{
    return sqrt(z.real*z.real+z.imag*z.imag);
}
```

### اندازه عدد مختلط چیست؟

اندازه یک عدد مختلط، فاصله آن عدد از مبدأ در صفحه مختلط است.

اگر:

\[
z=a+bi
\]

باشد، اندازه آن از رابطه زیر محاسبه می‌شود:

\[
|z|=\sqrt{a^2+b^2}
\]

این رابطه بر اساس قضیه فیثاغورس به دست آمده است.

### مثال

عدد زیر را در نظر بگیرید:

\[
z_1=3+4i
\]

اندازه آن برابر است با:

\[
|z_1|=\sqrt{3^2+4^2}
\]

\[
|z_1|=\sqrt{9+16}
\]

\[
|z_1|=\sqrt{25}
\]

\[
|z_1|=5
\]

### بررسی کد

```c
sqrt(z.real*z.real+z.imag*z.imag)
```

این عبارت مراحل زیر را انجام می‌دهد:

۱. مربع بخش حقیقی را محاسبه می‌کند.

۲. مربع بخش موهومی را محاسبه می‌کند.

۳. دو مقدار را با یکدیگر جمع می‌کند.

۴. جذر نتیجه را محاسبه می‌کند.

تابع `sqrt()` در کتابخانه `math.h` تعریف شده است.

نوع خروجی تابع `Abs()` برابر `float` است؛ زیرا اندازه عدد مختلط یک عدد حقیقی است.

## ۱۱. جمع دو عدد مختلط (Addition)

در برنامه برای جمع دو عدد مختلط از تابع زیر استفاده می‌کنیم:

```c
Add(z1,z2);
```

تعریف تابع:

```c
Complex Add(Complex z1, Complex z2)
{
    Complex z={z1.real + z2.real,z1.imag + z2.imag};
    return z;
}
```

### فرمول ریاضی

دو عدد مختلط زیر را در نظر بگیرید:

\[
z_1=a+bi
\]

\[
z_2=c+di
\]

حاصل جمع آن‌ها برابر است با:

\[
z_1+z_2=(a+c)+(b+d)i
\]

یعنی:

- بخش‌های حقیقی را با هم جمع می‌کنیم.
- بخش‌های موهومی را با هم جمع می‌کنیم.

### مثال

فرض کنیم:

\[
z_1=3+4i
\]

\[
z_2=1-5i
\]

پس:

\[
z_1+z_2=(3+1)+(4-5)i
\]

\[
z_1+z_2=4-i
\]

### بررسی کد

```c
Complex z={z1.real + z2.real,z1.imag + z2.imag};
```

در این خط یک ساختار جدید ایجاد می‌شود که دارای مقادیر زیر است:

```text
real = 3 + 1 = 4
imag = 4 + (-5) = -1
```

در پایان:

```c
return z;
```

نتیجه به‌صورت زیر برگردانده می‌شود:

\[
4-i
\]

## ۱۲. تفریق دو عدد مختلط (Subtraction)

برای تفریق دو عدد مختلط از تابع زیر استفاده می‌کنیم:

```c
Subtract(z1,z2);
```

تعریف تابع:

```c
Complex Subtract(Complex z1, Complex z2)
{
    Complex z={z1.real - z2.real,z1.imag - z2.imag};
    return z;
}
```

### فرمول ریاضی

اگر دو عدد مختلط داشته باشیم:

\[
z_1=a+bi
\]

\[
z_2=c+di
\]

تفاضل آن‌ها برابر است با:

\[
z_1-z_2=(a-c)+(b-d)i
\]

یعنی:

- بخش حقیقی را از بخش حقیقی دیگر کم می‌کنیم.
- بخش موهومی را از بخش موهومی دیگر کم می‌کنیم.

### مثال

با فرض:

\[
z_1=3+4i
\]

\[
z_2=1-5i
\]

داریم:

\[
z_1-z_2=(3-1)+(4-(-5))i
\]

\[
z_1-z_2=2+9i
\]

### بررسی کد

```c
Complex z={z1.real - z2.real,z1.imag - z2.imag};
```

مقادیر ساختار جدید برابر هستند با:

```text
real = 3 - 1 = 2
imag = 4 - (-5) = 9
```

بنابراین خروجی تابع:

\[
2+9i
\]

خواهد بود.

## ۱۳. ضرب دو عدد مختلط (Multiplication)

در برنامه برای ضرب دو عدد مختلط از تابع زیر استفاده می‌کنیم:

```c
Product(z1,z2);
```

تعریف تابع:

```c
Complex Product(Complex z1, Complex z2)
{
    Complex z;

    z.real = z1.real*z2.real-z1.imag*z2.imag;
    z.imag = z1.real*z2.imag+z1.imag*z2.real;

    return z;
}
```

### فرمول ریاضی

دو عدد مختلط زیر را در نظر بگیرید:

\[
z_1=a+bi
\]

\[
z_2=c+di
\]

حاصل‌ضرب آن‌ها:

\[
z_1z_2=(a+bi)(c+di)
\]

با استفاده از خاصیت توزیع‌پذیری:

\[
z_1z_2=ac+adi+bci+bdi^2
\]

از آنجایی که:

\[
i^2=-1
\]

داریم:

\[
z_1z_2=ac+adi+bci-bd
\]

با جدا کردن بخش حقیقی و موهومی:

\[
z_1z_2=(ac-bd)+(ad+bc)i
\]

بنابراین:

\[
Real=ac-bd
\]

\[
Imag=ad+bc
\]

### بررسی کد

بخش حقیقی:

```c
z.real = z1.real*z2.real-z1.imag*z2.imag;
```

این دستور فرمول زیر را پیاده‌سازی می‌کند:

\[
Real=ac-bd
\]

بخش موهومی:

```c
z.imag = z1.real*z2.imag+z1.imag*z2.real;
```

این دستور فرمول زیر را پیاده‌سازی می‌کند:

\[
Imag=ad+bc
\]

### مثال

فرض کنیم:

\[
z_1=3+4i
\]

\[
z_2=1-5i
\]

حاصل‌ضرب:

\[
z_1z_2=(3+4i)(1-5i)
\]

با باز کردن پرانتز:

\[
=3-15i+4i-20i^2
\]

چون:

\[
i^2=-1
\]

پس:

\[
=3-11i+20
\]

در نتیجه:

\[
z_1z_2=23-11i
\]

خروجی تابع:

```text
23.000000 - 11.000000i
```

خواهد بود.

## ۱۴. تقسیم دو عدد مختلط (Division)

برای تقسیم دو عدد مختلط از تابع زیر استفاده می‌کنیم:

```c
Division(z1,z2);
```

تعریف تابع:

```c
Complex Division(Complex z1, Complex z2)
{
    Complex z;
    float den = z2.real*z2.real + z2.imag*z2.imag;

    z.real = (z1.real*z2.real+z1.imag*z2.imag)/den;
    z.imag = (z1.imag*z2.real-z1.real*z2.imag)/den;

    return z;
}
```

این عملیات نسبت به جمع، تفریق و ضرب کمی پیچیده‌تر است.

### فرمول ریاضی

دو عدد مختلط زیر را در نظر بگیرید:

\[
z_1=a+bi
\]

\[
z_2=c+di
\]

می‌خواهیم عبارت زیر را محاسبه کنیم:

\[
\frac{z_1}{z_2}=\frac{a+bi}{c+di}
\]

برای حذف بخش موهومی از مخرج، صورت و مخرج را در مزدوج مخرج ضرب می‌کنیم:

\[
\frac{a+bi}{c+di}
\times
\frac{c-di}{c-di}
\]

بنابراین:

\[
\frac{z_1}{z_2}
=
\frac{(a+bi)(c-di)}{(c+di)(c-di)}
\]

مخرج برابر می‌شود با:

\[
(c+di)(c-di)=c^2+d^2
\]

صورت را باز می‌کنیم:

\[
(a+bi)(c-di)
\]

\[
=ac-adi+bci-bdi^2
\]

با توجه به اینکه:

\[
i^2=-1
\]

داریم:

\[
=ac+bd+(bc-ad)i
\]

بنابراین فرمول نهایی تقسیم:

\[
\frac{z_1}{z_2}
=
\frac{ac+bd}{c^2+d^2}
+
\frac{bc-ad}{c^2+d^2}i
\]

پس:

\[
Real=\frac{ac+bd}{c^2+d^2}
\]

\[
Imag=\frac{bc-ad}{c^2+d^2}
\]

### بررسی مخرج کد

```c
float den = z2.real*z2.real + z2.imag*z2.imag;
```

این دستور عبارت زیر را محاسبه می‌کند:

\[
den=c^2+d^2
\]

این مقدار برابر مربع اندازه عدد مختلط تقسیم‌کننده است.

### محاسبه بخش حقیقی

```c
z.real = (z1.real*z2.real+z1.imag*z2.imag)/den;
```

این دستور فرمول زیر را پیاده‌سازی می‌کند:

\[
Real=\frac{ac+bd}{c^2+d^2}
\]

### محاسبه بخش موهومی

```c
z.imag = (z1.imag*z2.real-z1.real*z2.imag)/den;
```

این دستور فرمول زیر را پیاده‌سازی می‌کند:

\[
Imag=\frac{bc-ad}{c^2+d^2}
\]

### مثال

فرض کنیم:

\[
z_1=3+4i
\]

\[
z_2=1-5i
\]

ابتدا مخرج را محاسبه می‌کنیم:

\[
den=1^2+(-5)^2
\]

\[
den=1+25=26
\]

بخش حقیقی:

\[
Real=\frac{3(1)+4(-5)}{26}
\]

\[
Real=\frac{3-20}{26}
\]

\[
Real=-\frac{17}{26}
\]

بخش موهومی:

\[
Imag=\frac{4(1)-3(-5)}{26}
\]

\[
Imag=\frac{4+15}{26}
\]

\[
Imag=\frac{19}{26}
\]

پس نتیجه نهایی:

\[
\frac{3+4i}{1-5i}
=
-\frac{17}{26}+\frac{19}{26}i
\]

به‌صورت تقریبی:

\[
=-0.653846+0.730769i
\]

## ۱۵. مشکل مهم: تقسیم بر صفر

تابع تقسیم در نسخه اصلی برنامه یک محدودیت مهم دارد.

فرض کنید عدد مختلط زیر را داشته باشیم:

```c
Complex z3 = {0, 0};
```

اگر دستور زیر را اجرا کنیم:

```c
Division(z1, z3);
```

مقدار مخرج برابر خواهد شد با:

\[
den=0^2+0^2=0
\]

در نتیجه برنامه تلاش می‌کند عددی را بر صفر تقسیم کند.

از نظر ریاضی تقسیم بر صفر تعریف نشده است.

بنابراین باید قبل از انجام تقسیم، صفر بودن مقسوم‌علیه را بررسی کنیم.

یک نسخه بهبودیافته می‌تواند به شکل زیر باشد:

```c
#include <stdbool.h>

bool Division(Complex z1, Complex z2, Complex *result)
{
    float den = z2.real*z2.real + z2.imag*z2.imag;

    if (den == 0.0f)
        return false;

    result->real =
        (z1.real*z2.real + z1.imag*z2.imag) / den;

    result->imag =
        (z1.imag*z2.real - z1.real*z2.imag) / den;

    return true;
}
```

در این نسخه:

- اگر تقسیم موفق باشد، مقدار `true` برگردانده می‌شود.
- اگر مقسوم‌علیه صفر باشد، مقدار `false` برگردانده می‌شود.
- نتیجه از طریق اشاره‌گر `result` به تابع فراخواننده منتقل می‌شود.

برای محاسبات عمومی‌تر با اعداد بسیار بزرگ یا بسیار کوچک، بهتر است از الگوریتم تقسیم عدد مختلط با پایداری عددی بیشتر استفاده شود؛ زیرا محاسبه مربع مؤلفه‌ها ممکن است باعث سرریز یا کم‌ریزی عددی شود.

## ۱۶. مفهوم بازگرداندن Structure از تابع

یکی از مفاهیم مهم زبان C که در این برنامه استفاده شده، بازگرداندن یک ساختار از تابع است.

برای مثال:

```c
Complex Add(Complex z1, Complex z2)
{
    Complex z={z1.real + z2.real,z1.imag + z2.imag};
    return z;
}
```

ابتدا یک ساختار محلی ایجاد می‌کنیم:

```c
Complex z;
```

سپس نتیجه عملیات ریاضی را در آن قرار می‌دهیم.

در پایان:

```c
return z;
```

ساختار به‌عنوان خروجی تابع برگردانده می‌شود.

این کار در زبان C کاملاً مجاز است.

برای مثال:

```c
DispComplex(Add(z1,z2));
```

این دستور دو مرحله انجام می‌دهد:

۱. تابع `Add(z1,z2)` دو عدد مختلط را جمع می‌کند و ساختار نتیجه را برمی‌گرداند.

۲. تابع `DispComplex()` ساختار برگشتی را دریافت می‌کند و آن را نمایش می‌دهد.

بنابراین لازم نیست برای هر محاسبه یک متغیر جداگانه تعریف کنیم.

همین روش برای توابع زیر نیز استفاده شده است:

```c
DispComplex(Conj(z1));
DispComplex(Subtract(z1,z2));
DispComplex(Product(z1,z2));
DispComplex(Division(z1,z2));
```

این روش باعث کوتاه‌تر و خواناتر شدن برنامه می‌شود.

## ۱۸. بهبود تابع نمایش اعداد مختلط

تابع نمایش اصلی برای مقادیر این مثال درست کار می‌کند، اما می‌توان آن را بهبود داد.

برای مثال، همیشه شش رقم اعشار نمایش می‌دهد و برای مقادیر بسیار کوچک یا منفی صفر، رفتار مناسبی ندارد.

نسخه بهبودیافته:

```c
#include <stdio.h>
#include <math.h>

#define EPSILON 0.000001f

void DispComplex(Complex z)
{
    float x = z.real;
    float y = z.imag;

    if (fabsf(x) < EPSILON)
        x = 0.0f;

    if (fabsf(y) < EPSILON)
        y = 0.0f;

    if (x == 0.0f && y == 0.0f)
    {
        printf("0");
    }
    else if (y == 0.0f)
    {
        printf("%.2f", x);
    }
    else if (x == 0.0f)
    {
        printf("%.2fi", y);
    }
    else
    {
        printf("%.2f %c %.2fi", x, (y >= 0.0f) ? '+' : '-', fabsf(y));
    }
}
```

این نسخه:

- برای تشخیص صفر از مقدار خطای مجاز استفاده می‌کند.
- فقط دو رقم اعشار نمایش می‌دهد.
- علامت مثبت و منفی بخش موهومی را به‌درستی نمایش می‌دهد.
- از نمایش منفی صفر جلوگیری می‌کند.

در عبارت زیر:

```c
(y >= 0.0f) ? '+' : '-'
```

از عملگر شرطی یا Ternary Operator استفاده شده است.

اگر `y` مثبت یا صفر باشد، علامت `+` انتخاب می‌شود؛ در غیر این صورت علامت `-` انتخاب می‌شود.

تابع `fabsf()` نیز قدر مطلق یک مقدار از نوع `float` را محاسبه می‌کند.

## ۱۹. نوع Complex آماده در استاندارد C

زبان C علاوه بر امکان پیاده‌سازی دستی اعداد مختلط با استفاده از ساختار، از استاندارد C99 به بعد امکانات داخلی برای محاسبات اعداد مختلط نیز ارائه می‌دهد.

برای مثال:

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z1 = 3.0 + 4.0 * I;
    double complex z2 = 1.0 - 5.0 * I;

    double complex sum = z1 + z2;
    double complex product = z1 * z2;
    double complex quotient = z1 / z2;

    printf("z1 = %.2f %+.2fi\n", creal(z1), cimag(z1));
    printf("z2 = %.2f %+.2fi\n", creal(z2), cimag(z2));

    printf("Sum = %.2f %+.2fi\n", creal(sum), cimag(sum));
    printf("Product = %.2f %+.2fi\n", creal(product), cimag(product));
    printf("Division = %.2f %+.2fi\n", creal(quotient), cimag(quotient));

    return 0;
}
```

در این برنامه:

- `double complex` برای تعریف یک عدد مختلط استفاده می‌شود.
- `I` نشان‌دهنده واحد موهومی است.
- `creal()` بخش حقیقی را استخراج می‌کند.
- `cimag()` بخش موهومی را استخراج می‌کند.

این قابلیت در استاندارد C99 و نسخه‌های بعدی که از امکانات اعداد مختلط پشتیبانی می‌کنند وجود دارد.

با این حال، پیاده‌سازی دستی اعداد مختلط با استفاده از Structure تمرین بسیار خوبی برای یادگیری ساختارها، توابع، آرگومان‌ها، مقادیر بازگشتی و فرمول‌های ریاضی است.

## ۲۱. تمرین‌ها

برای تسلط بیشتر بر این مفاهیم، تمرین‌های زیر را انجام دهید.

### تمرین اول – تعریف یک عدد مختلط جدید

یک متغیر جدید تعریف کنید:

```c
Complex z6 = {-2, 3};
```

بخش حقیقی و موهومی آن را نمایش دهید.

\[
z=5-7i
\]

خروجی مورد انتظار:

\[
\overline{z}=5+7i
\]

### تمرین سوم – محاسبه اندازه

اندازه عدد مختلط زیر را محاسبه کنید:

\[
z=5+12i
\]

خروجی مورد انتظار:

\[
|z|=13
\]

### تمرین چهارم – آزمایش ضرب

عبارت زیر را محاسبه کنید:

\[
(2+3i)(4-2i)
\]

نتیجه را با تابع `Product()` مقایسه کنید.

### تمرین پنجم – آزمایش تقسیم

عبارت زیر را محاسبه کنید:

\[
\frac{5+2i}{1+3i}
\]

برنامه را تغییر دهید تا نتیجه را نمایش دهد.

### تمرین ششم – آزمایش تفریق

عبارت زیر را محاسبه کنید:

\[
(7-4i)-(2+6i)
\]

### تمرین هفتم – مدیریت تقسیم بر صفر

تابع `Division()` را تغییر دهید تا در صورت صفر بودن مقسوم‌علیه، خطا را تشخیص دهد و از انجام تقسیم بر صفر جلوگیری کند.

### تمرین هشتم – محاسبه مربع عدد مختلط

تابع زیر را تعریف کنید:

```c
Complex Square(Complex z);
```

این تابع باید مقدار زیر را محاسبه کند:

\[
z^2=(a+bi)^2
\]

فرمول مورد استفاده:

\[
z^2=(a^2-b^2)+2abi
\]

### تمرین نهم – محاسبه فاصله دو عدد مختلط

تابعی بنویسید که فاصله دو عدد مختلط را محاسبه کند:

\[
d=|z_1-z_2|
\]

برای پیاده‌سازی می‌توانید از توابع `Subtract()` و `Abs()` که قبلاً نوشته‌اید استفاده کنید.
