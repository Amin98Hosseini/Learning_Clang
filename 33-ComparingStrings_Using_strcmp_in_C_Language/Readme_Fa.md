# 33- آموزش زبان C – مقایسه رشته‌ها با استفاده از تابع `strcmp()`

## ۱. مقدمه

در زبان برنامه‌نویسی C، رشته‌ها (Strings) به‌صورت آرایه‌ای از کاراکترها ذخیره می‌شوند که در انتهای آن‌ها یک کاراکتر ویژه به نام **Null Terminator یا `'\0'`** قرار می‌گیرد.

در بسیاری از برنامه‌ها لازم است دو رشته را با یکدیگر مقایسه کنیم تا متوجه شویم:

- آیا دو رشته کاملاً یکسان هستند؟
- آیا رشته اول از رشته دوم کوچک‌تر است؟
- آیا رشته اول از رشته دوم بزرگ‌تر است؟

برای انجام این کار، کتابخانه استاندارد زبان C تابعی به نام `strcmp()` در اختیار ما قرار می‌دهد.

این تابع در کتابخانه `<string.h>` تعریف شده است.

در این آموزش با موارد زیر آشنا می‌شویم:

- مقایسه دو رشته با استفاده از `strcmp()`
- بررسی برابر بودن دو رشته
- مقایسه رشته‌ها از نظر ترتیب لغت‌نامه‌ای (Lexicographical Order)
- نوشتن تابع اختصاصی برای مقایسه رشته‌ها
- تفاوت مقایسه رشته‌ها با `==` و `strcmp()`

## ۲. کتابخانه‌های موردنیاز

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
```

کاربرد هر کتابخانه:

| کتابخانه | کاربرد |
|---|---|
| `stdio.h` | برای توابع ورودی و خروجی مانند `printf()` |
| `stdlib.h` | برای توابع عمومی زبان C؛ در این مثال استفاده نشده است. |
| `string.h` | برای توابع پردازش رشته، از جمله `strcmp()` |

در این برنامه فقط به دو کتابخانه `stdio.h` و `string.h` نیاز داریم.

## ۳. کد کامل برنامه

```c
#include <stdio.h>
#include <string.h>

void CompareString(const char *str1, const char *str2);

int main()
{
    char s1[] = "abc";
    char s2[] = "abc";
    char s3[] = "abd";
    char s4[] = "abb";

    printf("Input strings:\n");

    printf("s1 = %s\n", s1);
    printf("s2 = %s\n", s2);
    printf("s3 = %s\n", s3);
    printf("s4 = %s\n", s4);

    printf("\n");

    printf("Comparing s1 and s2:\n");
    CompareString(s1, s2);

    printf("\n");

    printf("Comparing s1 and s3:\n");
    CompareString(s1, s3);

    printf("\n");

    printf("Comparing s1 and s4:\n");
    CompareString(s1, s4);

    return 0;
}

void CompareString(const char *str1, const char *str2)
{
    int result = strcmp(str1, str2);

    if (result == 0)
    {
        printf("%s = %s\n", str1, str2);
    }
    else if (result > 0)
    {
        printf("%s > %s\n", str1, str2);
    }
    else
    {
        printf("%s < %s\n", str1, str2);
    }
}
```

در این نسخه، عملکرد برنامه اصلی حفظ شده است؛ اما تابع `CompareString()` بهینه‌تر شده و فقط یک بار تابع `strcmp()` را اجرا می‌کند.

## ۴. بررسی قسمت‌های مختلف برنامه

### ۴.۱. اعلان تابع (Function Prototype)

```c
void CompareString(const char *str1, const char *str2);
```

در این قسمت تابعی با نام `CompareString()` معرفی می‌کنیم.

این تابع دو ورودی از نوع اشاره‌گر به کاراکتر دریافت می‌کند:

- `str1`: اشاره‌گر به رشته اول
- `str2`: اشاره‌گر به رشته دوم

نوع خروجی تابع `void` است؛ یعنی این تابع هیچ مقداری را به محل فراخوانی برنمی‌گرداند.

در عوض، دو رشته را مقایسه کرده و نتیجه را با استفاده از `printf()` نمایش می‌دهد.

**چرا از `const char *` استفاده می‌کنیم؟**

کلمه کلیدی `const` مشخص می‌کند که تابع نباید از طریق این اشاره‌گرها محتوای رشته‌ها را تغییر دهد.

برای مثال، دستور زیر داخل تابع مجاز نیست:

```c
str1[0] = 'A';
```

زیرا `str1` به کاراکترهایی اشاره می‌کند که تابع متعهد شده آن‌ها را تغییر ندهد.

استفاده از `const char *` زمانی مفید است که تابع فقط نیاز به خواندن اطلاعات رشته داشته باشد.

### ۴.۲. تعریف رشته‌ها

```c
char s1[] = "abc";
char s2[] = "abc";
char s3[] = "abd";
char s4[] = "abb";
```

در این قسمت چهار آرایه از نوع `char` تعریف شده‌اند.

| متغیر | مقدار | توضیح |
|---|---|---|
| `s1` | `"abc"` | رشته اول |
| `s2` | `"abc"` | مشابه رشته اول |
| `s3` | `"abd"` | متفاوت با رشته اول |
| `s4` | `"abb"` | متفاوت با رشته اول |

هر رشته در حافظه همراه با کاراکتر پایان‌دهنده ذخیره می‌شود.

برای مثال:

```text
s1:  a  b  c  \0
s2:  a  b  c  \0
s3:  a  b  d  \0
s4:  a  b  b  \0
```

### ۴.۳. نمایش رشته‌های ورودی

```c
printf("Input strings:\n");

printf("s1 = %s\n", s1);
printf("s2 = %s\n", s2);
printf("s3 = %s\n", s3);
printf("s4 = %s\n", s4);
```

در این قسمت از فرمت `%s` برای چاپ رشته‌ها استفاده می‌کنیم.

خروجی:

```text
Input strings:
s1 = abc
s2 = abc
s3 = abd
s4 = abb
```

فرمت `%s` برای نمایش رشته‌های معتبر و پایان‌یافته با `'\0'` استفاده می‌شود.

### ۴.۴. فراخوانی تابع مقایسه رشته‌ها

```c
CompareString(s1, s2);
CompareString(s1, s3);
CompareString(s1, s4);
```

در این قسمت تابع `CompareString()` سه مرتبه فراخوانی می‌شود.

در هر بار فراخوانی، دو رشته به‌عنوان ورودی به تابع ارسال می‌شوند.

| فراخوانی تابع | آرگومان اول | آرگومان دوم |
|---|---|---|
| `CompareString(s1, s2)` | `"abc"` | `"abc"` |
| `CompareString(s1, s3)` | `"abc"` | `"abd"` |
| `CompareString(s1, s4)` | `"abc"` | `"abb"` |

هنگام فراخوانی تابع، آدرس اولین کاراکتر آرایه‌ها به پارامترهای اشاره‌گری ارسال می‌شود.

سپس تابع از طریق `str1` و `str2` به محتوای رشته‌ها دسترسی پیدا می‌کند.

## ۵. بررسی تابع `strcmp()`

تابع `strcmp()` برای مقایسه دو رشته پایان‌یافته با `'\0'` استفاده می‌شود.

این تابع در کتابخانه زیر تعریف شده است:

```c
#include <string.h>
```

ساختار کلی:

```c
strcmp(string1, string2);
```

تابع، کاراکترهای دو رشته را از ابتدا و به‌ترتیب با یکدیگر مقایسه می‌کند.

نتیجه این تابع یک مقدار صحیح است که علامت آن یکی از سه حالت زیر را مشخص می‌کند:

| مقدار بازگشتی | مفهوم |
|---|---|
| `0` | دو رشته برابر هستند. |
| عدد منفی | رشته اول از نظر ترتیب لغت‌نامه‌ای کوچک‌تر است. |
| عدد مثبت | رشته اول از نظر ترتیب لغت‌نامه‌ای بزرگ‌تر است. |

**نکته مهم:** استاندارد C فقط علامت مقدار بازگشتی را تضمین می‌کند، نه مقدار دقیق آن را.

بنابراین نباید فرض کنید که `strcmp()` حتماً مقادیر `-1`، `0` یا `1` را برمی‌گرداند.

## ۶. نحوه مقایسه رشته‌ها

### ۶.۱. مقایسه دو رشته برابر

```c
strcmp("abc", "abc");
```

تابع کاراکترهای دو رشته را به‌ترتیب مقایسه می‌کند:

```text
رشته اول:  a  b  c
رشته دوم:  a  b  c
           |  |  |
           ✓  ✓  ✓
```

تمام کاراکترهای متناظر با یکدیگر برابر هستند و هر دو رشته در یک موقعیت به پایان می‌رسند.

بنابراین نتیجه برابر با صفر است:

```c
strcmp("abc", "abc") == 0
```

در برنامه داریم:

```c
if (result == 0)
{
    printf("%s = %s\n", str1, str2);
}
```

چون مقدار `result` برابر صفر است، شرط برقرار شده و خروجی زیر چاپ می‌شود:

```text
abc = abc
```

### ۶.۲. مقایسه رشته‌های `"abc"` و `"abd"`

```c
strcmp("abc", "abd");
```

تابع از چپ به راست کاراکترها را مقایسه می‌کند:

| موقعیت | رشته اول | رشته دوم | نتیجه |
|---:|:---:|:---:|---|
| ۱ | a | a | برابر |
| ۲ | b | b | برابر |
| ۳ | c | d | متفاوت |

دو کاراکتر اول برابر هستند.

اما در موقعیت سوم، کاراکتر `c` از نظر مقدار کاراکتری از `d` کوچک‌تر است.

بنابراین:

```text
abc < abd
```

در نتیجه، مقدار بازگشتی `strcmp()` منفی خواهد بود.

برنامه این حالت را بررسی می‌کند:

```c
else
{
    printf("%s < %s\n", str1, str2);
}
```

خروجی:

```text
abc < abd
```

### ۶.۳. مقایسه رشته‌های `"abc"` و `"abb"`

```c
strcmp("abc", "abb");
```

مقایسه کاراکترها:

| موقعیت | رشته اول | رشته دوم | نتیجه |
|---:|:---:|:---:|---|
| ۱ | a | a | برابر |
| ۲ | b | b | برابر |
| ۳ | c | b | متفاوت |

در موقعیت سوم، مقدار کاراکتر `c` از `b` بزرگ‌تر است.

بنابراین:

```text
abc > abb
```

مقدار بازگشتی تابع `strcmp()` مثبت خواهد بود.

در نتیجه برنامه خروجی زیر را نمایش می‌دهد:

```text
abc > abb
```

## ۷. بررسی تابع CompareString

تابع اصلی برنامه به شکل زیر نوشته شده است:

```c
void CompareString(const char* str1, const char *str2)
{
    if(strcmp(str1,str2)==0)
    {
        printf("%s = %s\n",str1,str2);
    }

    if(strcmp(str1,str2)>0)
    {
        printf("%s > %s\n",str1,str2);
    }

    if(strcmp(str1,str2)<0)
    {
        printf("%s < %s\n",str1,str2);
    }
}
```

این تابع برای رشته‌های معتبر به‌درستی کار می‌کند؛ اما در این روش، تابع `strcmp()` سه مرتبه اجرا می‌شود.

روش بهتر این است که یک بار نتیجه مقایسه را در یک متغیر ذخیره کنیم:

```c
int result = strcmp(str1, str2);
```

سپس مقدار آن را بررسی کنیم:

```c
if (result == 0)
{
    /* رشته‌ها برابر هستند */
}
else if (result > 0)
{
    /* رشته اول بزرگ‌تر است */
}
else
{
    /* رشته اول کوچک‌تر است */
}
```

این روش خواناتر و کارآمدتر است.

همچنین استفاده از `else if` باعث می‌شود فقط یکی از حالت‌های مقایسه اجرا شود.

## ۸. خروجی برنامه

خروجی نهایی برنامه به شکل زیر است:

```text
Input strings:
s1 = abc

Comparing s1 and s2:
abc = abc

Comparing s1 and s3:

```

## ۹. نکات مهم و اشتباهات رایج

### ۹.۱. برای مقایسه محتوای رشته‌ها از `==` استفاده نکنید

یکی از اشتباهات رایج در ابتدای یادگیری زبان C، استفاده از `==` برای مقایسه دو رشته است.

مثال اشتباه:

```c
if (s1 == s2)
{
    printf("Strings are equal");
}
```

این دستور محتوای رشته‌ها را مقایسه نمی‌کند.

در این عبارت، نام آرایه‌ها در این موقعیت به اشاره‌گر تبدیل می‌شوند و مقایسه بررسی می‌کند که آیا دو اشاره‌گر به یک آدرس حافظه اشاره می‌کنند یا خیر.

حتی اگر دو آرایه جداگانه دارای محتوای یکسان باشند، معمولاً آدرس آن‌ها متفاوت است.

روش صحیح:

```c
if (strcmp(s1, s2) == 0)
{
    printf("Strings are equal");
}
```

### ۹.۲. تابع `strcmp()` به حروف بزرگ و کوچک حساس است

تابع `strcmp()` حروف بزرگ و کوچک را متفاوت در نظر می‌گیرد.

برای مثال:

```c
strcmp("Hello", "hello");
```

این دو رشته برابر نیستند؛ زیرا کاراکترهای `H` و `h` متفاوت هستند.

بنابراین:

```text
"Hello" != "hello"
```

در بعضی سیستم‌ها توابعی مانند `strcasecmp()` یا `_stricmp()` برای مقایسه بدون حساسیت به حروف بزرگ و کوچک وجود دارند؛ اما این توابع جزو استاندارد ISO C نیستند.

### ۹.۳. مقایسه رشته با مقایسه عددی متفاوت است

به مثال زیر توجه کنید:

```c
strcmp("10", "2");
```

این تابع رشته‌ها را از نظر ترتیب کاراکترها مقایسه می‌کند، نه از نظر مقدار عددی.

در اولین موقعیت، کاراکتر `'1'` با `'2'` مقایسه می‌شود.

از آنجایی که `'1'` کوچک‌تر است، نتیجه مقایسه رشته‌ای به شکل زیر خواهد بود:

```text
"10" < "2"
```

اما از نظر عددی:

```text
10 > 2
```

اگر قصد مقایسه مقدار عددی را دارید، ابتدا باید رشته‌ها را با توابعی مانند `strtol()` به عدد تبدیل کنید.

### ۹.۴. مقایسه رشته‌هایی با طول متفاوت

مثال:

```c
strcmp("abc", "abcd");
```

سه کاراکتر اول برابر هستند، اما رشته اول زودتر به پایان می‌رسد.

اگر یک رشته پیشوند رشته دیگر باشد، رشته کوتاه‌تر از نظر ترتیب لغت‌نامه‌ای کوچک‌تر در نظر گرفته می‌شود.

بنابراین:

```text
"abc" < "abcd"
```

### ۹.۵. استفاده از رشته‌های دارای Null Terminator

تابع `strcmp()` انتظار دارد هر دو ورودی رشته‌های معتبر و پایان‌یافته با `'\0'` باشند.

اگر آرایه‌ای فاقد Null Terminator معتبر به تابع ارسال شود، ممکن است تابع خارج از محدوده آرایه را بخواند و رفتار تعریف‌نشده ایجاد شود.

## ۱۰. تفاوت `strcmp()` و `strncmp()`

در کتابخانه `<string.h>` تابع دیگری به نام `strncmp()` نیز وجود دارد.

تفاوت این تابع با `strcmp()` در این است که فقط تعداد مشخصی از کاراکترهای دو رشته را مقایسه می‌کند.

ساختار کلی:

```c
strncmp(string1, string2, number_of_characters);
```

مثال:

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char s1[] = "abcdef";
    char s2[] = "abcxyz";

    printf("strcmp result: %d\n", strcmp(s1, s2));
    printf("strncmp result: %d\n", strncmp(s1, s2, 3));

    return 0;
}
```

در این مثال، سه کاراکتر اول دو رشته برابر هستند:

```text
s1 = abcdef
s2 = abcxyz
     abc
```

بنابراین تابع `strncmp()` فقط سه کاراکتر اول را بررسی می‌کند و مقدار صفر برمی‌گرداند.

اما تابع `strcmp()` مقایسه را ادامه می‌دهد تا به اولین کاراکتر متفاوت برسد.

| تابع | نحوه مقایسه |
|---|---|
| `strcmp(s1, s2)` | مقایسه تا رسیدن به اولین تفاوت یا پایان یکی از رشته‌ها |
| `strncmp(s1, s2, n)` | مقایسه حداکثر `n` کاراکتر اول |

توجه کنید که `strncmp()` جایگزین بررسی معتبر بودن حافظه یا پایان رشته نیست. اشاره‌گرهای ورودی همچنان باید به حافظه معتبر برای کاراکترهایی که تابع می‌خواند اشاره کنند.

**تمرین ۳ – مقایسه سه رشته**

سه رشته تعریف کنید و مشخص کنید کدام رشته از نظر ترتیب لغت‌نامه‌ای زودتر قرار می‌گیرد.

**تمرین ۴ – مقایسه حساس به حروف بزرگ و کوچک**

دو رشته زیر را مقایسه کنید:

```c
char s1[] = "Embedded";
char s2[] = "embedded";
```

بررسی کنید که آیا این دو رشته برابر هستند یا خیر.

**تمرین ۵ – مقایسه سه کاراکتر اول**

با استفاده از `strncmp()` فقط سه کاراکتر اول رشته‌های زیر را مقایسه کنید:

```c
char s1[] = "STM32F103";
char s2[] = "STM32F407";
```

**تمرین ۶ – مرتب‌سازی رشته‌ها**

یک آرایه شامل پنج رشته تعریف کنید و با استفاده از `strcmp()` و الگوریتم Bubble Sort آن‌ها را به ترتیب حروف الفبا مرتب کنید.

راهنمایی: از `strcmp()` برای تشخیص نیاز به جابه‌جایی دو رشته مجاور استفاده کنید.

## ۱۳. اهداف آموزشی

پس از مطالعه این آموزش باید بتوانید:

- نحوه ذخیره‌سازی رشته‌ها در زبان C را توضیح دهید.
- با استفاده از `strcmp()` دو رشته را مقایسه کنید.
- مفهوم مقادیر بازگشتی تابع `strcmp()` را درک کنید.
- نحوه مقایسه لغت‌نامه‌ای رشته‌ها را توضیح دهید.
- تابعی بنویسید که رشته‌ها را از طریق اشاره‌گر دریافت کند.
- کاربرد `const char *` را برای ورودی‌های فقط خواندنی درک کنید.
- دلیل نامناسب بودن `==` برای مقایسه محتوای رشته‌ها را توضیح دهید.
- تفاوت مقایسه حساس به حروف بزرگ و کوچک را درک کنید.
- تفاوت `strcmp()` و `strncmp()` را تشخیص دهید.
