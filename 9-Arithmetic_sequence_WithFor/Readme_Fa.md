# 9- آموزش برنامه‌نویسی C – دنباله حسابی با استفاده از حلقه For

## ۱. مقدمه

در این مثال با استفاده از زبان برنامه‌نویسی C، یک دنباله حسابی (Arithmetic Progression) ایجاد می‌کنیم و مجموع اعضای آن را با استفاده از حلقه `for` محاسبه خواهیم کرد.

دنباله حسابی به دنباله‌ای از اعداد گفته می‌شود که اختلاف بین دو عضو متوالی آن ثابت است.

برنامه سه مقدار از کاربر دریافت می‌کند:

- `a` : اولین عضو دنباله.
- `d` : اختلاف مشترک یا گام دنباله.
- `n` : تعداد اعضای دنباله.

سپس برنامه:

۱. هر عضو دنباله را محاسبه می‌کند.

۲. مقدار هر عضو را به مجموع قبلی اضافه می‌کند.

۳. شماره عضو، مقدار آن و مجموع تجمعی را در قالب یک جدول نمایش می‌دهد.

۴. پس از پایان حلقه، مجموع نهایی دنباله را نمایش می‌دهد.

## ۲. کد برنامه

```c
#include <stdio.h>

int main()
{
    float a, d;
    int n;

    // Get a
    printf("Enter first element of series (a): ");
    scanf("%f", &a);
    printf("\n");

    // Get d
    printf("Enter step size of series (d): ");
    scanf("%f", &d);
    printf("\n");

    // Get n
    printf("Enter number of elements (n): ");
    scanf("%d", &n);
    printf("\n");

    float S = 0;
    float ai;

    printf("i\ta(i)\t\tS(i)\n");

    int i;

    for (i = 0; i < n; i++)
    {
        ai = a + i * d;
        S += ai;
        printf("%d\t%f\t%f\n", i, ai, S);
    }

    printf("\n\nFinal Sum of Series (S) = %f\n", S);

    return 0;
}
```

## ۳. مبانی ریاضی دنباله حسابی

برای محاسبه اعضای دنباله حسابی از رابطه زیر استفاده می‌کنیم:

\[
a_i = a + i \times d
\]

که در آن:

- \(a_i\) : عضو فعلی دنباله.
- \(a\) : اولین عضو دنباله.
- \(i\) : شماره یا اندیس عضو که از صفر شروع می‌شود.
- \(d\) : اختلاف مشترک بین اعضای متوالی.

مجموع تمام اعضای دنباله:

\[
S_n = \sum_{i=0}^{n-1}(a+i\times d)
\]

فرمول محاسبه مجموع نهایی:

\[
S_n = \frac{n}{2}[2a+(n-1)d]
\]

### مثال

فرض کنید ورودی‌های زیر را داشته باشیم:

```text
a = 2
d = 3
n = 5
```

دنباله حاصل:

```text
2, 5, 8, 11, 14
```

مجموع نهایی:

\[
S = 2+5+8+11+14 = 40
\]

## ۴. بررسی و توضیح کد

### ۴.۱. اضافه کردن کتابخانه ورودی و خروجی

```c
#include <stdio.h>
```

این کتابخانه برای انجام عملیات ورودی و خروجی در زبان C استفاده می‌شود.

توابع مهم:

- `printf()` : نمایش اطلاعات در صفحه‌نمایش.
- `scanf()` : دریافت اطلاعات از کاربر.

### ۴.۲. تعریف متغیرها

```c
float a, d;
int n;
```

در این قسمت سه متغیر تعریف می‌کنیم:

| متغیر | نوع داده | کاربرد |
|---|---|---|
| `a` | float | اولین عضو دنباله |
| `d` | float | اختلاف مشترک اعضای دنباله |
| `n` | int | تعداد اعضای دنباله |

از `float` استفاده می‌کنیم، زیرا مقدار اولین عضو و اختلاف مشترک می‌توانند اعشاری باشند.

اما تعداد اعضای دنباله یک عدد صحیح است و به همین دلیل از `int` استفاده می‌کنیم.

### ۴.۳. دریافت اطلاعات از کاربر

```c
printf("Enter first element of series (a): ");
scanf("%f", &a);
```

در ابتدا برنامه از کاربر می‌خواهد اولین عضو دنباله را وارد کند.

سپس تابع `scanf()` مقدار واردشده را دریافت کرده و در متغیر `a` ذخیره می‌کند.

مشخص‌کننده‌های فرمت:

- `%f` : برای دریافت اعداد اعشاری از نوع `float`.
- `%d` : برای دریافت اعداد صحیح از نوع `int`.

این فرآیند برای متغیرهای `d` و `n` نیز تکرار می‌شود.

### ۴.۴. مقداردهی اولیه مجموع

```c
float S = 0;
float ai;
```

در این قسمت دو متغیر جدید تعریف می‌کنیم:

- `S` : برای نگهداری مجموع تجمعی اعضای دنباله.
- `ai` : برای ذخیره عضو فعلی دنباله.

متغیر `S` با مقدار صفر مقداردهی اولیه می‌شود؛ زیرا هنوز هیچ عضوی به مجموع اضافه نشده است.

### ۴.۵. نمایش عنوان ستون‌های جدول

```c
printf("i\ta(i)\t\tS(i)\n");
```

این دستور عنوان ستون‌های جدول را نمایش می‌دهد.

کاراکترهای کنترلی:

- `\t` : ایجاد فاصله افقی (Tab).
- `\n` : رفتن به خط بعدی (New Line).

جدول شامل سه ستون است:

| ستون | توضیح |
|---|---|
| `i` | شماره یا اندیس عضو |
| `a(i)` | مقدار عضو فعلی |
| `S(i)` | مجموع اعضا تا این مرحله |

### ۴.۶. آشنایی با حلقه For

```c
for (i = 0; i < n; i++)
{
    // Statements
}
```

حلقه `for` یکی از ساختارهای تکرار در زبان C است که برای اجرای چندباره یک مجموعه دستور استفاده می‌شود.

این حلقه از سه قسمت اصلی تشکیل شده است:

```c
for (initialization; condition; update)
```

**۱. مقداردهی اولیه (Initialization)**

```c
i = 0;
```

در این قسمت شمارنده حلقه با مقدار صفر مقداردهی اولیه می‌شود.

**۲. شرط ادامه حلقه (Condition)**

```c
i < n;
```

تا زمانی که مقدار `i` کوچک‌تر از `n` باشد، دستورات داخل حلقه اجرا می‌شوند.

**۳. افزایش شمارنده (Update)**

```c
i++
```

پس از هر بار اجرای دستورات داخل حلقه، مقدار `i` یک واحد افزایش پیدا می‌کند.

برای مثال، اگر `n = 5` باشد، مقادیر شمارنده عبارت‌اند از:

```text
i = 0
i = 1
i = 2
i = 3
i = 4
```

بنابراین حلقه پنج مرتبه اجرا خواهد شد.

### ۴.۷. محاسبه عضو فعلی دنباله

```c
ai = a + i * d;
```

در این قسمت با استفاده از فرمول ریاضی دنباله حسابی، عضو فعلی محاسبه می‌شود.

فرض کنید:

```text
a = 2
d = 3
```

نتایج محاسبات:

| i | محاسبه | ai |
|---|---|---|
| 0 | 2 + 0 × 3 | 2 |
| 1 | 2 + 1 × 3 | 5 |
| 2 | 2 + 2 × 3 | 8 |
| 3 | 2 + 3 × 3 | 11 |
| 4 | 2 + 4 × 3 | 14 |

### ۴.۸. محاسبه مجموع تجمعی

```c
S += ai;
```

این دستور از عملگر انتساب ترکیبی (Compound Assignment) استفاده می‌کند.

عبارت بالا معادل دستور زیر است:

```c
S = S + ai;
```

در هر بار اجرای حلقه، مقدار عضو فعلی به مجموع قبلی اضافه می‌شود.

### ۴.۹. نمایش اطلاعات هر مرحله

```c
printf("%d\t%f\t%f\n", i, ai, S);
```

این دستور سه مقدار را نمایش می‌دهد:

- شماره عضو فعلی.
- مقدار عضو فعلی دنباله.
- مجموع تجمعی تا این مرحله.

به این ترتیب پس از هر بار اجرای حلقه، یک سطر جدید در جدول نمایش داده می‌شود.

### ۴.۱۰. نمایش مجموع نهایی دنباله

```c
printf("\n\nFinal Sum of Series (S) = %f\n", S);
```

این دستور پس از پایان حلقه `for` اجرا می‌شود.

در این قسمت مجموع نهایی تمام اعضای دنباله به کاربر نمایش داده می‌شود.

تفاوت این نسخه با مثال قبلی این است که علاوه بر نمایش مجموع در هر مرحله، مجموع نهایی نیز به‌صورت جداگانه نمایش داده می‌شود.

### ۴.۱۱. پایان برنامه

```c
return 0;
```

این دستور باعث پایان اجرای تابع `main()` می‌شود و مقدار صفر نشان‌دهنده اجرای موفقیت‌آمیز برنامه است.

## ۶. تفاوت حلقه While و For

در مثال قبلی برای محاسبه دنباله حسابی از حلقه `while` استفاده کردیم؛ اما در این مثال همان عملیات را با حلقه `for` انجام می‌دهیم.

هر دو حلقه قابلیت انجام محاسبات یکسان را دارند.

**حلقه While:**

```c
int i = 0;

while (i < n)
{
    ai = a + i * d;
    S += ai;

    printf("%d\t%f\t%f\n", i, ai, S);

    i++;
}
```

**حلقه For:**

```c
for (i = 0; i < n; i++)
{
    ai = a + i * d;
    S += ai;

    printf("%d\t%f\t%f\n", i, ai, S);
}
```

تفاوت اصلی این دو ساختار در نحوه نوشتن آن‌ها است.

در حلقه `for`، مقداردهی اولیه، شرط ادامه و افزایش شمارنده در یک خط نوشته می‌شوند.

معمولاً زمانی که تعداد دفعات اجرای حلقه از قبل مشخص باشد، استفاده از `for` مناسب‌تر و خواناتر است.

- تمرین ۱: حلقه `for` را با حلقه `while` جایگزین کنید.
- تمرین ۲: یک دنباله حسابی نزولی با مقدار منفی `d` ایجاد کنید.
- تمرین ۳: میانگین تمام اعضای دنباله را محاسبه و نمایش دهید.
- تمرین ۴: اعضای دنباله را به‌صورت معکوس نمایش دهید.
- تمرین ۵: فقط اعضای زوج دنباله را نمایش دهید.
- تمرین ۶: مجموع محاسبه‌شده توسط حلقه را با فرمول ریاضی مجموع دنباله مقایسه کنید.
