# 8- آموزش برنامه‌نویسی C – دنباله حسابی و محاسبه مجموع آن

## ۱. مقدمه

در این مثال با استفاده از زبان برنامه‌نویسی C، یک دنباله حسابی (Arithmetic Progression) ایجاد می‌کنیم و مجموع اعضای آن را محاسبه خواهیم کرد.

دنباله حسابی به دنباله‌ای از اعداد گفته می‌شود که اختلاف بین هر دو عضو متوالی آن ثابت است.

برنامه سه مقدار از کاربر دریافت می‌کند:

- `a` : اولین عضو دنباله.
- `d` : اختلاف مشترک یا گام دنباله.
- `n` : تعداد اعضای دنباله.

سپس برنامه با استفاده از یک حلقه `while` اعضای دنباله را محاسبه می‌کند، مجموع آن‌ها را به دست می‌آورد و نتیجه را به‌صورت یک جدول نمایش می‌دهد.

## ۲. کد برنامه

```c
#include <stdio.h>

int main()
{
    float a, d;
    int n;

    // Get a
    printf("Enter first element of series (a): ");
    scanf("%f", &a);
    printf("\n");

    // Get d
    printf("Enter step size of series (d): ");
    scanf("%f", &d);
    printf("\n");

    // Get n
    printf("Enter number of elements (n): ");
    scanf("%d", &n);
    printf("\n");

    float S = 0;
    float ai;

    printf("i\ta(i)\t\tS(i)\n");

    int i = 0;

    while (i < n)
    {
        ai = a + i * d;
        S += ai;
        printf("%d\t%f\t%f\n", i, ai, S);
        i++;
    }
}
```

## ۳. مبانی ریاضی دنباله حسابی

دنباله حسابی با فرمول زیر تعریف می‌شود:

\[
a_i = a + i \times d
\]

که در آن:

- \(a_i\) : عضو فعلی دنباله.
- \(a\) : اولین عضو دنباله.
- \(i\) : شماره یا اندیس عضو دنباله که از صفر شروع می‌شود.
- \(d\) : اختلاف مشترک بین اعضای متوالی.

مجموع اعضای دنباله نیز از رابطه زیر محاسبه می‌شود:

\[
S_n = \sum_{i=0}^{n-1}(a+i\times d)
\]

فرمول ساده‌شده مجموع دنباله حسابی:

\[
S_n = \frac{n}{2}[2a+(n-1)d]
\]

### مثال ریاضی

فرض کنید مقادیر زیر را داشته باشیم:

```text
a = 2
d = 3
n = 5
```

در این صورت دنباله به شکل زیر خواهد بود:

```text
2, 5, 8, 11, 14
```

مجموع اعضا:

\[
S = 2+5+8+11+14=40
\]

## ۴. بررسی و توضیح کد

### ۴.۱. اضافه کردن کتابخانه ورودی و خروجی

```c
#include <stdio.h>
```

این کتابخانه برای انجام عملیات ورودی و خروجی استفاده می‌شود.

توابع مهم مورد استفاده:

- `printf()` : نمایش اطلاعات در صفحه‌نمایش.
- `scanf()` : دریافت اطلاعات از کاربر.

### ۴.۲. تعریف متغیرها

```c
float a, d;
int n;
```

در این قسمت سه متغیر تعریف می‌کنیم:

| متغیر | نوع داده | کاربرد |
|---|---|---|
| `a` | float | اولین عضو دنباله |
| `d` | float | اختلاف مشترک اعضای دنباله |
| `n` | int | تعداد اعضای دنباله |

چرا از `float` استفاده می‌کنیم؟

زیرا مقدار اولین عضو و اختلاف مشترک می‌توانند دارای قسمت اعشاری باشند.

اما تعداد اعضای دنباله یک عدد صحیح است، بنابراین از `int` استفاده می‌کنیم.

### ۴.۳. دریافت اطلاعات از کاربر

```c
printf("Enter first element of series (a): ");
scanf("%f", &a);
```

ابتدا با استفاده از `printf()` پیامی برای دریافت اولین عضو دنباله نمایش داده می‌شود.

سپس با استفاده از `scanf()` مقدار واردشده دریافت و در متغیر `a` ذخیره می‌شود.

مشخص‌کننده‌های فرمت:

- `%f` : برای دریافت عدد اعشاری از نوع `float`.
- `%d` : برای دریافت عدد صحیح از نوع `int`.

این عملیات برای متغیرهای `d` و `n` نیز تکرار می‌شود.

### ۴.۴. مقداردهی اولیه مجموع

```c
float S = 0;
float ai;
```

در این قسمت دو متغیر جدید تعریف می‌کنیم:

- `S` : برای ذخیره مجموع اعضای دنباله استفاده می‌شود.
- `ai` : برای ذخیره عضو فعلی دنباله استفاده می‌شود.

مقدار اولیه `S` برابر صفر است؛ زیرا در ابتدای محاسبات هنوز هیچ عضوی به مجموع اضافه نشده است.

### ۴.۵. نمایش عنوان ستون‌های جدول

```c
printf("i\ta(i)\t\tS(i)\n");
```

این دستور عنوان ستون‌های جدول را نمایش می‌دهد.

کاراکترهای کنترلی:

- `\t` : ایجاد فاصله افقی (Tab).
- `\n` : رفتن به خط بعدی (New Line).

ستون‌های جدول عبارت‌اند از:

| ستون | توضیح |
|---|---|
| `i` | شماره یا اندیس عضو |
| `a(i)` | مقدار عضو فعلی دنباله |
| `S(i)` | مجموع اعضا تا این مرحله |

### ۴.۶. مقداردهی اولیه شمارنده حلقه

```c
int i = 0;
```

متغیر `i` برای مشخص کردن شماره عضو فعلی استفاده می‌شود.

مقدار اولیه آن صفر است؛ زیرا در این برنامه اندیس‌گذاری از صفر شروع می‌شود.

بنابراین اولین عضو دنباله از رابطه زیر محاسبه می‌شود:

\[
a_0 = a + 0 \times d = a
\]

### ۴.۷. آشنایی با حلقه While

```c
while (i < n)
{
    // Statements
}
```

حلقه `while` تا زمانی اجرا می‌شود که شرط داخل پرانتز برقرار باشد.

در این مثال شرط برابر است با:

```c
i < n
```

به عنوان مثال، اگر `n = 5` باشد، مقادیر متغیر `i` در هر بار اجرای حلقه عبارت‌اند از:

```text
0, 1, 2, 3, 4
```

بنابراین حلقه دقیقاً پنج بار اجرا خواهد شد.

### ۴.۸. محاسبه عضو فعلی دنباله

```c
ai = a + i * d;
```

در این قسمت با استفاده از فرمول دنباله حسابی، عضو فعلی محاسبه می‌شود.

فرض کنید:

```text
a = 2
d = 3
```

مقادیر محاسباتی به شکل زیر خواهند بود:

| i | محاسبه | ai |
|---|---|---|
| 0 | 2 + 0 × 3 | 2 |
| 1 | 2 + 1 × 3 | 5 |
| 2 | 2 + 2 × 3 | 8 |
| 3 | 2 + 3 × 3 | 11 |
| 4 | 2 + 4 × 3 | 14 |

### ۴.۹. محاسبه مجموع اعضای دنباله

```c
S += ai;
```

این دستور یکی از عملگرهای انتساب ترکیبی (Compound Assignment) در زبان C است.

دستور بالا معادل عبارت زیر است:

```c
S = S + ai;
```

در هر بار اجرای حلقه، مقدار عضو جدید به مجموع قبلی اضافه می‌شود.

برای مثال:

| مرحله | عضو جدید | مجموع قبلی | مجموع جدید |
|---|---|---|---|
| 1 | 2 | 0 | 2 |
| 2 | 5 | 2 | 7 |
| 3 | 8 | 7 | 15 |
| 4 | 11 | 15 | 26 |
| 5 | 14 | 26 | 40 |

### ۴.۱۰. نمایش اطلاعات در هر مرحله

```c
printf("%d\t%f\t%f\n", i, ai, S);
```

در این قسمت سه مقدار نمایش داده می‌شوند:

۱. اندیس عضو فعلی.

۲. مقدار عضو فعلی دنباله.

۳. مجموع محاسبه‌شده تا این مرحله.

### ۴.۱۱. افزایش شمارنده حلقه

```c
i++;
```

این دستور مقدار متغیر `i` را یک واحد افزایش می‌دهد.

معادل عبارت زیر است:

```c
i = i + 1;
```

با افزایش شمارنده، برنامه به سراغ عضو بعدی دنباله می‌رود.

اگر این دستور وجود نداشته باشد، مقدار `i` تغییر نمی‌کند و در صورت برقرار بودن شرط، حلقه به‌صورت نامحدود اجرا خواهد شد.

## ۸. تمرین‌های پیشنهادی

برای تسلط بیشتر بر مفاهیم این برنامه، تمرین‌های زیر را انجام دهید:

- تمرین ۱: برنامه را تغییر دهید تا یک دنباله حسابی نزولی با مقدار منفی `d` ایجاد کند.
- تمرین ۲: اعضای دنباله را به‌صورت معکوس نمایش دهید.
- تمرین ۳: میانگین تمام اعضای دنباله را محاسبه کنید.
- تمرین ۴: حلقه `while` را با حلقه `for` جایگزین کنید.
- تمرین ۵: فقط اعضایی را نمایش دهید که بر عدد ۲ بخش‌پذیر هستند.
- تمرین ۶: مجموع محاسبه‌شده توسط حلقه را با فرمول ریاضی مجموع دنباله حسابی مقایسه کنید.
- تمرین ۷: خروجی را به دو رقم اعشار محدود کنید. برای این کار از `%.2f` استفاده کنید.

## ۹. نکات مهم

- در نسخه فعلی برنامه فرض شده است که کاربر ورودی عددی معتبر وارد می‌کند.

- مشخص‌کننده `%f` در تابع `printf()` به‌صورت پیش‌فرض شش رقم اعشار نمایش می‌دهد.
- در این برنامه اندیس‌گذاری از صفر آغاز می‌شود؛ بنابراین اولین عضو اندیس صفر دارد.
- بهتر است در انتهای تابع `main()` از `return 0;` استفاده شود تا اجرای موفق برنامه به‌صورت صریح اعلام شود.
