# 36- خواندن رشته با استفاده از Scanset در تابع `scanf()` در زبان C

## 1. مقدمه

در این پروژه با قابلیت **Scanset** در تابع `scanf()` آشنا می‌شویم.

Scanset به ما اجازه می‌دهد هنگام دریافت ورودی، مجموعه‌ای از کاراکترهای مجاز را مشخص کنیم یا تعیین کنیم که خواندن ورودی با مشاهده چه کاراکترهایی متوقف شود.

در این برنامه از دستور زیر استفاده شده است:

```c
scanf("%[^aeiou]", str);
```

این دستور به تابع `scanf()` می‌گوید کاراکترها را بخواند تا زمانی که به یکی از حروف صدادار کوچک انگلیسی زیر برسد:

- `a`
- `e`
- `i`
- `o`
- `u`

به عبارت دیگر، تمام کاراکترهایی خوانده می‌شوند که جزو این پنج حرف نباشند.

به این روش، استفاده از Scanset منفی یا Negated Scanset گفته می‌شود.

## 2. کد کامل برنامه

کد اصلی برنامه:

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    char str[10];

    printf("Enter the string: ");
    scanf("%[^aeiou]", str);
    printf("\n");

    printf("Result:\n");
    puts(str);
    printf("\n");

    return 0;
}
```

**نکته مهم:** کد اولیه دو مشکل احتمالی دارد:

1. آرایه `str` فقط ظرفیت 9 کاراکتر ورودی به‌علاوه کاراکتر پایان رشته را دارد. اما Scanset هیچ محدودیت طولی ندارد؛ بنابراین ورودی طولانی می‌تواند باعث سرریز بافر شود.
2. اگر اولین کاراکتر ورودی یکی از حروف صدادار کوچک باشد، تابع `scanf()` هیچ مقداری در `str` ذخیره نمی‌کند. در این شرایط استفاده از `puts(str)` باعث استفاده از آرایه مقداردهی‌نشده می‌شود.

در ادامه نسخه اصلاح‌شده و ایمن‌تر برنامه را بررسی می‌کنیم.

## 3. کتابخانه‌های موردنیاز

### کتابخانه `stdio.h`

این کتابخانه توابع ورودی و خروجی استاندارد را در اختیار برنامه قرار می‌دهد.

در این برنامه از توابع زیر استفاده شده است:

- `printf()` برای نمایش پیام‌ها.
- `scanf()` برای دریافت ورودی.
- `puts()` برای نمایش یک رشته به همراه رفتن به خط بعدی.

### کتابخانه `stdlib.h`

این کتابخانه شامل توابع عمومی و کاربردی زبان C است.

در برنامه فعلی از هیچ تابعی از این کتابخانه استفاده نشده است؛ بنابراین می‌توان آن را حذف کرد.

## 4. آشنایی با Scanset در تابع `scanf()`

مهم‌ترین قسمت برنامه دستور زیر است:

```c
scanf("%[^aeiou]", str);
```

برای درک بهتر این دستور، ابتدا باید با مفهوم Scanset آشنا شویم.

Scanset قابلیتی در خانواده توابع `scanf()` است که به ما اجازه می‌دهد مجموعه‌ای از کاراکترهای قابل قبول برای دریافت ورودی را مشخص کنیم.

ساختار عمومی آن به شکل زیر است:

```c
%[characters]
```

برای مثال:

```c
scanf("%[abc]", str);
```

این دستور کاراکترها را تا زمانی دریافت می‌کند که هر کاراکتر یکی از حروف `a`، `b` یا `c` باشد.

### علامت `^` چه کاربردی دارد؟

اگر علامت `^` بلافاصله بعد از براکت باز قرار بگیرد، مجموعه کاراکترهای مشخص‌شده را معکوس می‌کند.

برای مثال:

```c
%[^abc]
```

یعنی:

کاراکترها را بخوان تا زمانی که به یکی از حروف `a`، `b` یا `c` برخورد کنی.

در اینجا علامت `^` به معنی جست‌وجوی خود کاراکتر `^` نیست؛ بلکه مشخص می‌کند کاراکترهای داخل مجموعه نباید پذیرفته شوند.

### بررسی `%[^aeiou]`

در برنامه ما:

```c
scanf("%[^aeiou]", str);
```

پنج کاراکتر زیر از مجموعه کاراکترهای مجاز حذف شده‌اند:

| کاراکتر | توضیحات |
|---|---|
| `a` | حرف a کوچک |
| `e` | حرف e کوچک |
| `i` | حرف i کوچک |
| `o` | حرف o کوچک |
| `u` | حرف u کوچک |

بنابراین تابع تمام کاراکترها را می‌خواند تا زمانی که به یکی از این حروف صدادار کوچک برسد.

برای مثال، اگر کاربر عبارت زیر را وارد کند:

```text
Hello World
```

مراحل پردازش به این صورت خواهد بود:

- کاراکتر `H` پذیرفته می‌شود.
- کاراکتر `e` جزو حروف حذف‌شده است؛ بنابراین خواندن ورودی متوقف می‌شود.
- کاراکترهای باقی‌مانده از ورودی در این فراخوانی مصرف نمی‌شوند.

در نتیجه مقدار ذخیره‌شده در `str` برابر است با:

```text
H
```

## 5. بررسی خط به خط برنامه

### مرحله اول: تعریف آرایه کاراکتری

```c
char str[10];
```

در این دستور یک آرایه با ظرفیت 10 کاراکتر تعریف می‌کنیم.

اما در زبان C هر رشته باید با کاراکتر پایان رشته یعنی `'\0'` تمام شود.

بنابراین این آرایه می‌تواند شامل موارد زیر باشد:

- حداکثر 9 کاراکتر معمولی.
- یک کاراکتر پایان رشته `'\0'`.

برای مثال رشته زیر:

```text
Hello\0
```

شش خانه از آرایه را اشغال می‌کند.

### مرحله دوم: نمایش پیام ورودی

```c
printf("Enter the string: ");
```

این دستور پیامی را نمایش می‌دهد تا کاربر رشته موردنظر خود را وارد کند.

### مرحله سوم: دریافت ورودی با استفاده از Scanset

```c
scanf("%[^aeiou]", str);
```

این دستور بخش اصلی برنامه است.

تابع `scanf()` کاراکترها را یکی پس از دیگری دریافت می‌کند تا زمانی که به یکی از حروف صدادار کوچک برسد.

برخلاف `%s`، در Scanset استفاده‌شده در این برنامه وجود فاصله باعث متوقف شدن دریافت ورودی نمی‌شود.

برای مثال، اگر ورودی زیر را داشته باشیم:

```text
BCD Hello 123
```

تمام کاراکترها پذیرفته می‌شوند؛ زیرا هیچ‌کدام از آن‌ها حروف صدادار کوچک نیستند.

رشته حاصل:

```text
BCD Hello 123
```

البته آرایه اصلی فقط 10 خانه دارد و این ورودی باعث سرریز بافر می‌شود. برای جلوگیری از این مشکل باید حداکثر طول ورودی را مشخص کنیم.

### مرحله چهارم: رفتن به خط بعدی

```c
printf("\n");
```

این دستور مکان‌نما را به خط بعدی منتقل می‌کند.

### مرحله پنجم: نمایش نتیجه

```c
printf("Result:\n");
puts(str);
```

دستور اول عنوان نتیجه را نمایش می‌دهد.

تابع `puts()` رشته موردنظر را چاپ می‌کند و به‌صورت خودکار در انتهای آن یک کاراکتر خط جدید اضافه می‌کند.

## 6. نمونه خروجی برنامه

### مثال اول: ورودی با یک حرف بی‌صدا شروع شود

ورودی:

```text
Enter the string: Hello
```

اولین کاراکتر `H` است و پذیرفته می‌شود.

کاراکتر بعدی `e` است که جزو حروف حذف‌شده محسوب می‌شود.

خروجی:

```text
Result:
H
```

### مثال دوم: ورودی شامل حروف صدادار کوچک نباشد

ورودی:

```text
Enter the string: BCDXYZ
```

تمام کاراکترها پذیرفته می‌شوند.

خروجی:

```text
Result:
BCDXYZ
```

### مثال سوم: ورودی شامل فاصله باشد

ورودی:

```text
Enter the string: BCD XYZ 123
```

چون فاصله جزو مجموعه کاراکترهای حذف‌شده نیست، پذیرفته می‌شود.

خروجی:

```text
Result:
BCD XYZ 123
```

این موضوع یکی از تفاوت‌های مهم بین `%s` و `%[^aeiou]` است.

### مثال چهارم: ورودی با حرف صدادار شروع شود

ورودی:

```text
Enter the string: apple
```

اولین کاراکتر `a` است و جزو مجموعه کاراکترهای حذف‌شده قرار دارد.

بنابراین Scanset هیچ کاراکتری را دریافت نمی‌کند.

در این حالت تابع `scanf()` هیچ رشته‌ای در `str` ذخیره نمی‌کند. اگر برنامه اصلی بدون بررسی نتیجه، تابع `puts(str)` را اجرا کند، از آرایه مقداردهی‌نشده استفاده خواهد کرد و رفتار برنامه تعریف‌نشده می‌شود.

برای جلوگیری از این مشکل باید مقدار بازگشتی `scanf()` را بررسی کنیم.

## 7. تفاوت `%s` و `%[^aeiou]`

این دو قالب عملکرد متفاوتی دارند.

| ویژگی | `%s` | `%[^aeiou]` |
|---|---|---|
| دریافت کاراکترها | تا رسیدن به فضای خالی | تا رسیدن به یکی از حروف صدادار کوچک |
| پذیرش فاصله | خیر | بله |
| پذیرش اعداد | بله | بله |
| پذیرش علائم نگارشی | بله | بله |
| امکان محدود کردن طول ورودی | بله | بله |
| استفاده از Scanset | خیر | بله |

برای مثال ورودی زیر را در نظر بگیرید:

```text
BCD XYZ
```

اگر از دستور زیر استفاده کنیم:

```c
scanf("%s", str);
```

نتیجه برابر خواهد بود با:

```text
BCD
```

اما با دستور زیر:

```c
scanf("%[^aeiou]", str);
```

نتیجه برابر است با:

```text
BCD XYZ
```

زیرا فاصله جزو کاراکترهای حذف‌شده نیست.

## 8. نکته مهم: جلوگیری از سرریز بافر (Buffer Overflow)

در برنامه اصلی داریم:

```c
char str[10];

scanf("%[^aeiou]", str);
```

این روش ایمن نیست؛ زیرا هیچ محدودیتی برای تعداد کاراکترهای دریافتی مشخص نشده است.

اگر کاربر بیشتر از 9 کاراکتر قابل قبول وارد کند، تابع `scanf()` ممکن است اطلاعات را خارج از محدوده آرایه بنویسد.

این مشکل **Buffer Overflow** نام دارد و می‌تواند باعث رفتار غیرقابل پیش‌بینی یا حتی متوقف شدن برنامه شود.

برای آرایه‌ای با 10 خانه باید حداکثر 9 کاراکتر دریافت کنیم:

```c
scanf("%9[^aeiou]", str);
```

عدد `9` حداکثر تعداد کاراکترهایی را مشخص می‌کند که می‌توانند در آرایه ذخیره شوند.

خانه دهم برای کاراکتر پایان رشته یعنی `'\0'` در نظر گرفته می‌شود که تابع `scanf()` پس از دریافت موفق ورودی آن را به‌صورت خودکار اضافه می‌کند.

**نکته:** تعیین حداکثر طول از سرریز بافر جلوگیری می‌کند، اما تضمین نمی‌کند که تمام ورودی کاربر مصرف شده باشد. کاراکترهای باقی‌مانده همچنان در جریان ورودی باقی می‌مانند.

## 9. نسخه کامل و ایمن‌تر برنامه

در نسخه زیر مشکل سرریز بافر برطرف شده و مقدار بازگشتی `scanf()` نیز بررسی می‌شود:

```c
#include <stdio.h>

int main()
{
    char str[10];

    printf("Enter the string: ");

    if (scanf("%9[^aeiou]", str) == 1)
    {
        printf("\nResult:\n");
        puts(str);
    }
    else
    {
        printf("\nNo valid characters were read.\n");
    }

    return 0;
}
```

### تغییرات ایجادشده

**1. حذف کتابخانه غیرضروری**

```c
#include <stdio.h>
```

برنامه فقط به توابع ورودی و خروجی استاندارد نیاز دارد.

**2. محدود کردن طول ورودی**

```c
scanf("%9[^aeiou]", str);
```

با این کار حداکثر 9 کاراکتر در آرایه 10 خانه‌ای ذخیره می‌شود.

**3. بررسی مقدار بازگشتی تابع**

```c
if (scanf("%9[^aeiou]", str) == 1)
```

تابع `scanf()` تعداد ورودی‌هایی را برمی‌گرداند که با موفقیت دریافت و ذخیره شده‌اند.

در برنامه ما:

- مقدار `1` یعنی Scanset با موفقیت یک رشته را دریافت و ذخیره کرده است.
- مقدار `0` یعنی هیچ کاراکتری با مجموعه مشخص‌شده مطابقت نداشته است.
- مقدار `EOF` یعنی قبل از شروع تبدیل، خطای ورودی یا پایان جریان ورودی اتفاق افتاده است.

فقط در صورت موفقیت عملیات، رشته را نمایش می‌دهیم.

## 10. نکته مهم: تمام ورودی به‌صورت خودکار مصرف نمی‌شود

فرض کنید کاربر رشته زیر را وارد کند:

```text
BCD123456789XYZ
```

و از دستور زیر استفاده کنیم:

```c
char str[10];
scanf("%9[^aeiou]", str);
```

در این حالت فقط 9 کاراکتر اول دریافت می‌شوند:

```text
BCD123456
```

کاراکترهای باقی‌مانده:

```text
789XYZ
```

در جریان ورودی باقی می‌مانند.

این موضوع زمانی اهمیت دارد که بخواهیم بعد از این دستور، ورودی دیگری نیز دریافت کنیم.

اگر هدف ما دریافت و پردازش یک خط کامل از ورودی باشد، معمولاً استفاده از `fgets()` انتخاب مناسب‌تری است؛ زیرا حداکثر تعداد کاراکترهای دریافتی را مشخص می‌کند و سپس می‌توانیم رشته دریافت‌شده را پردازش کنیم.

## 11. مثال‌های بیشتر از Scanset

### مثال اول: دریافت فقط اعداد

```c
scanf("%[0123456789]", str);
```

این دستور فقط اعداد را تا زمانی که کاراکتر غیرعددی مشاهده شود دریافت می‌کند.

ورودی:

```text
12345ABC
```

نتیجه:

```text
12345
```

### مثال دوم: دریافت فقط حروف کوچک انگلیسی

```c
scanf("%[abcdefghijklmnopqrstuvwxyz]", str);
```

این دستور فقط حروف کوچک انگلیسی را دریافت می‌کند.

ورودی:

```text
hello123
```

نتیجه:

```text
hello
```

### مثال سوم: دریافت تمام کاراکترها به‌جز اعداد

```c
scanf("%[^0123456789]", str);
```

این دستور تمام کاراکترها را تا زمان برخورد با یک عدد دریافت می‌کند.

ورودی:

```text
Hello123
```

نتیجه:

```text
Hello
```

### مثال چهارم: دریافت تمام کاراکترها به‌جز فاصله

```c
scanf("%[^ ]", str);
```

این دستور کاراکترها را تا رسیدن به فاصله دریافت می‌کند.

رفتار آن برای ورودی معمولی مشابه `%s` است؛ البته نحوه برخورد با سایر کاراکترهای فضای خالی متفاوت است.

### مثال پنجم: دریافت حروف کوچک، بزرگ و فاصله

```c
scanf("%[a-zA-Z ]", str);
```

این دستور حروف کوچک، حروف بزرگ و فاصله را دریافت می‌کند.

ورودی:

```text
Hello World123
```

نتیجه:

```text
Hello World
```

فراموش نکنید که همیشه باید متناسب با اندازه آرایه، حداکثر طول ورودی را مشخص کنید.

برای مثال، اگر آرایه 50 خانه داشته باشد:

```c
char str[50];

scanf("%49[a-zA-Z ]", str);
```

## 13. تمرین‌های پیشنهادی

برای تسلط بیشتر بر Scanset تمرین‌های زیر را انجام دهید:

1. Scanset را تغییر دهید تا تمام کاراکترها به‌جز حروف صدادار بزرگ انگلیسی (`AEIOU`) دریافت شوند.
2. برنامه‌ای بنویسید که فقط اعداد را دریافت کند.
3. برنامه‌ای بنویسید که فقط حروف کوچک انگلیسی را دریافت کند.
4. برنامه‌ای بنویسید که کاراکترها را تا زمان رسیدن به کاما دریافت کند.
5. تمام کاراکترها به‌جز اعداد و فاصله را دریافت کنید.
6. اندازه آرایه را به 50 تغییر دهید و حداکثر طول ورودی مناسب را مشخص کنید.
7. تعداد کاراکترهای دریافت‌شده را محاسبه کنید.
8. با استفاده از `fgets()` یک خط کامل دریافت کنید و سپس برنامه‌ای بنویسید که حروف صدادار کوچک را از آن حذف کند.

## 14. مواردی که در این پروژه یاد می‌گیرید

پس از انجام این پروژه با مفاهیم زیر آشنا می‌شوید:

- نحوه استفاده از Scanset در تابع `scanf()`.
- مفهوم `%[...]` در رشته قالب (Format String).
- کاربرد علامت `^` برای معکوس کردن مجموعه کاراکترها.
- نحوه دریافت کاراکترها تا زمان برخورد با یک کاراکتر مشخص.
- تفاوت `%s` با `%[^...]`.
- محدود کردن طول ورودی برای جلوگیری از Buffer Overflow.
- اهمیت بررسی مقدار بازگشتی تابع `scanf()`.
- پردازش رشته‌ها با استفاده از آرایه‌های کاراکتری.
