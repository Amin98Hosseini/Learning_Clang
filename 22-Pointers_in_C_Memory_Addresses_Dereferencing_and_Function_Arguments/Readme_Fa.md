# 22- آموزش اشاره‌گرها (Pointers) در زبان C – آدرس حافظه، Dereferencing و ارسال پارامتر به توابع

## ۱. معرفی پروژه

در این پروژه با یکی از مهم‌ترین و اساسی‌ترین مفاهیم زبان برنامه‌نویسی C یعنی **Pointer یا اشاره‌گر** آشنا می‌شویم.

اشاره‌گر متغیری است که آدرس حافظه یک متغیر یا شیء دیگر را در خود ذخیره می‌کند.

با استفاده از اشاره‌گرها می‌توانیم به داده‌ها از طریق آدرس حافظه دسترسی داشته باشیم و حتی مقدار آن‌ها را تغییر دهیم.

اشاره‌گرها در موارد زیر کاربرد بسیار مهمی دارند:

- ارسال آدرس متغیرها به توابع.
- تغییر مقدار متغیر اصلی از داخل یک تابع.
- کار با آرایه‌ها و رشته‌ها.
- تخصیص پویای حافظه.
- پیاده‌سازی لیست‌های پیوندی، درخت‌ها و ساختارهای داده.
- دسترسی به رجیسترهای سخت‌افزاری در سیستم‌های Embedded.
- مدیریت و استفاده بهینه از حافظه.

در این پروژه سه روش مختلف برای کار با یک متغیر از طریق توابع را بررسی می‌کنیم:

۱. **Call by Value:** ارسال یک کپی از مقدار متغیر به تابع.

۲. **Call by Value + Assignment:** ارسال کپی متغیر به تابع، تغییر مقدار آن و بازگرداندن نتیجه به تابع فراخواننده.

۳. **Pointer-Based Modification:** ارسال آدرس متغیر به تابع و تغییر مقدار متغیر اصلی از طریق اشاره‌گر.

در پایان این آموزش باید بتوانید مفهوم اشاره‌گرها را درک کنید و بدانید چرا در برنامه‌نویسی C اهمیت زیادی دارند.

---

## ۲. کد برنامه

```c
#include <stdio.h>

void Func1(int a);
int Func2(int a);
void Func3(int *a);

int main()
{
    int a;

    printf("Please enter an integer: ");
    scanf("%d", &a);
    printf("\n");

    printf("You have entered %d.\n\n", a);

    Func1(a); // Call by Value

    printf("After calling Func1, the value of a is: %d\n\n", a);

    a = Func2(a); // Call by Value + Assignment

    printf("After calling Func2, the value of a is: %d\n\n", a);

    Func3(&a); // Call by Reference

    printf("After calling Func3, the value of a is: %d\n\n", a);

    printf("a = %d, is stored at %p", a, (void *)&a);

    return 0;
}

void Func1(int a)
{
    a *= 2;

    printf("Inside function Func1, a is %d.\n", a);
}

int Func2(int a)
{
    a *= 2;

    printf("Inside function Func2, a is %d.\n", a);

    return a;
}

void Func3(int *aPtr)
{
    *aPtr *= 2;

    printf("Inside function Func3, a is %d.\n", *aPtr);
}
```

**نکته:** در کد بالا یک اصلاح کوچک نسبت به کد اولیه انجام شده است. برای چاپ آدرس با `%p` از `(void *)&a` استفاده کرده‌ایم؛ زیرا قالب `%p` به آرگومانی از نوع `void *` نیاز دارد.

# ۳. آشنایی با حافظه در زبان C

قبل از یادگیری اشاره‌گرها، ابتدا باید بدانیم متغیرها چگونه در حافظه کامپیوتر ذخیره می‌شوند.

وقتی یک متغیر تعریف می‌کنیم:

```c
int a = 10;
```

کامپیوتر قسمتی از حافظه را برای ذخیره مقدار ۱۰ در نظر می‌گیرد.

هر قسمت از حافظه دارای یک آدرس مشخص است.

برای درک بهتر، فرض کنیم متغیر `a` در آدرس فرضی `0x1000` ذخیره شده باشد.

```
+---------------------------+
|       Computer Memory     |
+---------------------------+
| Address  | Value          |
+---------------------------+
| 0x1000   | 10             |
| 0x1004   | ...            |
| 0x1008   | ...            |
+---------------------------+
```

آدرس‌های بالا فقط مثال هستند. آدرس واقعی به سیستم، کامپایلر و نحوه اجرای برنامه بستگی دارد.

در زبان C می‌توانیم با استفاده از عملگر **Address-of (`&`)** آدرس حافظه یک متغیر را به دست بیاوریم.

مثال:

```c
int a = 10;

printf("%p", (void *)&a);
```

عبارت زیر:

```c
&a
```

یعنی:

**آدرس حافظه متغیر `a` را به من بده.**

برای نمایش آدرس حافظه از قالب `%p` در تابع `printf()` استفاده می‌کنیم.

# ۴. Pointer چیست؟

اشاره‌گر یا Pointer متغیری است که آدرس حافظه یک متغیر یا شیء دیگر را ذخیره می‌کند.

برای مثال:

```c
int a = 10;

int *p;

p = &a;
```

بیایید این دستورات را مرحله‌به‌مرحله بررسی کنیم.

### مرحله اول: تعریف یک متغیر صحیح

```c
int a = 10;
```

یک متغیر صحیح با نام `a` تعریف می‌کنیم و مقدار اولیه آن را برابر ۱۰ قرار می‌دهیم.

### مرحله دوم: تعریف یک اشاره‌گر

```c
int *p;
```

در این قسمت یک اشاره‌گر با نام `p` تعریف می‌کنیم.

اجزای این تعریف:

- `int`: اشاره‌گر قرار است به یک متغیر از نوع `int` اشاره کند.
- `*`: مشخص می‌کند که متغیر `p` یک اشاره‌گر است.
- `p`: نام اشاره‌گر است.

در این مرحله اشاره‌گر هنوز مقداردهی اولیه نشده است. مقدار آن نامشخص است و نباید آن را Dereference کنیم.

### مرحله سوم: ذخیره آدرس متغیر در اشاره‌گر

```c
p = &a;
```

در این دستور آدرس حافظه متغیر `a` را داخل اشاره‌گر `p` قرار می‌دهیم.

اکنون `p` به متغیر `a` اشاره می‌کند.

نمایش مفهومی:

```
+---------------------+       +---------------------+
| Variable a          |       | Pointer p           |
+---------------------+       +---------------------+
| Value: 10           |       | Stores address of a |
| Address: 0x1000     |<------| Value: 0x1000       |
+---------------------+       +---------------------+
```

آدرس‌های بالا فرضی هستند و آدرس واقعی حافظه نیستند.

# ۵. دو عملگر اصلی در اشاره‌گرها

در زبان C دو عملگر بسیار مهم برای کار با اشاره‌گرها وجود دارد:

۱. عملگر آدرس (`&`)

۲. عملگر Dereference یا دسترسی به مقدار (`*`)

## ۵.۱ عملگر Address-of (&)

عملگر `&` آدرس حافظه یک متغیر را برمی‌گرداند.

مثال:

```c
int a = 20;

int *p = &a;
```

در اینجا عبارت:

```c
&a
```

آدرس متغیر `a` را برمی‌گرداند.

این آدرس داخل اشاره‌گر `p` ذخیره می‌شود.

مثال دیگر:

```c
printf("Value of a: %d\n", a);
printf("Address of a: %p\n", (void *)&a);
printf("Value stored in p: %p\n", (void *)p);
```

دو آدرس چاپ‌شده در دو خط آخر باید یکسان باشند؛ زیرا اشاره‌گر `p` آدرس متغیر `a` را ذخیره کرده است.

## ۵.۲ عملگر Dereference (*)

عملگر `*` برای دسترسی به شیئی استفاده می‌شود که اشاره‌گر به آن اشاره می‌کند.

مثال:

```c
int a = 20;

int *p = &a;

printf("%d\n", *p);
```

خروجی:

```text
20
```

عبارت:

```c
*p
```

یعنی:

**به آدرسی که داخل اشاره‌گر `p` ذخیره شده برو و مقدار موجود در آن آدرس را بخوان.**

با استفاده از این عملگر می‌توانیم مقدار متغیر اصلی را نیز تغییر دهیم.

```c
*p = 50;
```

اکنون مقدار متغیر `a` برابر ۵۰ خواهد شد.

مثال کامل:

```c
#include <stdio.h>

int main(void)
{
    int a = 20;
    int *p = &a;

    printf("Before modification: %d\n", a);

    *p = 50;

    printf("After modification: %d\n", a);

    return 0;
}
```

خروجی:

```text
Before modification: 20
After modification: 50
```

این مثال یکی از مهم‌ترین قابلیت‌های اشاره‌گرها را نشان می‌دهد:

**با استفاده از اشاره‌گر می‌توانیم مقدار متغیر اصلی را تغییر دهیم.**

# ۶. نحوه تعریف و مقداردهی اولیه اشاره‌گرها

ساختار کلی تعریف یک اشاره‌گر به شکل زیر است:

```c
data_type *pointer_name;
```

چند مثال:

```c
int *p;
float *fPtr;
char *cPtr;
double *dPtr;
```

هر اشاره‌گر برای اشاره به یک شیء از نوع مشخص‌شده تعریف می‌شود.

| تعریف | نوع اشاره‌گر | اشاره به |
|---|---|---|
| `int *p` | اشاره‌گر صحیح | `int` |
| `float *p` | اشاره‌گر اعشاری | `float` |
| `char *p` | اشاره‌گر کاراکتری | `char` |
| `double *p` | اشاره‌گر Double | `double` |

مثال:

```c
int a = 10;
float b = 3.14f;
char c = 'A';

int *p1 = &a;
float *p2 = &b;
char *p3 = &c;
```

**نکته مهم:** نوع اشاره‌گر اهمیت زیادی دارد؛ زیرا مشخص می‌کند اطلاعاتی که در آدرس موردنظر قرار دارند چگونه تفسیر شوند و عملیات Pointer Arithmetic چگونه انجام شود.

# ۷. تفاوت عملگرهای & و *

این دو عملگر ارتباط نزدیکی با یکدیگر دارند، اما کاربرد آن‌ها متفاوت است.

| عبارت | مفهوم |
|---|---|
| `a` | مقدار متغیر `a` |
| `&a` | آدرس حافظه متغیر `a` |
| `p` | آدرسی که داخل اشاره‌گر `p` ذخیره شده است |
| `*p` | مقدار متغیری که `p` به آن اشاره می‌کند |
| `&p` | آدرس خود متغیر اشاره‌گر `p` |

به مثال زیر توجه کنید:

```c
int a = 10;
int *p = &a;
```

در این حالت:

```c
a     // مقدار 10
&a    // آدرس متغیر a
p     // آدرس متغیر a
*p    // مقدار 10
&p    // آدرس خود اشاره‌گر p
```

یکی از اشتباهات رایج افراد مبتدی، اشتباه گرفتن `p` با `*p` است.

به خاطر بسپارید:

- `p` آدرسی را که در اشاره‌گر ذخیره شده است نشان می‌دهد.
- `*p` مقدار موجود در آن آدرس را نشان می‌دهد.

---

# ۸. بررسی مرحله‌به‌مرحله برنامه اصلی

اکنون که با مفهوم اشاره‌گر آشنا شدیم، کد اصلی را بررسی می‌کنیم تا نحوه عملکرد اشاره‌گرها در توابع را بهتر درک کنیم.

## ۸.۱ تعریف اولیه توابع

```c
void Func1(int a);
int Func2(int a);
void Func3(int *a);
```

در این قسمت سه تابع معرفی شده‌اند.

### تابع Func1

```c
void Func1(int a);
```

یک عدد صحیح را به‌صورت مقداری دریافت می‌کند و خروجی ندارد.

### تابع Func2

```c
int Func2(int a);
```

یک عدد صحیح را به‌صورت مقداری دریافت می‌کند و در پایان یک عدد صحیح برمی‌گرداند.

### تابع Func3

```c
void Func3(int *a);
```

یک اشاره‌گر به عدد صحیح دریافت می‌کند.

این اشاره‌گر امکان دسترسی به متغیر اصلی و تغییر مقدار آن را فراهم می‌کند.

## ۸.۲ دریافت ورودی از کاربر

```c
int a;

printf("Please enter an integer: ");
scanf("%d", &a);
printf("\n");
```

در این قسمت یک متغیر صحیح با نام `a` تعریف می‌کنیم.

سپس مقدار واردشده توسط کاربر را در آن ذخیره می‌کنیم.

دقت کنید که در تابع `scanf()` از عبارت زیر استفاده کرده‌ایم:

```c
&a
```

زیرا تابع `scanf()` به آدرس متغیر نیاز دارد تا مقدار ورودی را در آن ذخیره کند.

## ۸.۳ نمایش مقدار اولیه

```c
printf("You have entered %d.\n\n", a);
```

این دستور مقدار اولیه واردشده توسط کاربر را نمایش می‌دهد.

برای مثال:

```text
You have entered 10.
```

## ۸.۴ فراخوانی Func1(): روش Call by Value

```c
Func1(a);
```

در این روش مقدار متغیر `a` به تابع ارسال می‌شود.

تابع یک کپی از مقدار اصلی دریافت می‌کند.

تعریف تابع:

```c
void Func1(int a)
{
    a *= 2;

    printf("Inside function Func1, a is %d.\n", a);
}
```

دستور:

```c
a *= 2;
```

معادل دستور زیر است:

```c
a = a * 2;
```

فرض کنیم مقدار اولیه متغیر برابر ۱۰ باشد.

داخل تابع مقدار محلی `a` برابر ۲۰ می‌شود.

اما مقدار متغیر اصلی در تابع `main()` همچنان ۱۰ باقی می‌ماند.

چرا؟

زیرا در زبان C آرگومان‌ها به‌صورت مقداری (By Value) به توابع ارسال می‌شوند. بنابراین تابع یک نسخه جداگانه از مقدار متغیر دریافت می‌کند.

نمایش مفهومی:

```
main()                         Func1()

a = 10                         a = 10
  |                               |
  |---- Copy of value ----------->|
                                  |
                               a = a * 2
                                  |
                                a = 20

Original a remains 10.
```

پس از پایان تابع، پارامتر محلی آن دیگر وجود ندارد.

به همین دلیل دستور زیر:

```c
printf("After calling Func1, the value of a is: %d\n\n", a);
```

مقدار اصلی متغیر را نمایش می‌دهد.

## ۸.۵ فراخوانی Func2(): روش Call by Value + Assignment

```c
a = Func2(a);
```

در این روش نیز تابع یک کپی از مقدار متغیر اصلی دریافت می‌کند.

تعریف تابع:

```c
int Func2(int a)
{
    a *= 2;

    printf("Inside function Func2, a is %d.\n", a);

    return a;
}
```

فرض کنیم مقدار اولیه متغیر برابر ۱۰ باشد.

در داخل تابع:

```c
a *= 2;
```

مقدار محلی به ۲۰ تبدیل می‌شود.

سپس:

```c
return a;
```

مقدار ۲۰ را به تابع فراخواننده برمی‌گرداند.

در دستور زیر:

```c
a = Func2(a);
```

مقدار بازگشتی تابع داخل متغیر اصلی ذخیره می‌شود.

بنابراین اکنون مقدار متغیر اصلی `a` برابر ۲۰ خواهد بود.

در این روش تابع مستقیماً متغیر اصلی را تغییر نمی‌دهد؛ بلکه نتیجه را برمی‌گرداند و تابع فراخواننده آن را در متغیر ذخیره می‌کند.

نمایش مفهومی:

```
main()                         Func2()

a = 10                         a = 10
  |                               |
  |---- Copy of value ----------->|
                                  |
                               a = 20
                                  |
                               return 20
  |                               |
  |<----------- 20 ---------------|
  |
a = 20
```

## ۸.۶ فراخوانی Func3(): تغییر مقدار با استفاده از Pointer

```c
Func3(&a);
```

در این مرحله دیگر مقدار متغیر `a` را به تابع ارسال نمی‌کنیم.

بلکه آدرس حافظه آن را ارسال می‌کنیم.

تعریف تابع:

```c
void Func3(int *aPtr)
{
    *aPtr *= 2;

    printf("Inside function Func3, a is %d.\n", *aPtr);
}
```

این قسمت را با دقت بیشتری بررسی کنیم.

### مرحله اول: ارسال آدرس متغیر

```c
Func3(&a);
```

عبارت `&a` آدرس حافظه متغیر اصلی را برمی‌گرداند.

### مرحله دوم: دریافت آدرس توسط اشاره‌گر

```c
void Func3(int *aPtr)
```

پارامتر `aPtr` یک اشاره‌گر به متغیر صحیح است.

این اشاره‌گر آدرسی را دریافت می‌کند که از تابع `main()` ارسال شده است.

بنابراین `aPtr` به متغیر اصلی `a` اشاره می‌کند.

### مرحله سوم: استفاده از عملگر Dereference

```c
*aPtr *= 2;
```

این دستور از طریق آدرس حافظه به متغیر اصلی دسترسی پیدا می‌کند و مقدار آن را دو برابر می‌کند.

این دستور معادل عبارت زیر است:

```c
*aPtr = *aPtr * 2;
```

چون `aPtr` به متغیر اصلی اشاره می‌کند، مقدار خود متغیر اصلی تغییر می‌کند.

### مرحله چهارم: نمایش مقدار جدید

```c
printf("Inside function Func3, a is %d.\n", *aPtr);
```

عبارت `*aPtr` مقدار ذخیره‌شده در متغیر اصلی را نمایش می‌دهد.

اگر مقدار `a` قبل از فراخوانی تابع برابر ۲۰ باشد، مقدار آن به ۴۰ تبدیل می‌شود.

پس از بازگشت از تابع نیز مقدار اصلی همچنان ۴۰ خواهد بود.

نمایش مفهومی:

```
main()                         Func3()

a = 20
Address = 0x1000
  |
  |---- Address of a -----------> aPtr
                                  |
                                  | stores 0x1000
                                  |
                               *aPtr = 20
                                  |
                               *aPtr *= 2
                                  |
                               *aPtr = 40

Original a is now 40.
```

این دقیقاً مفهوم اصلی تغییر مقدار متغیر از طریق اشاره‌گر است.

# ۹. مقایسه Call by Value و Pointer-Based Modification

این مقایسه یکی از مهم‌ترین مباحث در یادگیری زبان C است.

| ویژگی | Func1 | Func2 | Func3 |
|---|---|---|---|
| نوع پارامتر | `int a` | `int a` | `int *aPtr` |
| مقدار دریافتی | کپی مقدار | کپی مقدار | کپی آدرس |
| تغییر متغیر اصلی | خیر | خیر، نه به‌صورت مستقیم | بله |
| مقدار بازگشتی | ندارد | دارد | ندارد |
| روش اصلی | Call by Value | Return + Assignment | تغییر از طریق Pointer |

**نکته بسیار مهم:** از نظر فنی در زبان C تمام آرگومان‌های توابع به‌صورت مقداری ارسال می‌شوند؛ حتی اشاره‌گرها.

در تابع `Func3` نیز مقدار اشاره‌گر، یعنی آدرس متغیر، کپی می‌شود. اما تابع با استفاده از این آدرس می‌تواند به متغیر اصلی دسترسی داشته باشد و آن را تغییر دهد.

اصطلاح Call by Reference معمولاً به‌صورت غیررسمی برای این روش استفاده می‌شود؛ اما زبان C مانند C++ پارامترهای Reference واقعی ندارد.

# ۱۰. بررسی دستور printf() در انتهای برنامه


اجزای دستور:


مقدار متغیر را نمایش می‌دهد.


آدرس حافظه متغیر را برمی‌گرداند.

```c
(void *)&a
```

آدرس متغیر را به نوع `void *` تبدیل می‌کند که نوع موردنیاز برای قالب `%p` است.

نمونه خروجی:

```text

```

آدرس نمایش‌داده‌شده فقط یک مثال است و ممکن است در هر اجرا و روی هر سیستم متفاوت باشد.

# ۱۲. نکات ایمنی مهم در استفاده از Pointer

اشاره‌گرها دسترسی قدرتمندی به حافظه فراهم می‌کنند؛ اما استفاده نادرست از آن‌ها می‌تواند باعث خطاهای جدی شود.

### ۱۲.۱ همیشه اشاره‌گرها را مقداردهی اولیه کنید

روش اشتباه:

```c
int *p;
*p = 10;
```

در این حالت اشاره‌گر مقداردهی اولیه نشده است و استفاده از آن برای دسترسی به حافظه باعث رفتار تعریف‌نشده (Undefined Behavior) می‌شود.

روش صحیح:

```c
int a;
int *p = &a;

*p = 10;
```

### ۱۲.۲ در صورت نیاز مقدار NULL را بررسی کنید

یک اشاره‌گر ممکن است عمداً مقدار `NULL` داشته باشد.

```c
int *p = NULL;

if(p != NULL)
{
    printf("%d\n", *p);
}
```

هرگز یک اشاره‌گر `NULL` را Dereference نکنید.

### ۱۲.۳ پس از پایان عمر متغیر از آدرس آن استفاده نکنید

نباید از یک اشاره‌گر برای دسترسی به متغیری استفاده کنیم که طول عمر آن به پایان رسیده است.

برای مثال، برگرداندن آدرس یک متغیر محلی از تابع باعث ایجاد Dangling Pointer می‌شود.

روش اشتباه:

```c
int *GetValue(void)
{
    int a = 10;
    return &a;
}
```

پس از پایان اجرای تابع، متغیر محلی `a` دیگر وجود ندارد.

### ۱۲.۴ نوع اشاره‌گر را درست انتخاب کنید

برای مثال:

```c
int a = 10;
int *p = &a;
```

اشاره‌گر `int *` باید به یک شیء صحیح مناسب اشاره کند.

تبدیل نادرست نوع اشاره‌گرها می‌تواند باعث دسترسی اشتباه به حافظه و رفتار تعریف‌نشده شود.

### ۱۲.۵ ساختار تعریف اشاره‌گر را به خاطر بسپارید

دو دستور زیر از نظر تعریف اشاره‌گر معادل هستند:

```c
int *p;
int* p;
```

اما دستور زیر:

```c
int* p1, p2;
```

فقط `p1` را به‌عنوان اشاره‌گر به `int` تعریف می‌کند و `p2` یک متغیر صحیح معمولی است.

به همین دلیل بهتر است به شکل زیر بنویسیم:

```c
int *p1;
int p2;
```

# ۱۳. مثال‌های تکمیلی Pointer

## مثال اول: تغییر مقدار متغیر با استفاده از Pointer

```c
#include <stdio.h>

int main(void)
{
    int a = 10;
    int *p = &a;

    printf("Before: %d\n", a);

    *p = 100;

    printf("After: %d\n", a);

    return 0;
}
```

خروجی:

```text
Before: 10
After: 100
```

در این مثال با استفاده از اشاره‌گر مقدار متغیر اصلی را تغییر دادیم.

## مثال دوم: جابه‌جایی مقدار دو متغیر با Pointer

یکی از کاربردهای بسیار رایج اشاره‌گرها، جابه‌جایی مقدار دو متغیر است.

```c
#include <stdio.h>

void Swap(int *a, int *b);

int main(void)
{
    int x = 10;
    int y = 20;

    printf("Before swapping:\n");
    printf("x = %d, y = %d\n", x, y);

    Swap(&x, &y);

    printf("After swapping:\n");
    printf("x = %d, y = %d\n", x, y);

    return 0;
}

void Swap(int *a, int *b)
{
    int temp = *a;

    *a = *b;
    *b = temp;
}
```

خروجی:

```text
Before swapping:
x = 10, y = 20

After swapping:
x = 20, y = 10
```

این مثال نشان می‌دهد که با استفاده از اشاره‌گرها می‌توانیم مقدار چند متغیر اصلی را از داخل یک تابع تغییر دهیم.

## مثال سوم: اشاره‌گر به متغیر کاراکتری

```c
#include <stdio.h>

int main(void)
{
    char c = 'A';
    char *p = &c;

    printf("Character: %c\n", *p);

    *p = 'B';

    printf("Modified character: %c\n", c);

    return 0;
}
```

خروجی:

```text
Character: A
Modified character: B
```

اشاره‌گرها فقط برای اعداد صحیح استفاده نمی‌شوند و می‌توانند به انواع مختلف داده اشاره کنند.

# ۱۴. ارتباط Pointer و Array

اشاره‌گرها و آرایه‌ها در زبان C ارتباط بسیار نزدیکی با یکدیگر دارند.

به مثال زیر توجه کنید:

```c
int a[] = {10, 20, 30, 40};

int *p = a;
```

در بیشتر عبارت‌ها، نام آرایه `a` به اشاره‌گری به اولین عنصر آرایه تبدیل می‌شود.

بنابراین:

```c
p = &a[0];
```

با دستور زیر معادل است:

```c
p = a;
```

اکنون می‌توانیم با استفاده از اشاره‌گر به عناصر آرایه دسترسی داشته باشیم:

```c
printf("%d\n", *p);
printf("%d\n", *(p + 1));
printf("%d\n", *(p + 2));
printf("%d\n", *(p + 3));
```

خروجی:

```text
10
20
30
40
```

عبارت:

```c
*(p + 1)
```

به عنصر دوم آرایه دسترسی پیدا می‌کند.

به این قابلیت Pointer Arithmetic گفته می‌شود.

عملیات اشاره‌گر به‌صورت خودکار اندازه نوع داده را در نظر می‌گیرد.

برای مثال، افزایش یک اشاره‌گر `int *` به اندازه یک بایت نیست؛ بلکه آن را به عنصر صحیح بعدی منتقل می‌کند.

# ۱۵. اهمیت Pointer در سیستم‌های Embedded

اشاره‌گرها در برنامه‌نویسی Embedded، به‌خصوص در پروژه‌های STM32 و سایر میکروکنترلرها، اهمیت بسیار زیادی دارند.

برخی از کاربردهای آن‌ها عبارت‌اند از:

- دسترسی به رجیسترهای سخت‌افزاری.
- کار با آدرس‌های حافظه مربوط به Peripheralها.
- ارسال Bufferهای بزرگ به توابع بدون کپی‌کردن تمام داده‌ها.
- مدیریت Bufferهای ارتباطی UART، SPI، I2C، CAN و Ethernet.
- کار با DMA.
- پیاده‌سازی Driverها و Hardware Abstraction Layer.
- مدیریت حافظه پویا در صورت نیاز.

برای مثال، می‌توان از اشاره‌گر برای دسترسی به یک رجیستر سخت‌افزاری استفاده کرد:

```c
#define GPIO_REGISTER_ADDRESS 0x4001080C

volatile unsigned int *GPIO_REGISTER =
    (volatile unsigned int *)GPIO_REGISTER_ADDRESS;
```

کلمه کلیدی `volatile` به کامپایلر اعلام می‌کند که مقدار این متغیر ممکن است مستقل از روند عادی اجرای برنامه تغییر کند؛ همانند اتفاقی که ممکن است برای رجیسترهای سخت‌افزاری رخ دهد.

**نکته مهم:** این مثال صرفاً برای درک مفهوم است. آدرس واقعی رجیسترها، اندازه دسترسی و Qualifierهای موردنیاز باید از Reference Manual میکروکنترلر موردنظر استخراج شوند. در پروژه‌های STM32 معمولاً فایل‌های HAL و CMSIS تعریف‌های مناسب رجیسترها را در اختیار برنامه‌نویس قرار می‌دهند.

# ۱۷. تمرین‌های آموزشی

برای درک بهتر اشاره‌گرها تمرین‌های زیر را انجام دهید.

### سطح مقدماتی

۱. یک متغیر صحیح تعریف کنید و مقدار و آدرس آن را نمایش دهید.

۲. یک اشاره‌گر صحیح تعریف کنید و آن را به متغیر موردنظر متصل کنید.

۳. مقدار اشاره‌گر را با استفاده از `%p` نمایش دهید.

۴. مقدار متغیری را که اشاره‌گر به آن متصل است با استفاده از `*` نمایش دهید.

۵. مقدار متغیر اصلی را با استفاده از اشاره‌گر تغییر دهید.

۶. یک اشاره‌گر از نوع `float` و یک اشاره‌گر از نوع `char` تعریف کنید.

### سطح متوسط

۷. تابعی بنویسید که با استفاده از اشاره‌گر مقدار یک عدد را دو برابر کند.

۸. تابعی بنویسید که مقدار یک عدد را سه برابر کند.

۹. تابعی برای جابه‌جایی مقدار دو عدد با استفاده از اشاره‌گرها بنویسید.

۱۰. تابعی بنویسید که یک آرایه دریافت کند و تمام عناصر آن را تغییر دهد.

۱۱. تابعی بنویسید که مجموع و میانگین عناصر یک آرایه را با استفاده از پارامترهای اشاره‌گری محاسبه کند.

۱۲. تفاوت تابعی که مقدار برمی‌گرداند با تابعی که متغیر اصلی را از طریق اشاره‌گر تغییر می‌دهد بررسی کنید.

### سطح پیشرفته

۱۳. یک اشاره‌گر به اشاره‌گر تعریف کنید (`int **p`).

۱۴. با استفاده از اشاره‌گرها و بدون استفاده از اندیس آرایه، عناصر یک آرایه را پیمایش کنید.

۱۵. با استفاده از `malloc()` یک آرایه به‌صورت پویا ایجاد کنید.

۱۶. تابعی بنویسید که حافظه تخصیص دهد و آدرس آن را از طریق پارامتر اشاره‌گری به تابع فراخواننده منتقل کند.

۱۷. نحوه استفاده از اشاره‌گرها برای دسترسی به رجیسترهای Peripheral در STM32 را بررسی کنید.

# جمع‌بندی

اشاره‌گرها یکی از قدرتمندترین قابلیت‌های زبان برنامه‌نویسی C هستند.

یک متغیر معمولی مقدار را ذخیره می‌کند؛ اما یک اشاره‌گر آدرس حافظه یک شیء را در خود نگهداری می‌کند.

دو عملگر اصلی در کار با اشاره‌گرها عبارت‌اند از:

```c
&variable
```

آدرس حافظه یک متغیر را برمی‌گرداند.

```c
*pointer
```

به شیئی که در آدرس ذخیره‌شده در اشاره‌گر قرار دارد دسترسی پیدا می‌کند.

مهم‌ترین نکته‌ای که از این پروژه یاد می‌گیریم این است که در زبان C تمام آرگومان‌های توابع به‌صورت مقداری ارسال می‌شوند. اما اگر یک اشاره‌گر را به تابع ارسال کنیم، تابع یک کپی از آدرس را دریافت می‌کند و می‌تواند با استفاده از آن آدرس، شیء اصلی را تغییر دهد.

درک کامل اشاره‌گرها پیش‌نیاز مهمی برای یادگیری آرایه‌ها، رشته‌ها، تخصیص پویای حافظه، ساختارها، لیست‌های پیوندی و برنامه‌نویسی سیستم‌های Embedded است.
