# 29- قالب‌بندی اعداد اعشاری با استفاده از توابع `printf()` و `sprintf()` در زبان C

## 1. مقدمه

در برنامه‌نویسی C، گاهی لازم است اعداد را با قالب مشخصی نمایش دهیم یا مقادیر عددی را به رشته‌های متنی تبدیل کنیم.

برای مثال، دو متغیر زیر را در نظر بگیرید:

```c
double x = 10.5624;
double y = -4.8746;
```

ممکن است نخواهیم تمام ارقام اعشاری را نمایش دهیم و فقط دو رقم بعد از ممیز برای ما کافی باشد:

```text
(x = 10.56, y = -4.87)
```

زبان C توابع مختلفی برای قالب‌بندی خروجی در اختیار ما قرار می‌دهد. دو تابع پرکاربرد عبارت‌اند از:

- `printf()` – داده‌ها را با قالب مشخص مستقیماً در خروجی استاندارد، معمولاً ترمینال، نمایش می‌دهد.
- `sprintf()` – داده‌ها را با قالب مشخص به یک رشته تبدیل کرده و نتیجه را داخل یک آرایه کاراکتری ذخیره می‌کند.

در این آموزش، نحوه استفاده از این دو تابع و تفاوت آن‌ها را بررسی می‌کنیم.

## 2. کتابخانه‌های مورد نیاز

```c
#include <stdio.h>
#include <stdlib.h>
```

### کتابخانه `stdio.h`

این کتابخانه توابع ورودی و خروجی استاندارد زبان C را فراهم می‌کند. از جمله:

- `printf()` – نمایش خروجی قالب‌بندی‌شده.
- `sprintf()` – ذخیره خروجی قالب‌بندی‌شده در یک رشته.
- `puts()` – نمایش یک رشته و افزودن خط جدید در انتهای آن.

### کتابخانه `stdlib.h`

این کتابخانه شامل توابع عمومی و کاربردی زبان C است، مانند:

- `malloc()`
- `free()`
- `atoi()`
- `strtod()`
- `exit()`

**نکته:** در برنامه فعلی هیچ تابعی از کتابخانه `stdlib.h` استفاده نشده است؛ بنابراین می‌توانیم آن را حذف کنیم و برنامه همچنان بدون مشکل اجرا خواهد شد.

## 3. کد کامل برنامه

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    double x = 10.5624;
    double y = -4.8746;

    printf("Using printf function:\n");
    printf("(x = %.2f, y = %.2f)", x, y);
    printf("\n\n");

    char str[100];

    sprintf(str, "(x = %.2f, y = %.2f)", x, y);

    printf("Using sprintf function:\n");
    puts(str);
    printf("\n\n");

    return 0;
}
```

## 4. بررسی و توضیح بخش‌های مختلف برنامه

### 4.1. تعریف متغیرهای اعشاری

```c
double x = 10.5624;
double y = -4.8746;
```

در این قسمت دو متغیر با نوع داده `double` تعریف کرده‌ایم.

نوع داده `double` برای ذخیره اعداد اعشاری استفاده می‌شود و نسبت به `float` دقت بیشتری دارد.

| نام متغیر | مقدار |
|---|---:|
| `x` | 10.5624 |
| `y` | -4.8746 |

در ادامه برنامه از این دو متغیر برای نمایش خروجی قالب‌بندی‌شده استفاده می‌کنیم.

### 4.2. نمایش متن با تابع `printf()`

```c
printf("Using printf function:\n");
```

تابع `printf()` برای نمایش متن و مقادیر در خروجی استاندارد استفاده می‌شود.

کاراکتر ویژه `\n` به معنی رفتن به خط بعد است.

بنابراین دستور بالا متن موردنظر را نمایش داده و سپس مکان‌نما را به خط بعد منتقل می‌کند.

### 4.3. قالب‌بندی اعداد اعشاری

```c
printf("(x = %.2f, y = %.2f)", x, y);
```

این دستور مهم‌ترین قسمت مثال اول است.

تابع `printf()` با استفاده از مشخص‌کننده‌های قالب‌بندی (Format Specifiers) تعیین می‌کند که مقادیر چگونه نمایش داده شوند.

عبارت زیر را بررسی کنیم:

```c
%.2f
```

معنی اجزای آن:

- `%` شروع یک مشخص‌کننده قالب‌بندی است.
- `.2` مشخص می‌کند که فقط دو رقم بعد از ممیز نمایش داده شود.
- `f` نشان‌دهنده نمایش عدد اعشاری با قالب ده‌دهی است.

برای مثال:

| مقدار اصلی | قالب | مقدار نمایش‌داده‌شده |
|---:|---|---:|
| 10.5624 | `%.2f` | 10.56 |
| -4.8746 | `%.2f` | -4.87 |
| 10.5624 | `%.3f` | 10.562 |
| -4.8746 | `%.1f` | -4.9 |
| 10.5624 | `%.0f` | 11 |

تعداد ارقام بعد از ممیز با عددی که پس از نقطه در مشخص‌کننده قالب‌بندی قرار می‌گیرد، تعیین می‌شود.

**نکته مهم:** استفاده از `%.2f` فقط نحوه نمایش مقدار را تغییر می‌دهد و مقدار اصلی ذخیره‌شده در متغیر را تغییر نمی‌دهد.

مثال:

```c
double x = 10.5624;

printf("%.2f\n", x);
printf("%.4f\n", x);
```

خروجی:

```text
10.56
10.5624
```

مقدار اصلی متغیر `x` همچنان برابر با `10.5624` است.

### 4.4. ایجاد خطوط خالی

```c
printf("\n\n");
```

در این دستور دو کاراکتر خط جدید چاپ می‌کنیم.

به این ترتیب دو بار به خط بعد منتقل می‌شویم و یک خط خالی بین قسمت‌های مختلف خروجی ایجاد می‌شود.

### 4.5. تعریف آرایه کاراکتری

```c
char str[100];
```

در این قسمت یک آرایه کاراکتری به نام `str` با ظرفیت ۱۰۰ کاراکتر تعریف می‌کنیم.

در زبان C، رشته‌ها در قالب آرایه‌ای از کاراکترها ذخیره می‌شوند و در انتهای آن‌ها یک کاراکتر ویژه به نام Null Terminator قرار می‌گیرد:

```c
'\0'
```

برای مثال، رشته زیر:

```text
Hello
```

در حافظه به شکل زیر ذخیره می‌شود:

```text
'H' 'e' 'l' 'l' 'o' '\0'
```

آرایه `str` فضای کافی برای ذخیره متن قالب‌بندی‌شده این مثال را در اختیار ما قرار می‌دهد.

### 4.6. آشنایی با تابع `sprintf()`

```c
sprintf(str, "(x = %.2f, y = %.2f)", x, y);
```

تابع `sprintf()` عملکردی مشابه `printf()` دارد؛ با این تفاوت که به‌جای نمایش نتیجه در ترمینال، خروجی را داخل یک آرایه کاراکتری ذخیره می‌کند.

ساختار عمومی این تابع:

```c
sprintf(destination, format, value1, value2, ...);
```

پارامترهای تابع:

| پارامتر | توضیح |
|---|---|
| `destination` | آرایه کاراکتری مقصد که متن در آن ذخیره می‌شود |
| `format` | رشته قالب‌بندی شامل متن معمولی و مشخص‌کننده‌های قالب‌بندی |
| `value1`, `value2`, ... | مقادیری که جایگزین مشخص‌کننده‌های قالب‌بندی می‌شوند |

در مثال ما:

```c
sprintf(str, "(x = %.2f, y = %.2f)", x, y);
```

تابع مراحل زیر را انجام می‌دهد:

1. مقدار متغیر `x` را دریافت می‌کند.
2. آن را با دو رقم اعشار قالب‌بندی می‌کند.
3. مقدار متغیر `y` را دریافت می‌کند.
4. آن را نیز با دو رقم اعشار قالب‌بندی می‌کند.
5. متن نهایی را داخل آرایه `str` ذخیره می‌کند.
6. در انتهای رشته کاراکتر پایان رشته `'\0'` را قرار می‌دهد.

پس از اجرای این دستور، محتوای آرایه `str` برابر خواهد بود با:

```text
(x = 10.56, y = -4.87)
```

**نکته مهم:** تابع `sprintf()` اندازه آرایه مقصد را بررسی نمی‌کند. اگر متن تولیدشده از ظرفیت آرایه بیشتر باشد، ممکن است اطلاعات خارج از محدوده آرایه نوشته شوند و رفتار تعریف‌نشده (Undefined Behavior) رخ دهد.

برای جلوگیری از این مشکل، بهتر است از تابع `snprintf()` استفاده کنیم:

```c
snprintf(str, sizeof(str), "(x = %.2f, y = %.2f)", x, y);
```

پارامتر دوم حداکثر اندازه مجاز بافر مقصد را مشخص می‌کند. این اندازه باید فضای موردنیاز برای کاراکتر پایان رشته را نیز در بر بگیرد.

در برنامه‌های واقعی، استفاده از `snprintf()` معمولاً انتخاب امن‌تری است.

### 4.7. نمایش رشته با تابع `puts()`

```c
printf("Using sprintf function:\n");
puts(str);
```

دستور اول عنوان بخش را نمایش می‌دهد.

دستور دوم محتوای آرایه `str` را در خروجی چاپ می‌کند.

تابع `puts()` پس از نمایش رشته، به‌صورت خودکار یک کاراکتر خط جدید اضافه می‌کند.

بنابراین:

```c
puts(str);
```

از نظر کاربرد معمول تقریباً معادل دستور زیر است:

```c
printf("%s\n", str);
```

هر دو روش برای نمایش یک رشته متنی استفاده می‌شوند.

## 5. تفاوت توابع `printf()`، `sprintf()` و `snprintf()`

هر سه تابع از قالب‌بندی خروجی پشتیبانی می‌کنند؛ اما مقصد خروجی و ویژگی‌های ایمنی آن‌ها متفاوت است.

| تابع | مقصد خروجی | افزودن خودکار Null Terminator | بررسی ظرفیت بافر |
|---|---|---|---|
| `printf()` | خروجی استاندارد | کاربرد ندارد | کاربرد ندارد |
| `sprintf()` | آرایه کاراکتری | بله | خیر |
| `snprintf()` | آرایه کاراکتری | در صورت بزرگ‌تر بودن اندازه بافر از صفر، بله | بله |

### تابع `printf()`

داده‌ها را مستقیماً در خروجی نمایش می‌دهد:

```c
printf("Temperature: %.2f\n", 25.6789);
```

خروجی:

```text
Temperature: 25.68
```

### تابع `sprintf()`

خروجی قالب‌بندی‌شده را داخل یک رشته ذخیره می‌کند:

```c
char buffer[50];

sprintf(buffer, "Temperature: %.2f", 25.6789);
```

محتوای نهایی رشته:

```text
Temperature: 25.68
```

### تابع `snprintf()`

خروجی را داخل یک رشته ذخیره می‌کند و تعداد کاراکترهای مجاز را محدود می‌کند:

```c
char buffer[50];

snprintf(buffer, sizeof(buffer), "Temperature: %.2f", 25.6789);
```

هنگام کار با آرایه‌های کاراکتری با اندازه ثابت، معمولاً استفاده از این تابع انتخاب مناسب‌تری است.

## 6. نسخه اصلاح‌شده و ایمن‌تر برنامه

در نسخه زیر، تابع `sprintf()` را با `snprintf()` جایگزین کرده‌ایم تا از نوشتن اطلاعات خارج از محدوده بافر جلوگیری شود.

```c
#include <stdio.h>

int main(void)
{
    double x = 10.5624;
    double y = -4.8746;

    printf("Using printf function:\n");
    printf("(x = %.2f, y = %.2f)\n\n", x, y);

    char str[100];

    int result = snprintf(
        str,
        sizeof(str),
        "(x = %.2f, y = %.2f)",
        x,
        y
    );

    if (result < 0)
    {
        printf("Formatting error!\n");
        return 1;
    }

    if ((size_t)result >= sizeof(str))
    {
        printf("Warning: Output was truncated!\n");
        return 1;
    }

    printf("Using snprintf function:\n");
    puts(str);

    return 0;
}
```

### چرا از `snprintf()` استفاده می‌کنیم؟

تابع `snprintf()` تعداد کاراکترهایی را برمی‌گرداند که در صورت کافی بودن فضای مقصد نوشته می‌شدند. کاراکتر پایان رشته در مقدار بازگشتی محاسبه نمی‌شود.

- اگر مقدار بازگشتی منفی باشد، خطایی در قالب‌بندی رخ داده است.
- اگر مقدار بازگشتی بزرگ‌تر یا مساوی ظرفیت بافر باشد، خروجی ناقص شده است.
- در غیر این صورت، رشته کامل در آرایه مقصد ذخیره شده است.

تبدیل `(size_t)` در مقایسه، پس از بررسی منفی نبودن `result` انجام می‌شود و مقایسه را با نوع مناسب اندازه حافظه انجام می‌دهد.

## 7. خروجی مورد انتظار

خروجی برنامه اصلی و نسخه اصلاح‌شده از نظر مقادیر قالب‌بندی‌شده یکسان است:

```text
Using printf function:
(x = 10.56, y = -4.87)

Using sprintf function:
(x = 10.56, y = -4.87)
```

در نسخه اصلاح‌شده، عنوان بخش دوم به‌جای `Using sprintf function:` عبارت `Using snprintf function:` خواهد بود.

هر دو روش مقادیر عددی یکسانی تولید می‌کنند.

## 8. کاربردهای عملی

تبدیل مقادیر عددی به رشته‌های قالب‌بندی‌شده در بسیاری از پروژه‌های زبان C کاربرد دارد.

### 8.1. ایجاد پیام‌های Debug

```c
char message[100];

double voltage = 12.567;
double current = 2.345;

snprintf(message, sizeof(message),
         "Voltage: %.2f V, Current: %.2f A",
         voltage, current);

printf("%s\n", message);
```

خروجی:

```text
Voltage: 12.57 V, Current: 2.35 A
```

### 8.2. آماده‌سازی داده برای ارسال از طریق UART

در سیستم‌های Embedded ممکن است لازم باشد قبل از ارسال مقادیر عددی از طریق UART، آن‌ها را به رشته متنی تبدیل کنیم.

```c
char uart_buffer[100];

float temperature = 28.65f;

snprintf(uart_buffer, sizeof(uart_buffer),
         "TEMP:%.2f\r\n", temperature);
```

رشته تولیدشده را می‌توان با استفاده از تابع مناسب UART ارسال کرد.

برای مثال، در STM32 HAL:

```c
HAL_UART_Transmit(
    &huart1,
    (uint8_t *)uart_buffer,
    (uint16_t)strlen(uart_buffer),
    HAL_MAX_DELAY
);
```

این مثال به کتابخانه زیر نیاز دارد:

```c
#include <string.h>
```

همچنین باید هدر مناسب STM32 HAL و تعریف هندل UART در پروژه وجود داشته باشد.

### 8.3. آماده‌سازی داده برای ارتباط TCP

از رشته‌های قالب‌بندی‌شده می‌توان برای آماده‌سازی پیام‌های متنی پیش از ارسال از طریق TCP نیز استفاده کرد.

```c
char tcp_buffer[100];

double x = 10.5624;
double y = -4.8746;

int length = snprintf(
    tcp_buffer,
    sizeof(tcp_buffer),
    "X=%.2f,Y=%.2f",
    x,
    y
);
```

رشته تولیدشده:

```text
X=10.56,Y=-4.87
```

متغیر `length` تعداد کاراکترهای پیام را مشخص می‌کند و می‌توان از آن برای تعیین تعداد بایت‌های موردنیاز هنگام ارسال استفاده کرد.

**نکته:** در ارتباط TCP، یک بار فراخوانی تابع `send()` لزوماً به معنی ارسال کامل پیام نیست. برنامه شبکه باید ارسال ناقص را مدیریت کند و برای تشخیص مرز پیام‌ها از یک روش مشخص مانند طول پیام یا جداکننده استفاده کند.

## 9. اشتباهات رایج

### اشتباه اول: استفاده از `sprintf()` بدون توجه به اندازه بافر

روش ناامن:

```c
char str[10];

sprintf(str, "Temperature: %.2f", 25.67);
```

اندازه آرایه مقصد برای ذخیره متن تولیدشده کافی نیست.

روش ایمن‌تر:

```c
char str[100];

snprintf(str, sizeof(str), "Temperature: %.2f", 25.67);
```

### اشتباه دوم: اشتباه گرفتن دقت نمایش با دقت مقدار متغیر

```c
printf("%.2f", x);
```

این دستور مقدار واقعی `x` را تغییر نمی‌دهد و فقط نحوه نمایش آن را کنترل می‌کند.

### اشتباه سوم: فراموش کردن Null Terminator

هر رشته در زبان C باید با کاراکتر `'\0'` پایان یابد.

توابعی مانند `sprintf()` و `snprintf()` در صورت وجود فضای کافی، این کاراکتر را به‌صورت خودکار اضافه می‌کنند.

### اشتباه چهارم: استفاده از `%s` برای عدد اعشاری

نادرست:

```c
printf("%s", x);
```

درست:

```c
printf("%.2f", x);
```

مشخص‌کننده `%s` برای رشته‌ها و `%f` برای مقادیر اعشاری استفاده می‌شود.


با استفاده از `sprintf()` یا `snprintf()` تمام مقادیر را در یک رشته ذخیره کنید.

**تمرین سوم – اضافه کردن واحد اندازه‌گیری**

رشته‌ای با قالب زیر تولید کنید:

```text
Temperature = 25.68 C, Voltage = 12.35 V
```

**تمرین چهارم – استفاده از Field Width**

مشخص‌کننده‌های زیر را بررسی کنید:

```c
printf("|%10.2f|\n", x);
printf("|%-10.2f|\n", x);
```

تفاوت تراز کردن مقدار از سمت راست و چپ را بررسی کنید.

**تمرین پنجم – ساخت پیام UART**

رشته‌ای شامل مقادیر دما، ولتاژ و جریان بسازید و سپس آن را با استفاده از STM32 HAL UART ارسال کنید.

## 12. اهداف آموزشی

پس از مطالعه این آموزش باید بتوانید:

- اعداد اعشاری را با تابع `printf()` قالب‌بندی کنید.
- تعداد ارقام بعد از ممیز را با `%.2f`، `%.3f` و موارد مشابه کنترل کنید.
- با استفاده از `sprintf()` مقادیر عددی را به رشته تبدیل کنید.
- متن قالب‌بندی‌شده را در آرایه‌های کاراکتری ذخیره کنید.
- از تابع `puts()` برای نمایش رشته استفاده کنید.
- تفاوت توابع `printf()`، `sprintf()` و `snprintf()` را توضیح دهید.
- دلیل ایمن‌تر بودن `snprintf()` برای بافرهای با اندازه ثابت را درک کنید.
- از رشته‌های قالب‌بندی‌شده در پروژه‌های Embedded و پروتکل‌های ارتباطی استفاده کنید.
