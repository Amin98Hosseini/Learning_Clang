# 10-C Programming – Arithmetic Progression and Power Series Using For Loop

## 1. Introduction

In this example, we extend the previous arithmetic progression program by introducing mathematical power calculations using the `math.h` library.

The program generates an arithmetic progression, calculates the sum of its elements, raises each element to a specified power, and calculates the sum of the resulting values.

The program receives four values from the user:

- `a`: First element of the arithmetic progression.
- `d`: Common difference (step size).
- `n`: Number of elements.
- `p`: Exponent power.

The program calculates two different series:

**First series – Original arithmetic progression:**

\[
a_i = a + i \times d
\]

Its cumulative sum is:

\[
S = \sum_{i=0}^{n-1}a_i
\]

**Second series – Power of each element:**

\[
b_i = (a_i)^p
\]

Its cumulative sum is:

\[
T = \sum_{i=0}^{n-1}(a_i)^p
\]

Finally, both sums are displayed separately.

## 2. Source Code

```c
#include <stdio.h>
#include <math.h>

int main()
{
    float a, d, p;
    int n;

    // Get a
    printf("Enter first element of series (a): ");
    scanf("%f", &a);
    printf("\n");

    // Get d
    printf("Enter step size of series (d): ");
    scanf("%f", &d);
    printf("\n");

    // Get n
    printf("Enter number of elements (n): ");
    scanf("%d", &n);
    printf("\n");

    // Get p
    printf("Enter exponent power (p): ");
    scanf("%f", &p);
    printf("\n");

    float S = 0;
    float ai;

    float T = 0;
    float bi;

    printf("i\ta(i)\t\tS(i)\t\tb(i)\t\tT(i)\n");

    for (int i = 0; i < n; i++)
    {
        ai = a + i * d;     // calculate the i-th element
        S += ai;

        bi = pow(ai, p);
        T += bi;

        printf("%d\t%f\t%f\t%f\t%f\n", i, ai, S, bi, T);
    }

    printf("\n\nFinal Sum of Series (S) = %f\n", S);
    printf("\n\nFinal Sum of Series Powers (T) = %f\n", T);

    return 0;
}
```

## 3. Mathematical Background

### 3.1. Arithmetic Progression

The first series is an arithmetic progression.

Its elements are calculated using:

\[
a_i = a + i \times d
\]

Where:

- \(a_i\): Current element.
- \(a\): First element.
- \(i\): Element index, starting from zero.
- \(d\): Common difference.

The sum of the original series is:

\[
S = \sum_{i=0}^{n-1}a_i
\]

### 3.2. Power Series

The second series is generated by raising each element of the original arithmetic progression to the power `p`.

The formula is:

\[
b_i = (a_i)^p
\]

The total sum of the power series is:

\[
T = \sum_{i=0}^{n-1}(a_i)^p
\]

**Important:** This program calculates the power of each individual element and then adds the results together. It does not calculate the power of the total sum.

In general:

\[
\sum_{i=0}^{n-1}(a_i)^p \neq
\left(\sum_{i=0}^{n-1}a_i\right)^p
\]

## 4. Code Explanation

### 4.1. Including Header Files

```c
#include <stdio.h>
#include <math.h>
```

The program uses two standard C libraries.

**stdio.h**

Provides input and output functions:

- `printf()`
- `scanf()`

**math.h**

Provides mathematical functions.

In this program, we use:

```c
pow(ai, p);
```

The `pow()` function calculates a number raised to a specified power.

Its general syntax is:

```c
pow(base, exponent);
```

Example:

```c
pow(2, 3);   // Result: 8
pow(5, 2);   // Result: 25
pow(4, 0.5); // Result: 2
```

The return type of `pow()` is `double`.

### 4.2. Declaring Variables

```c
float a, d, p;
int n;
```

These variables store the user's input.

| Variable | Data Type | Description |
|---|---|---|
| `a` | float | First element |
| `d` | float | Common difference |
| `p` | float | Exponent power |
| `n` | int | Number of elements |

The exponent `p` is defined as `float`, allowing both integer and fractional powers.

### 4.3. Receiving User Input

```c
printf("Enter exponent power (p): ");
scanf("%f", &p);
```

In addition to the previous inputs, the program receives an exponent value.

For example:

- `p = 2`: Calculates squares.
- `p = 3`: Calculates cubes.
- `p = 0.5`: Calculates square roots for non-negative inputs.
- `p = 1`: Returns the original elements.

### 4.4. Initializing the Summation Variables

```c
float S = 0;
float ai;

float T = 0;
float bi;
```

Four variables are declared:

| Variable | Description |
|---|---|
| `S` | Cumulative sum of the original series |
| `ai` | Current element of the original series |
| `T` | Cumulative sum of the power series |
| `bi` | Current powered element |

Both summation variables start at zero.

### 4.5. Displaying the Table Header

```c
printf("i\ta(i)\t\tS(i)\t\tb(i)\t\tT(i)\n");
```

The output table contains five columns:

| Column | Description |
|---|---|
| `i` | Element index |
| `a(i)` | Original element |
| `S(i)` | Cumulative original sum |
| `b(i)` | Powered element |
| `T(i)` | Cumulative power sum |

### 4.6. Understanding the For Loop

```c
for (int i = 0; i < n; i++)
{
    // Calculations
}
```

The `for` loop executes the calculations for every element of the series.

It contains three parts:

1. Initialization: `int i = 0`
2. Condition: `i < n`
3. Increment: `i++`

If `n = 5`, the loop executes five times with indices from zero to four.

### 4.7. Calculating the Original Element

```c
ai = a + i * d;
```

This calculates the current element of the arithmetic progression.

For example:

```text
a = 2
d = 3
n = 5
```

The resulting elements are:

```text
2, 5, 8, 11, 14
```

### 4.8. Calculating the Original Series Sum

```c
S += ai;
```

This statement adds the current element to the previous cumulative sum.

It is equivalent to:

```c
S = S + ai;
```

### 4.9. Calculating the Power of Each Element

```c
bi = pow(ai, p);
```

This is the new mathematical operation introduced in this example.

The `pow()` function raises `ai` to the power `p`.

For example, if:

```text
ai = 5
p = 2
```

The calculation becomes:

\[
b_i = 5^2 = 25
\]

If `p = 3`:

\[
b_i = 5^3 = 125
\]

The result is stored in variable `bi`.

### 4.10. Calculating the Power Series Sum

```c
T += bi;
```

This statement adds the current powered element to the cumulative power sum.

It is equivalent to:

```c
T = T + bi;
```

Unlike `S`, which stores the sum of the original elements, `T` stores the sum of their powered values.

### 4.11. Displaying the Results of Each Iteration

```c
printf("%d\t%f\t%f\t%f\t%f\n", i, ai, S, bi, T);
```

At every iteration, the program displays:

- Current index.
- Original element.
- Cumulative original sum.
- Powered element.
- Cumulative power sum.

This allows us to observe both calculations simultaneously.

### 4.12. Displaying the Final Results

```c
printf("\n\nFinal Sum of Series (S) = %f\n", S);

printf("\n\nFinal Sum of Series Powers (T) = %f\n", T);
```

These statements execute after the loop finishes.

The first displays the total sum of the original arithmetic progression.

The second displays the total sum of all powered elements.

## 8. Important Notes

- The `pow()` function returns a `double`, even when its arguments are `float`.
- Assigning its result to `float bi` converts the result to `float`, which can lose some precision.
- Negative bases with fractional exponents can produce undefined mathematical results in the real number system and may result in a domain error.
- Zero raised to a negative exponent is also a domain error.
- The current program assumes valid numeric input and does not validate `n`.
- For higher precision, consider using `double` instead of `float`.
