# 10- آموزش برنامه‌نویسی C – دنباله حسابی و محاسبه مجموع توان اعضا با حلقه For

## ۱. مقدمه

در این مثال برنامه دنباله حسابی قبلی را توسعه می‌دهیم و با استفاده از کتابخانه `math.h` عملیات محاسبه توان را نیز به آن اضافه می‌کنیم.

برنامه ابتدا یک دنباله حسابی تولید می‌کند، مجموع اعضای آن را محاسبه می‌کند، سپس هر عضو را به توان مشخص‌شده می‌رساند و در نهایت مجموع مقادیر توان‌دار را نیز به دست می‌آورد.

برنامه چهار مقدار از کاربر دریافت می‌کند:

- `a` : اولین عضو دنباله حسابی.
- `d` : اختلاف مشترک یا گام دنباله.
- `n` : تعداد اعضای دنباله.
- `p` : توان موردنظر.

در این برنامه دو دنباله و دو مجموع مستقل محاسبه می‌شوند.

**دنباله اول – دنباله حسابی اصلی:**

\[
a_i = a + i \times d
\]

مجموع اعضای آن:

\[
S = \sum_{i=0}^{n-1}a_i
\]

**دنباله دوم – توان اعضای دنباله:**

\[
b_i = (a_i)^p
\]

مجموع اعضای آن:

\[
T = \sum_{i=0}^{n-1}(a_i)^p
\]

در پایان هر دو مجموع به‌صورت جداگانه نمایش داده می‌شوند.

## ۲. کد برنامه

```c
#include <stdio.h>
#include <math.h>

int main()
{
    float a, d, p;
    int n;

    // Get a
    printf("Enter first element of series (a): ");
    scanf("%f", &a);
    printf("\n");

    // Get d
    printf("Enter step size of series (d): ");
    scanf("%f", &d);
    printf("\n");

    // Get n
    printf("Enter number of elements (n): ");
    scanf("%d", &n);
    printf("\n");

    // Get p
    printf("Enter exponent power (p): ");
    scanf("%f", &p);
    printf("\n");

    float S = 0;
    float ai;

    float T = 0;
    float bi;

    printf("i\ta(i)\t\tS(i)\t\tb(i)\t\tT(i)\n");

    for (int i = 0; i < n; i++)
    {
        ai = a + i * d;
        S += ai;

        bi = pow(ai, p);
        T += bi;

        printf("%d\t%f\t%f\t%f\t%f\n", i, ai, S, bi, T);
    }

    printf("\n\nFinal Sum of Series (S) = %f\n", S);
    printf("\n\nFinal Sum of Series Powers (T) = %f\n", T);

    return 0;
}
```

## ۳. مبانی ریاضی برنامه

### ۳.۱. دنباله حسابی

دنباله اول یک دنباله حسابی است که اعضای آن با رابطه زیر محاسبه می‌شوند:

\[
a_i = a + i \times d
\]

که در آن:

- \(a_i\) : عضو فعلی دنباله.
- \(a\) : اولین عضو دنباله.
- \(i\) : شماره یا اندیس عضو که از صفر شروع می‌شود.
- \(d\) : اختلاف مشترک اعضای متوالی.

مجموع دنباله اصلی:

\[
S = \sum_{i=0}^{n-1}a_i
\]

### ۳.۲. دنباله توانی

در دنباله دوم، هر عضو دنباله اصلی به توان `p` می‌رسد.

رابطه ریاضی آن:

\[
b_i = (a_i)^p
\]

مجموع دنباله توانی:

\[
T = \sum_{i=0}^{n-1}(a_i)^p
\]

**نکته مهم:** در این برنامه ابتدا تک‌تک اعضای دنباله به توان `p` می‌رسند و سپس نتایج با یکدیگر جمع می‌شوند.

این عملیات با محاسبه توان مجموع کل دنباله متفاوت است.

به‌طور کلی:

\[
\sum_{i=0}^{n-1}(a_i)^p \neq
\left(\sum_{i=0}^{n-1}a_i\right)^p
\]

## ۴. بررسی و توضیح کد

### ۴.۱. اضافه کردن کتابخانه‌ها

```c
#include <stdio.h>
#include <math.h>
```

در این برنامه از دو کتابخانه استاندارد استفاده می‌کنیم.

**کتابخانه stdio.h**

برای انجام عملیات ورودی و خروجی استفاده می‌شود.

توابع مهم:

- `printf()` : نمایش اطلاعات.
- `scanf()` : دریافت اطلاعات.

**کتابخانه math.h**

برای انجام محاسبات ریاضی استفاده می‌شود.

در این برنامه از تابع زیر استفاده می‌کنیم:

```c
pow(ai, p);
```

تابع `pow()` یک عدد را به توان عدد دیگری می‌رساند.

ساختار کلی تابع:

```c
pow(base, exponent);
```

مثال:

```c
pow(2, 3);   // Result: 8
pow(5, 2);   // Result: 25
pow(4, 0.5); // Result: 2
```

نوع خروجی تابع `pow()` از نوع `double` است.

### ۴.۲. تعریف متغیرها

```c
float a, d, p;
int n;
```

در این قسمت متغیرهای ورودی برنامه تعریف می‌شوند.

| متغیر | نوع داده | کاربرد |
|---|---|---|
| `a` | float | اولین عضو دنباله |
| `d` | float | اختلاف مشترک دنباله |
| `p` | float | توان موردنظر |
| `n` | int | تعداد اعضای دنباله |

متغیر `p` از نوع `float` تعریف شده است تا بتوانیم از توان‌های صحیح و اعشاری استفاده کنیم.

### ۴.۳. دریافت اطلاعات از کاربر

```c
printf("Enter exponent power (p): ");
scanf("%f", &p);
```

در این قسمت علاوه بر ورودی‌های قبلی، مقدار توان نیز از کاربر دریافت می‌شود.

برای مثال:

- `p = 2` : محاسبه توان دوم یا مربع.
- `p = 3` : محاسبه توان سوم یا مکعب.
- `p = 0.5` : محاسبه ریشه دوم برای مقادیر غیرمنفی.
- `p = 1` : بازگشت مقدار اصلی هر عضو.

### ۴.۴. تعریف و مقداردهی اولیه متغیرهای مجموع

```c
float S = 0;
float ai;

float T = 0;
float bi;
```

در این قسمت چهار متغیر تعریف می‌کنیم:

| متغیر | کاربرد |
|---|---|
| `S` | مجموع تجمعی دنباله اصلی |
| `ai` | عضو فعلی دنباله اصلی |
| `T` | مجموع تجمعی دنباله توانی |
| `bi` | مقدار توان‌دار عضو فعلی |

دو متغیر `S` و `T` با مقدار صفر مقداردهی اولیه می‌شوند.

### ۴.۵. نمایش عنوان ستون‌های جدول

```c
printf("i\ta(i)\t\tS(i)\t\tb(i)\t\tT(i)\n");
```

در این برنامه جدول خروجی شامل پنج ستون است:

| ستون | توضیح |
|---|---|
| `i` | شماره عضو |
| `a(i)` | مقدار عضو اصلی |
| `S(i)` | مجموع تجمعی دنباله اصلی |
| `b(i)` | مقدار عضو پس از محاسبه توان |
| `T(i)` | مجموع تجمعی دنباله توانی |

### ۴.۶. آشنایی با حلقه For

```c
for (int i = 0; i < n; i++)
{
    // Calculations
}
```

در این قسمت از حلقه `for` برای اجرای محاسبات روی تمام اعضای دنباله استفاده می‌کنیم.

حلقه شامل سه بخش اصلی است:

۱. مقداردهی اولیه:

```c
int i = 0;
```

۲. شرط ادامه حلقه:

```c
i < n;
```

۳. افزایش شمارنده:

```c
i++
```

اگر مقدار `n` برابر پنج باشد، حلقه با اندیس‌های صفر تا چهار اجرا می‌شود.

### ۴.۷. محاسبه عضو دنباله اصلی

```c
ai = a + i * d;
```

این دستور با استفاده از فرمول دنباله حسابی، عضو فعلی را محاسبه می‌کند.

برای مثال:

```text
a = 2
d = 3
n = 5
```

اعضای دنباله:

```text
2, 5, 8, 11, 14
```

### ۴.۸. محاسبه مجموع دنباله اصلی

```c
S += ai;
```

این دستور مقدار عضو فعلی را به مجموع قبلی اضافه می‌کند.

معادل عبارت زیر است:

```c
S = S + ai;
```

بنابراین متغیر `S` در هر مرحله به‌روزرسانی می‌شود.

### ۴.۹. محاسبه توان هر عضو

```c
bi = pow(ai, p);
```

این قسمت عملیات ریاضی جدید برنامه است.

تابع `pow()` مقدار `ai` را به توان `p` می‌رساند.

برای مثال:

```text
ai = 5
p = 2
```

محاسبه:

\[
b_i = 5^2 = 25
\]

اگر مقدار `p` برابر سه باشد:

\[
b_i = 5^3 = 125
\]

نتیجه محاسبه در متغیر `bi` ذخیره می‌شود.

### ۴.۱۰. محاسبه مجموع دنباله توانی

```c
T += bi;
```

در این قسمت مقدار توان‌دار عضو فعلی به مجموع قبلی اضافه می‌شود.

این دستور معادل عبارت زیر است:

```c
T = T + bi;
```

تفاوت دو متغیر مجموع:

- `S` : مجموع اعضای اصلی دنباله.
- `T` : مجموع توان اعضای دنباله.

### ۴.۱۱. نمایش نتایج هر مرحله

```c
printf("%d\t%f\t%f\t%f\t%f\n", i, ai, S, bi, T);
```

در هر بار اجرای حلقه، پنج مقدار نمایش داده می‌شوند:

۱. شماره عضو فعلی.

۲. مقدار اصلی عضو.

۳. مجموع تجمعی دنباله اصلی.

۴. مقدار توان‌دار عضو.

۵. مجموع تجمعی دنباله توانی.

به این ترتیب دو محاسبه به‌صورت هم‌زمان قابل مشاهده هستند.

### ۴.۱۲. نمایش مجموع نهایی

```c
printf("\n\nFinal Sum of Series (S) = %f\n", S);

printf("\n\nFinal Sum of Series Powers (T) = %f\n", T);
```

این دستورات بعد از پایان حلقه اجرا می‌شوند.

دستور اول مجموع نهایی دنباله اصلی را نمایش می‌دهد.

دستور دوم مجموع نهایی اعضای توان‌دار را نمایش می‌دهد.

## ۸. نکات مهم

- تابع `pow()` مقدار خروجی از نوع `double` برمی‌گرداند؛ حتی اگر ورودی‌های آن از نوع `float` باشند.
- ذخیره خروجی `pow()` در متغیر `float` باعث تبدیل نوع داده می‌شود و ممکن است مقداری از دقت محاسبات از دست برود.
- پایه منفی با توان اعشاری ممکن است در مجموعه اعداد حقیقی جواب نداشته باشد و باعث خطای دامنه ریاضی شود.
- صفر به توان منفی نیز دارای خطای دامنه است.
- در نسخه فعلی اعتبارسنجی برای ورودی‌های عددی و مقدار `n` انجام نمی‌شود.
- برای افزایش دقت محاسبات می‌توان به جای `float` از `double` استفاده کرد.

## ۹. تمرین‌های پیشنهادی

- تمرین ۱: مقدار `p` را برابر دو قرار دهید و مجموع مربع اعضای دنباله را محاسبه کنید.
- تمرین ۲: مقدار `p` را برابر سه قرار دهید و مجموع مکعب اعضا را به دست آورید.
- تمرین ۳: با قرار دادن `p = 0.5` ریشه دوم هر عضو را محاسبه کنید.
- تمرین ۴: متغیر جدیدی تعریف کنید تا مجموع قدرمطلق اعضای دنباله را محاسبه کند.
- تمرین ۵: فقط اعضایی را نمایش دهید که مقدار توان‌دار آن‌ها بیشتر از ۱۰۰ باشد.
- تمرین ۶: متغیرهای `float` را با `double` جایگزین کنید.
- تمرین ۷: خروجی را برای مقادیر مختلف توان مقایسه کنید.
- تمرین ۸: اعتبارسنجی ورودی برای مقادیر نامعتبر `n` و `p` اضافه کنید.
