# آموزش زبان C

مجموعه‌ای از **۴۰ درس شماره‌دار** برای یادگیری زبان C، به‌صورت گام‌به‌گام و عملی. هر درس در پوشه‌ای جداگانه قرار دارد، شامل یک برنامه‌ی مستقل و کوچک به‌همراه مستندات خودش (`Readme.md` به انگلیسی و `Readme_Fa.md` به فارسی).

شماره‌گذاری پوشه‌ها ترتیب مطالعه را نشان می‌دهد: از چاپ یک خط متن شروع می‌شود و به ساختارها (structure)، اشاره‌گر به تابع و شمارشی‌ها (enum) می‌رسد. هر درس بر پایه‌ی درس‌های قبلی بنا شده است، بنابراین خواندن پوشه‌ها به ترتیب، یک مسیر کامل از سطح مبتدی تا متوسط را تشکیل می‌دهد.

## این مخزن چه چیزی در خود دارد؟

- **۴۰ درس**، هر کدام در یک پوشه با نام `<شماره>-<موضوع>`.
- **یک فایل `main.c` برای هر درس** (درس اول `helloworld.c` و درس بیست‌وپنجم `mian.c` نام دارد).
- **فایل `Readme.md` (انگلیسی) و `Readme_Fa.md` (فارسی) در هر پوشه**، شامل توضیح مفهوم، بررسی کد و خروجی مورد انتظار.
- **فایل‌های اجرایی ویندوز (`*.exe`)** که با GCC از MinGW-w64 ساخته شده‌اند و کنار سورس قرار دارند.
- **یک تسک ساخت (build task) برای VS Code** که فایل باز فعلی را کامپایل می‌کند.

## پیش‌نیازها

- یک کامپایلر C. تسک آماده‌ی VS Code برای **GCC از MinGW-w64** در مسیر `C:\mingw64\bin\gcc.exe` (ویندوز) تنظیم شده است. هر نسخه‌ای از GCC یا Clang کار می‌کند؛ فقط مسیر داخل تسک را تغییر دهید.
- اختیاری: [Visual Studio Code](https://code.visualstudio.com/) به‌همراه افزونه‌ی [C/C++](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools) برای استفاده از تنظیمات ساخت و اشکال‌زدایی موجود.

بررسی نصب کامپایلر:

```bash
gcc --version
```

## کامپایل برنامه‌ها

### با GCC از ترمینال

برای کامپایل یک درس، مسیر فایل سورس را به GCC بدهید؛ خروجی کنار همان سورس ساخته می‌شود:

```bash
gcc -Wall -g 5-EvenOdd_PositiveNegative_Zero/main.c -o 5-EvenOdd_PositiveNegative_Zero/main.exe
```

در لینوکس و macOS معمولاً پسوند `.exe` لازم نیست:

```bash
gcc -Wall -g 5-EvenOdd_PositiveNegative_Zero/main.c -o evenodd
```

**درس‌هایی که از `<math.h>` استفاده می‌کنند** — درس‌های ۱۰، ۱۲، ۱۴، ۱۶ و ۳۹ — در لینوکس و macOS نیاز به لینک کردن کتابخانه‌ی ریاضی دارند:

```bash
gcc -Wall 14-Quadratic_Equation_Solver/main.c -o quad -lm
```

کامپایل همه‌ی درس‌ها با یک دستور از ریشه‌ی مخزن (نقل‌قول لازم است، چون نام یکی از پوشه‌ها فاصله دارد):

```bash
for src in */main.c */helloworld.c; do
    gcc -Wall -std=c11 "$src" -o "${src%.c}.exe" || echo "failed: $src"
done
```

### با Visual Studio Code

1. پوشه‌ی مخزن را در VS Code باز کنید.
2. فایل `.c` مورد نظر را باز کنید.
3. با <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> تسک پیش‌فرض **C/C++: gcc.exe build active file** را اجرا کنید.
4. فایل اجرایی کنار سورس و با همان نام سورس ساخته می‌شود.

اگر کامپایلر شما در `C:\mingw64\bin\gcc.exe` نیست، فیلد `command` را در [`.vscode/tasks.json`](.vscode/tasks.json) تغییر دهید. در پوشه‌ی `1-HelloWorld` یک `launch.json` هم وجود دارد؛ با <kbd>F5</kbd> برنامه ساخته و در حالت اشکال‌زدایی اجرا می‌شود، به شرطی که `miDebuggerPath` به `gdb.exe` شما اشاره کند.

## سرفصل درس‌ها به تفصیل

### بخش ۱ — نخستین برنامه‌ها (۱ تا ۴)

- **1-HelloWorld** — کوچک‌ترین برنامه‌ی کامل C: `#include`، `int main()`، یک `printf` و `return 0`. پایان‌خط ویندوزی `\r\n` نیز معرفی می‌شود.
- **2-StringInPrint** — چهار فراخوانی `printf` برای نمایش تب، خط جدید، هشدار صوتی `\a` و نقل‌قول داخل رشته.
- **3-GetInputUser** — تعریف `int n`، نمایش پیام، خواندن با `scanf("%d", &n)` و چاپ مقدار. `&` نخستین برخورد با آدرس‌ها است.
- **4-SimppleAdder_Scanf** — دو عدد در `a` و `b` خوانده می‌شود، `c = a + b` محاسبه و کل معادله چاپ می‌شود.

### بخش ۲ — تصمیم‌گیری، عملگرها و حلقه‌ها (۵ تا ۱۱)

- **۵** — زوج/فرد بودن با عملگر `%` و سپس مثبت/منفی/صفر بودن با زنجیره‌ی `if`/`else if`/`else`.
- **۶** — مقایسه‌ی `b1 = ++a1;` با `b2 = a2++;` و دلیل تفاوت مقادیر چاپ‌شده.
- **۷** — جمع اعداد تا رسیدن به مقدار پایانی `-1`، سپس چاپ مجموع و میانگین؛ استفاده از `#define` برای `TRUE`.
- **۸** — خواندن `a` (جمله‌ی اول)، `d` (قدر نسبت) و `n` (تعداد جملات) و چاپ `i`، `a(i)` و مجموع جاری با حلقه‌ی `while`.
- **۹** — همان تصاعد حسابی با حلقه‌ی `for` و چاپ مجموع نهایی.
- **۱۰** — گسترش تصاعد به سری توانی: برای هر جمله مقدار `pow(a(i), p)` نیز جمع می‌شود و هر دو مجموع جاری در یک جدول چاپ می‌شوند.
- **۱۱** — شمارش حروف A، B، C، D و F از ورودی استاندارد تا `EOF` با `switch` و fallthrough برای حروف بزرگ و کوچک، سپس گزارش تعداد، درصد و درصد تجمعی هر نمره.

### بخش ۳ — توابع، بازگشت و ریاضیات (۱۲ تا ۱۴)

- **۱۲** — تابع `IsPrime()` بخش‌پذیری را از ۲ تا `sqrt(a)` بررسی می‌کند و `main` تا وارد کردن عدد نامثبت ادامه می‌دهد.
- **۱۳** — تابع `Fibo1()` فیبوناچی را تکراری و در زمان O(n) حساب می‌کند و `Fibo()` آن را بازگشتی و در زمان O(2ⁿ). هر دو `F(0)` تا `F(44)` را چاپ می‌کنند تا تفاوت چشمگیر زمان اجرا دیده شود؛ بخش نسبت طلایی به‌صورت کامنت باقی مانده است.
- **۱۴** — حل معادله‌ی `ax² + bx + c = 0` با در نظر گرفتن حالت `a == 0` (خطی یا حل‌نشدنی)، دلتای صفر (ریشه‌ی مضاعف)، دلتای مثبت (دو ریشه‌ی حقیقی) و دلتای منفی (ریشه‌های موهومی یا مختلط).

### بخش ۴ — آرایه‌ها، تحلیل داده و مرتب‌سازی (۱۵ تا ۲۱)

- **۱۵** — ساخت اعداد فیبوناچی ۰ تا ۲۴ در آرایه‌ی `int F[25]` و چاپ آن‌ها همراه با اندیس.
- **۱۶** — محاسبه‌ی مجموع، میانگین، انحراف معیار نمونه‌ای و هیستوگرام فراوانی ارقام ۰ تا ۹ روی ۶۰ عدد ثابت، با کشیدن میله‌ها به‌وسیله‌ی `*`.
- **۱۷** — ذخیره‌ی نام در `char name[10]` با `scanf("%9s", ...)` (محدودشده برای جلوگیری از سرریز)، سپس مقایسه‌ی `sizeof` (ظرفیت آرایه) با شمارش دستی طول رشته تا رسیدن به `'\0'`.
- **۱۸** — چهار تابع روی یک آرایه: `PrintArray`، `Mean`، `MakeDouble` (آرایه‌ی فراخواننده را تغییر می‌دهد، چون آرایه به اشاره‌گر تبدیل می‌شود) و `MakeDouble2` (فقط نسخه‌ی محلی متغیر را تغییر می‌دهد).
- **۱۹** — مرتب‌سازی حبابی با پرچم `swapped` برای خروج زودهنگام، با سپردن چاپ و جابه‌جایی به توابع جداگانه.
- **۲۰** — خواندن `N` و تعریف `int a[2*N]` (آرایه با طول متغیر) و سپس گزارش تعداد عناصر با `sizeof`.
- **۲۱** — `GetDivisors(n, NULL)` ابتدا تعداد بخش‌پذیرها را می‌شمارد؛ سپس فراخواننده آرایه‌ی `int D[nd]` را می‌سازد و تابع را دوباره برای پر کردن فراخوانی می‌کند — الگوی کلاسیک «اول اندازه، بعد داده».
- **درس‌های ۱۵ تا ۲۱** برای محاسبه‌ی تعداد عناصر از `sizeof(a) / sizeof(a[0])` استفاده می‌کنند، نه از طول ثابت.

### بخش ۵ — اشاره‌گرها (۲۲ تا ۲۴)

- **۲۲** — توابع `Func1(int)` و `Func2(int)` نسخه‌ای از مقدار را می‌گیرند و نمی‌توانند `a` را تغییر دهند؛ اما `Func3(int *)` آدرس `&a` را می‌گیرد و تغییرش پایدار می‌ماند. در پایان آدرس متغیر با `%p` چاپ می‌شود.
- **۲۳** — همان مرتب‌سازی حبابی، این بار با پارامترهای اشاره‌گر (`int *const a`)، آرگومان‌های `&a[j]` و تابع `Swap` مبتنی بر اشاره‌گر.
- **۲۴** — تابع `BubbleSort` یک تابع مقایسه به‌صورت `int (*compare)(int, int)` می‌گیرد. سه مقایسه‌گر — صعودی، نزولی و صعودی بر اساس باقیمانده‌ی تقسیم بر ۳ — در آرایه‌ای از اشاره‌گر تابع ذخیره و یکی پس از دیگری روی همان آرایه اعمال می‌شوند.

### بخش ۶ — کاراکترها و رشته‌ها (۲۵ تا ۳۷)

- **۲۵** — خواندن کاراکترها تا `EOF`، چاپ کد ASCII هر یک و دسته‌بندی آن با `isdigit`، `isalpha`، `islower`، `ispunct` و `isspace`.
- **۲۶** — استخراج سه عدد از `"1.2 -3.5 10.8"` با فراخوانی مکرر `strtof` و بازخوردن `pEnd` به آن؛ فراخوانی آخر `NULL` می‌گیرد چون داده‌ای بعد از آن نیست.
- **۲۷** — خواندن یک خط با `fgets`، چاپ `strlen(str) - 1` (بدون احتساب خط جدید پایانی) و معکوس کردن متن با بازگشت تا انتهای رشته و چاپ کاراکترها در مسیر بازگشت.
- **۲۸** — پر کردن `char str[50]` در حلقه‌ی `while ((c = getchar()) != '\n')`، محافظت از مرز بافر و افزودن دستی `'\0'`.
- **۲۹** — قالب‌بندی دو `double` با `%.2f` دو بار: یک بار مستقیم روی صفحه با `printf` و یک بار در یک بافر با `sprintf` و سپس `puts`.
- **۳۰** — تجزیه‌ی رشته‌ی `"(x = -5.45, y = 10.67)"` با قالب متناظر در `sscanf` و استخراج `x` و `y`.
- **۳۱** — حلقه‌ی خواندن کد خطا و چاپ `strerror(e)` برای هر کد؛ کد منفی برنامه را پایان می‌دهد.
- **۳۲** — `strcpy` کپی کامل رشته، `strncpy` کپی پنج کاراکتر با افزودن دستی پایان‌دهنده، و `strcat` چسباندن یک رشته به انتهای رشته‌ی دیگر.
- **۳۳** — مقایسه‌ی `"abc"` با خودش، با `"abd"` و با `"abb"` و تبدیل علامت خروجی `strcmp` به `=`، `>` و `<`.
- **۳۴** — پیمایش جمله‌ی شکسپیر با `strchr` برای گزارش موقعیت همه‌ی تکرارهای یک کاراکتر (از ۱، با تفریق اشاره‌گر) و سپس `strstr` برای یافتن نخستین تکرار یک کلمه.
- **۳۵** — جدا کردن `"1.2 2.5 -5.6,7,8,10 1.41 -6.5,-17"` بر اساس فاصله و ویرگول با `strtok` و چاپ هر توکن در یک خط.
- **۳۶** — استفاده از اسکن‌ست `%[^aeiou]` که همه‌چیز را تا نخستین حرف صدادار می‌خواند؛ بنابراین برای `"hello"` مقدار `"h"` به دست می‌آید.
- **۳۷** — خواندن `YYYY-MM-DD` با `%d%*c%d%*c%d`: مشخصه‌ی `%*c` جداکننده‌ها را می‌خواند و دور می‌ریزد، پس هر کاراکتر تک‌تایی می‌تواند جداکننده باشد.

### بخش ۷ — ساختارها و شمارشی‌ها (۳۸ تا ۴۰)

- **۳۸** — تعریف `Student` (شامل `id`، `firstName`، `lastName` و `gpa`) با `typedef struct`. تابع `DisplayStudentInformation` یک نسخه می‌گیرد، پس `id += 1000` در آن از بین می‌رود؛ اما `DisplayStudentInformation2` اشاره‌گر می‌گیرد، از `->` استفاده می‌کند و تغییرش پایدار می‌ماند — که با چاپ دوباره‌ی همان دانشجو دیده می‌شود.
- **۳۹** — تعریف `Complex { float real, imag; }` و پیاده‌سازی `Conj`، `Abs`، `Add`، `Subtract`، `Product` و `Division`، همراه با قالب‌بند `DispComplex` که حالت‌های حقیقی محض، موهومی محض و موهومی منفی را درست نمایش می‌دهد.
- **۴۰** — تعریف `typedef enum months { FAR = 1, ..., ESF } Month` و سپس آرایه‌ی `char *MonthNames[]` که اندیس صفر آن رشته‌ی خالی است تا `MonthNames[m]` برای ماه‌های ۱ تا ۱۲ مستقیماً کار کند؛ حلقه‌ی `for` روی enum تقویم را چاپ می‌کند.

## نکات و ایرادهای شناخته‌شده

این موارد بخشی از وضعیت فعلی مخزن هستند و دست‌نخورده باقی مانده‌اند تا درس‌های قبلی دقیقاً همان‌طور که نوشته شده‌اند بمانند:

- **درس ۵ یک باگ واقعی دارد که ارزش اصلاحش را دارد.** شاخه‌های مثبت، منفی و صفر `"%d is Positive.\n"` را بدون پاس دادن `a` چاپ می‌کنند، بنابراین عدد نمایش داده نمی‌شود (یا مقدار نامعتبر چاپ می‌شود). افزودن آرگومان جاافتاده یک تمرین خوب برای شروع است.
- **`25-.../mian.c`** — نام فایل سورس اشتباه تایپ شده (`mian` به‌جای `main`) و در نتیجه فایل اجرایی آن `mian.exe` است. هر دستور ساخت محلی باید همین نام را به کار ببرد.
- **`30-.../Readmem_Fa.md`** — نام سند فارسی این پوشه یک `m` اضافه دارد.
- **`36-Reading_Strings_with_scanf_Using_Scanset _in_C_Language`** — نام پوشه پیش از `_in` یک فاصله دارد، پس دستورهای شل و لینک‌ها باید نقل‌قول شوند.
