# 38- ساختارها (Structures)، typedef و ارسال ساختار به توابع در زبان C

## ۱. مقدمه

در زبان برنامه‌نویسی C، از `struct` برای تعریف یک نوع داده جدید استفاده می‌کنیم.

ساختار به ما اجازه می‌دهد چند متغیر با نوع داده‌های متفاوت را در کنار یکدیگر و تحت یک نام واحد قرار دهیم.

برای مثال، اطلاعات یک دانشجو می‌تواند شامل موارد زیر باشد:

- شماره دانشجویی (`int`)
- نام (`char *`)
- نام خانوادگی (`char *`)
- معدل (`float`)

به‌جای اینکه برای هر دانشجو چهار متغیر جداگانه تعریف کنیم، می‌توانیم یک ساختار به نام `Student` ایجاد کنیم و تمام اطلاعات دانشجو را در آن قرار دهیم.

این برنامه مفاهیم زیر را آموزش می‌دهد:

۱. تعریف ساختار با استفاده از `typedef`

۲. تعریف متغیر از نوع ساختار

۳. مقداردهی اولیه اعضای ساختار

۴. دسترسی به اعضای ساختار با عملگر نقطه (`.`)

۵. ارسال ساختار به تابع به روش Pass by Value

۶. ارسال آدرس ساختار به تابع با استفاده از Pointer

۷. دسترسی به اعضای ساختار از طریق اشاره‌گر با عملگر فلش (`->`)

۸. تفاوت تغییر نسخه کپی‌شده ساختار با تغییر ساختار اصلی

## ۲. کد کامل برنامه

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct
{
    int id;
    char *firstName;
    char *lastName;
    float gpa;
} Student;

void DisplayStudentInformation(Student stu);
void DisplayStudentInformation2(Student *pstu);

int main()
{

    Student stu1;
    stu1.id=101;
    stu1.firstName="Ali";
    stu1.lastName="Alavi";
    stu1.gpa=18;

    Student stu2={102,"Reza","Razavi",19};

    printf("Using First Function (By Value):\n");
    DisplayStudentInformation(stu1);
    DisplayStudentInformation(stu2);
    DisplayStudentInformation(stu1);

    printf("------------------------------------------------\n");

    printf("Using Second Function (By Reference):\n");
    DisplayStudentInformation2(&stu1);
    DisplayStudentInformation2(&stu2);
    DisplayStudentInformation2(&stu1);

    return 0;
}

void DisplayStudentInformation(Student stu)
{
    printf("Student Information:\n");
    printf("        ID: %d\n",stu.id);
    printf("First Name: %s\n",stu.firstName);
    printf(" Last Name: %s\n",stu.lastName);
    printf("       GPA: %.2f\n",stu.gpa);
    stu.id+=1000;
    printf("    New ID: %d\n",stu.id);
    printf("\n");
}

void DisplayStudentInformation2(Student *pstu)
{
    printf("Student Information:\n");
    printf("        ID: %d\n",pstu->id);
    printf("First Name: %s\n",pstu->firstName);
    printf(" Last Name: %s\n",pstu->lastName);
    printf("       GPA: %.2f\n",pstu->gpa);
    pstu->id+=1000;
    printf("    New ID: %d\n",pstu->id);
    printf("\n");
}
```

## ۴. تعریف ساختار با استفاده از typedef

```c
typedef struct
{
    int id;
    char *firstName;
    char *lastName;
    float gpa;
} Student;
```

این قسمت یکی از مهم‌ترین بخش‌های برنامه است.

### ساختار چیست؟

ساختار یا `Structure` یک نوع داده تعریف‌شده توسط برنامه‌نویس است که امکان قرار دادن چند متغیر با انواع داده متفاوت را در یک مجموعه فراهم می‌کند.

در این مثال، یک ساختار برای نگهداری اطلاعات دانشجو تعریف کرده‌ایم.

بیایید اعضای آن را بررسی کنیم.

| عضو | نوع داده | توضیح |
|---|---|---|
| `id` | `int` | شماره دانشجویی |
| `firstName` | `char *` | اشاره‌گر به نام |
| `lastName` | `char *` | اشاره‌گر به نام خانوادگی |
| `gpa` | `float` | معدل دانشجو |

### کلمه کلیدی typedef چیست؟

از `typedef` برای ایجاد یک نام مستعار برای یک نوع داده استفاده می‌شود.

بدون استفاده از `typedef` می‌توانستیم ساختار را به این شکل تعریف کنیم:

```c
struct Student
{
    int id;
    char *firstName;
    char *lastName;
    float gpa;
};
```

برای تعریف یک متغیر از این ساختار باید می‌نوشتیم:

```c
struct Student stu1;
```

اما با استفاده از `typedef` می‌توانیم بنویسیم:

```c
typedef struct
{
    int id;
    char *firstName;
    char *lastName;
    float gpa;
} Student;
```

حالا برای تعریف متغیر کافی است بنویسیم:

```c
Student stu1;
```

بنابراین، `typedef` باعث کوتاه‌تر و خواناتر شدن تعریف متغیرهای ساختاری می‌شود.

**نکته:** دستور `typedef` خودش یک متغیر ایجاد نمی‌کند؛ بلکه یک نام مستعار برای نوع داده می‌سازد.

### بررسی char *

در ساختار دو عضو زیر را داریم:

```c
char *firstName;
char *lastName;
```

علامت `*` نشان می‌دهد که این متغیرها اشاره‌گر به کاراکتر هستند.

یعنی به‌جای ذخیره مستقیم مجموعه کاراکترها درون ساختار، آدرس رشته‌ها را نگهداری می‌کنند.

در برنامه مقداردهی به این شکل انجام شده است:

```c
stu1.firstName = "Ali";
stu1.lastName = "Alavi";
```

در این حالت اشاره‌گرها به رشته‌های ثابت یا String Literal اشاره می‌کنند.

رشته‌های ثابت نباید تغییر داده شوند.

اگر بخواهیم نام دانشجو را در حافظه قابل‌تغییر نگهداری کنیم، می‌توانیم از آرایه کاراکتری استفاده کنیم:

```c
char firstName[] = "Ali";
char lastName[] = "Alavi";
```

یا ساختار را به این شکل تعریف کنیم:

```c
typedef struct
{
    int id;
    char firstName[30];
    char lastName[30];
    float gpa;
} Student;
```

در این حالت، آرایه‌های نام و نام خانوادگی مستقیماً داخل هر متغیر ساختاری قرار می‌گیرند.

## ۵. اعلان اولیه توابع (Function Prototypes)

```c
void DisplayStudentInformation(Student stu);
void DisplayStudentInformation2(Student *pstu);
```

این دو خط، توابع برنامه را قبل از تابع `main()` به کامپایلر معرفی می‌کنند.

اعلان اولیه تابع مشخص می‌کند:

- نام تابع چیست.
- نوع خروجی تابع چیست.
- تابع چه پارامترهایی دریافت می‌کند.

هر دو تابع دارای نوع خروجی `void` هستند.

یعنی هیچ مقداری را به محل فراخوانی خود برنمی‌گردانند.

اما تفاوت اصلی آن‌ها در نوع پارامتر ورودی است.

### تابع اول

```c
void DisplayStudentInformation(Student stu);
```

این تابع یک متغیر از نوع `Student` دریافت می‌کند.

در این روش، ساختار به‌صورت مقداری به تابع ارسال می‌شود و تابع یک نسخه مستقل از آن دریافت می‌کند.

### تابع دوم

```c
void DisplayStudentInformation2(Student *pstu);
```

این تابع یک اشاره‌گر به ساختار `Student` دریافت می‌کند.

یعنی به‌جای دریافت کل ساختار، آدرس یک متغیر ساختاری را دریافت می‌کند.

در نتیجه می‌تواند از طریق آن اشاره‌گر به ساختار اصلی دسترسی پیدا کند و اعضای آن را تغییر دهد.

## ۶. تعریف و مقداردهی اولیه دانشجوی اول

```c
Student stu1;

stu1.id=101;
stu1.firstName="Ali";
stu1.lastName="Alavi";
stu1.gpa=18;
```

در ابتدا یک متغیر از نوع `Student` تعریف می‌کنیم:

```c
Student stu1;
```

نام این متغیر `stu1` است.

سپس اعضای آن را مقداردهی می‌کنیم.

### عملگر نقطه (.)

برای دسترسی به اعضای یک متغیر ساختاری، از عملگر نقطه استفاده می‌کنیم.

برای مثال:

```c
stu1.id = 101;
```

یعنی:

- متغیر ساختاری `stu1` را انتخاب کن.
- عضو `id` آن را پیدا کن.
- مقدار `101` را در آن قرار بده.

سایر اعضا نیز به همین شکل مقداردهی می‌شوند:

```c
stu1.firstName = "Ali";
stu1.lastName = "Alavi";
stu1.gpa = 18;
```

پس از اجرای این دستورات، اطلاعات دانشجوی اول به شکل زیر خواهد بود:

| عضو | مقدار |
|---|---|
| `id` | `101` |
| `firstName` | `"Ali"` |
| `lastName` | `"Alavi"` |
| `gpa` | `18.0` |

---

## ۷. تعریف و مقداردهی اولیه دانشجوی دوم

```c
Student stu2={102,"Reza","Razavi",19};
```

در زبان C می‌توان هنگام تعریف یک متغیر ساختاری، تمام اعضای آن را به‌صورت هم‌زمان مقداردهی کرد.

مقادیر بر اساس ترتیب تعریف اعضای ساختار به آن‌ها اختصاص داده می‌شوند.

ساختار ما به این شکل تعریف شده است:

```c
typedef struct
{
    int id;
    char *firstName;
    char *lastName;
    float gpa;
} Student;
```

بنابراین دستور زیر:

```c
Student stu2={102,"Reza","Razavi",19};
```

معادل دستورات زیر است:

```c
Student stu2;

stu2.id = 102;
stu2.firstName = "Reza";
stu2.lastName = "Razavi";
stu2.gpa = 19;
```

اطلاعات دانشجوی دوم:

| عضو | مقدار |
|---|---|
| `id` | `102` |
| `firstName` | `"Reza"` |
| `lastName` | `"Razavi"` |
| `gpa` | `19.0` |

این روش مقداردهی را Aggregate Initialization می‌نامند.

همچنین می‌توانیم از Designated Initializer استفاده کنیم:

```c
Student stu2 = {
    .id = 102,
    .firstName = "Reza",
    .lastName = "Razavi",
    .gpa = 19
};
```

در این روش نام هر عضو مشخص می‌شود و خوانایی کد بیشتر خواهد بود.

## ۸. فراخوانی تابع اول – ارسال ساختار به روش Pass by Value

```c
printf("Using First Function (By Value):\n");

DisplayStudentInformation(stu1);
DisplayStudentInformation(stu2);
DisplayStudentInformation(stu1);
```

در این قسمت تابع اول سه مرتبه فراخوانی می‌شود.

در هر بار فراخوانی، یک متغیر ساختاری مستقیماً به تابع ارسال می‌شود.

برای مثال:

```c
DisplayStudentInformation(stu1);
```

در این حالت، تابع یک نسخه کپی‌شده از `stu1` را دریافت می‌کند.

برای درک بهتر، می‌توان رفتار آن را به‌صورت مفهومی مشابه دستور زیر در نظر گرفت:

```c
Student localCopy = stu1;
```

این فقط یک نمایش مفهومی از رفتار ارسال با مقدار است و لازم نیست چنین دستوری را داخل تابع بنویسیم.

متغیر `localCopy` یک ساختار مستقل است.

بنابراین اگر داخل تابع مقدار یکی از اعضای این کپی تغییر کند، ساختار اصلی تغییر نخواهد کرد.

## ۹. بررسی تابع اول

```c
void DisplayStudentInformation(Student stu)
{
    printf("Student Information:\n");
    printf("        ID: %d\n",stu.id);
    printf("First Name: %s\n",stu.firstName);
    printf(" Last Name: %s\n",stu.lastName);
    printf("       GPA: %.2f\n",stu.gpa);

    stu.id+=1000;

    printf("    New ID: %d\n",stu.id);
    printf("\n");
}
```

### پارامتر تابع

```c
Student stu
```

این پارامتر یک متغیر محلی از نوع `Student` است.

وقتی ساختار را به تابع ارسال می‌کنیم، مقدار اعضای آن در پارامتر تابع کپی می‌شود.

بنابراین متغیر `stu` مستقل از متغیر اصلی است.

### نمایش اطلاعات دانشجو

```c
printf("        ID: %d\n",stu.id);
printf("First Name: %s\n",stu.firstName);
printf(" Last Name: %s\n",stu.lastName);
printf("       GPA: %.2f\n",stu.gpa);
```

این دستورات اطلاعات دانشجو را نمایش می‌دهند.

دقت کنید که برای دسترسی به اعضا از عملگر نقطه (`.`) استفاده شده است.

دلیل آن این است که `stu` یک متغیر ساختاری معمولی است، نه اشاره‌گر.

### افزایش شماره دانشجویی

```c
stu.id+=1000;
```

این دستور معادل عبارت زیر است:

```c
stu.id = stu.id + 1000;
```

فرض کنیم شماره دانشجو برابر `101` باشد.

پس از اجرای دستور، مقدار محلی آن برابر می‌شود با:

```text
101 + 1000 = 1101
```

سپس دستور زیر مقدار جدید را چاپ می‌کند:

```c
printf("    New ID: %d\n",stu.id);
```

اما نکته مهم این است که مقدار اصلی `stu1.id` تغییر نمی‌کند.

چرا؟

چون متغیر `stu` فقط یک نسخه کپی‌شده از ساختار اصلی است.

بنابراین تغییرات فقط روی همان نسخه محلی اعمال می‌شوند.

### مثال

فرض کنیم دستور زیر اجرا شود:

```c
DisplayStudentInformation(stu1);
```

قبل از اجرای تابع:

```text
stu1.id = 101
```

داخل تابع:

```text
stu.id = 101
stu.id = 101 + 1000
stu.id = 1101
```

پس از پایان تابع:

```text
stu1.id = 101
```

همان‌طور که مشاهده می‌کنید، مقدار اصلی همچنان `101` باقی می‌ماند.

این ویژگی اصلی ارسال ساختار به روش Pass by Value است.

## ۱۰. فراخوانی تابع دوم – ارسال آدرس ساختار با Pointer

```c
printf("Using Second Function (By Reference):\n");

DisplayStudentInformation2(&stu1);
DisplayStudentInformation2(&stu2);
DisplayStudentInformation2(&stu1);
```

در این قسمت قبل از نام هر متغیر از علامت `&` استفاده شده است.

برای مثال:

```c
DisplayStudentInformation2(&stu1);
```

عملگر `&` آدرس حافظه یک متغیر را برمی‌گرداند.

بنابراین:

```c
&stu1
```

یعنی آدرس متغیر ساختاری `stu1`.

این آدرس به تابع ارسال می‌شود.

در نتیجه تابع می‌تواند با استفاده از اشاره‌گر به ساختار اصلی دسترسی داشته باشد.

**نکته مهم درباره زبان C:** در زبان C تمام آرگومان‌های توابع به‌صورت مقداری ارسال می‌شوند. حتی در این مثال، خود اشاره‌گر نیز به‌صورت مقداری به تابع داده می‌شود؛ اما چون مقدار اشاره‌گر آدرس ساختار اصلی است، تابع می‌تواند از طریق آن ساختار اصلی را تغییر دهد. این روش را معمولاً Pass by Reference می‌نامند، اما از نظر فنی C دارای پارامترهای مرجع واقعی مانند C++ نیست.

## ۱۱. بررسی تابع دوم

```c
void DisplayStudentInformation2(Student *pstu)
{
    printf("Student Information:\n");
    printf("        ID: %d\n",pstu->id);
    printf("First Name: %s\n",pstu->firstName);
    printf(" Last Name: %s\n",pstu->lastName);
    printf("       GPA: %.2f\n",pstu->gpa);

    pstu->id+=1000;

    printf("    New ID: %d\n",pstu->id);
    printf("\n");
}
```

### پارامتر تابع

```c
Student *pstu
```

این دستور یک اشاره‌گر به ساختار `Student` تعریف می‌کند.

نام اشاره‌گر `pstu` است.

این اشاره‌گر آدرس یک متغیر ساختاری را در خود نگهداری می‌کند.

در مقایسه با تابع اول، این تابع یک نسخه کامل از ساختار دریافت نمی‌کند؛ بلکه آدرس ساختار اصلی را دریافت می‌کند.

### عملگر فلش (->)

در تابع اول برای دسترسی به اعضای ساختار از دستور زیر استفاده کردیم:

```c
stu.id
```

اما در تابع دوم می‌نویسیم:

```c
pstu->id
```

دلیل این تفاوت چیست؟

چون `pstu` یک اشاره‌گر به ساختار است.

برای دسترسی به اعضای یک ساختار از طریق اشاره‌گر، از عملگر `->` استفاده می‌کنیم.

دو عبارت زیر کاملاً معادل هستند:

```c
pstu->id
```

```c
(*pstu).id
```

در عبارت دوم، پرانتز ضروری است؛ زیرا اولویت عملگر نقطه از عملگر Dereference بیشتر است.

### نمایش اطلاعات دانشجو

```c
printf("        ID: %d\n",pstu->id);
printf("First Name: %s\n",pstu->firstName);
printf(" Last Name: %s\n",pstu->lastName);
printf("       GPA: %.2f\n",pstu->gpa);
```

این دستورات اعضای ساختار اصلی را از طریق اشاره‌گر می‌خوانند و نمایش می‌دهند.

### تغییر شماره دانشجویی اصلی

```c
pstu->id+=1000;
```

این دستور شماره دانشجویی ساختار اصلی را ۱۰۰۰ واحد افزایش می‌دهد.

برای مثال، اگر مقدار اولیه این باشد:

```c
stu1.id = 101;
```

بعد از اجرای دستور زیر:

```c
DisplayStudentInformation2(&stu1);
```

مقدار ساختار اصلی به شکل زیر تغییر می‌کند:

```c
stu1.id = 1101;
```

برخلاف تابع اول، این تغییر پس از پایان تابع نیز باقی می‌ماند.

---

## ۱۲. تفاوت عملگرهای نقطه و فلش

این دو عملگر در کار با ساختارها بسیار مهم هستند.

| عملگر | کاربرد | مثال |
|---|---|---|
| `.` | دسترسی مستقیم به عضو ساختار | `stu1.id` |
| `->` | دسترسی به عضو ساختار از طریق اشاره‌گر | `pstu->id` |

به مثال زیر توجه کنید:

```c
Student stu1;
Student *pstu = &stu1;
```

دسترسی مستقیم به شماره دانشجویی:

```c
stu1.id = 101;
```

دسترسی به همان عضو از طریق اشاره‌گر:

```c
pstu->id = 101;
```

هر دو دستور یک عضو از یک ساختار را تغییر می‌دهند.

همچنین دستور زیر:

```c
pstu->id = 101;
```

با دستور زیر معادل است:

```c
(*pstu).id = 101;
```

## ۱۳. بررسی مرحله‌به‌مرحله اجرای برنامه

این بخش مهم‌ترین قسمت مثال است.

در ابتدا دو ساختار ما دارای اطلاعات زیر هستند:

| ساختار | شماره دانشجویی | نام | نام خانوادگی | معدل |
|---|---:|---|---|---:|
| `stu1` | 101 | Ali | Alavi | 18 |
| `stu2` | 102 | Reza | Razavi | 19 |

### بخش اول: اجرای تابع با Pass by Value

سه دستور زیر اجرا می‌شوند:

```c
DisplayStudentInformation(stu1);
DisplayStudentInformation(stu2);
DisplayStudentInformation(stu1);
```

هر بار تابع یک نسخه کپی‌شده از ساختار را دریافت می‌کند.

بنابراین نتیجه افزایش شماره دانشجویی به شکل زیر است:

| فراخوانی تابع | شماره اصلی | شماره داخل تابع پس از افزایش |
|---|---:|---:|
| فراخوانی اول با `stu1` | 101 | 1101 |
| فراخوانی دوم با `stu2` | 102 | 1102 |
| فراخوانی سوم با `stu1` | 101 | 1101 |

نکته مهم این است که در فراخوانی سوم، شماره دانشجو دوباره از `101` شروع می‌شود.

چون فراخوانی اول هیچ تغییری در ساختار اصلی `stu1` ایجاد نکرده است.

پس از پایان این سه فراخوانی:

```text
stu1.id = 101
stu2.id = 102
```

### بخش دوم: اجرای تابع با Pointer

اکنون سه دستور زیر اجرا می‌شوند:

```c
DisplayStudentInformation2(&stu1);
DisplayStudentInformation2(&stu2);
DisplayStudentInformation2(&stu1);
```

این بار آدرس ساختارهای اصلی به تابع ارسال می‌شود.

بیایید تغییرات را بررسی کنیم.

**فراخوانی اول:**

```c
DisplayStudentInformation2(&stu1);
```

مقدار اولیه:

```text
stu1.id = 101
```

پس از افزایش:

```text
stu1.id = 1101
```

**فراخوانی دوم:**

```c
DisplayStudentInformation2(&stu2);
```

مقدار اولیه:

```text
stu2.id = 102
```

پس از افزایش:

```text
stu2.id = 1102
```

**فراخوانی سوم:**

```c
DisplayStudentInformation2(&stu1);
```

دقت کنید که مقدار `stu1.id` قبلاً به `1101` تغییر کرده است.

بنابراین این بار:

```text
stu1.id = 1101 + 1000
stu1.id = 2101
```

در پایان برنامه، مقادیر اصلی به شکل زیر خواهند بود:

```text
stu1.id = 2101
stu2.id = 1102
```

این مثال به‌خوبی تفاوت ارسال ساختار به‌صورت مقدار و ارسال اشاره‌گر به ساختار را نشان می‌دهد.

## ۱۵. مفهوم حافظه: کپی ساختار در مقابل اشاره‌گر به ساختار

برای درک بهتر تفاوت این دو روش، می‌توانیم آن‌ها را به‌صورت ساده نمایش دهیم.

### ارسال ساختار به روش Pass by Value

```c
DisplayStudentInformation(stu1);
```

از نظر مفهومی:

```text
ساختار اصلی                         پارامتر تابع
+------------------+                +------------------+
| ID: 101          |  ------------> | ID: 101          |
| First: Ali       |      کپی        | First: Ali       |
| Last: Alavi      |                | Last: Alavi      |
| GPA: 18.0        |                | GPA: 18.0        |
+------------------+                +------------------+
```

تابع یک ساختار مستقل دریافت می‌کند.

اگر شماره دانشجویی را در داخل تابع تغییر دهیم، ساختار اصلی تغییر نمی‌کند.

### ارسال اشاره‌گر به ساختار

```c
DisplayStudentInformation2(&stu1);
```

نمایش مفهومی:

```text
ساختار اصلی
+------------------+
| ID: 101          |
| First: Ali       |
| Last: Alavi      |
| GPA: 18.0        |
+------------------+
         ^
         |
         | آدرس
         |
+------------------+
| pstu             |
| اشاره‌گر به stu1 |
+------------------+
```

در این روش، اشاره‌گر آدرس ساختار اصلی را در اختیار تابع قرار می‌دهد.

بنابراین وقتی دستور زیر اجرا می‌شود:

```c
pstu->id += 1000;
```

عضو `id` در ساختار اصلی تغییر می‌کند.

**نکته:** هنگام کپی کردن ساختاری که دارای اشاره‌گر است، خود آدرس اشاره‌گرها کپی می‌شود، نه محتوای رشته‌هایی که به آن‌ها اشاره می‌کنند. در این مثال، اشاره‌گرهای نام به رشته‌های ثابت اشاره می‌کنند و هیچ‌کدام از توابع محتوای آن رشته‌ها را تغییر نمی‌دهند.

## ۱۶. چرا ساختار را با Pointer به تابع ارسال می‌کنیم؟

ارسال ساختار به‌صورت مقدار زمانی مفید است که تابع به یک نسخه مستقل از اطلاعات نیاز داشته باشد.

اما ارسال ساختار با اشاره‌گر مزایای مهمی دارد:

۱. از کپی شدن کل ساختار جلوگیری می‌کند.

۲. امکان تغییر ساختار اصلی را فراهم می‌کند.

۳. برای ساختارهای بزرگ معمولاً کارآمدتر است.

۴. چند تابع می‌توانند روی یک ساختار اصلی کار کنند.

۵. هنگام کار با آرایه ساختارها، لیست‌های پیوندی و سایر ساختارهای داده بسیار کاربردی است.

برای مثال، فرض کنید ساختار ما به شکل زیر باشد:

```c
typedef struct
{
    int id;
    char name[100];
    float grades[1000];
    int numberOfGrades;
} Student;
```

کپی کردن چنین ساختار بزرگی در هر بار فراخوانی تابع می‌تواند غیرضروری باشد.

در چنین شرایطی، ارسال اشاره‌گر معمولاً انتخاب مناسب‌تری است.

---

## ۱۷. بهبود برنامه: استفاده از const برای توابع فقط‌خواندنی

یک نکته مهم در طراحی برنامه وجود دارد.

هر دو تابع مثال اصلی اطلاعات دانشجو را نمایش می‌دهند، اما هم‌زمان شماره دانشجویی را نیز تغییر می‌دهند.

اگر هدف یک تابع فقط نمایش اطلاعات باشد، بهتر است اجازه تغییر اطلاعات اصلی را نداشته باشد.

می‌توانیم نمایش اطلاعات و تغییر اطلاعات را در دو تابع جداگانه قرار دهیم.

برای مثال:

```c
void DisplayStudent(const Student *pstu)
{
    printf("Student Information:\n");
    printf("        ID: %d\n", pstu->id);
    printf("First Name: %s\n", pstu->firstName);
    printf(" Last Name: %s\n", pstu->lastName);
    printf("       GPA: %.2f\n", pstu->gpa);
    printf("\n");
}
```

در اینجا:

```c
const Student *pstu
```

یعنی تابع از طریق این اشاره‌گر اجازه تغییر اعضای ساختار را ندارد.

برای مثال، دستور زیر مجاز نیست:

```c
pstu->id += 1000;
```

کامپایلر برای این دستور خطا صادر می‌کند.

اگر بخواهیم شماره دانشجو را تغییر دهیم، تابع جداگانه‌ای تعریف می‌کنیم:

```c
void IncreaseStudentID(Student *pstu)
{
    pstu->id += 1000;
}
```

در نتیجه وظایف توابع از یکدیگر جدا می‌شوند:

- `DisplayStudent()` فقط اطلاعات را نمایش می‌دهد.
- `IncreaseStudentID()` شماره دانشجویی را تغییر می‌دهد.

این روش طراحی تمیزتر و قابل‌نگهداری‌تری ایجاد می‌کند.

---

## ۱۸. نسخه کامل بهبودیافته برنامه

```c
#include <stdio.h>

typedef struct
{
    int id;
    char *firstName;
    char *lastName;
    float gpa;
} Student;

void DisplayStudent(const Student *pstu);
void IncreaseStudentID(Student *pstu);

int main(void)
{
    Student stu1 = {101, "Ali", "Alavi", 18.0f};
    Student stu2 = {102, "Reza", "Razavi", 19.0f};

    printf("Initial student information:\n\n");

    DisplayStudent(&stu1);
    DisplayStudent(&stu2);

    printf("Increasing student IDs...\n\n");

    IncreaseStudentID(&stu1);
    IncreaseStudentID(&stu2);

    printf("Updated student information:\n\n");

    DisplayStudent(&stu1);
    DisplayStudent(&stu2);

    return 0;
}

void DisplayStudent(const Student *pstu)
{
    printf("Student Information:\n");
    printf("        ID: %d\n", pstu->id);
    printf("First Name: %s\n", pstu->firstName);
    printf(" Last Name: %s\n", pstu->lastName);
    printf("       GPA: %.2f\n", pstu->gpa);
    printf("\n");
}

void IncreaseStudentID(Student *pstu)
{
    pstu->id += 1000;
}
```

در این نسخه، نمایش اطلاعات و تغییر اطلاعات در دو تابع جداگانه انجام می‌شوند.

همچنین با استفاده از `const` از تغییر ناخواسته اطلاعات در تابع نمایش جلوگیری می‌کنیم.

## ۱۹. نکات فنی مهم

### نکته اول: در زبان C ارسال واقعی با Reference وجود ندارد

در زبان C تمام آرگومان‌های توابع به‌صورت Pass by Value ارسال می‌شوند.

حتی زمانی که یک اشاره‌گر را به تابع ارسال می‌کنیم، مقدار خود اشاره‌گر کپی می‌شود.

اما این مقدار کپی‌شده همچنان آدرس همان ساختار اصلی را نگهداری می‌کند.

به همین دلیل تابع می‌تواند از طریق آن ساختار اصلی را تغییر دهد.

### نکته دوم: کپی ساختار دارای Pointer

وقتی یک ساختار دارای اشاره‌گر را کپی می‌کنیم، آدرس اشاره‌گرها نیز کپی می‌شود.

به این نوع کپی، Shallow Copy گفته می‌شود.

برای مثال:

```c
Student copy = stu1;
```

هر دو ساختار دارای آدرس یکسانی برای رشته‌های نام و نام خانوادگی خواهند بود.

### نکته سوم: بررسی معتبر بودن اشاره‌گر

تابع دوم انتظار دارد یک اشاره‌گر معتبر دریافت کند.

برای ایمنی بیشتر می‌توانیم مقدار `NULL` را بررسی کنیم:

```c
void DisplayStudentInformation2(Student *pstu)
{
    if (pstu == NULL)
    {
        printf("Invalid student pointer!\n");
        return;
    }

    printf("ID: %d\n", pstu->id);
}
```

### نکته چهارم: استفاده از float

عضو معدل در ساختار به شکل زیر تعریف شده است:

```c
float gpa;
```

برای مقداردهی می‌توانیم از پسوند `f` استفاده کنیم:

```c
stu1.gpa = 18.0f;
```

پسوند `f` مشخص می‌کند که مقدار عددی از نوع `float` است.

### نکته پنجم: ساختارهای بزرگ

اگر ساختار اعضای زیادی داشته باشد، ارسال آن به‌صورت مقدار ممکن است باعث کپی شدن حجم زیادی از داده‌ها شود.

در چنین شرایطی ارسال اشاره‌گر معمولاً انتخاب بهتری است.

## ۲۱. تمرین‌ها

برای تسلط بیشتر بر این مفاهیم، تمرین‌های زیر را انجام دهید.

### تمرین اول – اضافه کردن دانشجوی سوم

یک متغیر ساختاری جدید تعریف کنید:

```c
Student stu3 = {103, "Sara", "Ahmadi", 17.5f};
```

اطلاعات آن را با هر دو تابع نمایش دهید.

### تمرین دوم – تغییر معدل دانشجو

تابعی بنویسید که یک اشاره‌گر به ساختار دانشجو دریافت کند و معدل او را یک واحد افزایش دهد.

```c
void IncreaseGPA(Student *pstu);
```

بررسی کنید که آیا ساختار اصلی تغییر می‌کند یا خیر.

### تمرین سوم – مقایسه دو دانشجو

تابعی بنویسید که آدرس دو دانشجو را دریافت کند و مشخص کند کدام دانشجو معدل بیشتری دارد.

```c
void CompareStudents(const Student *s1, const Student *s2);
```

### تمرین چهارم – آرایه‌ای از ساختارها

یک آرایه شامل پنج دانشجو ایجاد کنید:

```c
Student students[5];
```

با استفاده از حلقه، اطلاعات تمام دانشجویان را نمایش دهید.

### تمرین پنجم – محاسبه میانگین معدل

تابعی بنویسید که آرایه‌ای از دانشجویان را دریافت کند و میانگین معدل آن‌ها را محاسبه کند.

### تمرین ششم – آزمایش Pass by Value

تابعی ایجاد کنید که یک ساختار را به‌صورت مقداری دریافت کند و تمام اعضای آن را تغییر دهد.

پس از فراخوانی تابع، ساختار اصلی را چاپ کنید و بررسی کنید که آیا تغییر کرده است یا خیر.

## ۲۲. مواردی که پس از مطالعه این مثال یاد می‌گیرید

پس از بررسی این برنامه باید بتوانید:

- مفهوم Structure در زبان C را توضیح دهید.
- با استفاده از `typedef` یک نوع داده ساختاری تعریف کنید.
- متغیرهای ساختاری ایجاد و مقداردهی کنید.
- با عملگر نقطه (`.`) به اعضای ساختار دسترسی پیدا کنید.
- ساختار را با روش Pass by Value به تابع ارسال کنید.
- اشاره‌گر به ساختار را به تابع ارسال کنید.
- با عملگر فلش (`->`) اعضای ساختار را از طریق اشاره‌گر بخوانید و تغییر دهید.
- تفاوت تغییر نسخه کپی‌شده و ساختار اصلی را درک کنید.
- بدانید چرا از نظر فنی در C تمام آرگومان‌ها به‌صورت مقداری ارسال می‌شوند.
- از `const` همراه اشاره‌گر ساختار استفاده کنید.
- مفهوم Shallow Copy و Deep Copy را بشناسید.
