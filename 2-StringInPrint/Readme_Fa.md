# 2 - آشنایی با کاراکترهای کنترلی (Escape Sequences) در زبان C

## معرفی پروژه (Overview)

این پروژه با هدف آموزش کاراکترهای کنترلی (Escape Sequences) در زبان برنامه‌نویسی C طراحی شده است.

کاراکترهای کنترلی ترکیبی از کاراکترها هستند که با علامت بک‌اسلش (`\`) شروع می‌شوند و برای کنترل نحوه نمایش متن و استفاده از کاراکترهای خاص در خروجی برنامه کاربرد دارند.

در این مثال با استفاده از تابع `printf()` نحوه ایجاد خط جدید، فاصله افقی، ارسال هشدار و نمایش علامت نقل‌قول دوتایی بررسی می‌شود.

کاراکترهای کنترلی استفاده‌شده در این برنامه عبارت‌اند از:

- `\n` : رفتن به خط جدید (New Line)
- `\t` : ایجاد فاصله افقی (Horizontal Tab)
- `\a` : ارسال کاراکتر هشدار (Alert / Bell)
- `\"` : نمایش علامت نقل‌قول دوتایی (Double Quotation Mark)

## اهداف آموزشی (Learning Objectives)

با مطالعه این برنامه، مفاهیم زیر را یاد می‌گیرید:

- آشنایی با مفهوم Escape Sequences.
- نحوه ایجاد خط جدید با استفاده از `\n`.
- نحوه ایجاد فاصله افقی با استفاده از `\t`.
- نحوه ارسال کاراکتر هشدار با استفاده از `\a`.
- نحوه نمایش علامت نقل‌قول دوتایی داخل رشته متنی.
- قالب‌بندی خروجی برنامه با استفاده از تابع `printf()`.

## بررسی و توضیح کد (Source Code Explanation)

### 1. فراخوانی کتابخانه ورودی و خروجی

```c
#include <stdio.h>
```

این دستور کتابخانه استاندارد ورودی و خروجی زبان C را فراخوانی می‌کند.

این کتابخانه شامل توابعی مانند `printf()` برای نمایش اطلاعات در خروجی است.

### 2. کاراکتر رفتن به خط جدید (New Line)

```c
printf("A\tB\tC\t\n");
```

کاراکتر کنترلی `\n` باعث انتقال مکان‌نما به ابتدای خط بعدی می‌شود.

از این کاراکتر برای جدا کردن خطوط خروجی و افزایش خوانایی اطلاعات استفاده می‌شود.

مثال:

```c
printf("Hello\nWorld!\n");
```

خروجی:

```text
Hello
World!
```

### 3. کاراکتر فاصله افقی (Horizontal Tab)

```c
printf("A\tB\tC\t\n");
printf("Apple\tOrange\tBennana\t\n");
```

کاراکتر کنترلی `\t` یک فاصله افقی (Tab) بین متن‌ها ایجاد می‌کند.

این کاراکتر برای مرتب‌سازی اطلاعات و نمایش داده‌ها در ستون‌های مختلف کاربرد دارد.

خروجی تقریبی:

```text
A       B       C
Apple   Orange  Bennana
```

**نکته:** فاصله ایجادشده توسط Tab به تنظیمات Tab Stop در محیط کنسول بستگی دارد.

### 4. کاراکتر هشدار (Alert / Bell)

```c
printf("Cow\tSheep\tLion\t\a\n");
```

کاراکتر کنترلی `\a` با نام Alert یا Bell شناخته می‌شود.

این کاراکتر یک سیگنال هشدار به محیط خروجی ارسال می‌کند و بسته به سیستم‌عامل و محیط ترمینال ممکن است صدای هشدار ایجاد کند.

**نکته:** در برخی ترمینال‌های جدید ممکن است این کاراکتر نادیده گرفته شود یا صدای آن غیرفعال باشد.

### 5. نمایش علامت نقل‌قول دوتایی (Double Quotation Mark)

```c
printf("Hello \"world\" !\n");
```

در زبان C از علامت نقل‌قول دوتایی (`"`) برای مشخص کردن ابتدا و انتهای رشته‌های متنی (String) استفاده می‌شود.

اگر بخواهیم همین علامت را داخل یک رشته متنی نمایش دهیم، باید از کاراکتر کنترلی `\"` استفاده کنیم.

مثال:

```c
printf("He said: \"Hello World!\"\n");
```

خروجی:

```text
He said: "Hello World!"
```

## خروجی برنامه (Example Output)

```text
A       B       C
Apple   Orange  Bennana
Cow     Sheep   Lion
Hello "world" !
```

کاراکتر `\a` نیز ممکن است بسته به محیط اجرای برنامه صدای هشدار ایجاد کند.

## مفاهیم مهم برنامه‌نویسی C

| کاراکتر کنترلی | کاربرد |
|---|---|
| `\n` | انتقال مکان‌نما به خط بعدی |
| `\t` | ایجاد فاصله افقی (Tab) |
| `\a` | ارسال سیگنال هشدار (Alert / Bell) |
| `\"` | نمایش علامت نقل‌قول دوتایی |
| `\\` | نمایش کاراکتر بک‌اسلش |
| `\r` | بازگشت مکان‌نما به ابتدای خط فعلی |
| `\b` | حرکت مکان‌نما یک موقعیت به عقب |
| `\'` | نمایش علامت نقل‌قول تکی |
| `\0` | کاراکتر Null برای مشخص کردن انتهای رشته در زبان C |

## تمرین‌های پیشنهادی (Practice Exercises)

برای درک بهتر کاراکترهای کنترلی، تمرین‌های زیر را انجام دهید:

1. نام و سن خود را با استفاده از `\n` در دو خط جداگانه نمایش دهید.
2. با استفاده از `\t` یک جدول سه‌ستونه ایجاد کنید.
3. جمله‌ای شامل چند علامت نقل‌قول دوتایی چاپ کنید.
4. یک مسیر فایل ویندوز را با استفاده از کاراکتر `\\` نمایش دهید.
5. عملکرد کاراکترهای `\r` و `\b` را آزمایش کنید.
6. یک جدول شامل نام، سن و امتیاز چند نفر طراحی کنید.
