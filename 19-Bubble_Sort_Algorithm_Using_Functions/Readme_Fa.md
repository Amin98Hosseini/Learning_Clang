# 19- آموزش الگوریتم Bubble Sort و مرتب‌سازی آرایه در زبان C

## ۱. مقدمه

این برنامه نحوه مرتب‌سازی عناصر یک آرایه عدد صحیح را با استفاده از الگوریتم **Bubble Sort (مرتب‌سازی حبابی)** آموزش می‌دهد.

به طور کل Bubble Sort یکی از ساده‌ترین الگوریتم‌های مرتب‌سازی است. در این الگوریتم، عناصر مجاور آرایه با یکدیگر مقایسه می‌شوند و اگر ترتیب آن‌ها اشتباه باشد، جای آن‌ها با هم عوض می‌شود.

این عملیات چندین بار روی آرایه تکرار می‌شود تا تمام عناصر به ترتیب صحیح قرار بگیرند.

در این مثال با مفاهیم مهم زیر آشنا می‌شویم:

- الگوریتم‌های مرتب‌سازی (Sorting Algorithms)
- الگوریتم Bubble Sort
- آرایه‌ها و اندیس‌گذاری (Array Indexing)
- اعلان و تعریف توابع
- ارسال آرایه به تابع
- کلمه کلیدی `const`
- حلقه‌های تو در تو (Nested Loops)
- دستورات شرطی
- جابه‌جایی دو متغیر (Swap)
- متغیر موقت (Temporary Variable)
- دستور `break`
- پیچیدگی زمانی الگوریتم
- مرتب‌سازی در محل (In-place Sorting)

در این برنامه سه تابع اصلی داریم:

| نام تابع | وظیفه |
|---|---|
| `PrintArray()` | نمایش عناصر آرایه |
| `BubbleSort()` | مرتب‌سازی آرایه به‌صورت صعودی |
| `Swap()` | جابه‌جایی دو عنصر آرایه |

## ۲. کد اولیه برنامه

کدی که ارائه شده است:

```c
#include <stdio.h>

void PrintArray(int a[], int N);
void BubbleSort(const int a[], int N);
void Swap(int a[], int j1, int j2);

int main()
{
    int a[]={23,53,12,10,17,56,78,34,29,37,45,12,19,20,40,90,43,48,62};

    int N=sizeof(a)/sizeof(a[0]);

    printf("Array before sorting:\n");
    PrintArray(a,N);
    printf("\n\n");

    BubbleSort(a,N);

    printf("Array after sorting:\n");
    PrintArray(a,N);
    printf("\n\n");

    return 0;
}

void BubbleSort(const int a[], int N)
{
    int i, j;
    int swapped;

    for(i=0; i<N; i++)
    {
        swapped = 0;

        for(j=0; j<N-1; j++)
        {
            if(a[j]>a[j+1])
            {
                Swap(a,j,j+1);
                swapped = 1;
            }
        }

        if(!swapped) break;
    }
}

void Swap(int a[], int j1, int j2)
{
    int temp;

    temp = a[j1];
    a[j1] = a[j2];
    a[j2] = temp;
}

void PrintArray(int a[], int N)
{
    int i;

    for(i=0; i<N; i++)
    {
        printf("%d",a[i]);

        if(i<N-1)
        {
            printf(", ");
        }
    }
}
```

## ۳. اصلاح مهم در کد اولیه: کلمه کلیدی const

در کد اولیه یک مشکل مهم وجود دارد.

در اعلان تابع `BubbleSort()` از `const` استفاده شده است:

```c
void BubbleSort(const int a[], int N);
```

و در تعریف تابع نیز همین عبارت نوشته شده است:

```c
void BubbleSort(const int a[], int N)
```

کلمه کلیدی `const` اجازه تغییر عناصر آرایه را از طریق پارامتر `a` نمی‌دهد.

اما داخل تابع `BubbleSort()` دستور زیر اجرا می‌شود:

```c
Swap(a,j,j+1);
```

تابع `Swap()` به شکل زیر تعریف شده است:

```c
void Swap(int a[], int j1, int j2);
```

این تابع برای جابه‌جایی عناصر باید بتواند مقادیر آرایه را تغییر دهد.

در نتیجه ارسال آرایه با نوع اشاره‌گر به `const int` به پارامتری از نوع `int *` باعث حذف ویژگی `const` می‌شود. این کار در زبان استاندارد C معتبر نیست و کامپایلر باید درباره آن هشدار یا خطا صادر کند.

### راه‌حل صحیح

باید `const` را از پارامتر تابع `BubbleSort()` حذف کنیم.

اعلان صحیح:

```c
void BubbleSort(int a[], int N);
```

تعریف صحیح:

```c
void BubbleSort(int a[], int N)
```

زیرا این تابع باید بتواند عناصر آرایه اصلی را تغییر دهد.

**نکته:** در تابع `PrintArray()` استفاده از `const` مناسب است، چون این تابع فقط عناصر آرایه را نمایش می‌دهد و آن‌ها را تغییر نمی‌دهد.

void PrintArray(const int a[], int N);

## ۵. آشنایی با الگوریتم Bubble Sort

الگوریتم Bubble Sort با مقایسه دو عنصر مجاور کار می‌کند.

اگر عنصر سمت چپ از عنصر سمت راست بزرگ‌تر باشد، جای آن‌ها با یکدیگر عوض می‌شود.

شرط اصلی این الگوریتم برای مرتب‌سازی صعودی به شکل زیر است:

```c
if(a[j] > a[j+1])
{
    Swap(a,j,j+1);
}
```

در این روش، عناصر بزرگ‌تر به‌تدریج به سمت انتهای آرایه حرکت می‌کنند.

پس از پایان هر مرحله کامل (Pass)، بزرگ‌ترین عنصر بخش مرتب‌نشده در جایگاه نهایی خود قرار می‌گیرد.

این فرایند آن‌قدر تکرار می‌شود تا تمام عناصر مرتب شوند.

### مثال ساده

فرض کنید آرایه زیر را داریم:

```text
5, 3, 8, 2
```

در اولین مقایسه:

```text
5 > 3
```

شرط برقرار است؛ بنابراین جای دو عنصر عوض می‌شود:

```text
3, 5, 8, 2
```

در مقایسه بعدی:

```text
5 > 8
```

شرط برقرار نیست و تغییری انجام نمی‌شود.

در مقایسه بعدی:

```text
8 > 2
```

شرط برقرار است و دو عنصر جابه‌جا می‌شوند:

```text
3, 5, 2, 8
```

در پایان اولین مرحله، بزرگ‌ترین مقدار یعنی ۸ در آخر آرایه قرار گرفته است.

با ادامه مراحل، آرایه به شکل زیر مرتب می‌شود:

```text
2, 3, 5, 8
```

## ۶. بررسی تابع main

### ۶.۱. تعریف آرایه

```c
int a[]={23,53,12,10,17,56,78,34,29,37,45,12,19,20,40,90,43,48,62};
```

این دستور یک آرایه از نوع `int` با ۱۹ عنصر ایجاد می‌کند.

در ابتدا عناصر آرایه مرتب نیستند.

### ۶.۲. محاسبه تعداد عناصر آرایه

```c
int N=sizeof(a)/sizeof(a[0]);
```

عملگر `sizeof` اندازه یک متغیر یا آرایه را بر حسب بایت محاسبه می‌کند.

- `sizeof(a)` اندازه کل آرایه را برمی‌گرداند.
- `sizeof(a[0])` اندازه یک عنصر آرایه را برمی‌گرداند.

بنابراین:

\[
N=\frac{\text{اندازه کل آرایه}}{\text{اندازه یک عنصر}}
\]

با فرض اینکه اندازه هر متغیر `int` برابر ۴ بایت باشد:

\[
N=\frac{76}{4}=19
\]

در نتیجه مقدار `N` برابر ۱۹ خواهد بود.

### ۶.۳. نمایش آرایه قبل از مرتب‌سازی

```c
printf("Array before sorting:\n");
PrintArray(a,N);
```

ابتدا پیام مربوط به آرایه قبل از مرتب‌سازی نمایش داده می‌شود.

سپس تابع `PrintArray()` فراخوانی شده و تمام عناصر آرایه را چاپ می‌کند.

### ۶.۴. فراخوانی تابع مرتب‌سازی

```c
BubbleSort(a,N);
```

در این قسمت تابع `BubbleSort()` اجرا می‌شود.

دو آرگومان به تابع ارسال می‌شوند:

- `a`: آرایه‌ای که باید مرتب شود.
- `N`: تعداد عناصر آرایه.

این تابع از طریق اشاره‌گر به عناصر آرایه اصلی دسترسی دارد؛ بنابراین تغییرات انجام‌شده مستقیماً روی آرایه اصلی اعمال می‌شوند.

### ۶.۵. نمایش آرایه پس از مرتب‌سازی

```c
printf("Array after sorting:\n");
PrintArray(a,N);
```

پس از پایان مرتب‌سازی، دوباره تابع `PrintArray()` اجرا می‌شود تا آرایه مرتب‌شده نمایش داده شود.

## ۷. بررسی کامل تابع BubbleSort

```c
void BubbleSort(int a[], int N)
{
    int i, j;
    int swapped;

    for(i=0; i<N; i++)
    {
        swapped = 0;

        for(j=0; j<N-1; j++)
        {
            if(a[j]>a[j+1])
            {
                Swap(a,j,j+1);
                swapped = 1;
            }
        }

        if(!swapped) break;
    }
}
```

این تابع بخش اصلی الگوریتم مرتب‌سازی است.

در آن از موارد زیر استفاده شده است:

- دو حلقه `for`
- یک دستور شرطی `if`
- یک متغیر کنترلی به نام `swapped`
- تابع `Swap()`
- دستور `break`

### ۷.۱. پارامترهای تابع

```c
void BubbleSort(int a[], int N)
```

این تابع دو پارامتر دریافت می‌کند:

- `a[]`: آرایه‌ای که باید مرتب شود.
- `N`: تعداد عناصر آرایه.

نوع بازگشتی تابع `void` است؛ زیرا تابع مستقیماً آرایه اصلی را تغییر می‌دهد و نیازی به برگرداندن یک آرایه جدید ندارد.

### ۷.۲. تعریف متغیرها

```c
int i, j;
int swapped;
```

وظیفه هر متغیر:

- `i`: کنترل‌کننده حلقه بیرونی.
- `j`: کنترل‌کننده حلقه داخلی.
- `swapped`: مشخص می‌کند که آیا در مرحله جاری حداقل یک جابه‌جایی انجام شده است یا خیر.

متغیر `swapped` برای تشخیص مرتب‌بودن آرایه و جلوگیری از اجرای مراحل غیرضروری استفاده می‌شود.

### ۷.۳. بررسی حلقه بیرونی

```c
for(i=0; i<N; i++)
```

این حلقه تعداد مراحل مرتب‌سازی را کنترل می‌کند.

در بدترین حالت، این پیاده‌سازی ممکن است به `N` مرحله نیاز داشته باشد.

در هر مرحله، الگوریتم تلاش می‌کند عناصر بزرگ‌تر را به سمت انتهای آرایه منتقل کند.

### ۷.۴. مفهوم متغیر swapped

```c
swapped = 0;
```

در ابتدای هر مرحله مقدار این متغیر صفر می‌شود.

معنی مقادیر آن:

- `0`: هنوز هیچ جابه‌جایی انجام نشده است.
- `1`: حداقل یک جابه‌جایی انجام شده است.

هر زمان که دو عنصر جابه‌جا شوند، دستور زیر اجرا می‌شود:

```c
swapped = 1;
```

بنابراین در پایان هر مرحله می‌توان متوجه شد که آیا تغییری در آرایه انجام شده است یا خیر.

### ۷.۵. بررسی حلقه داخلی

```c
for(j=0; j<N-1; j++)
```

این حلقه مسئول مقایسه عناصر مجاور است.

در هر مرحله دو عنصر زیر با یکدیگر مقایسه می‌شوند:

```c
a[j]
a[j+1]
```

برای مثال:

| مقدار j | عنصر اول | عنصر دوم |
|---:|---|---|
| 0 | a[0] | a[1] |
| 1 | a[1] | a[2] |
| 2 | a[2] | a[3] |
| 3 | a[3] | a[4] |

حلقه تا اندیس `N-2` ادامه پیدا می‌کند؛ زیرا عنصر دوم آخرین مقایسه باید `a[N-1]` باشد.

### ۷.۶. مقایسه عناصر مجاور

```c
if(a[j]>a[j+1])
```

این شرط بررسی می‌کند که آیا دو عنصر مجاور در ترتیب اشتباه قرار گرفته‌اند یا خیر.

برای مرتب‌سازی صعودی:

- اگر عنصر سمت چپ بزرگ‌تر باشد، باید جابه‌جا شوند.
- اگر عنصر سمت چپ کوچک‌تر یا مساوی باشد، نیازی به جابه‌جایی نیست.

برای مثال:

```text
23, 12
```

چون:

\[
23>12
\]

بنابراین جای دو عنصر باید عوض شود.

نتیجه:

```text
12, 23
```

### ۷.۷. فراخوانی تابع Swap

```c
Swap(a,j,j+1);
```

این دستور تابع `Swap()` را فراخوانی می‌کند.

سه مقدار به تابع ارسال می‌شود:

- آرایه اصلی
- اندیس عنصر اول
- اندیس عنصر دوم

وظیفه تابع، جابه‌جایی مقدار دو عنصر مشخص‌شده است.

### ۷.۸. بررسی شرط break

```c
if(!swapped) break;
```

علامت `!` عملگر منطقی NOT است.

بنابراین عبارت زیر:

```c
!swapped
```

زمانی درست است که مقدار `swapped` برابر صفر باشد.

اگر در یک مرحله کامل هیچ جابه‌جایی انجام نشود، یعنی تمام عناصر آرایه در ترتیب صحیح قرار دارند.

در این حالت نیازی به ادامه حلقه نیست و دستور `break` اجرای حلقه بیرونی را متوقف می‌کند.

به این روش **Early Exit Optimization** یا خروج زودهنگام گفته می‌شود.

این بهینه‌سازی باعث می‌شود اگر آرایه از ابتدا مرتب باشد، الگوریتم مراحل غیرضروری را اجرا نکند.

## ۸. بررسی تابع Swap

```c
void Swap(int a[], int j1, int j2)
{
    int temp;

    temp = a[j1];
    a[j1] = a[j2];
    a[j2] = temp;
}
```

وظیفه این تابع جابه‌جایی دو عنصر آرایه است.

سه پارامتر دریافت می‌کند:

- `a[]`: آرایه اصلی
- `j1`: اندیس عنصر اول
- `j2`: اندیس عنصر دوم

### ۸.۱. چرا به متغیر موقت نیاز داریم؟

فرض کنید می‌خواهیم مقادیر دو خانه زیر را جابه‌جا کنیم:

```text
a[j1] = 10
a[j2] = 20
```

اگر مستقیماً بنویسیم:

```c
a[j1] = a[j2];
a[j2] = a[j1];
```

پس از اجرای دستور اول، مقدار هر دو خانه برابر ۲۰ خواهد شد.

در نتیجه مقدار اولیه خانه اول از بین می‌رود.

برای جلوگیری از این مشکل از یک متغیر موقت به نام `temp` استفاده می‌کنیم.

### ۸.۲. مراحل جابه‌جایی

**مرحله اول: ذخیره مقدار اول**

```c
temp = a[j1];
```

وضعیت متغیرها:

```text
temp = 10
a[j1] = 10
a[j2] = 20
```

**مرحله دوم: انتقال مقدار دوم به خانه اول**

```c
a[j1] = a[j2];
```

وضعیت متغیرها:

```text
temp = 10
a[j1] = 20
a[j2] = 20
```

**مرحله سوم: انتقال مقدار ذخیره‌شده به خانه دوم**

```c
a[j2] = temp;
```

نتیجه نهایی:

```text
a[j1] = 20
a[j2] = 10
```

به این ترتیب دو مقدار با موفقیت جابه‌جا می‌شوند.

## ۹. بررسی تابع PrintArray

```c
void PrintArray(const int a[], int N)
{
    int i;

    for(i=0; i<N; i++)
    {
        printf("%d",a[i]);

        if(i<N-1)
        {
            printf(", ");
        }
    }
}
```

این تابع تمام عناصر آرایه را نمایش می‌دهد.

### بررسی پارامترها

```c
const int a[], int N
```

- `a[]`: آرایه‌ای که باید نمایش داده شود.
- `N`: تعداد عناصر آرایه.
- `const`: از تغییر عناصر آرایه از طریق این پارامتر جلوگیری می‌کند.

استفاده از `const` در این تابع مناسب است، زیرا هدف فقط خواندن و نمایش اطلاعات است.

### بررسی حلقه

```c
for(i=0; i<N; i++)
```

این حلقه تمام عناصر آرایه را از ابتدا تا انتها بررسی می‌کند.

دستور زیر عنصر فعلی را نمایش می‌دهد:

```c
printf("%d",a[i]);
```

### جلوگیری از چاپ ویرگول اضافی

```c
if(i<N-1)
{
    printf(", ");
}
```

این شرط باعث می‌شود بعد از هر عنصر به‌جز آخرین عنصر، ویرگول چاپ شود.

در نتیجه بعد از آخرین مقدار آرایه ویرگول اضافی نخواهیم داشت.

## ۱۰. بررسی روند کامل مرتب‌سازی

آرایه اولیه برنامه به شکل زیر است:

```text
23, 53, 12, 10, 17, 56, 78, 34, 29, 37, 45, 12, 19, 20, 40, 90, 43, 48, 62
```

الگوریتم با مقایسه عناصر مجاور شروع می‌کند.

برای مثال، چند مقایسه ابتدایی در مرحله اول:

| مقایسه | شرط | نتیجه |
|---|---|---|
| 23 و 53 | 23 > 53؟ | بدون جابه‌جایی |
| 53 و 12 | 53 > 12؟ | جابه‌جایی |
| 53 و 10 | 53 > 10؟ | جابه‌جایی |
| 53 و 17 | 53 > 17؟ | جابه‌جایی |
| 53 و 56 | 53 > 56؟ | بدون جابه‌جایی |
| 56 و 78 | 56 > 78؟ | بدون جابه‌جایی |
| 78 و 34 | 78 > 34؟ | جابه‌جایی |

این فرایند تا انتهای آرایه ادامه پیدا می‌کند.

در پایان اولین مرحله کامل، بزرگ‌ترین مقدار آرایه یعنی ۹۰ در آخرین خانه قرار می‌گیرد.

در مراحل بعدی، عناصر باقی‌مانده نیز به ترتیب صحیح منتقل می‌شوند.

### نکته مهم درباره این پیاده‌سازی

در کد اولیه محدوده حلقه داخلی به شکل زیر است:

```c
j<N-1
```

این محدوده در تمام مراحل ثابت باقی می‌ماند.

این روش از نظر عملکرد صحیح است، اما باعث انجام تعدادی مقایسه غیرضروری می‌شود.

می‌توان از عبارت زیر استفاده کرد:

```c
for(j=0; j<N-i-1; j++)
```

با این کار در هر مرحله، تعداد مقایسه‌ها کاهش پیدا می‌کند؛ زیرا عناصر انتهایی آرایه قبلاً در جایگاه نهایی خود قرار گرفته‌اند.

نسخه اولیه برای یادگیری ساختار اصلی الگوریتم و مفهوم `swapped` مناسب است.

## ۱۱. خروجی مورد انتظار

**آرایه قبل از مرتب‌سازی:**

```text
23, 53, 12, 10, 17, 56, 78, 34, 29, 37, 45, 12, 19, 20, 40, 90, 43, 48, 62
```

**آرایه بعد از مرتب‌سازی:**

```text
10, 12, 12, 17, 19, 20, 23, 29, 34, 37, 40, 43, 45, 48, 53, 56, 62, 78, 90
```

در این خروجی، عناصر از کوچک‌ترین مقدار به بزرگ‌ترین مقدار مرتب شده‌اند.

## ۱۲. مرتب‌سازی نزولی با Bubble Sort

در برنامه فعلی آرایه به‌صورت صعودی مرتب می‌شود.

برای مرتب‌سازی نزولی کافی است شرط زیر:

```c
if(a[j]>a[j+1])
```

را به شکل زیر تغییر دهیم:

```c
if(a[j]<a[j+1])
```

در این حالت عناصر کوچک‌تر به سمت انتهای آرایه حرکت می‌کنند.

برای مثال:

```text
آرایه اولیه:
5, 3, 8, 2

آرایه مرتب‌شده نزولی:
8, 5, 3, 2
```

## ۱۳. نسخه بهینه‌تر الگوریتم Bubble Sort

در نسخه اولیه، حلقه داخلی در هر مرحله تمام آرایه را بررسی می‌کند.

اما پس از هر مرحله، بزرگ‌ترین عنصر بخش مرتب‌نشده در انتهای آن قرار می‌گیرد.

بنابراین دیگر نیازی به مقایسه مجدد عناصر مرتب‌شده انتهایی نیست.

نسخه بهینه‌تر:

```c
void BubbleSort(int a[], int N)
{
    int i, j;
    int swapped;

    for(i=0; i<N-1; i++)
    {
        swapped = 0;

        for(j=0; j<N-i-1; j++)
        {
            if(a[j]>a[j+1])
            {
                Swap(a,j,j+1);
                swapped = 1;
            }
        }

        if(!swapped)
            break;
    }
}
```

### چرا این نسخه بهتر است؟

پس از هر مرحله، بزرگ‌ترین عنصر باقی‌مانده در انتهای قسمت مرتب‌نشده قرار می‌گیرد.

بنابراین نیازی نیست دوباره آن را با عناصر دیگر مقایسه کنیم.

عبارت زیر:

```c
N-i-1
```

باعث کاهش تعداد مقایسه‌ها در مراحل بعدی می‌شود.

هر دو نسخه نتیجه صحیحی تولید می‌کنند، اما نسخه بهینه‌شده مقایسه‌های غیرضروری کمتری انجام می‌دهد.

## ۱۴. پیچیدگی زمانی و حافظه

فرض می‌کنیم تعداد عناصر آرایه برابر `N` باشد.

### نسخه اولیه برنامه

| حالت | پیچیدگی زمانی | توضیح |
|---|---|---|
| بهترین حالت | O(N) | آرایه مرتب است و الگوریتم پس از یک مرحله متوقف می‌شود |
| حالت متوسط | O(N²) | چندین مرحله مقایسه و جابه‌جایی انجام می‌شود |
| بدترین حالت | O(N²) | تعداد زیادی مرحله و جابه‌جایی موردنیاز است |

در حلقه داخلی در هر مرحله `N-1` مقایسه انجام می‌شود.

در بدترین حالت، حلقه بیرونی می‌تواند `N` بار اجرا شود.

بنابراین تعداد مقایسه‌ها حداکثر در حدود رابطه زیر است:

\[
N(N-1)
\]

در نتیجه پیچیدگی زمانی برابر است با:

\[
O(N^2)
\]

### نسخه بهینه‌شده

در نسخه بهینه‌شده نیز پیچیدگی زمانی به شکل زیر است:

- بهترین حالت: O(N)
- حالت متوسط: O(N²)
- بدترین حالت: O(N²)

### پیچیدگی حافظه

الگوریتم Bubble Sort از نوع In-place است.

یعنی برای مرتب‌سازی، آرایه جدیدی ایجاد نمی‌کند و عناصر را در همان آرایه اصلی جابه‌جا می‌کند.

تابع `Swap()` نیز فقط از یک متغیر موقت استفاده می‌کند.

بنابراین حافظه کمکی موردنیاز برابر است با:

\[
O(1)
\]

## ۱۵. ویژگی‌های مهم الگوریتم Bubble Sort

| ویژگی | توضیح |
|---|---|
| نوع الگوریتم | مرتب‌سازی مبتنی بر مقایسه |
| جهت مرتب‌سازی | صعودی در این برنامه |
| In-place | بله |
| Stable | بله |
| بهترین پیچیدگی زمانی | O(N) با خروج زودهنگام |
| پیچیدگی متوسط | O(N²) |
| بدترین پیچیدگی زمانی | O(N²) |
| حافظه کمکی | O(1) |

### مفهوم Stable Sorting چیست؟

یک الگوریتم مرتب‌سازی پایدار (Stable) ترتیب نسبی عناصر مساوی را حفظ می‌کند.

در این پیاده‌سازی شرط جابه‌جایی به شکل زیر است:

```c
a[j] > a[j+1]
```

بنابراین اگر دو عنصر مقدار یکسانی داشته باشند، جای آن‌ها با یکدیگر عوض نمی‌شود.

در نتیجه ترتیب نسبی عناصر مساوی حفظ خواهد شد.

## ۱۶. مفاهیم مهم زبان C در این برنامه

### پارامتر آرایه

```c
void BubbleSort(int a[], int N);
```

پارامتر آرایه از طریق یک اشاره‌گر امکان دسترسی به عناصر آرایه اصلی را فراهم می‌کند.

### کلمه کلیدی const

```c
void PrintArray(const int a[], int N);
```

استفاده از `const` مانع تغییر عناصر آرایه از طریق این پارامتر می‌شود.

### حلقه‌های تو در تو

الگوریتم Bubble Sort از دو حلقه استفاده می‌کند.

حلقه بیرونی تعداد مراحل مرتب‌سازی را کنترل می‌کند و حلقه داخلی مسئول مقایسه عناصر مجاور است.

### عملگر منطقی NOT

```c
if(!swapped)
```

عملگر `!` مقدار منطقی یک عبارت را معکوس می‌کند.

اگر مقدار `swapped` صفر باشد، عبارت `!swapped` درست خواهد بود.

### متغیر موقت

برای جابه‌جایی دو مقدار بدون ازدست‌دادن مقادیر اولیه از یک متغیر موقت استفاده می‌کنیم.

### دستور break

این دستور اجرای نزدیک‌ترین حلقه را فوراً متوقف می‌کند.
