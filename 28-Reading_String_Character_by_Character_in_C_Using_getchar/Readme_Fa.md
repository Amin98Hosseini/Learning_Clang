# 28- دریافت رشته کاراکتر به کاراکتر در زبان C با استفاده از `getchar()`

## ۱. مقدمه

در زبان برنامه‌نویسی C روش‌های مختلفی برای دریافت متن از کاربر وجود دارد.

برخی از توابع پرکاربرد برای دریافت اطلاعات عبارت‌اند از:

| تابع | توضیحات |
|---|---|
| `scanf()` | دریافت اطلاعات با قالب مشخص |
| `getchar()` | دریافت یک کاراکتر |
| `fgets()` | دریافت یک خط متن |
| `gets()` | دریافت یک خط متن، اما ناامن است و از استانداردهای جدید C حذف شده است |

در این آموزش روی تابع `getchar()` تمرکز می‌کنیم.

برخلاف تابع `fgets()` که می‌تواند چندین کاراکتر را در یک آرایه ذخیره کند، تابع `getchar()` در هر بار فراخوانی فقط یک کاراکتر دریافت می‌کند.

با استفاده از یک حلقه می‌توانیم این تابع را چندین بار فراخوانی کنیم و کاراکترهای دریافت‌شده را در یک آرایه ذخیره کنیم تا زمانی که کاربر کلید Enter را فشار دهد یا ظرفیت آرایه تکمیل شود.

برنامه ما عملیات زیر را انجام می‌دهد:

۱. یک آرایه کاراکتری ایجاد می‌کند.

۲. از کاربر می‌خواهد یک خط متن وارد کند.

۳. کاراکترها را با استفاده از `getchar()` یکی‌یکی دریافت می‌کند.

۴. کاراکترها را در آرایه ذخیره می‌کند.

۵. با قرار دادن `'\0'` پایان رشته را مشخص می‌کند.

۶. متن واردشده را با استفاده از `puts()` نمایش می‌دهد.

## ۲. کتابخانه مورد نیاز

در کد اولیه از دو کتابخانه زیر استفاده شده است:

```c
#include <stdio.h>
#include <stdlib.h>
```

اما برای این برنامه فقط کتابخانه زیر ضروری است:

```c
#include <stdio.h>
```

کتابخانه `<stdio.h>` امکانات زیر را در اختیار ما قرار می‌دهد:

- `printf()` برای نمایش خروجی قالب‌بندی‌شده.
- `getchar()` برای دریافت یک کاراکتر از ورودی استاندارد.
- `puts()` برای نمایش یک رشته همراه با کاراکتر Newline.
- `stdin` برای دسترسی به جریان ورودی استاندارد.
- `EOF` برای مشخص کردن پایان ورودی یا وقوع خطای ورودی.

کتابخانه `<stdlib.h>` در نسخه اولیه برنامه مورد استفاده قرار نگرفته است.

## ۳. بررسی کد اصلی برنامه

کد اولیه:

```c
#include <stdio.h>
#include <stdlib.h>

#define LENGTH 50

int main()
{
    char str[LENGTH];

    printf("Enter a line of text:\n");

    char c;
    int i = 0;

    while ((c = getchar()) != '\n')
    {
        str[i++] = c;

        if (i >= LENGTH - 1)
            break;
    }

    str[i] = '\0';

    printf("\nEntered line of text:\n");
    puts(str);
    printf("\n");

    return 0;
}
```

در ادامه بخش‌های مختلف برنامه را بررسی می‌کنیم.

## ۴. آشنایی با دستور `#define`

در ابتدای برنامه دستور زیر را داریم:

```c
#define LENGTH 50
```

دستور `#define` یک دستور پیش‌پردازنده یا Preprocessor Directive است.

با استفاده از این دستور یک ثابت نمادین به نام `LENGTH` با مقدار ۵۰ تعریف می‌کنیم.

پیش‌پردازنده قبل از مرحله کامپایل، تمام موارد استفاده از `LENGTH` را با عدد ۵۰ جایگزین می‌کند.

برای مثال:

```c
#define LENGTH 50

char str[LENGTH];
```

از نظر جایگزینی متن، معادل دستور زیر خواهد بود:

```c
char str[50];
```

### چرا از `#define` استفاده می‌کنیم؟

به‌جای اینکه عدد ۵۰ را در قسمت‌های مختلف برنامه تکرار کنیم، یک‌بار آن را تعریف می‌کنیم.

این کار باعث می‌شود تغییر اندازه آرایه در آینده ساده‌تر شود.

برای مثال، اگر بخواهیم اندازه آرایه را به ۱۰۰ افزایش دهیم، کافی است بنویسیم:

```c
#define LENGTH 100
```

بقیه برنامه همچنان از `LENGTH` استفاده می‌کند و نیازی به تغییر جداگانه ندارد.

**نکته:** دستور `#define` یک جایگزینی متنی انجام می‌دهد و مانند تعریف یک متغیر دارای نوع داده نیست.

در C مدرن، می‌توان از ثابت‌های تعریف‌شده با `enum` نیز استفاده کرد:

```c
enum { LENGTH = 50 };
```

در این آموزش همچنان از `#define` استفاده می‌کنیم.

## ۵. تعریف آرایه کاراکتری

```c
char str[LENGTH];
```

از آنجا که مقدار `LENGTH` برابر با ۵۰ است، این دستور یک آرایه با ۵۰ عنصر از نوع `char` ایجاد می‌کند.

از این آرایه برای ذخیره کاراکترهای واردشده توسط کاربر استفاده می‌کنیم.

ساختار مفهومی آرایه:

```text
str[0]
str[1]
str[2]
str[3]
...
str[49]
```

هر عنصر آرایه می‌تواند یک کاراکتر را ذخیره کند.

اما رشته در زبان C باید با یک کاراکتر ویژه به نام Null Terminator پایان یابد:

```c
'\0'
```

بنابراین با وجود اینکه آرایه ۵۰ خانه دارد، حداکثر می‌توانیم ۴۹ کاراکتر ورودی ذخیره کنیم؛ زیرا یک خانه باید برای کاراکتر پایان رشته رزرو شود.

## ۶. نمایش پیام دریافت ورودی

```c
printf("Enter a line of text:\n");
```

این دستور پیامی را برای درخواست ورود متن توسط کاربر نمایش می‌دهد.

کاراکتر `\n` باعث می‌شود مکان‌نما به خط بعدی منتقل شود.

## ۷. تعریف متغیرها

```c
char c;
int i = 0;
```

در این قسمت دو متغیر تعریف شده‌اند.

### ۷.۱. متغیر `c`

```c
char c;
```

در برنامه اولیه از متغیر `c` برای ذخیره موقت کاراکتر برگشتی از تابع `getchar()` استفاده شده است.

اما یک نکته مهم وجود دارد.

نوع خروجی واقعی تابع `getchar()` برابر با `int` است، نه `char`.

این تابع دو حالت خروجی دارد:

- کاراکتر خوانده‌شده که ابتدا به `unsigned char` و سپس به `int` تبدیل می‌شود.
- مقدار `EOF` در صورت رسیدن به انتهای جریان ورودی یا وقوع خطای ورودی.

بنابراین بهتر است متغیر را به شکل زیر تعریف کنیم:

```c
int c;
```

این کار امکان تشخیص صحیح `EOF` را فراهم می‌کند.

### ۷.۲. متغیر `i`

```c
int i = 0;
```

از متغیر `i` برای مشخص کردن اندیس آرایه استفاده می‌کنیم.

مقدار اولیه آن صفر است؛ زیرا اولین کاراکتر باید در خانه زیر ذخیره شود:

```c
str[0]
```

پس از ذخیره هر کاراکتر، مقدار `i` افزایش پیدا می‌کند تا کاراکتر بعدی در خانه بعدی قرار بگیرد.

## ۸. آشنایی با تابع `getchar()`

تابع `getchar()` در هر بار فراخوانی یک کاراکتر از ورودی استاندارد دریافت می‌کند.

تعریف این تابع:

```c
int getchar(void);
```

برای مثال:

```c
#include <stdio.h>

int main(void)
{
    int c;

    printf("Enter a character: ");

    c = getchar();

    printf("You entered: ");
    putchar(c);

    return 0;
}
```

اگر کاربر کاراکتر زیر را وارد کند:

```text
A
```

خروجی:

```text
Enter a character: A
You entered: A
```

برخلاف دستور `scanf("%s", ...)`، تابع `getchar()` در هر بار اجرا فقط یک کاراکتر دریافت می‌کند.

این ویژگی به ما اجازه می‌دهد کنترل بیشتری روی نحوه پردازش ورودی داشته باشیم.

## ۹. بررسی حلقه `while`

در برنامه اولیه از حلقه زیر استفاده شده است:

```c
while ((c = getchar()) != '\n')
{
    str[i++] = c;

    if (i >= LENGTH - 1)
        break;
}
```

بیایید این حلقه را مرحله‌به‌مرحله بررسی کنیم.

### ۹.۱. دریافت یک کاراکتر

```c
c = getchar();
```

در این دستور یک کاراکتر از ورودی استاندارد دریافت شده و در متغیر `c` ذخیره می‌شود.

برای مثال، اگر کاربر عبارت زیر را وارد کند:

```text
HELLO
```

برنامه کاراکترها را به ترتیب دریافت می‌کند:

```text
H
E
L
L
O
```

هنگامی که کاربر کلید Enter را فشار می‌دهد، در حالت معمول کاراکتر Newline یعنی `'\n'` در جریان ورودی قرار می‌گیرد.

### ۹.۲. بررسی کاراکتر Newline

```c
while ((c = getchar()) != '\n')
```

این عبارت دو عملیات انجام می‌دهد:

۱. تابع `getchar()` را فراخوانی کرده و مقدار برگشتی آن را در `c` ذخیره می‌کند.

۲. بررسی می‌کند که آیا کاراکتر دریافت‌شده با `'\n'` متفاوت است یا خیر.

اگر کاراکتر دریافت‌شده Newline نباشد، حلقه ادامه پیدا می‌کند.

وقتی کاربر Enter را فشار دهد، تابع `getchar()` کاراکتر `'\n'` را دریافت می‌کند و شرط حلقه نادرست می‌شود؛ بنابراین حلقه پایان می‌یابد.

### ۹.۳. ذخیره کاراکتر در آرایه

```c
str[i++] = c;
```

این دستور کاراکتر دریافت‌شده را در آرایه ذخیره می‌کند.

در اینجا از عملگر افزایش پسوندی یا Post-Increment استفاده شده است:

```c
i++
```

عملگر Post-Increment به این معنی است:

۱. ابتدا از مقدار فعلی `i` استفاده کن.

۲. عملیات را انجام بده.

۳. سپس مقدار `i` را یک واحد افزایش بده.

برای مثال:

```c
int i = 0;
str[i++] = 'A';
```

معادل دستورات زیر است:

```c
str[0] = 'A';
i = i + 1;
```

پس از اجرای آن:

```text
str[0] = 'A'
i = 1
```

وقتی کاراکتر بعدی دریافت شود، در خانه `str[1]` ذخیره خواهد شد.

### ۹.۴. بررسی ظرفیت آرایه

```c
if (i >= LENGTH - 1)
    break;
```

این شرط از نوشتن اطلاعات خارج از محدوده آرایه جلوگیری می‌کند.

از آنجا که:

```c
#define LENGTH 50
```

حداکثر تعداد کاراکترهای ورودی برابر است با:

```text
50 - 1 = 49
```

یک خانه برای Null Terminator رزرو شده است.

وقتی مقدار `i` به ۴۹ برسد، حلقه متوقف می‌شود.

در نتیجه دستور زیر معتبر باقی می‌ماند:

```c
str[i] = '\0';
```

اگر این محدودیت وجود نداشته باشد، ورود یک متن طولانی می‌تواند باعث دسترسی خارج از محدوده آرایه شود.

## ۱۰. مفهوم Null Terminator

پس از پایان حلقه، برنامه دستور زیر را اجرا می‌کند:

```c
str[i] = '\0';
```

این دستور یکی از مهم‌ترین قسمت‌های برنامه است.

Null Terminator نشان‌دهنده پایان یک رشته در زبان C است.

برای مثال، فرض کنید کاربر عبارت زیر را وارد کند:

```text
ABC
```

محتوای آرایه به شکل زیر خواهد بود:

| اندیس | کاراکتر |
|---:|:---:|
| 0 | `A` |
| 1 | `B` |
| 2 | `C` |
| 3 | `\0` |

کاراکتر پایان رشته به توابع پردازش رشته اعلام می‌کند که رشته در کجا به پایان رسیده است.

اگر این کاراکتر وجود نداشته باشد، توابعی مانند `puts()` ممکن است به خواندن حافظه بعد از محدوده رشته ادامه دهند و رفتار تعریف‌نشده ایجاد شود.

**به خاطر داشته باشید:** کاراکترهای `'\0'` و `'\n'` با یکدیگر متفاوت هستند.

- `'\n'` نشان‌دهنده رفتن به خط بعدی است.
- `'\0'` نشان‌دهنده پایان رشته در زبان C است.

## ۱۱. نمایش رشته با استفاده از `puts()`

در برنامه اولیه از دستورات زیر استفاده شده است:

```c
printf("\nEntered line of text:\n");
puts(str);
printf("\n");
```

تابع `puts()` یک رشته را نمایش می‌دهد و در انتهای آن به‌صورت خودکار یک کاراکتر Newline اضافه می‌کند.

ساختار تابع:

```c
int puts(const char *str);
```

برای مثال:

```c
char name[] = "Amin";

puts(name);
```

خروجی:

```text
Amin
```

مقایسه `puts()` و `printf()`:

| تابع | کاربرد |
|---|---|
| `puts(str)` | نمایش رشته همراه با Newline |
| `printf("%s", str)` | نمایش رشته بدون اضافه کردن خودکار Newline |
| `putchar(c)` | نمایش یک کاراکتر |

برای مثال:

```c
puts("Hello");
printf("World");
putchar('!');
```

خروجی:

```text
Hello
World!
```

## ۱۲. نسخه کامل اصلاح‌شده برنامه

در کد اولیه دو محدودیت مهم وجود دارد:

۱. برای ذخیره خروجی `getchar()` از متغیر `char` استفاده شده است که امکان تشخیص مطمئن `EOF` را از بین می‌برد.

۲. وقتی ظرفیت آرایه تکمیل می‌شود، برنامه دریافت ورودی را متوقف می‌کند؛ در نتیجه ادامه متن واردشده همچنان در جریان ورودی باقی می‌ماند.

می‌توانیم هر دو مورد را اصلاح کنیم.

کد کامل اصلاح‌شده:

```c
#include <stdio.h>

#define LENGTH 50

int main(void)
{
    char str[LENGTH];

    int c;
    size_t i = 0;
    int input_truncated = 0;

    printf("Enter a line of text:\n");

    while ((c = getchar()) != '\n' && c != EOF)
    {
        if (i < LENGTH - 1)
        {
            str[i++] = (char)c;
        }
        else
        {
            input_truncated = 1;
        }
    }

    str[i] = '\0';

    if (ferror(stdin))
    {
        printf("Error: Failed to read input.\n");
        return 1;
    }

    printf("\nEntered line of text:\n");
    puts(str);

    printf("Length of entered text: %zu\n", i);

    if (input_truncated)
    {
        printf("Warning: Input was too long and was truncated.\n");
    }

    return 0;
}
```

### ۱۲.۱. چرا از `int c` استفاده می‌کنیم؟

```c
int c;
```

زیرا تابع `getchar()` مقدار خروجی خود را از نوع `int` برمی‌گرداند.

مقدار `EOF` یک مقدار صحیح ویژه است. اگر نتیجه تابع را در یک متغیر `char` ذخیره کنیم، نمی‌توانیم به‌صورت مطمئن آن را از تمام مقادیر معتبر کاراکتر تشخیص دهیم.

### ۱۲.۲. چرا `EOF` را بررسی می‌کنیم؟

```c
while ((c = getchar()) != '\n' && c != EOF)
```

این حلقه در یکی از شرایط زیر متوقف می‌شود:

- کاربر کلید Enter را فشار دهد.
- جریان ورودی به پایان برسد.
- هنگام خواندن ورودی خطایی رخ دهد.

خطای ورودی را بعد از حلقه با دستور زیر بررسی می‌کنیم:

```c
if (ferror(stdin))
```

### ۱۲.۳. چرا از `size_t` برای متغیر `i` استفاده می‌کنیم؟

```c
size_t i = 0;
```

نوع `size_t` یک نوع داده صحیح بدون علامت است که معمولاً برای نگهداری اندازه و اندیس آرایه‌ها استفاده می‌شود.

همچنین نوع خروجی توابعی مانند `strlen()` و `sizeof` نیز از نوع `size_t` است.

### ۱۲.۴. چرا پس از پر شدن آرایه همچنان ورودی را می‌خوانیم؟

در برنامه اولیه از دستور زیر استفاده شده است:

```c
if (i >= LENGTH - 1)
    break;
```

این دستور به‌محض پر شدن ظرفیت آرایه، حلقه را متوقف می‌کند.

اما ادامه متن واردشده توسط کاربر همچنان در جریان ورودی باقی می‌ماند.

در نسخه اصلاح‌شده، دریافت کاراکترها تا زمان رسیدن به Enter یا `EOF` ادامه پیدا می‌کند، اما فقط ۴۹ کاراکتر اول در آرایه ذخیره می‌شوند.

```c
if (i < LENGTH - 1)
{
    str[i++] = (char)c;
}
else
{
    input_truncated = 1;
}
```

به این ترتیب، بخش باقی‌مانده ورودی مصرف می‌شود و به‌اشتباه به‌عنوان ورودی عملیات بعدی در نظر گرفته نخواهد شد.

### ۱۲.۵. چرا بعد از پایان حلقه `'\0'` قرار می‌دهیم؟

```c
str[i] = '\0';
```

صرف‌نظر از اینکه ورودی با Enter، `EOF` یا تکمیل ظرفیت آرایه متوقف شده باشد، این دستور تضمین می‌کند که متن ذخیره‌شده یک رشته معتبر در زبان C باشد.

### ۱۲.۶. چرا برای نمایش `i` از `%zu` استفاده می‌کنیم؟

```c
printf("Length of entered text: %zu\n", i);
```

زیرا نوع متغیر `i` برابر با `size_t` است و مشخص‌کننده قالب مناسب برای آن `%zu` است.

## ۱۳. نمایش مرحله‌به‌مرحله فرآیند دریافت ورودی

فرض کنید کاربر عبارت زیر را وارد کند:

```text
HELLO
```

برنامه کاراکترها را یکی‌یکی دریافت می‌کند.

```text
ورودی: H E L L O Enter

مرحله اول:
c = 'H'
str[0] = 'H'
i = 1

مرحله دوم:
c = 'E'
str[1] = 'E'
i = 2

مرحله سوم:
c = 'L'
str[2] = 'L'
i = 3

مرحله چهارم:
c = 'L'
str[3] = 'L'
i = 4

مرحله پنجم:
c = 'O'
str[4] = 'O'
i = 5

مرحله ششم:
c = '\n'
حلقه متوقف می‌شود.

عملیات نهایی:

```

در نهایت محتوای آرایه به شکل زیر خواهد بود:

```text
H E L L O \0
```

رشته ذخیره‌شده:

```text

```

## ۱۵. مقایسه `getchar()` و `fgets()`

هر دو تابع برای دریافت متن کاربرد دارند، اما روش عملکرد آن‌ها متفاوت است.

| ویژگی | `getchar()` | `fgets()` |
|---|---|---|
| نوع دریافت | یک کاراکتر در هر فراخوانی | چند کاراکتر در یک فراخوانی |
| محل ذخیره ورودی | مقدار بازگشتی تابع | آرایه کاراکتری |
| نیاز به حلقه برای دریافت یک خط کامل | بله | خیر |
| کنترل ظرفیت آرایه | بر عهده برنامه‌نویس | با پارامتر تابع مشخص می‌شود |
| تشخیص `EOF` | با بررسی مقدار صحیح خروجی | با بررسی مقدار بازگشتی تابع |
| امکان دریافت Newline | بله | بله، در صورت وجود فضای کافی |
| کاربرد اصلی | پردازش کاراکتر به کاراکتر | دریافت یک خط متن |

### مثال استفاده از `getchar()`

```c
int c;

c = getchar();
```

فقط یک کاراکتر دریافت می‌کند.

### مثال استفاده از `fgets()`

```c
char str[50];

fgets(str, sizeof(str), stdin);
```

چندین کاراکتر را در یک آرایه ذخیره می‌کند.

**چه زمانی از هرکدام استفاده کنیم؟**

از `getchar()` زمانی استفاده می‌کنیم که بخواهیم ورودی را کاراکتر به کاراکتر پردازش کنیم، برای مثال:

- طراحی یک Parser ساده.
- شمارش کاراکترها.
- تشخیص کاراکترهای خاص.
- پیاده‌سازی مفسر دستورات ساده.
- پردازش جریان‌های متنی.

از `fgets()` زمانی استفاده می‌کنیم که فقط به دریافت یک خط کامل متن نیاز داشته باشیم.

## ۱۶. نکات مهم

- تابع `getchar()` در هر بار فراخوانی یک کاراکتر از ورودی استاندارد دریافت می‌کند.
- نوع خروجی تابع `getchar()` برابر با `int` است، نه `char`.
- برای تشخیص پایان جریان ورودی از `EOF` استفاده می‌کنیم.
- دستور `#define` یک Macro برای پیش‌پردازنده تعریف می‌کند.
- مقدار `LENGTH` ظرفیت آرایه کاراکتری را مشخص می‌کند.
- یک خانه از آرایه باید برای Null Terminator رزرو شود.
- هر رشته در زبان C باید با `'\0'` پایان یابد.
- کاراکترهای `'\n'` و `'\0'` کاربرد متفاوتی دارند.
- تابع `puts()` در انتهای رشته به‌صورت خودکار Newline اضافه می‌کند.
- تابع `putchar()` برای نمایش یک کاراکتر استفاده می‌شود.
- قبل از نوشتن اطلاعات در آرایه، محدوده آن را بررسی کنید.
- همیشه برای ورود متنی طولانی‌تر از ظرفیت آرایه، رفتار مناسبی در نظر بگیرید.

## ۱۸. تمرین‌ها

برای درک بهتر این مبحث، تمرین‌های زیر را انجام دهید.

**تمرین اول: شمارش کاراکترها**

برنامه را تغییر دهید تا تعداد حروف بزرگ، حروف کوچک و ارقام واردشده توسط کاربر را محاسبه کند.

برنامه‌ای بنویسید که تعداد کاراکترهای فاصله در متن واردشده را محاسبه کند.

**تمرین سوم: شمارش حروف صدادار**

تعداد حروف صدادار موجود در رشته را محاسبه کنید:

```text
a, e, i, o, u
```

**تمرین چهارم: تبدیل به حروف بزرگ**


با استفاده از آرایه ذخیره‌شده، متن واردشده را به‌صورت معکوس چاپ کنید.

**تمرین ششم: دریافت ورودی با طول پویا**

برنامه را به شکلی توسعه دهید که بتواند یک خط متن با طول دلخواه دریافت کند و از حافظه تخصیص‌یافته به‌صورت پویا استفاده کند.

```c
malloc()
realloc()
free()
```

## ۱۹. اهداف آموزشی

پس از مطالعه این آموزش باید بتوانید:

- با استفاده از `#define` ثابت‌های نمادین تعریف کنید.
- آرایه‌های کاراکتری را تعریف و استفاده کنید.
- نحوه عملکرد تابع `getchar()` را درک کنید.
- ورودی را با استفاده از حلقه `while` پردازش کنید.
- عملکرد عملگر افزایش پسوندی (`i++`) را درک کنید.
- از دسترسی خارج از محدوده آرایه جلوگیری کنید.
- اهمیت Null Terminator را درک کنید.
- با استفاده از `puts()` رشته‌ها را نمایش دهید.
- دلیل استفاده از `int` برای ذخیره خروجی `getchar()` را بدانید.
- پایان جریان ورودی و خطاهای ورودی را تشخیص دهید.
