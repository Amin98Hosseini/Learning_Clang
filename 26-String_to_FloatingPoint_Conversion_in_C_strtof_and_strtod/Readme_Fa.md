# 26- تبدیل رشته به اعداد اعشاری در زبان C با استفاده از `strtof()` و `strtod()`

## ۱. مقدمه

در برنامه‌نویسی C، گاهی اوقات داده‌ها به‌جای اینکه به‌صورت عددی دریافت شوند، به شکل متن یا رشته (String) در اختیار برنامه قرار می‌گیرند.

برای مثال:

```c
char s[] = "1.2 -3.5 10.8";
```

این رشته شامل سه عدد اعشاری است که با فاصله از یکدیگر جدا شده‌اند.

اما از دید زبان C، این داده‌ها هنوز یک آرایه از کاراکترها هستند و برای انجام محاسبات ریاضی باید آن‌ها را به نوع داده عددی مانند `float` یا `double` تبدیل کنیم.

کتابخانه استاندارد C توابع مختلفی برای تبدیل رشته به عدد ارائه می‌دهد:

| تابع | نوع خروجی | کاربرد |
|---|---|---|
| `atoi()` | `int` | تبدیل رشته به عدد صحیح |
| `atof()` | `double` | تبدیل رشته به عدد اعشاری |
| `strtol()` | `long` | تبدیل رشته به عدد صحیح بزرگ |
| `strtof()` | `float` | تبدیل رشته به float |
| `strtod()` | `double` | تبدیل رشته به double |
| `strtold()` | `long double` | تبدیل رشته به long double |

در این آموزش روی دو تابع `strtof()` و `strtod()` تمرکز می‌کنیم.

## ۲. کتابخانه‌های مورد نیاز

در ابتدای برنامه دو کتابخانه زیر را اضافه می‌کنیم:

```c
#include <stdio.h>
#include <stdlib.h>
```

- کتابخانه `<stdio.h>` برای استفاده از تابع `printf()` و نمایش اطلاعات استفاده می‌شود.
- کتابخانه `<stdlib.h>` شامل توابع تبدیل رشته به عدد مانند `strtof()` و `strtod()` است.

## ۳. بررسی کد اصلی برنامه

کد اولیه:

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    char s[] = "1.2 -3.5 10.8";
    char *pEnd;

    double x = strtof(s, &pEnd);
    double y = strtof(pEnd, &pEnd);
    double z = strtof(pEnd, NULL);

    printf("x = %f\n", x);
    printf("y = %f\n", y);
    printf("z = %f\n", z);

    return 0;
}
```

در ادامه بخش‌های مختلف برنامه را بررسی می‌کنیم.

### ۳.۱. تعریف رشته

```c
char s[] = "1.2 -3.5 10.8";
```

در این قسمت یک آرایه از نوع `char` تعریف می‌کنیم که شامل متن زیر است:

```text
1.2 -3.5 10.8
```

این رشته شامل سه عدد اعشاری است که با کاراکتر فاصله از هم جدا شده‌اند.

محتوای آرایه به‌صورت زیر است:

| اندیس | کاراکتر |
|---:|:---:|
| 0 | `1` |
| 1 | `.` |
| 2 | `2` |
| 3 | ` ` |
| 4 | `-` |
| 5 | `3` |
| 6 | `.` |
| 7 | `5` |
| 8 | ` ` |
| 9 | `1` |
| 10 | `0` |
| 11 | `.` |
| 12 | `8` |
| 13 | `\0` |

کاراکتر `'\0'` یا Null Terminator نشان‌دهنده پایان یک رشته در زبان C است.

### ۳.۲. تعریف اشاره‌گر

```c
char *pEnd;
```

در این قسمت یک اشاره‌گر به نوع داده `char` تعریف می‌کنیم.

وظیفه این اشاره‌گر ذخیره آدرس کاراکتری است که تابع تبدیل عدد، عملیات خواندن را در آن متوقف کرده است.

به عبارت دیگر، `pEnd` مقدار عددی تبدیل‌شده را ذخیره نمی‌کند، بلکه آدرس یک کاراکتر در رشته اصلی را نگه می‌دارد.

### ۳.۳. معرفی تابع `strtof()`

ساختار کلی تابع:

```c
float strtof(const char *str, char **endptr);
```

این تابع دو ورودی دارد:

1. `str`: آدرس شروع رشته‌ای که باید به عدد تبدیل شود.
2. `endptr`: آدرس یک اشاره‌گر که تابع از طریق آن محل پایان عملیات تبدیل را مشخص می‌کند.

مقدار بازگشتی تابع از نوع `float` است.

برای مثال:

```c
char text[] = "25.75";
char *end;

float value = strtof(text, &end);

printf("Value = %f\n", value);
```

خروجی:

```text
Value = 25.750000
```

چون تمام رشته یک عدد معتبر است، پس از تبدیل، اشاره‌گر `end` به کاراکتر پایان رشته یعنی `'\0'` اشاره می‌کند.

### ۳.۴. مفهوم `char **endptr`

یکی از مفاهیم مهم این برنامه استفاده از اشاره‌گر به اشاره‌گر است.

به کد زیر توجه کنید:

```c
char *pEnd;

strtof(s, &pEnd);
```

در اینجا:

- `pEnd` یک اشاره‌گر به کاراکتر است.
- `&pEnd` آدرس خود اشاره‌گر `pEnd` است.
- تابع `strtof()` با دریافت `&pEnd` می‌تواند مقدار اشاره‌گر را تغییر دهد.

بنابراین پارامتر دوم تابع از نوع `char **` است.

به کمک این پارامتر، تابع می‌تواند دو اطلاعات مختلف را در اختیار برنامه قرار دهد:

1. عدد تبدیل‌شده را از طریق مقدار بازگشتی.
2. آدرس محل توقف تبدیل را از طریق `endptr`.

### ۳.۵. تبدیل عدد اول

```c
double x = strtof(s, &pEnd);
```

در این قسمت تابع `strtof()` از ابتدای رشته `s` شروع به خواندن می‌کند.

اولین عدد موجود در رشته:

```text
1.2
```

است.

تابع پس از خواندن عدد، به اولین کاراکتری می‌رسد که بخشی از عدد نیست. در اینجا آن کاراکتر فاصله است.

پس از اجرای دستور:

```text
x    = 1.2
pEnd = آدرس کاراکتر فاصله بعد از 1.2
```

نمایش مفهومی:

```text
s:
1 . 2 _ - 3 . 5 _ 1 0 . 8 \0
      ^
      |
     pEnd
```

در این شکل علامت `_` نشان‌دهنده کاراکتر فاصله است.

### ۳.۶. تبدیل عدد دوم

```c
double y = strtof(pEnd, &pEnd);
```

در این مرحله، تبدیل از آدرسی شروع می‌شود که در `pEnd` ذخیره شده است.

متن باقی‌مانده:

```text
 -3.5 10.8
```

تابع `strtof()` به‌صورت خودکار فاصله‌های ابتدای رشته را نادیده می‌گیرد و سپس عدد زیر را تبدیل می‌کند:

```text
-3.5
```

بعد از پایان تبدیل، اشاره‌گر `pEnd` به فاصله بعد از عدد `-3.5` اشاره خواهد کرد.

در نتیجه:

```text
y = -3.5
```

نکته مهم این است که در این دستور، از یک اشاره‌گر هم برای مشخص کردن محل شروع تبدیل و هم برای دریافت آدرس جدید محل پایان استفاده شده است.

این کار معتبر است؛ زیرا تابع ابتدا مقدار اشاره‌گر ورودی را دریافت می‌کند و سپس آدرس جدید را از طریق پارامتر دوم در همان متغیر قرار می‌دهد.

### ۳.۷. تبدیل عدد سوم

```c
double z = strtof(pEnd, NULL);
```

در این مرحله تبدیل از محل فعلی `pEnd` آغاز می‌شود.

متن باقی‌مانده:

```text
 10.8
```

تابع فاصله ابتدای رشته را نادیده گرفته و عدد زیر را تبدیل می‌کند:

```text
10.8
```

در پارامتر دوم مقدار `NULL` قرار داده‌ایم؛ زیرا دیگر نیازی به دریافت آدرس محل توقف تبدیل نداریم.

در نتیجه:

```text
z = 10.8
```

## ۴. خروجی برنامه

خروجی برنامه به شکل زیر خواهد بود:

```text
x = 1.200000
y = -3.500000
z = 10.800000
```

در تابع `printf()`، مشخص‌کننده قالب `%f` برای نمایش مقادیر اعشاری استفاده می‌شود و به‌صورت پیش‌فرض شش رقم بعد از ممیز را نمایش می‌دهد.

## ۵. تفاوت `strtof()` و `strtod()`

در برنامه اصلی، متغیرها از نوع `double` تعریف شده‌اند:

```c
double x = strtof(s, &pEnd);
```

اما تابع `strtof()` مقدار خروجی را از نوع `float` برمی‌گرداند.

زبان C مقدار `float` را هنگام انتساب به متغیر `double` تبدیل می‌کند؛ ولی این تبدیل، دقتی را که ممکن است در مرحله تبدیل اولیه به `float` از دست رفته باشد، بازیابی نمی‌کند.

اگر قصد استفاده از متغیرهای `double` را داریم، بهتر است از تابع `strtod()` استفاده کنیم.

ساختار تابع:

```c
double strtod(const char *str, char **endptr);
```

مقایسه دو تابع:

| ویژگی | `strtof()` | `strtod()` |
|---|---|---|
| نوع خروجی | `float` | `double` |
| دقت معمول | حدود ۶ تا ۷ رقم اعشار معنادار | حدود ۱۵ تا ۱۶ رقم اعشار معنادار |
| حجم حافظه معمول | ۴ بایت | ۸ بایت |
| نوع متغیر مناسب | `float` | `double` |

اندازه و دقت دقیق این نوع داده‌ها به کامپایلر و معماری سیستم بستگی دارد.

## ۶. نسخه اصلاح‌شده برنامه با `strtod()`

از آنجا که متغیرهای ما از نوع `double` هستند، نسخه زیر انتخاب مناسب‌تری است:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char s[] = "1.2 -3.5 10.8";
    char *pEnd;

    double x = strtod(s, &pEnd);
    double y = strtod(pEnd, &pEnd);
    double z = strtod(pEnd, NULL);

    printf("x = %f\n", x);
    printf("y = %f\n", y);
    printf("z = %f\n", z);

    return 0;
}
```

خروجی:

```text
x = 1.200000
y = -3.500000
z = 10.800000
```

## ۷. نسخه پیشرفته‌تر همراه با بررسی خطا

در مثال اولیه فرض کردیم که هر سه عدد موجود در رشته معتبر هستند.

اما در برنامه‌های واقعی، ممکن است داده ورودی اشتباه باشد. بنابراین بهتر است قبل از استفاده از مقادیر تبدیل‌شده، موفقیت عملیات تبدیل را بررسی کنیم.

کد زیر یک نسخه مقاوم‌تر از برنامه است:

```c
#include <stdio.h>
#include <stdlib.h>
#include <ctype.h>
#include <errno.h>

int main(void)
{
    char s[] = "1.2 -3.5 10.8";
    char *pEnd;
    double values[3];

    char *p = s;

    for (int i = 0; i < 3; i++)
    {
        while (isspace((unsigned char)*p))
        {
            p++;
        }

        if (*p == '\0')
        {
            printf("Error: Not enough numbers.\n");
            return 1;
        }

        errno = 0;
        values[i] = strtod(p, &pEnd);

        if (p == pEnd)
        {
            printf("Error: Invalid number at position %d.\n", i + 1);
            return 1;
        }

        if (errno == ERANGE)
        {
            printf("Error: Number is outside the representable range.\n");
            return 1;
        }

        p = pEnd;
    }

    while (isspace((unsigned char)*p))
    {
        p++;
    }

    if (*p != '\0')
    {
        printf("Error: Unexpected extra characters: %s\n", p);
        return 1;
    }

    printf("First number  = %f\n", values[0]);
    printf("Second number = %f\n", values[1]);
    printf("Third number  = %f\n", values[2]);

    return 0;
}
```

در این نسخه:

1. ابتدا فاصله‌های اضافی قبل از هر عدد حذف می‌شوند.
2. عدد بعدی با استفاده از `strtod()` تبدیل می‌شود.
3. بررسی می‌کنیم که آیا واقعاً کاراکتری به عدد تبدیل شده است یا خیر.
4. با استفاده از `errno` خطاهای مربوط به خارج بودن عدد از محدوده قابل نمایش بررسی می‌شوند.
5. در پایان بررسی می‌کنیم که پس از سه عدد، کاراکتر اضافی غیر از فاصله باقی نمانده باشد.

شرط زیر اهمیت زیادی دارد:

```c
if (p == pEnd)
```

اگر این شرط برقرار باشد، یعنی هیچ کاراکتری به عدد تبدیل نشده است.

در برنامه‌های صنعتی و حساس، بهتر است علاوه بر این بررسی‌ها، مشخص کنیم که آیا مقادیری مانند `NaN` و Infinity مجاز هستند یا خیر.

## ۸. مشاهده مرحله‌به‌مرحله فرآیند تبدیل

برای رشته زیر:

```text
1.2 -3.5 10.8
```

مراحل تبدیل به این شکل هستند:

```text
مرحله اول:
strtod(s, &pEnd)

عدد تبدیل‌شده: 1.2
متن باقی‌مانده:  -3.5 10.8

مرحله دوم:
strtod(pEnd, &pEnd)

عدد تبدیل‌شده: -3.5
متن باقی‌مانده:   10.8

مرحله سوم:
strtod(pEnd, NULL)

عدد تبدیل‌شده: 10.8
متن باقی‌مانده: بررسی نمی‌شود
```

مزیت این روش این است که برای هر عدد نیازی به ساخت یک رشته جدید نداریم. می‌توانیم با استفاده از اشاره‌گر در همان رشته اصلی حرکت کنیم.

## ۹. مثال‌های تکمیلی

### مثال اول: اعداد مثبت و منفی

```c
char s[] = "100 -25 3.14159";
char *end;

double a = strtod(s, &end);
double b = strtod(end, &end);
double c = strtod(end, NULL);
```

نتیجه:

```text
a = 100
b = -25
c = 3.14159
```

### مثال دوم: نمایش علمی اعداد

```c
char s[] = "1.5e3 -2.5e-2";
char *end;

double a = strtod(s, &end);
double b = strtod(end, NULL);
```

نتیجه:

```text
a = 1500
b = -0.025
```

تابع `strtod()` از نمایش علمی اعداد (Scientific Notation) نیز پشتیبانی می‌کند.

### مثال سوم: توقف تبدیل هنگام برخورد با متن نامعتبر

```c
char s[] = "123.45ABC";
char *end;

double value = strtod(s, &end);

printf("Value = %f\n", value);
printf("Remaining text = %s\n", end);
```

خروجی:

```text
Value = 123.450000
Remaining text = ABC
```

این مثال نشان می‌دهد که پارامتر `endptr` چقدر کاربردی است؛ زیرا می‌توانیم متن باقی‌مانده بعد از عدد را نیز بررسی کنیم.

## ۱۰. نکات مهم

- تابع `strtof()` رشته را به `float` تبدیل می‌کند.
- تابع `strtod()` رشته را به `double` تبدیل می‌کند.
- تابع `strtold()` رشته را به `long double` تبدیل می‌کند.
- پارامتر `endptr` آدرس محل پایان عملیات تبدیل را مشخص می‌کند.
- اگر به محل پایان تبدیل نیاز نداریم، می‌توانیم از `NULL` استفاده کنیم.
- فاصله‌های ابتدای رشته به‌صورت خودکار نادیده گرفته می‌شوند.
- عملیات تبدیل ممکن است قبل از رسیدن به انتهای رشته متوقف شود.
- هنگام پردازش داده‌های نامطمئن، حتماً موفقیت تبدیل را بررسی کنید.
- این توابع از نمایش علمی اعداد نیز پشتیبانی می‌کنند.
- جداکننده اعشاری به Locale فعال برنامه وابسته است. در Locale معمول `"C"`، جداکننده اعشار نقطه است.
- این توابع به‌تنهایی یک لیست از اعداد را به بخش‌های جداگانه تقسیم و اعتبارسنجی نمی‌کنند؛ مدیریت متن باقی‌مانده بر عهده برنامه‌نویس است.

- با استفاده از اشاره‌گر محل پایان عملیات تبدیل را پیدا کنید.
- مفهوم اشاره‌گر به اشاره‌گر (`char **`) را درک کنید.
- چند عدد را از یک رشته استخراج کنید.
- خطاهای مربوط به تبدیل رشته به عدد را بررسی کنید.
