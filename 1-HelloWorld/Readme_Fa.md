# 1 - اولین برنامه در زبان C (Hello World)

## معرفی پروژه (Overview)

این پروژه یک مثال ساده و مقدماتی برای شروع یادگیری زبان برنامه‌نویسی C است.

برنامه با استفاده از تابع `printf()` عبارت `Hello World!` را در محیط کنسول (Console) نمایش می‌دهد.

معمولاً اولین برنامه‌ای که هنگام یادگیری یک زبان برنامه‌نویسی نوشته می‌شود، برنامه Hello World است.

این مثال با ساختار اولیه یک برنامه C و نحوه نمایش متن در خروجی آشنا می‌کند.

## اهداف آموزشی (Learning Objectives)

با مطالعه این برنامه، مفاهیم زیر را یاد می‌گیرید:

- آشنایی با ساختار اولیه برنامه در زبان C.
- نحوه فراخوانی کتابخانه‌های استاندارد.
- آشنایی با تابع اصلی `main()`.
- نحوه استفاده از تابع `printf()`.
- نمایش متن در محیط کنسول.
- نحوه پایان دادن به برنامه با استفاده از `return 0`.

## بررسی و توضیح کد (Source Code Explanation)

### 1. فراخوانی کتابخانه ورودی و خروجی

```c
#include "stdio.h"
```

این دستور کتابخانه استاندارد ورودی و خروجی زبان C را فراخوانی می‌کند.

این کتابخانه شامل توابع مختلفی برای دریافت ورودی و نمایش خروجی است.

برای مثال:

- `printf()` : نمایش اطلاعات در خروجی.
- `scanf()` : دریافت اطلاعات از کاربر.

**نکته:** روش استاندارد فراخوانی کتابخانه‌های سیستمی در زبان C به شکل زیر است:

```c
#include <stdio.h>
```

### 2. تابع اصلی برنامه (Main Function)

```c
int main()
{
    // دستورات برنامه
}
```

تابع `main()` نقطه شروع اجرای برنامه در زبان C است.

هنگامی که برنامه اجرا می‌شود، پردازش دستورات از این تابع آغاز می‌شود.

اجزای این تابع:

- `int` : نوع داده خروجی تابع را مشخص می‌کند.
- `main()` : نام تابع اصلی برنامه است.
- `{ }` : محدوده دستورات داخل تابع را مشخص می‌کند.

### 3. نمایش متن با استفاده از printf()

```c
printf("Hello World!\r\n");
```

تابع `printf()` برای نمایش متن و اطلاعات در محیط کنسول استفاده می‌شود.

در این دستور سه بخش مهم وجود دارد:

- `Hello World!` : متنی که در خروجی نمایش داده می‌شود.
- `\r` : دستور Carriage Return که مکان‌نما را به ابتدای خط فعلی منتقل می‌کند.
- `\n` : دستور Line Feed که مکان‌نما را به خط بعدی منتقل می‌کند.

ترکیب `\r\n` برای رفتن به خط جدید در سیستم‌عامل ویندوز رایج است.

### 4. دستور Return

```c
return 0;
```

این دستور باعث پایان اجرای تابع `main()` می‌شود و یک مقدار خروجی به سیستم‌عامل برمی‌گرداند.

مقدار `0` معمولاً به معنی اجرای موفقیت‌آمیز برنامه است.

## خروجی برنامه (Example Output)

```text
Hello World!
```

## مفاهیم مهم برنامه‌نویسی C

| دستور یا مفهوم | کاربرد |
|---|---|
| `#include` | فراخوانی کتابخانه یا فایل Header |
| `stdio.h` | کتابخانه استاندارد ورودی و خروجی |
| `main()` | نقطه شروع اجرای برنامه |
| `printf()` | نمایش اطلاعات در خروجی |
| `\r` | بازگشت مکان‌نما به ابتدای خط |
| `\n` | انتقال مکان‌نما به خط بعدی |
| `return 0` | پایان موفقیت‌آمیز اجرای برنامه |

## تمرین‌های پیشنهادی (Practice Exercises)

برای درک بهتر مفاهیم اولیه زبان C، تمرین‌های زیر را انجام دهید:

1. عبارت `Hello World!` را با نام خودتان جایگزین کنید.
2. با استفاده از `\n` چند خط متن در خروجی نمایش دهید.
3. نام، سن و زبان برنامه‌نویسی موردعلاقه خود را چاپ کنید.
4. با استفاده از چند دستور `printf()` پیام‌های مختلف نمایش دهید.
5. عبارت `\r\n` را با `\n` جایگزین کنید و تفاوت خروجی را بررسی کنید.
